# 새 게임 · 불러오기 에셋

1920×1080 기준. 확정 시안 `13-load-anime-v2.png`, `14-new-game-anime-v1.png`의 청남색 잉크·보랏빛 음영·밝은 종이 재질로 제작했다.

| 텍스처 리소스 (`textures/`) | 용도 | 권장 표시 크기 |
| --- | --- | --- |
| `paper_panel.tres` | 두 화면의 공통 종이 패널·리본·토끼 장식 | 1540×940 |
| `autosave_frame.tres` | 불러오기 자동 저장 행, 안쪽 투명 | 1280×150 |
| `selected_row.tres` | 선택한 수동 슬롯, 연보라 종이 채움 | 1280×150 |
| `thumbnail_frame.tres` | 저장 시점 스크린샷 위에 얹는 투명 프레임 | 280×126 |
| `empty_thumbnail.tres` | 빈 슬롯 썸네일 | 280×126 |
| `ink_divider.tres` | 제목 아래·슬롯 사이 구분선 | 1280×24 |
| `primary_button.tres` | 시작하기·불러오기 버튼의 공통 바탕 | 310×90 |
| `close_icon.tres` | 닫기 X | 40×40 |
| `menu_background.tres` | 기존 서재 배경 참조 | 1920×1080 |

PNG 8개는 생성 원본이다. `.tres`는 원본의 투명 여백을 제외한 AtlasTexture로, 이미지 픽셀을 변경하지 않는다. 극히 낮은 알파의 잔여 픽셀 때문에 여백이 커지지 않도록 알파 16 초과 영역에 2px 여유를 더했다. 좌표·원본 크기·SHA-256은 `manifest.json`에 있다.

## 배치

- 새 게임: 수동 슬롯 3개. 선택 슬롯에 `selected_row`, 미선택 슬롯은 종이 위에 썸네일과 텍스트만 배치한다.
- 불러오기: 자동 저장 1개와 수동 슬롯 3개. 자동 저장에는 `autosave_frame`; 선택 시 안쪽에 연보라 ColorRect를 깐다. `selected_row`를 겹치면 테두리가 중복된다.
- 저장된 슬롯: 실제 저장 시점 스크린샷 + `thumbnail_frame`. 빈 슬롯: `empty_thumbnail`만 사용한다.
- 제목, 슬롯명, 날짜, 플레이 시간, 뒤로, 시작하기, 불러오기는 Label/Button 텍스트로 표시한다. 에셋에 문자를 굽지 않았다.
- `TextureRect.expand_mode = EXPAND_IGNORE_SIZE`로 설정하고 위 권장 크기에 맞춘다. 닫기는 40px 그림보다 넓은 56×56 입력 영역을 사용한다.
- 원본 PNG 크기는 표시 크기가 아니다. 자동 저장과 선택 행은 가로로 늘려 쓰도록 제작했다. 버튼과 썸네일은 표시 크기에 맞춰 전체를 축소한다.

## 버튼 상태

`primary_button_theme.tres`를 Button의 Theme에 지정하면 기본·호버·누름·비활성·키보드 포커스 상태를 사용할 수 있다. 시작하기/불러오기는 같은 바탕에 문구만 바꾼다. 뒤로는 종이 위의 텍스트 버튼이다. 닫기 아이콘은 호버 시 밝기를 높이고 눌림 시 어둡게 한다. 빈 슬롯을 불러오려는 경우는 비활성 상태로 처리한다.

## 배경과 생성 기록

배경은 `res://assets/ui/design_2026_10/menu_background__r01.png`를 참조한다. 새로운 배경 파일을 중복 저장하지 않았다. 8종 이미지 제작은 내장 image_gen을 사용했으며, 각 `*.receipt.json`과 manifest의 `prompt`에 원본 경로·참조 이미지·최종 프롬프트를 보관했다.

## 검증과 적용 범위

`outputs/save-load-assets/`에 PNG/알파 검사 결과, Godot 로드 검사 결과, 1920×1080 조합 렌더를 저장했다. 조합 렌더의 날짜·시간과 배경 썸네일은 배치 확인용 예시다. 검증용 글꼴은 시스템 바탕체이며 배포용 폰트를 포함하지 않는다.

이 폴더는 화면 제작에 필요한 에셋과 텍스처/테마 리소스 패키지다. 실제 새 게임·불러오기 동작 및 저장 데이터 연결은 포함하지 않는다.

Godot 4.7.2에서 프로젝트의 임포트된 텍스처 9개와 버튼 상태 5개를 로드하고 두 화면을 OpenGL로 렌더했다. 검증 프로세스에서는 기존 MCP Runtime 애드온의 포트 7777 서버 시작 오류가 함께 출력되었지만, 에셋 로드·렌더는 성공했다. 해당 애드온은 수정하지 않았다.
