- `[x] 완료`: 해당 항목에 명시한 범위가 근거로 확인됨. 부분 검사 통과를 전체 단계 완료로 확대하지 않는다.

- `[ ] 대기`: 아직 착수하지 않았거나 외부 조건을 기다림. 이유를 붙인다.
- 작업 시작 시 현재 작업, 작업 중에는 확인된 완료/새 문제, 작업 종료 시 결과·근거·남은 일을 갱신한다. 대화에서도 해당 체크 항목을 요약한다.

## 범위 밖·외부 의존

- 개인 자유 메모는 사용자 결정에 따라 후속 기능이다. 이번 완료 조건에 새로 끼워 넣지 않는다.
- 최종 아트·BGM·SFX 교체는 제작 완료 뒤의 별도 단계다. 현재 구현/입력 검증을 대신하거나 이번 목표의 새로운 필수 의존성으로 만들지 않는다.
- 사용자 수정 파일과 실제 세이브는 보존한다. 검증된 작업을 develop에 범위 한정 commit하고 문제 없을 때 push하는 기존 방침을 유지한다.
