## 보완한 검사

기존 검사는 관찰된 콘텐츠 ID와 언어를 집계했다. 선택창은 한 콘텐츠 안에 제목·질문·여러 선택지를 보유하므로 ID 존재만으로 모든 공개 문단을 보았는지 알 수 없었다. 다른 생산자의 오브젝트/화면 기록도 기존 `covered` 집계에 포함되어 그 총수만을 NP01~NP03 완료 수치로 쓰면 안 됐다.

요구 집합은 모든 등록 카탈로그에서 producer_id로 선별한다. 키는 `producer, content, version, node, variant, segment, locale`이다. 실제 커밋된 observation/segment에서 동일 키를 추출하고, 요구하지만 미실행인 조합과 미등록 관찰을 각각 NOT_COVERED/UNMAPPED로 출력한다. 접두어를 바꾸거나 ID 수가 같아도 노드·문단 누락은 통과할 수 없다.

현재 대상 정의는 모두 의미 버전 1이고 과거/현재 이중 버전은 없다. 향후 과거 버전을 유지한 채 새 버전이 추가되면 힌트 감사처럼 실제 생산자 버전과 과거 재열람 요구를 명시적으로 분리해야 한다. 요구 집합에서 과거 버전을 조용히 삭제하지 않는다.
