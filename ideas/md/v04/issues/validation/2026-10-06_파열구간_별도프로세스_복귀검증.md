# 파열 구간 별도 프로세스 복귀 검증

## 범위와 방법

기준 develop `050e13e`. notebook_fracture_smoke에 seed/resume 별도 프로세스 경로를 추가했다. D5 여덟 번째 대사 표시, D6 침실/비상 캡슐 수면 전환 2.5초 시점을 한국어·영어로 저장하고 다른 OS 프로세스에서 실제 슬롯 JSON을 설치해 새 BasementController로 재개한다. 총 6경로·12개 실행 단계다.

이는 headless controller 검증이다. 실제 입력, 모든 중단 시점, 강제 종료·전원 차단이나 전편 완주로 계산하지 않는다. IME ERR-0042는 별도로 미해결 상태다.

| 경로 | 별도 프로세스에서 확인한 조건 |
| --- | --- |
| D5 | index 7·전체 snapshot 불변, 아홉 번째 문장 비공개, 이후 원래 callback으로 D6 이동·D5 실제 출처 보존 |
| D6 침실 | 선택 경로 유지, 복귀만으로 broken sleep/day 진행 금지, E1 비공개, 전환 완료 후 깨진 수면과 wake 기록 1회 획득 |
| D6 캡슐 | capsule 경로 유지와 침실과 같은 계약, 완료된 타이머 재호출의 snapshot 불변 |

기존 관찰의 순서·UID·원문·보호 등급이 prefix로 보존되는지 검사한다. 개발 체크포인트의 이전 last_feedback에는 authored 출처가 없는 원문이 포함된다. 삭제/신규 ID 추정 변환 없이 보존하며 복귀 이후 미분류 항목은 seed에 이미 있던 영속 값과 같을 때만 허용한다.

D6 타이머는 기존 정책대로 복귀 시 0초부터 재구성된다. 2.5초 진행률 자체를 영구 저장하도록 제품 규칙을 변경하지 않았다. 선택 경로와 이미 표시한 원문은 보존한다.

## 결과와 재현

- 격리 폴더 `%TEMP%/ggb-fracture-process-final-20261006`, 별도 APPDATA·빈 실행 경로·PCK.
- Godot `4.7.2.stable.steam.ed1daf0bf`. 기본 rollout OFF, 검사만 `--ggb-dev-notebook-v2`.
- 최종 PCK SHA-256 `3AB809DD069537BA879415790DCF9A30789F9CC7C7E8331CD7DE8E5C2920BC88`.
- import/export 종료 0. 12개 seed/resume 단계 종료 0·PASS. 각 resume에서 seed와 다른 PID임을 단언했다.
- D5 재개는 언어별 18 content ID, D6는 경로·언어별 8개. 집계가 겹치므로 전체 생산자 수로 합산하지 않는다.
- 원자료는 위 폴더의 `ko-KR_d5_seed.out.log`부터 `en-US_capsule_resume.out.log`까지 12개 out/err 파일이다. 기존 인증서 저장소 경고 외 파싱/스크립트 오류 없음.
- 사용자 저장 파일·편집기 및 프로덕션 동작은 변경하지 않았다.

아래 명령을 동일한 격리 APPDATA/PCK에서 각각 새 프로세스로 실행한다. route는 d5/bedroom/capsule, locale은 ko-KR/en-US다.

```text
godot.exe --headless --path <empty> --main-pack <notebook.pck> -- --ggb-dev-notebook-v2 --notebook-fracture-smoke --fracture-process-phase=seed --fracture-process-route=d5 --fracture-process-locale=ko-KR
godot.exe --headless --path <empty> --main-pack <notebook.pck> -- --ggb-dev-notebook-v2 --notebook-fracture-smoke --fracture-process-phase=resume --fracture-process-route=d5 --fracture-process-locale=ko-KR
```

## 초기 검사와 한계

최초 D5 resume와 후속 D6 seed는 체크포인트 기존 미분류 원문을 새 오류로 판정해 실패했다. sequence 0에 `XIII. CAMOUFLAGE FILTER OFF...`가 이미 있었음을 확인하고 추가 process 경로만 기존 원문 보존과 새 미분류 생성 금지를 분리했다. 기본 suite의 authored 제한은 유지했다. fixture 범위 보완이며 제품 오류 수정으로 세지 않는다. 이전 두 실행 폴더의 실패 로그를 보존하고 최종 12단계를 재실행했다.

동일 최종 PCK의 기존 fracture suite는 67 ID·134 ID/언어·154 문단/언어·휴식 저장 복귀 8조건, fracture-surfaces suite는 50 ID·100 ID/언어에서 종료 0·PASS했다. 로그는 `fracture_final_baseline.out.log`, `surface_final_baseline.out.log`다. 모든 검증 프로세스는 종료되었다. T13 전체, 모든 전환/실패/반복 조건과 공통 수첩 소비·실기·최종 인수는 미완료다.
