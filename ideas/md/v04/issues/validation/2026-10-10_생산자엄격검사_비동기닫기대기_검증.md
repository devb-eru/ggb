# 생산자 엄격 검사와 비동기 닫기 대기 검증

## 범위

기준 develop `71d282cfde6bb95db6174b71be94ef90efe7da03`. T19l2 전 생산자 엄격 검사를 시작하고 처음 실패한 지하 검사 순서 오류를 수정한다. 전체 단계 완료가 아니다. 제품 Godot 4.7, rollout OFF, ERR-0042 OPEN을 유지한다.

실제 4.6.3 게임 검색칸의 추가 네 입력 조건은 사용자가 모두 정상이라고 확인했다. 이미 [후보 보고서](2026-10-07_공식4.6.3_최신코드_호환재검증.md)에 기록한 다섯 국소 조건과 같은 결과이므로 이번 자동 실행이나 새로운 실기 횟수로 중복 집계하지 않는다. 후보 전체 호환·제품 채택·전편 입력은 여전히 남는다.

검사는 새 TEMP 증거 폴더와 실행별 APPDATA/LOCALAPPDATA에서 순차 실행한다. suite별 종료 시 stdout/stderr/receipt를 즉시 복사하고 receipt의 `stdout_sha256/stderr_sha256`을 대조했다. 사용자 세이브와 기존 실행 중 Godot는 수정하지 않는다. 기본 timeout은 1,800초지만 이번 정식 세 실행에서 시간 제한 종료는 없었다. 남은 authority-archive는 기존 완료 실행이 약 2,671초였으므로 다음 실행에는 3,600초 등 충분한 watchdog을 별도로 선택해야 한다.

## 원인과 수정

[ERR-0052](../items/GGB-ERR-2026-0052_지하검사_비동기수첩닫기_완료대기누락.md)는 **검사 코드의 닫기 완료 대기 누락**이다. `request_close()`는 요청이고 준비/저장 worker 종료에 따라 실제 host 종료가 다음 frame으로 미뤄질 수 있다. 그 동안 controller가 입력을 막는 것은 정상이다. 검사에서 host 종료를 기다리지 않아 뒤의 선택 기록과 fixture에 오염이 이어졌다.

`notebook_test_wait.closed()`는 host가 유효하고 suspended인 동안 process frame을 양보한다. 60초 watchdog 이후 실패를 반환하며 게임 입력을 재전송하거나 필수 단언을 건너뛰지 않는다. 지하의 수첩 열람과 확인창 재검토 복귀 두 지점에서 이를 기다리고 controller의 수첩 닫힘도 확인한다. production 스크립트는 변경하지 않았고 기존 56 ID·44개 복귀 경로·저장 실패/취소 불변과 오래된 callback 차단 검사를 유지한다.

## 진단 원자료의 구분

1. `diagnostic_basement`: 임시 출력 코드의 지역 변수명 실수로 컴파일 오류. 해당 검사 자식 PID만 확인하여 종료했다. 게임 결함이나 시간 제한으로 분류하지 않는다.
2. `diagnostic2_basement`: 선택창만 실행한 부분 검사 PASS. 전체 ID/복귀 경로 검사가 아니므로 정식 전수 근거에 넣지 않는다.
3. `diagnostic3_basement`: 원래 전체 순서와 writer 실패 출력으로 동일 순서 문제 재현. 일부 누락 위치는 초기 실행과 다르며 재현되지 않았다고 보지 않는다.
4. `diagnostic4_basement`: 실제 guard에서 `notebook: true` 상태를 확인했다. 의도적인 stale callback 거부와 주입된 저장 실패도 포함하므로 모든 진단 출력이 오류는 아니다.

진단 코드는 TEMP에서만 적용하고 종료 후 원본으로 복원했다. 원자료를 성공 로그로 덮지 않는다. 첫 카탈로그 사전 대조 래퍼가 `path` 필드를 조회했지만 실제 inventory 필드는 `catalog`였다. 실행 전 래퍼를 고쳐 스크립트 264개와 카탈로그 29개/엔진 SHA를 재대조했다. 이 래퍼 오류는 게임 결함이나 suite 실패 수가 아니다.

## 남은 작업

전달한 43개 파일의 commit tree `fab569b4987dbb140a54a96b2bd7fcb1e3e6125f`는 사전 검증한 staging 아카이브와 같다. 복원본에서 264개 스크립트 SHA·29카탈로그·10세트 receipt/raw hash와 엄격 고유 184경로를 다시 확인했다. 실제 폴더의 기존 사용자 수정 17개는 각각의 SHA를 보존했고 사용자 추가 파일·세이브·Steam 설치를 수정하지 않았다. 임시 진단용 자식 실행은 모두 종료했으며 실행 중인 사용자 Godot를 종료하지 않았다.

T19l2의 같은 수정 소스 전 생산자 엄격 실행과 독립 필수 분기 감사, T22 후보 재확보·현재 전체 호환/빌드·채택, T23 실제 마우스 전용/키보드 전용 전편, T20/T21/T24 성능 및 38항목 최종 인수는 미완료다. 좁은 검사 수정으로 전체 목표를 완료 처리하지 않는다.
