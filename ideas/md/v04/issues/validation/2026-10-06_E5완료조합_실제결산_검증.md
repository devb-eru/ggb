# E5 사용인 완료 조합의 실제 결산·기록 공개 검증

## 1. 기준과 목적

- 기준 develop: `86629b3379b894eff953ff4f25171815caf51513`.
- 계획 범위: 통합 수첩 NP15 결산 생산자, ToDo T15의 하위 T15e.
- 변경: `game/scripts/tests/notebook_settlement_smoke.gd`의 실제 컨트롤러 경로 확장. 제품의 결산 규칙·저장 형식·문구는 변경하지 않았다.
- 기존 32개 완료 조합 × 호감 3종 × 결과 2종 × 한영의 384조건은 규칙 함수와 표시 descriptor 대조다. 이번 64경로는 이 검사와 별개로 버튼 signal, 화면 문단 공개, 게임 저장과 컨트롤러 재생성을 실행한다.

## 2. 독립된 실행 범위

| 항목 | 이번 실행 |
| --- | --- |
| 완료 조합 | 에드가·마라 1·루카·이리스·마라 2의 5bit 마스크 0~31 |
| 언어 | ko-KR / en-US |
| 추가 경로 | 32 × 2 = 64 |
| 신규 경로의 관계 수치 | 전원 bond 0 / alert 0 |
| 완료 사건의 결과 | 각 사용인의 첫 결과. 미완료자는 사건 완료 기록 없음 |
| 공동 질문 | wish / leave / stay를 마스크별 순환 배정. 각 마스크에서 세 질문 모두를 실행한 것은 아님 |
| 시작 상태 | 기존 개발 E5 체크포인트. 이전 챕터 실제 완주의 대체 증거가 아님 |

단계 기대값은 완료 bit 개수를 직접 세어 LOW(0~1), MID(2~3), HIGH(4), ALL(5)로 대조한다. 제품의 `tier()` 반환값을 그대로 기대값으로 사용하지 않는다.

## 3. 실제 경로와 불변 조건

1. 실제 E5 진입 버튼을 누르고 첫 문단만 공개됐는지 확인한 뒤 나머지 문단을 진행한다.
2. 식탁·좌석 조사, 홀 이동·식당 복귀, 착석을 실제 버튼으로 수행한다.
3. 첫 착석 문단에서 후속 대사/질문이 미리 기록되지 않는 기존 검사를 유지한다.
4. 착석 대화 완료 후 모든 사용인의 개인 삽입/거리 응답을 완료 bit와 각각 대조한다. 미완료자의 개인 삽입은 0건이고 거리 응답만 1건이다.
5. 사용인별 두 결과 overlay를 각각 대조한다. 본인 완료 + 선택한 첫 결과에 해당하는 기록만 1건이며 다른 결과/미완료자의 결과 기록은 0건이다.
6. 정확한 tier의 opening만 기록되고 다른 tier는 공개되지 않는다. ALL의 두 문단은 다섯 명 모두 완료한 마스크에서만 기록된다.
7. 착석 상태를 저장 JSON에서 다시 로드하고 컨트롤러를 새로 만들어 완료된 대사가 재생되지 않는지 확인한다.
8. 순환 배정된 공동 질문 하나를 선택한다. 선택 답변 3문단만 공개되고 다른 두 답변은 미공개다.
9. 저녁 종료 확인을 한 번 취소하고 다시 확정한다. 취소는 결산을 잠그지 않으며 확정은 E6까지만 진행한다.
10. 결산 전후 사용인 상태의 정확한 동등성, 연구원 원장 획득 없음, 다섯 명 완료일 때만 `all_servants_complete`, 정확한 `completed_owner_ids`, 선택한 질문 보존을 확인한다.
11. 완료 상태를 JSON에서 다시 설치하고 새 컨트롤러의 E6 복귀·완료 커서·새 표시 범위 연결을 확인한다.
12. 현재 관계를 바꾼 후에도 과거 관찰 UID·내용이 그대로이며 한영 재열람이 가능한 기존 검사를 유지한다.

실제 대화 기록의 CHAPTER_3/E5~E6 사건 문맥, 무매핑 기록 없음, 지식 원장 출처 검증도 기존 `_collect()`에서 계속 검사한다.

## 5. 판단과 남은 범위

- 이번 범위에서 제품 오류는 추가 발견하지 않았다. 테스트만 확장했다.
- 64개 추가 경로는 모든 완료 마스크를 검사하지만 마스크 × 세 질문 × 모든 bond/alert × 모든 결과 × 저장 실패의 전 곱집합은 아니다. 기존 outcome/호감 규칙 행렬과 제한된 실제 추가 경로를 구분한다.
- 이전 챕터에서 관계 사건을 모두 실제 획득한 완주, J4 이전 흐름, 별도 프로세스 중단 재개, 실제 OS 마우스·키보드 입력, 공통 수첩 UI, 정식 성능 인수는 미완료다.
- E5 이후 익명/기명 출처의 모든 후반 소비와 엔딩 인수도 이번 검사만으로 완료 처리하지 않는다. 전체 T15/T16과 목표는 진행 중이며 기본 rollout은 비활성으로 유지한다.
