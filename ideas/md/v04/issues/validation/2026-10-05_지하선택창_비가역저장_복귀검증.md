## 3. 저장·복귀 계약

1. 실제 확인창의 질문은 저장된다. 확인 답변 기록은 허용하되 뒤따르는 게임 저장은 정확히 한 번 거절한다.
2. 저장 실패 시 커서는 `selection_pending`으로 남고 물리 상태·실패 기록·관계·지식·파열 상태는 바뀌지 않는다.
3. 비교는 기존 원문을 유지하고 추가 관찰과 그 관찰로 뒷받침된 화면 receipt만 허용한다. 진행 필드를 임의로 제외하지 않는다.
4. 실제 테스트 슬롯에서 다시 load하고 controller를 제거·재생성한다. 같은 답변 토큰을 복원하지만 축/중앙 손잡이/보조 레버를 자동 조작하지 않는다.
5. 명시 재시도에서 저장 성공 응답 유실도 복구하고 위 행렬의 결과를 정확히 한 번 적용한다.
6. 취소는 기록된 시도 답변을 삭제하지 않으며 시도했던 기믹도 실행하지 않는다.
7. 원래 답변의 entry UID와 관찰은 그대로 유지한다. 보조 레버 기록처럼 실제 지식 출처가 된 답변에는 `knowledge_source:` 보호가 추가될 수 있으므로, 기존 보호를 유지하면서 실제 source_links로 뒷받침되는 추가만 허용한다. 모든 보호 변경을 무시하는 비교가 아니다.
8. 오래된 확인 callback으로 비가역 행동이 재실행되지 않는다.
