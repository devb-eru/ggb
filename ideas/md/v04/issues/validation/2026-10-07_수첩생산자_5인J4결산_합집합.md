J4/결산은 실제 관계 플레이로 다섯 기록을 획득한 캠페인 연속 완주가 아니라 명시한 완료 mask와 원문 출처 fixture에서 시작한다. 관계의 기록 획득과 후속 소비는 각각 검사하며, 서로 다른 시작 상태를 완주 하나처럼 연결하지 않는다.

## 추적·실행 계약

세 새 suite의 `_collect()`에 공통 원장 capture를 연결하고 종료 직전 추적 유효성을 단언한다. 기존 표시/관계/출처 검사와 실패 조건은 유지한다. 수집·출력은 debug build의 `--notebook-producer-trace` 옵션에서만 활성이다. 저장에 없는 미확정 실패 후보나 pure 함수 fixture를 공통 원장 경로로 세지 않는다.

실행기의 허용 목록에 `authority-archive`, `journal-four-display`, `settlement`를 추가한다. 기본 여섯 suite는 그대로이며 이 묶음은 `-Suites`로 지정한다. suite마다 새 격리 환경과 종료 receipt를 남긴다. 이전 실행의 소스와 섞이지 않도록 관계 3인도 다시 실행한다. 긴 기존 authority 수치 행렬은 조건을 줄이지 않고 이번 실행에서 suite당 3,600초 제한을 명시한다.

각 suite의 기존 요약과 공통 tuple는 분모가 다르므로 합산하지 않는다. 원장 표본 authored 수는 순서대로 3,994/3,040/2,668/184/1,108/1,044, legacy/unmapped는 각각 0이다. 시작 fixture를 포함하므로 신규 생산 누락 0의 증거가 아니다.

261개 GDScript 지문은 `2cf4b4a5d33234feae743bc94c51c00a272581de36d73f98c1322923d76dd11f`다.

- 집계기 자체 검사: 전역 최신/역사적 버전, 중복 제거와 미확인 수치, 잘못된 보고서 14/receipt 5/로그 12조건 거부 PASS.
- 실행기 구문과 실행 전 거부 5조건 PASS(빈 목록, 중복 authority-archive, 대소문자 오류, 사용자 프로젝트, 기존 evidence 폴더). [근거](evidence/2026-10-07_runtime_union_servants_runner_guards.json).
- 모든 GDScript 경로/개수/파일 SHA가 TEMP 실행 프로젝트와 제출 작업본에서 같음을 사전 대조했다.
- 여섯 로그를 두 번 입력한 12보고서도 고유 1,478경로로 동일하며, 이전 T19e 로그 혼합은 `STALE_SCRIPT_CORPUS`로 거부했다. [집계 방어 근거](evidence/2026-10-07_runtime_union_servants_merge_guards.json).
- 미관찰 문단/언어는 JSON에 명시한다. 최신 등록 문단 충족을 실제 허용 node/행동 전체 곱집합이나 전편 신규 unmapped 0의 증거로 대체하지 않는다.

근거 생성 래퍼의 첫 `catalog_count`는 PowerShell 속성 열거 때문에 숫자가 아닌 29개 원소 배열로 나왔다. `@(...Properties).Count`로 재생성해 숫자 29를 확인했다. 게임 실행이나 원본 로그를 다시 실행/변경한 것은 아니며 집계 JSON의 카탈로그 지문은 처음부터 정상이다.

## 재현·보존

```powershell
$suites = @('authority-archive', 'journal-four-display', 'settlement', 'mara1', 'iris', 'luca')
./scripts/run_notebook_runtime_audit.ps1 -EnginePath $engine -ProjectPath $tempProject -EvidencePath $newTempEvidence -TimeoutSeconds 3600 -Suites $suites
$base = 'ideas/md/v04/issues/validation/evidence/2026-10-07_runtime_union_servants_'
./scripts/audit_notebook_runtime_union.ps1 -GamePath ./game -TraceLogs @($suites | ForEach-Object { $base + $_ + '.out.log' })
```

각 `.out.log/.err.log/.run.json`을 위 접두부로 보관한다. `*runtime_union_*.log`의 Git 줄끝 예외로 원본 로그와 receipt의 바이트 SHA를 보존한다. 알려진 인증서 저장소 경고만 오류 예외로 허용한다.

이전 T19e의 294경로와 이번 수를 더하지 않는다. 같은 소스 기준의 새 집계만 이번 근거다. 표본 class 수는 fixture 포함 확정 원장을 뜻하며 생산자별 신규 legacy/unmapped/UI 제외 수는 null, 필수 분기 전수는 NOT_AUDITED다.
