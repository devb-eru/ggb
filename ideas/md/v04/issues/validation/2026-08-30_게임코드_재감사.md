## 6. 처리 결과

2026-08-30 후속 작업에서 다음 기반을 구현했다.

- `GameState`, `EventManager`, `SaveManager` autoload와 일반 시스템 `StateWriter`를 분리했다.
- `FOUNDATION_SMOKE` 읽기 전용 Resource의 두 영구 효과와 event history를 한 revision으로 커밋한다.
- 허용되지 않은 경로와 stale revision을 거부하고, 저장 실패 시 직전 snapshot으로 되돌린다.
- schema 1 새 게임·정상 리셋·손상 primary·future schema fixture와 자동 smoke runner를 추가했다.
- SHA-256이 포함된 `progress.tmp.json → 검증 → progress.bak.json → progress.json` 저장 경로를 구현했다.
- 필수 InputMap, 1920×1080 기준 viewport, 1280×720 창, 키보드 포커스, 포커스 복귀 지연과 입력 1회 소비 guard를 추가했다.
- 연습 씬의 네 자식 스크립트에서 형제 `NodePath`를 제거하고 부모 controller가 초기 snapshot과 의존성을 배포하게 했다.
- D3D12·Forward+ 고정을 제거하고 GL Compatibility를 임시 실행 기준으로 둔 뒤, 동일 debug export를 두 렌더러로 실행하는 검증 스크립트를 추가했다.

정적 문서·리소스·fixture 검사와 Godot 4.7.2 실기·Windows debug export는 통과했다. 입력 기반은 구현됐지만 Windows 배율 100·150·200%, UI 200%, Alt+Tab과 키보드 전용의 수동 화면 검사가 남아 ERR-0020은 `RESOLVED`로 유지한다. 실제 C5·D5·E1 연출과 네 장비 성능 계측이 없어 renderer 결정은 `BLOCKED`다.
