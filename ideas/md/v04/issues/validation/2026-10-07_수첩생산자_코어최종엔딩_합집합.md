# 코어·최종 선택·두 엔딩 실행 합집합

## 범위

- 기준 develop: `4e6e3960d09baa92a001bf76595c857469e4834e`.
- 실행 후 반영 직전 develop에 문서 개정 `3677b62`가 추가되어 첫 HEAD 보호 검사가 복사를 거부했다. 해당 10개 문서는 이번 선택 파일과 겹치지 않고 GDScript/카탈로그도 변경하지 않았다. 기존 작업을 덮어쓰지 않고 새 HEAD 기준으로 선택 파일을 다시 대조해 반영한다. 실행 근거의 시작 기준은 바꾸지 않는다.
- T19g: NP16~19의 실제 수첩 생성/소비 경로를 기존 네 검사에서 공통 추적한다. 게임 원고·수치·퍼즐·엔딩 선택 규칙은 변경하지 않는다.
- `core`, `final`, `reality`의 기존 `_collect()`에 공통 원장 추적을 추가하고 종료 전 추적 유효성을 단언한다. 기존 `stay`도 동일 소스로 다시 실행한다.
- TEMP 프로젝트, suite별 별도 APPDATA/LOCALAPPDATA, Steam Godot 4.7.2 headless 검사다. 사용자 저장·Windows 실제 입력·4.6.3 후보 채택 검증은 아니다.
- 기존 집중 옵션 `--notebook-retained-endings-only`/`--notebook-handoff-history-only` 없이 전체 suite를 실행한다. 기본 여섯 실행 목록은 유지하고 새 세 suite는 허용 목록만 확장한다.
- 전체 T10/T15/T16/T19, 필수 전편 분기/정적 제외/실기/성능/엔진 채택은 미완료, rollout OFF 유지.

- 독립 카탈로그 인벤토리의 최신 문단 수 × 한영과 집계 분모를 생산자 22종 전부 대조했다. 이는 등록량 대조이며 22종 실행 완료가 아니다.
