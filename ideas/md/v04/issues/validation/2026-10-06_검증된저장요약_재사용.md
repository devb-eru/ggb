# 검증된 저장 요약 재사용

- 기준: develop `a3b7efa`.
- 관련: T20f, ERR-0027. 저장 검증을 생략하지 않고 최초 슬롯 요약 재검증 비용을 줄인다.

## 구현

`save_manager.gd`에서 임시 저장 파일의 정상 검증 결과를 작은 요약과 지문으로 보관한다. 지문은 인코딩 예정 문자열이 아니라 실제 검증에 사용한 텍스트에서 계산한다. 정상 승격 이후에만 이 쌍을 본파일 캐시 키에 연결한다. 승격 실패 시 후보 요약은 공개하지 않는다.

일반 `_read_and_validate`는 기본적으로 여전히 독립 전체 검증을 수행한다. 선택적 요약 수집은 `save_snapshot`의 임시 파일 검증에만 사용한다. `inspect_slot`은 기존처럼 실제 파일 바이트를 읽어 지문을 대조한다. 파일 변조·교체 시 전체 검증으로 돌아가며, 파일 시각/길이나 헤더 checksum만으로 캐시를 신뢰하지 않는다.

캐시에 전체 snapshot이나 원본 버퍼를 보관하지 않는다. 기존 경로·rollout namespace 구분, LRU 개수 제한과 메타데이터 크기 제한을 유지한다. 임시 파일 요약은 승격 전에 캐시에서 제거하고, 성공했을 때만 로컬에 보관한 작은 쌍을 본파일 키에 넣는다.
