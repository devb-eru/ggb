## 발견과 조치

### C5 실제 표시의 출처 연결

[ERR-0071](../items/GGB-ERR-2026-0071_C5_실제표시_출처연결_누락.md). 최초 정적 검토는 미클릭 채널 전체 작성을 누출로 의심했으나, 실제 화면은 버튼에 문양·음향을 이미 표시하고 있었다. 미클릭과 미공개는 다르며, 사용자는 **현행 표시 유지·출처 연결 보완**을 확정했다. 초기 ‘미조사면 숨겨야 한다’는 검사 가정과 회로만 남기는 후보는 채택하지 않는다.

실제 누락은 v1의 출처 목록이 구형 SCAN ID만 인식하여 현행 채널 라벨·EP02 개별 관찰을 연결하지 못한다는 점이다. 탁본 v2는 v1의 한영 본문·제목·요약을 그대로 유지하고 이미 표시된 라벨과 실제 클릭 대사의 참조를 연결한다. 표시는 클릭 조사를 완료시키지 않으며 도식 뷰어도 유지한다. v1 정의·과거 UID와 출처·핀/비교를 소급 삭제하거나 수정하지 않는다. 시트·실패 해결 원문은 개작하지 않는다.

### J3 건너뛴 기억

[ERR-0072](../items/GGB-ERR-2026-0072_J3_미열람기억_자동기록.md). 차 기억은 선택 장면의 열람 자격인데, `j3_restore`가 이를 문 기억 열람 증거로 사용했다. 건너뛰어도 새 기억 플래그와 원문이 생겼다.

Controller가 이미 사용하는 실제 장면 마지막 행 관찰/완료 영수증의 판정을 공유 helper로 옮겨 Session 복원에도 적용한다. 자격과 열람을 분리하고 건너뛴 새 기억은 쓰지 않는다. 정당하게 이미 획득한 과거 기억이나 관찰을 지우지 않는다.

### J3 뒷면 안내

[ERR-0073](../items/GGB-ERR-2026-0073_J3_뒷면안내_기록저장_실패.md). 원본 Controller는 `j3_flip_page`를 EP02 표시 어댑터에 전달하지 않아 실제 문장 노드가 아닌 J3 노드로 기록하려 한다. 이 공통 표시 실패가 원본의 여섯 J3 경로를 먼저 막았다. 뒷면 안내만 교정한 대조군을 별도로 실행하여 기억 복원 문제를 분리한다. 작성된 관찰 검증을 끄거나 허용 노드를 넓히지 않고 기존 EP02 행 표시 경로를 사용한다.

### 일반 검은 거울 회귀의 구형 UI 가정

[ERR-0074](../items/GGB-ERR-2026-0074_검은거울회귀_통합수첩_검사경로_불일치.md). 수첩 거울 회귀는 통과했지만 `black_mirror_smoke`는 통합 수첩에서 구형 `HistoryTranscript`를 찾고, 엄격 작성 ID 모드에서 미등록 테스트 대사를 사용하여 실패했다. 새 기능을 끄거나 단언을 제거하는 대신 실제 작성 대사·모델 준비·본문·닫기 및 도구 경로를 검사하도록 보완한다. 이 테스트 파일을 바꾸면 최종 소스 지문이 달라지므로 위 중간 성공을 새 최종 후보의 성공으로 재사용하지 않는다.

추가로 최신 EP02 UI는 C4/CF 힌트를 4단계로 제한하지만 구형 자료와 회귀는 5단계다. 사용자는 **최신 EP02의 4단계 유지, 구형 H5 기록 보존**을 확정했다. 회귀는 C3의 5단계와 C4의 4단계를 명시적으로 구분하고, 마지막 단계 이후 추가 요청 버튼 부재·새 H5 관찰 부재와 구형 H5 정의 보존을 검사한다. 기존 H5 원문·저장 기록을 삭제하거나 카탈로그에서 제거하지 않는다.

4차 후보는 앞선 통합 수첩·C3/C4 힌트 검사를 지나갔으나, 최신 C4의 안내 대사→선택창을 즉시 구형 모달로 가정한 검사와 테스트 실행기에 없는 Bootstrap 함수를 호출한 검사에서 실패했다. 실제 작성 안내 완료·선택지 저장 후 안전 포커스를 검사하고, 필요한 경우 실제 main Scene을 생성하여 제품 Bootstrap의 로드 경로를 검사하도록 보완한다. 고정 후보와 원자료는 덮어쓰지 않는다.

### C4 영문 실행 확인

[ERR-0075](../items/GGB-ERR-2026-0075_C4_실행확인_영문카탈로그_한국어잔존.md). 최신 안내·선택지의 en-US가 한국어로 남아 있었다. 사용자는 C4 실행 확인에 필요한 영문만 보완하도록 확정했다. 안내 1개·선택 문장 3개·선택지 묶음 1개·선택 결과 3개를 `ep02_c4_confirmation_v2.json`의 v2로 추가했다. 한국어·동작·출처는 그대로이며 원본 시트와 v1 정의는 수정하지 않는다. 새 선택지의 v2와 과거 선택지의 v1에 각각 맞는 선택 결과가 연결되는지 검사한다. 제목이 빈 최신 레이아웃에 구형 제목을 강제로 추가하지 않는다.

## 검사 경계

새 56조건은 두 언어에서 두 선택 모드의 옵션/선택 저장 거절, 명시 재시도, ACK 유실, 선택 중 재입력·화면 교체·locale/문맥 교체, 다섯 답변, 선택창 및 모든 답변의 선택 보류 저장 복귀를 다룬다. 취침 확정 뒤에는 새 전환 대사가 시작되어야 하지만 실제 리셋은 아직 실행되면 안 된다. 취침 취소는 완료 커서로 닫히고, 아침 답변은 각자의 실제 대사로 이어지되 일차나 인계를 앞당기지 않는다.

기존 네 종류의 선택 검사는 유지한다. 이 중 `P6_SLEEP` fixture는 새 live EP01 진입과 혼동하지 않고 구형 저장 모달의 실제 공통 표시 함수로 구성한다. 새 live 선택은 위 56조건으로 별도 검증한다.

첫 50조건 결과와 최종 56조건은 다른 하네스이므로 성공 실행이나 고유 조건 수를 합쳐 집계하지 않는다. 각 실행은 격리 profile, 실제 인자/시각/PID·native 종료, 제품/콘텐츠/검사기/로그 지문을 기록한다. 새 공개 경계의 실패 시도와 기존 근거도 보존한다.
