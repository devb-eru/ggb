## 검사 계약

- 선택창의 실제 descriptor ID 및 각 버튼 문구를 현재 언어 정의와 대조한다.
- 표시된 선택지 목록은 options_presented이며 아직 선택한 답변으로 계산하지 않는다.
- 재그리기와 다시 기록 요청은 전체 snapshot을 바꾸지 않는다.
- 선택한 답변의 ID만 한 건 기록된다. 취소가 기록되는 선택인지 UI 닫기인지는 row의 취소/choice 계약을 따른다.
- 답변의 event_occurrence_id와 conversation_session_id는 표시한 질문과 같고 presentation_token은 별개다.
- 닫힌 선택창의 이전 callback을 다시 호출해도 게임·기록 snapshot이 바뀌지 않는다.
- 기존 개발 체크포인트의 last_feedback으로 만들어진 미분류 원문은 유지한다. 선택 이후 새 미분류 원문을 추가하면 실패한다.

## 초기 검사 오류와 수정

첫 실행은 정의 row에 content_id가 있다고 가정한 테스트 오류로 중단됐다. 실제 descriptor에서 ID를 읽도록 수정했다. 두 번째 실행은 모든 archive 항목이 observation을 가진다는 잘못된 가정으로 중단됐다. 개발 체크포인트에서 복귀한 기존 feedback은 미분류 원문일 수 있으므로 이전 snapshot의 동일 항목인지 검증하도록 수정했다. 이를 제품 오류 재현이나 신규 기록 누락 해결로 보고하지 않는다. 개발 체크포인트 자체의 전체 scope/매핑 감사는 T17에서 따로 수행한다.
