## 추가 경로

1. F0-D 역할 조사에서 마라 2 연구원 기록 미획득 상태의 주민 자료를 실제 버튼 signal로 조사한다. `NB_CORE_D_INDEX_RECORD`와 `ANON_PURPLE_RESIDENT_INDEX` revision이 한 번만 획득되어야 한다.
2. 역할 퍼즐 완료 후 실제 격리 슬롯의 JSON을 로드한다. 기록·관계·원문과 snapshot이 동일해야 한다. 기명 조건에서는 익명 revision을 만들지 않는다.
3. 익명 기록의 원장 출처가 실제 관찰로 연결되고, 미공개 마라 2 연구원 기록을 인용하지 않는지 확인한다.
4. 이 실제 원장으로 query를 열고 모든 인물 페이지를 조회한다. 익명 참조가 `unidentified` 자료에 남고 MARA2 자료로 흡수되지 않아야 한다. 50개 첫 페이지만 조회해 누락을 오판하지 않는다.
5. A1 표식 3종별로 F0-D부터 익명 자료를 획득한다. 관찰 후 표식 유형을 바꾸지 않는다. F0-E 상태를 보존하고 실제 표시 복원 절차로 완료 화면의 선택 범위를 복구한 뒤 표식 3종 × 의향 3종의 전체 조합을 진행한다. 현실/잔류/미정 각각 F1에 진입하되 엔딩 선택이나 관계 보상을 하지 않는다.
6. 해당 아홉 경로의 JSON 복귀 후 이전 역할·익명 관찰의 UID·본문·순번이 동일해야 하며 익명 자료 분류를 다시 확인한다.

한영 각각 표식별 역할 직후 3회와 아홉 인증 경로 후 9회, 합계 24개 익명 조회를 검사한다. 추가 인증 경로는 9 × 한영 = 18개다. 기존 checkpoint 인증 경로도 유지한다. 모든 조회 실행 수는 단언과 `CORE_ANONYMOUS_REVIEWS` 로그로 확인한다.
