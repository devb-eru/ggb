## 현재 코드에서 도출한 방문 조건

| 에드가 경계 | 마라 2 시간표 | index 첫 조사 | 필요하면 drawer 조사 | 응답 실행 |
| --- | --- | --- | --- | --- |
| 0 | 미확인 | attention 1, 방문 없음 | attention 2, 방문 시작 | 대화 또는 숨기/퇴장 |
| 0 | 확인 | attention 1, 방문 없음 | attention 2, 방문 없음 | 실행하지 않음 |
| 4 | 미확인 | attention 1, 방문 시작 | 방문 중 추가 조사하지 않음 | 대화 또는 숨기/퇴장 |
| 4 | 확인 | attention 1, 방문 없음 | attention 2, 방문 시작 | 대화 또는 숨기/퇴장 |

근거는 `chapter_one_session.gd::inspect_inner`: index/drawer를 처음 조사할 때만 attention +1, 기본 임계값 2/높은 경계 1, 일정 확인 시 +1이다. 따라서 경계 0 + 일정 확인 시 이 두 조사만으로는 방문이 시작되지 않는다. 이 경우 응답 후보를 두 가지로 준비하더라도 실제 대화/숨기 분기가 실행됐다고 집계하지 않는다. 실행된 응답은 원자료의 response_executed로 구분한다. 이것은 현재 동작 검증이며 새 게임 규칙을 도입한 것이 아니다.
