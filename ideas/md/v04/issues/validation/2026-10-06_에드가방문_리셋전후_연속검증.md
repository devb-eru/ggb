## 2. 실행 경로

각 경로는 프롤로그 완료 표시를 가진 초기 상태에서 시작한다. 첫 표식, 시간표 지식, 방문/기억 플래그를 미리 부여하지 않는다. 최초 경계만 0/4로 설정한다.

1. 같은 침실에서 sentence 표식을 실제 작성하고 일과를 완료한다.
2. 실제 `session.sleep()`/ResetCoordinator로 수면·초기화·다음 아침을 진행한다. 결과 대사는 controller의 표시 경로로 확인한다.
3. A2 표식 유지 확인, 당일 일과, 중앙홀·사용인 공용실 이동을 실행한다.
4. 에드가/루카 시간표를 읽고 정답 시간대 결론을 제출한다.
5. 중앙홀 → 외부 서고 → 기록 내실의 연결된 이동을 실행한다.
6. 벽감·색인, 필요할 때 서랍을 조사하여 경계별 실제 소음 기준으로 방문을 유발한다. entering 플래그를 직접 넣지 않는다.
7. 첫 대응은 talk 또는 hide/leave다. 방문을 정상 종료하고 외부 서고·중앙홀·같은 침실로 돌아간다.
8. 두 번째 실제 수면을 진행한다. 아침의 일과/소음/방문 상태가 초기화됐는지 확인한다.
9. 영구 시간표 정보를 이용해 당일 일과·연결 이동·새 조사로 다음 방문을 유발하고 실제 대화한다.
10. 최종 저장 JSON을 LoadCoordinator로 다시 설치하여 두 방문의 원문·기억·지식이 보존됐는지 확인한다.

시작점 프롤로그 완료와 경계 값은 테스트 fixture다. 프롤로그 완주·경계 획득 과정을 검사한 것은 아니다. 행동은 session API와 실제 controller 대사/다음 버튼 경로이며 OS 마우스·키보드 입력은 아니다.
