# 수첩 닫기 실제 Windows 입력 재검증

## 실행 범위

사용자가 잠금 해제와 입력 가능 상태를 확인한 뒤 `@oai/sky`로 격리 게임을 조작했다. 2026-10-05 밤 시작, 10-06 결과 정리. Godot 4.7.2, OpenGL 3.3/Intel Iris Xe, 관찰 화면 1707×1067. CLI 1280×720과 실제 프로필 적용 화면은 다르므로 720p/DPI 인수로 계산하지 않는다.

- PCK: `%TEMP%/ggb-design-fixed-20261005/notebook.pck`.
- SHA-256: `B8AD108E6B57754B28A3F2A8890149C647C9EBCCD49E25A1B5C789BAAF7535AD`.
- 실행: `--path <empty> --main-pack <PCK> --windowed --resolution 1280x720 -- --ggb-dev-notebook-v2 --ggb-dev-full`.
- APPDATA/LOCALAPPDATA: `%TEMP%/ggb-notebook-native-visible-20261005/appdata`. 비어 있는 슬롯 1에서 새 게임. 사용자 저장·사용 중인 Godot 편집기에 입력하지 않았다.
- 최초 제한 환경 실행은 사용자 데스크톱에 노출되지 않아 PID/시작 시각을 확인해 종료했다. 이후 사용자 데스크톱 실행을 대상으로 삼았다. 최종 게임 창은 Alt+F4로 종료하고 PID 50716이 사라짐을 확인했다.

## 관찰 결과

| 실제 입력 | 결과 |
| --- | --- |
| 새 게임·기본 설정·빈 슬롯 1 클릭 | 침실 첫 대사 표시 |
| 마우스로 수첩 버튼 클릭 | 수첩 표시, 개발자 버튼 숨김 |
| 오늘의 일과 상세 클릭 | 해당 상세와 책갈피/비교 버튼 표시 |
| 오른쪽 위 닫기 클릭 | 개발자 창이 아닌 원래 침실·동일 첫 대사로 복귀, 수첩 버튼 포커스 |
| N 입력 | 이전 상세로 수첩 재진입 |
| 수첩 안에서 F10 | 개발자 창 열리지 않음, 수첩 유지 |
| Escape 두 단계 | 상세 탐색에서 목록 포커스로, 다음 Escape에서 같은 대사로 복귀 |
| 수첩 밖에서 F10 | 개발자 창 정상 표시. 시점 이동 없이 Escape로 닫음 |

각 행동 뒤 화면을 다시 관찰했다. 개발자 창 표시의 첫 캡처는 입력 직후 이전 프레임이었고 추가 관찰에서 최종 창을 확인했다. 같은 키를 재전송하지 않았다.

[ERR-0031](../items/GGB-ERR-2026-0031_개발자버튼이_수첩닫기를_가림.md)의 실제 마우스 재검증을 완료했다. 같은 PCK의 host 548개·비동기 저장 303개 자동 회귀도 통과했다. 화면 관찰 근거는 이번 대화의 도구 캡처이며 별도 캡처 파일을 생성했다고 주장하지 않는다.

## 남은 범위

게임 종료 뒤 최종 창 목록 확인에서 물리 Escape에 의한 Computer Use 중단 통보를 받았다. 이후 화면 조작을 중단했다. 그 전 실제 입력·화면 관찰 결과와 PID 종료 확인만 위 근거로 사용하며, 중단된 최종 목록 호출을 성공한 검사로 세지 않는다. 재개 확인 전 추가 입력은 하지 않는다.

이번 실행은 수첩 닫기 겹침 및 개발자 입력 복원에 대한 국소 검사다. IME 조합·검색·200%·갤러리 실제 입력·Alt+Tab·마우스 전용/키보드 전용 전편 완주·정식 성능 인수는 미완료다. 자동 PASS나 이 클릭 결과로 확대하지 않는다.
