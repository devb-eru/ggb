# 수첩 개발자 입력 가드 검증: 2026-10-05

## 배경과 범위

기준 develop `f747337`에서 추적 중인 [ERR-0031](../items/GGB-ERR-2026-0031_개발자버튼이_수첩닫기를_가림.md)을 수정한다. 변경 전 실제 Windows 마우스 재현은 [실제 입력 기록](2026-10-05_수첩_Windows_실제입력_검증.md)에 있다. 본 문서는 수정 후 자동 회귀를 별도로 기록하며 Windows 입력 재검증으로 대신하지 않는다.

제품 변경은 일반 수첩·갤러리 수첩 host와 개발자 패널의 입력 소유권에 한정한다. 기존 사용자 씬·오디오·아트·대사 카탈로그·저장 파일과 저장 schema는 변경하지 않는다.

## 동작 계약

1. 두 종류 host는 열기 성공 후에만 `notebook_input_hosts` 그룹에 등록한다. `notebook_input_observers`에 즉시 알려 다음 프레임 이전부터 개발자 버튼을 숨긴다. 그룹은 런타임 상태이며 저장하지 않는다.
2. 개발자 버튼은 숨김·마우스 제외·FOCUS_NONE 상태가 된다. 개발자 패널의 직접 `toggle()` 호출도 열람 중에는 거부한다.
3. F10 개발자 진입은 열람 중 중단하되 이벤트 자체를 소비하지 않는다. 플레이어가 수첩의 탐색 키로 F10을 재지정한 경우 수첩이 입력을 받는다.
4. 닫는 입력의 release를 기다리는 동안 host 그룹을 유지한다. 정상 닫기에서는 즉시 알리고, 비정상 소유자 종료·queued 삭제는 개발자 패널의 프레임 확인으로 복구한다.
5. 수첩을 닫은 뒤 기존 개발자 시점 이동이 다시 가능하다. 기록 열람 중 개발자 시점으로 강제 이동하거나 기본 슬롯을 덮어쓰는 새 경로는 추가하지 않는다.
