## 4. 비차단 개선

- 현재 `Windows Desktop Debug` preset은 `all_resources`라 연습 씬과 test runner도 debug 산출물에 포함한다. 버티컬 슬라이스 제품 preset을 만들 때 production·test export 경계를 분리한다.
- `--foundation-smoke`는 debug 검증 용도다. release preset을 추가할 때 비-debug 빌드에서 test hook을 호출할 수 없도록 feature gate를 둔다.
- renderer 후보 실행 smoke는 headless 기반선이며 실제 Compatibility·Forward+ 화면 품질이나 성능 판정이 아니다.

## 5. 결론

조치한 코드에서 추가 parse 오류, Resource 누락, 저장 checksum·backup 오류, 연습 씬 첫 프레임 불일치는 발견되지 않았다. 새로 등록한 세 건은 현재 smoke의 결함이 아니라 다음 gameplay 구현 전에 필요한 누락 기반이며, 이외의 신규 게임 코드 충돌은 확인되지 않았다.
