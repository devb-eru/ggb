- 전체 목표의 T20n 부분 개선. 기준 develop `a6e87b11cb5bd278ea2bb7d65ca978a53dd77ada`에서 추출한 새 TEMP 프로젝트를 사용했다.

## 2. 원인과 수정

기존 갤러리 호스트는 `panel.present`로 기본 단서 화면을 구성한 다음 읽기 전용 설정을 적용하고, 다시 `restore_view`로 저장된 목록·상세·비교 위치를 복원했다. 본편 호스트에서 이미 제거한 기본 화면 중복이 갤러리 경로에는 남아 있었다.

수정 후 읽기 전용·임시 비교 권한을 `redraw=false`로 먼저 설정하고 기존 `present(..., initial_view)` API에 복원 상태를 전달한다. 복원이 필요한 경우 기본 단서 목록을 먼저 생성하지 않는다. 별도 복원 호출을 제거했으며, 저장된 위치가 없는 기본 진입은 기존 query suite의 갤러리 검사와 함께 회귀한다.

영속 책갈피 쓰기는 여전히 허용하지 않고 임시 비교만 유지한다. `refresh`에서 읽기 모델을 새로 열고 임시 바구니를 재구성하는 정상 호출은 제거 대상이 아니다.

## 6. 남은 조건

T20n은 이 중복 제거와 명시 회귀 범위만 완료다. [ERR-0027](../items/GGB-ERR-2026-0027_대용량_수첩_표시검색저장_지연.md)은 IN_PROGRESS, 전체 목표도 진행 중이다. 전체 생산자 독립 분기·NP22 소비, 장비별 cold 20/warm 100/p95·RAM·실제 입력 프레임, 마우스/키보드 전용 전편, 최신 4.6.3 release/템플릿·엔진 계약은 남는다.

기존 T22f2 후보 검증의 소스는 위 수정 전 지문이다. 이번 수정 후 지문의 후보 엔진 전체 호환 검증으로 재사용하지 않는다. 제품 Godot 4.7과 기본 rollout OFF를 유지한다. develop 전달은 사용자 변경 보존·선택 파일 반영·동일 Git tree 검사 후 진행하며 결과는 Git 기록과 작업 종료 안내로 확인한다.
