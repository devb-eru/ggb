# 수첩 메타데이터 전 버전 감사

## 판정과 범위

- 기준: `develop`의 `5f3c5343e3b18988ba8ed43cc1bc3f33d5c451fb`.
- 관련: [구현 계획 16절](notebook_history_review_plan.md#16-기록-생산자와-콘텐츠-공급-범위-nb-p15), [ERR-0026](../items/GGB-ERR-2026-0026_플레이어_문구_내부ID_노출.md), [생산자 재감사](../../../../../docs/notebook_producer_audit_validation.md).
- **이번 감사 범위에서 추가 제품 결함 없음.** 등록 카탈로그의 제목·요약·화자, 부분 공개 메타데이터, 의미 버전별 원문 재생, 실제 조회 모델의 상세 제목 연결을 검사했다.
- 테스트·검증 근거만 추가했다. 게임 제품 코드, 콘텐츠 카탈로그, 저장 schema, 원문, 번역, 기본 rollout은 변경하지 않았다.
- 전체 계획과 ERR-0026은 IN_PROGRESS다. 컨트롤러의 최초 공개 시점·모든 동적 변수/분기·실제 Windows 화면·입력·전체 본문 ID 검사는 이 감사의 범위가 아니다.

## 검사 방법

`notebook_metadata_smoke.gd`를 기존 `--notebook-query-smoke`에 연결했다. 별도 시험 카탈로그를 전수 검사인 것처럼 세지 않고, 제품 `CONTENT.CATALOGS`의 모든 파일과 모든 의미 버전을 직접 열거한다. 중복 ID/버전, 실제 로드 정의와 파일 정의의 불일치, 빠진 생산자 그룹을 거부한다. NP22는 소비·관리 경로이므로 새 본편 콘텐츠 정의가 없는 것이 정상이다.

각 정의에서 고정 대표 변수로 실제 `CONTENT.presentation → observe`를 거친 한국어 관찰 fixture를 만들고 JSON 왕복 후 한국어·영어 조회를 검사한다. enum은 정렬한 첫 값을 사용한다. 이 대표 변수는 사건의 정답·진행 경로가 아니며 모든 enum 조합을 실행했다는 뜻도 아니다. 임시 위치·장·노드는 스키마에 유효한 fixture 문맥으로서 실제 장소 방문 증거가 아니다.

| 검사 | 합격 조건 |
| --- | --- |
| 공개 제목·요약·화자 | `NB_*`, `REC_*`, 단계 ID가 공개 메타데이터에 없음. 한국어 조사 앞도 놓치지 않는 ASCII 토큰 경계로 검사 |
| 정상 공개 이름 | 원래 내부 ID가 없는 필드는 원고와 정확히 같음. 모든 제목을 일반 문구로 숨겨 통과시키는 구현을 허용하지 않음 |
| 과거 의미 버전 | 해당 버전의 각 문장 재생이 같은 버전의 presentation과 일치. 최신 문구로 바꾸지 않음 |
| 부분 공개 | 다중 문서의 각 단일 segment, 3개 이상인 문서의 각 하나 빠진 집합에서 제목은 일반 기록명, 요약은 빈 값 |
| 실제 조회 모델 | 전체 공개 fixture를 각각 독립 archive로 만든 뒤 `NotebookQuery.open/detail`의 모든 문장 제목·요약이 검토된 메타데이터와 일치 |
| 출처 불변 | 언어 전환·조회 전후 관찰, archive, 출처 참조 및 GameState가 동일 |
| 잘못된 공개 근거 | 중복 segment로 전체 공개처럼 보이게 하거나 producer를 다른 값으로 바꾼 fixture 거부 |
| 없는 의미 버전 | 최신 메타데이터를 빌리지 않고 일반 제목·빈 요약/화자 사용. 본문은 실제 captured text fallback, 관찰 불변 |
| 파일 불변 | 29개 카탈로그의 검사 전후 내용 SHA-256이 같음 |

부분 공개 집합은 모든 비어 있지 않은 진부분집합의 조합을 전수 생성한 것이 아니다. 각 단일 문장과 각 한 문장 누락을 검사한다. 공개 완전성 판정은 유효한 고유 segment들의 개수와 소속 검사에 기반함도 코드를 대조했다. 실제 UI 픽셀이나 사건 표시 시점의 정확성까지 증명하지 않는다.

## 실패 이력과 잔여 인수

- 최초 `%TEMP%/ggb-notebook-metadata-audit-20261005` 실행은 새 검사 코드가 presentation segment의 `text`를 관찰의 `captured_text` 필드로 잘못 읽어 중단했다. 해당 실행은 실패이며 제품 결함으로 집계하지 않는다.
- 필드를 교정한 `metadata-final` 실행은 PASS했다. 이후 정상 공개 명칭의 정확한 보존과 없는 버전/위조 출처 반례를 추가한 위 `metadata-verified` 패키지로 전체 query를 다시 실행했다. 앞선 PASS를 최종본에 소급하지 않는다.
- 내부 ID가 들어 있는 과거 **본문**은 원문 보존 대상이다. 이번 메타데이터 검사는 그 본문을 삭제·치환하거나 제품 카탈로그를 재생성하지 않는다.
- 실제 화면/컨트롤러의 모든 발생·반복·실패·선택 분기, 전편 신규 미매핑 0 및 필수 NOT_COVERED 0은 아직 증명되지 않았다. 기존 생산자 테스트의 해당 실행 근거와 이 조회 fixture를 구분한다.
- Windows 잠금 해제 응답이 없어 실제 입력을 재개하지 않았다. IME·시각 QA·장비별 성능 및 비차단 저장도 별도 미완료다.
