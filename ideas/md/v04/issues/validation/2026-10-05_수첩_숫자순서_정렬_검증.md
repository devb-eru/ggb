# 수첩 첫 목록의 숫자 순서 정렬 검증

기준 develop: `ebc439e9d2f4bfb59d0a6b2eec64b31d1fdccd18`.
[ERR-0027](../items/GGB-ERR-2026-0027_대용량_수첩_표시검색저장_지연.md) 후속. 조회의 순서 생성 비용만 개선했으며 전체 수첩 성능 인수 완료는 아니다.

## 1. 변경과 불변 조건

[notebook_query.gd](../../../../../game/scripts/systems/notebook_query.gd)의 `_ordered_for`는 모든 참조 키를 사용자 비교 함수로 정렬하면서 매 비교마다 행 사전을 조회했다. 다음과 같이 변경했다.

1. 대화는 `session_end`, 인물/최근 목록은 `sequence` 숫자로 묶는다.
2. 묶음의 숫자 키를 정렬한다. 인물은 오름차순, 대화/최근 목록은 내림차순이다.
3. 같은 묶음 안의 `sequence → segment_order`가 이미 오름차순이면 유지한다. 역전이 발견된 묶음에만 보조 정렬을 수행한다.
4. 기존과 같은 하나의 키 배열로 합쳐 원래의 최대 3개 정렬 캐시에 넣는다.

반환 순서는 여전히 대화 `(-session_end, sequence, segment_order)`, 인물 `(sequence, segment_order)`, 최근 목록 `(-sequence, segment_order)`다. 세션을 합치거나 과거 시각을 추론하지 않는다. 이전 수첩 투영 행의 음수 순번과 동일 종료 순번도 보조 정렬로 기존 의미를 유지한다.

본문·공개 범위·언어·페이지 크기 50·필터·UID 앵커·저장 schema는 바꾸지 않는다. 정렬을 위해 자료를 생략하거나 최신 일부로 자르지 않는다. 새 묶음 사전과 임시 배열은 정렬 생성 중에만 사용하며 영속 캐시는 기존 3개다.

## 2. 기능 검증

[notebook_query_smoke.gd](../../../../../game/scripts/tests/notebook_query_smoke.gd)에 이전 튜플 비교를 검증 기준으로 남겼다.

- 이전 기록 3개, 서로 엇갈려 등장하는 3개 세션의 42개 관찰, 관찰당 2개 공개 문단, 이미 고정한 이전 수첩과 아직 투영만 한 수첩을 함께 구성했다.
- 한국어·영어, 4개 탭, 원래 입력 및 역순 입력에서 반환 키 배열을 이전 정렬과 정확히 대조했다. 역순 입력은 저장 데이터를 바꾸지 않는 모델 내부의 방어 검사다.
- 모든 페이지의 전체 키 목록과 각 행의 UID 앵커/페이지 번호를 대조했다.
- 원본 archive 불변, 본문 렌더링 없음, 3개 캐시 한도, 기존 필터·검색·닫기/재열기 회귀를 확인했다.

최종 query **3,599개 PASS**. 메타데이터 64,420개, legacy 73개, view 83개, browse 213개, visual 210개, search 180개, investigation 300개, person retention 64개, memory 83개, self-mark 270개, gallery 189개도 PASS했다.

첫 목록 모델 조회는 순서 생성뿐 아니라 필터와 최대 50개 행 반환까지 포함한다. 전체 시간에는 수정하지 않은 모델 검증/복제·메타데이터 구성·레이아웃 비용이 남아 있다. 이 모델/패널 probe에는 실제 호스트의 슬롯 확인과 입력 전달 비용이 포함되지 않는다. 수첩 버튼부터의 실기 응답 시간이나 순수 정렬 시간으로 바꾸어 보고하지 않는다.

네 경우 모두 탐색 표본은 개선됐으나 p95/장비별 보증이 아니다. 긴 문서·보호 기록을 포함한 입력의 조회 전후 불변과 숨은 문서/미요청 힌트 검색 금지 검사는 기존 probe에서 함께 PASS했다. warm 0회이므로 probe의 append/prune·동기 저장 반복 검사는 이번 계측에서 실행하지 않았다.

## 4. 재현과 로그

- 수정 전 PCK: `D8870F7137ADEEAC3F2EF35C98489D88A692EC00559F9BE52276DBBD97E03A0E`.
- 최종 PCK: `DC69122ECE119C274E21639508EA6F9A540AFF1185A7128039FB4A02FE49F0A1`.
- 로그: `%TEMP%/ggb-notebook-order-before-20261005`, `%TEMP%/ggb-notebook-order-after-20261005`.
- 옵션: `--notebook-performance-probe --ggb-dev-notebook-v2 --nb-perf-fixture=<fixture> --nb-perf-locale=ko-KR --nb-perf-warm=0`.

최종 import 21.1초, export 7.9초, query 46.9초, 네 probe 각각 6.5/9.7/8.5/6.9초로 종료 코드 0/PASS했다. 시간은 테스트 전체 실행 시간이다. 실행 전 러너의 반복문 닫는 괄호 누락으로 한 차례 실행이 시작되지 않았고 수정 후 재실행했다. 스크립트/리소스 오류는 없으며 기존 Windows 루트 인증서 읽기 경고는 남아 있다.

## 5. 남은 작업

모델 검증·복제·메타데이터 구성, 첫 패널/검색과 저장 시작·완료 비용, 실제 Windows 키보드/마우스·IME·확대 UI, 장비별 cold 20/warm 100·RAM, 생산자 미열거 분기와 전체 계획 인수는 미완료다. 특히 현재 패널까지의 계측만으로 계획의 수첩 첫 유효 목록/입력 지연 예산을 통과했다고 판단하지 않는다.

ERR-0027 및 전체 목표는 IN_PROGRESS, 개발 rollout 기본 비활성 유지. 실제 Windows 입력은 잠금 해제 확인 대기이며 이번 자동 검사로 대체하지 않는다.
