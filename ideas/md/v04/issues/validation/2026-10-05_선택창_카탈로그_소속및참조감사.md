# 선택창 카탈로그 소속·참조 감사

- 기준 develop: `1a7c2fcf22ed80f2e98c41ca85aa6423fbde836c`.
- 범위: 29개 수첩 카탈로그의 전체 의미 버전 1,734개 중 choices를 선언한 정의. 공통 선택창을 이용한다고 모두 NP05인 것은 아니다.

- 이 검사는 정적 계약 검사다. 등록된 모든 창의 실제 도달·표시·선택·저장 성공을 입증하지 않는다. UI 메뉴, choices 없는 월드 버튼, 미등록 직접 호출은 별도 감사 대상이다.

## 검사하는 계약

- 중복 ID/버전 선언, 빈 choices, 누락 생산자와 취소 인덱스 범위를 검사한다.
- UI 전용 선택에는 기록 참조가 없어야 한다.
- 비 UI 선택이 참조하는 v1 정의가 실제로 존재해야 하며 선택 확정/취소 종류가 일치해야 한다.
- 한영 option_N 문구가 존재하고 참조한 선택 기록의 body와 정확히 일치해야 한다.
- 취소 인덱스는 취소 기록 또는 UI 닫기로 연결되어야 하며 확정 행동을 가리키면 거부한다.
- confirm/cancel 및 choice_confirmed/choice_cancelled라는 기존 두 표기를 모두 같은 의미로 다룬다. 카탈로그를 임의 개작하지 않는다.

정상 fixture 3종과 손상 fixture 10종으로 검사 도구를 자체 검증했다. 누락 참조, 잘못된 target 종류, 언어 불일치/누락, 취소의 확정 실행, 인덱스 범위, 알 수 없는 kind, UI 기록 참조, 빈 choices, 생산자 누락을 각각 거부했다.

초기 도구는 overlay의 정상 UI 닫기 5개를 취소 기록이 아니라는 이유로 잘못 거부했다. 공통 controller가 UI 닫기에도 취소 인덱스를 사용할 수 있음을 확인하고 정상 fixture로 고정했다. 또한 OrderedDictionary의 생산자 그룹 집계는 명시적인 키 접근으로 수정했다. 둘 다 감사 도구의 가정 오류이며 게임 결함이 아니다.
