# 초기 전체 화면 위치와 잘림 검증

## 범위

[ERR-0078](../items/GGB-ERR-2026-0078_초기전체화면_창모드덮어쓰기_화면잘림.md). 사용자가 실제 화면의 우측·하단 잘림과 중심의 우하단 치우침을 확인한 후 진단했다. 수첩 전체 구현 완료나 전편 OS 완주 검증은 아니다.

## 재현과 원인

기존 격리 GUI 기준은 `c4abc09e`, 307 GDScript·63 data다. 자연 마우스 진행으로 P2·P3 완료(아침 일과 2/3)까지 도달한 슬롯만 별도 APPDATA로 복사했다. 실제 사용자 세이브나 Steam 편집기에는 입력하지 않았다.

1. 원래 소스·강제 창 옵션에서 정상 실행→실제 이어하기 클릭으로 우측 인벤토리와 하단 안내 잘림 재현.
2. 별도 읽기 전용 SceneTree 측정에서 창 모드 0, native 크기 `2560×1600`, 위치 `(89,55)` 확인. 논리 뷰포트와 UI는 `1920×1200`에 맞게 배치됐다.
3. 같은 소스에서 강제 창 옵션을 제외해도 모드 0, 위치 `(629,359)`로 재현. 런처 옵션만 제거하면 해결된다고 결론내리지 않았다.
4. 초기 디스플레이 적용만 첫 process frame 이후로 옮긴 후보는 모드 3, 위치 `(0,0)`, native 크기로 수렴했다.
5. 진단 스크립트 없는 정상 메인 씬 실행에서 실제 이어하기를 클릭해 인벤토리 6칸·하단 수첩·대화기록 버튼이 전부 표시됨을 확인했다.

전체 화면 설정과 초기 창 구성이 겹치는 수명 문제다. UI 전역 이동, DPI 설정 변경, 최소 UI 축소로 덮지 않았다. 시스템 디스플레이·보안·개인정보 설정은 변경하지 않았다.

## 후보와 제한

제품 수정은 `game/scripts/ui/start_screen.gd`의 `_apply_initial_display()` 하나다. 첫 process frame을 기다리고, 화면이 tree 안에 있고 삭제 예약되지 않았을 때만 기존 backend를 호출한다. 나머지 창 설정·미리보기·되돌림 로직은 유지한다.

실제 화면 확인은 4.6.3 후보와 기존 GUI 소스에 이 수정만 적용한 비교다. ERR-0077의 310스크립트 저장 경계 증거를 레이아웃 검증으로 전용하지 않는다. 후속 native 회귀는 별도 source 지문·프로필로 기록한다.

초기 진단 후보를 소스 복사 완료 전에 실행한 시도에서는 preload 누락이 발생했다. 해당 실행은 폐기 진단이며 성공으로 세지 않는다. 소스 복사 종료와 의도한 변경 1파일을 확인한 뒤 새 프로세스로 재실행했다. 진단 스크립트 경로의 저장 요약 표시를 실제 OS 저장 접근 인수로 사용하지 않고, 정상 실행 경로에서 실제 이어하기 성공을 별도로 확인했다.

## 최종 근거

[증거 README](evidence/display-startup-20261105/README.md), `manifest.json`, `raw.zip`에 실행별 결과와 311스크립트·63data 지문을 보존했다. native 정식 원본 대조와 최종 후보 사이 소스 차이는 startup 한 파일뿐이다. 후보 다섯 실행의 검사 수는 150/154/152/152/150이며 동일 조건을 다시 합산하지 않는다. 원본·초기 검사 오판과 최종 성공은 구분한다.

native 회귀는 정상 main을 엔진이 로드하도록 두고, 격리 사본에만 마지막 관찰용 autoload를 등록한다. `--script` SceneTree 직접 실행은 main의 초기화 시점을 바꿔 원래 결함을 놓쳤으므로 폐기하고 이력을 보존했다. 최초 검사에서 생성 전 native 창 조회와 main 준비 전 검사를 한 실패, 저장 프로필 숫자 표현 오판도 원자료의 diagnostics에 남겼다. 최종 실제 시작 순서 검사는 첫 process frame 전 StartScreen ready를 확인한다.

headless 실행 시 테스트 autoload는 활성 플래그가 없으므로 상태·프로필을 구성하지 않는다. 테스트용 autoload 등록은 실제 저장소의 project.godot에 반영하지 않는다. 사용자 미커밋 project 설정과 엔진 설치는 유지한다. 현재 근거는 4.6.3 후보 기준이며 4.7 재실행이나 정식 엔진 전환을 완료했다고 해석하지 않는다.
