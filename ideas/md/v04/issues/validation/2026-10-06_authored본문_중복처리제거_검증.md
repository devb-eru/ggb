# Authored 본문 중복 처리 제거 검증

## 범위와 기준

- 기준 develop: `5acc302f53beefd3f7c31c506b48e2f859a01c0e`.
- 대상: `game/scripts/systems/notebook_content.gd`의 전체/단일 문단 재열람 렌더링.
- 전체 계획은 진행 중이다. T20/ERR-0027, 실제 입력, 전편 완주와 정식 성능 인수는 완료 처리하지 않는다.

## 수정

1. `render_segment`는 선택하지 않은 문단을 포함한 관찰 전체를 먼저 검증한다. 이후 공통 내부 렌더러에 선택한 문단만 전달한다. 두 번의 schema 검증과 두 개의 얕은 투영 복사만 제거했다.
2. 공통 렌더러는 초기화된 카탈로그 행을 읽기 전용으로 사용한다. 공개 `definition()`의 깊은 복사 계약은 유지한다. 렌더러가 카탈로그나 원문을 수정하지 않는다.
3. 변수 명세가 빈 문구는 치환용 정규식을 만들지 않는다. 카탈로그 로딩의 placeholder/명세 검사와 공개 진입의 변수 검사는 유지한다. 변수가 있는 문구의 단일 패스 치환, enum 번역과 JSON 정수 표시는 변경하지 않는다.
4. 미지원 의미 버전은 당시 원문을 사용한다. 현재 버전으로 대체하거나 미공개 문단을 재구성하지 않는다.
