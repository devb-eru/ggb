# 실제 F0 자료의 엔딩 후속·완료 갤러리 검증

## 1. 기준과 변경

- 기준 develop: `cdab21075b447d27b78d3a3295c92c9fccb84d9b`.
- 계획: 통합 수첩 T15/T16, NP18/NP19 후속 소비와 완료 갤러리의 실제 기록 보존.
- 변경 파일: `game/scripts/tests/notebook_final_smoke.gd`. 제품 코드·저장 형식·서사는 변경하지 않았다.
- 기존 검증은 실제 F0 자료를 J5·대면·최종 결정까지 이어받았지만, 엔딩 후속/갤러리 검사는 별도 체크포인트·합성 원장으로 시작했다. 이번에는 해당 경계를 실제 상태 그대로 연결했다.
- 집중 실행 옵션 `--notebook-retained-endings-only`를 추가했다. 이 옵션은 독립 F1/F2/F3 fixture 검사를 생략하며 결과에도 집중 실행 여부를 반환한다. 기본 final suite에서는 기존 검사와 이번 연결을 모두 실행하도록 유지한다.

## 2. 실행 범위

| 범위 | 실행 |
| --- | --- |
| 최초 실제 자료 | F0-D 역할 조사에서 취득한 익명 기록 |
| 표식 | house_glyph |
| 인증/잠정 의향 | reality / stay / undecided |
| 최종 선택 | 각 의향에서 reality / stay 모두 가능 |
| 언어 | ko-KR / en-US |
| 최종 결정 경로 | 3 × 2 × 2 = 12 |
| 엔딩 후속 경로 | undecided에서 두 엔딩 × 한영 = 4 |
| 익명 조회 | 기존 경계 + 두 후속/갤러리, 총 40회 |

엔딩 후속은 해당 실제 최종 결정 상태를 계속 사용한다. 엔딩 체크포인트를 설치하거나 완료 노드·관계 플래그를 직접 넣지 않는다. 시작점 F0-D 자체는 개발 체크포인트이며 프롤로그부터 전편을 완주한 검사가 아니다.

## 3. 실제 연속 실행

### 공통

1. 실제 역할 조사 → 익명 자료 획득 → 인증/의향 선택.
2. 동일 자료를 F1 재생/J5 작성 → F2 대면/사실 확인 → F3 조사와 최종 결정으로 넘긴다.
3. 각 경계에서 저장 JSON 설치, 과거 관찰 UID·내용·순번, 관계와 결정 비변경, 익명/기명 인물 분류를 확인한다.
4. 잠정 미정 의향의 두 최종 결정에서만 아래 후속 전체를 실행한다. 다른 의향은 최종 결정까지 검사한다.

### 현실

- 실제 기상 확정/아카이브 상태 → 다섯 인계 기록 → 연결 해제의 실제 fade callback → 신체 기상.
- 손·호흡 표시기·고정 벨트 조사 → 신체 확인 완료.
- 현장 수첩의 표지·첫 72시간·SUBJECT 인계 페이지를 전문으로 열고 읽음 확인한다. 각 페이지의 구조화된 `REALITY_*` 획득 1건과 `physical` 수명을 검증한다.
- 현장 수첩 종료 → 출입 패널 3종 조사 → 수동 해금 → 에어록 진입 → 바깥 시점.
- 실제 session의 8회 tick과 화면 공개를 거쳐 CREDITS_REALITY에 도달한다.

### 잔류

- 실제 잔류 확정/안정화 → 기억 헌장 3개 → contextual 외형 선택 → 다섯 사용인 자율성 제안.
- 중앙홀 → 식당 착석 → 다섯 식탁 대상 대화 → 두 SUBJECT 문장 작성.
- 최종 프레임의 실제 session tick 2회와 화면 공개 → 종료 버튼 → CREDITS_STAY.

timer tick은 session API로 실행했다. 물리적 Windows 입력·실제 포커스/중단 시간 측정의 대체 검사가 아니다. 연결 해제 fade만 기존 callback을 대기하여 실행한다.

## 4. 보존과 갤러리

- 어느 후속에서도 기존 사용인 상태가 달라지지 않는다. 연구원 완료를 새로 보상하거나 잠정/최종 선택을 재해석하지 않는다.
- 기존 지식 revision과 source_refs는 이후 원장에 그대로 남는다.
- 후속 종료 후 저장 JSON을 다시 설치하여 이전 F0 관찰 UID·원문·순번과 익명 출처를 확인한다.
- 실제 완료 상태를 전용 임시 갤러리에 capture하고 디스크 파일을 read_entry로 다시 검증한다.
- 갤러리의 아카이브와 원장은 실제 완료 상태의 것과 persisted-value로 동등하다. 크레딧 관련 필드 정규화는 갤러리의 기존 계약대로 허용한다.
- read model의 모든 인물 페이지를 조사하여 익명 자료가 unidentified에 있고 MARA2에 없음을 확인한다.
- 갤러리 읽기 전후 현재 GameState와 capture 파일 바이트는 불변이다.
