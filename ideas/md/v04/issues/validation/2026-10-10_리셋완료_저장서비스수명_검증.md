## 원자료와 회귀

[원자료 manifest](evidence/2026-10-10_reset_lifetime/manifest.json)는 로그·receipt·실행 하네스·세 파일의 변경 전후를 SHA-256과 바이트 길이로 연결한다. 사용자 프로필/저장 파일과 엔진 바이너리는 Git에 넣지 않는다.

지정 회귀: reset 집중 136조건·3,364단언, UI 16조건·372단언, 동기 ACK 20조건; campaign 수면 세션 76조건·3,748단언, 실제 UI 콜백 24조건·2,016단언; 공통 history 72조건·870단언, host 548확인(내부 async 341확인), migration 381확인. 최종 수명 검사를 포함해 9개 실행이 모두 native 0이다. host 내부 단언 중 worker 대기 프레임 관찰은 조건부이므로 기존 보고서의 342를 이번 횟수로 복사하지 않는다. 후보 버전 경고는 제품 4.7 계약을 유지한 기대 경고이며 스크립트 오류와 구분했다.
