# GGB-ERR-2026-0075: C4 실행 확인 영문 카탈로그의 한국어 잔존

| 심각도 | 중간 |
| 해결 상태 | VERIFIED |

| 우선순위 | P2 |
| 담당자 | Codex |

## 문제

최신 `ep02_sheet_v1.json`의 `NB_EP02_C4_COMMIT_001`, 실행 확인 선택지 및 `NB_EP02_CHOICE_C4_COMMIT`는 `en-US`에도 한국어 안내·선택지를 갖는다. 현재 로딩하는 전체 카탈로그를 조사했을 때 이 안내와 계획 재확인 선택지에 더 높은 영문 버전이 없었다. 원본 시트의 영어 칸도 비어 있다.

실제 C4는 구형 즉시 확인창 대신 `EP02_C4_COMMIT_001` 안내 후 선택창을 연다. 따라서 구형 영어 제목을 강제로 복원할 문제와, 최신 실제 안내·선택지를 영어로 읽을 수 없는 문제를 구분한다. 빈 제목만으로 결함이라 단정하지 않는다.

## 권장 조치

- 원본 시트와 v1 정의, 이미 저장한 원문·UID·참조는 변경하지 않는다.
- C4 실행 확인에 필요한 안내·선택지의 영문 카탈로그만 새 버전으로 보완한다.
- 현재 표시와 선택 결과가 같은 버전의 원문을 보존하는지 확인한다.
- 기본 포커스는 계획 재확인이며 젖은 천 실행으로 이동시키지 않는다.
- 모든 EP02 번역을 완료했다고 확대 보고하지 않는다.

사용자는 C4 실행 확인에 필요한 영문 카탈로그만 보완하도록 확정했다. `ep02_c4_confirmation_v2.json`에서 안내 1개·선택 문장 3개·선택지 묶음 1개·선택 결과 3개를 v2로 추가했다. v1 정의와 원본 시트는 수정하지 않았다. 표시된 v1/v2 선택지에 맞는 버전의 선택 결과가 대응하는지, 영문 외의 한국어·동작·출처 메타데이터가 그대로인지 검사했다. 실제 C4 확인·안전 포커스, 같은 후보의 9개 실행·독립 감사와 PCK의 두 모드 회귀가 통과했다. 관련 검사기 보완은 [ERR-0074](GGB-ERR-2026-0074_검은거울회귀_통합수첩_검사경로_불일치.md)로 별도 추적한다. 전 EP02 번역 완료나 실제 Windows 입력 인수는 아니다.

```yaml
resolved_in:
  - game/data/notebook/ep02_c4_confirmation_v2.json
  - game/scripts/systems/notebook_content.gd
  - game/scripts/tests/black_mirror_smoke.gd
resolution_summary: 원본 시트와 과거 v1을 보존하는 국소 영문 v2 추가
verification_ids:
  - NB-SHEET-20261105
verified_on: 2026-11-05
```
