## 재현

기준 develop `2d1287a`에서 실제 침대·확인·다음 대사 버튼으로 P6 콜백에 진입한다. fade 또는 첫 저장 worker 대기 중 화면이나 호스트를 트리에서 빼고 즉시 다시 붙인다. 현재 트리 소속만 보는 guard가 이전 요청을 되살려 일차·디스크 본파일/백업을 변경하고 후속 worker를 시작한다. 새 UI 상태와 fade도 이전 작업이 덮어쓴다. 한영 재진입 6조건에서 재현했다.

기준 12조건에서 정상 대조군 2건은 통과하고 만료 소유자 10건은 실패했다. 그중 부팅의 4건은 ERR-0064로 분리한다. 최초 검사 장치의 자동 대기 오류 및 이후 정리 함수에 해제된 Node를 넘긴 타입 오류는 게임 오류에 합산하지 않는다. verbose 원자료에는 종료 Tween 누수와 orphan `finished`도 있다.

## 조치

- 화면 트리 세대, 부모 호스트 세대, 슬롯·기록 scope·coordinator와 요청 동일성을 암전 시작 전에 캡처한다.
- 강하게 보유한 RefCounted 정적 작업에서 대기하고 화면·호스트는 WeakRef로 조회한다.
- Node-bound Tween의 `finished`를 직접 기다리지 않고 SceneTree 프레임에서 소유권과 종료를 검사한다. Tween 색 적용도 매번 소유권을 확인한다.
- 이탈 시 자체 pending·Tween·암전막을 정리한다. 만료된 작업은 교체 UI·재시도 모달을 건드리지 않는다.
- 살아 있는 동일 소유자의 실제 저장 실패는 기존 명시 재시도를 유지한다. ChapterOneController는 기본 화면 종료 처리를 상위 호출한다.
