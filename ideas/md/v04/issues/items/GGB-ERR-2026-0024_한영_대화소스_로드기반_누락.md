## 문제

`GameState`에는 `dialogue_history` 저장 형태가 있지만 `game/data/dialogue/`와 text ID registry, 한국어·영어 문자열을 읽는 repository가 없다. `TECH_01_FOUNDATION`은 두 언어 문자열 소스와 대화 기록 형식의 로드를 완료 조건으로 둔다.

현재 UI 문구는 `main.tscn`과 `bootstrap.gd`에 직접 적혀 있어 이후 사건 대사를 연결하면 ID·placeholder·언어 전환·대화 기록 역참조를 검증할 수 없다.

## 권장 해결안

1. `TEXT_*` ID registry와 한국어·영어 원문 Resource 또는 Godot Translation 리소스를 만든다.
2. `DialogueRepository`가 locale fallback, speaker ID, placeholder 타입을 검증하고 읽기 전용 문자열만 반환하게 한다.
3. production UI의 직접 문자열을 기술 fixture ID부터 교체한다.
4. `dialogue_history.line_id`가 현재 locale 문자열로 재표시되는 smoke를 만든다.
5. 한국어·영어 placeholder 집합과 타입이 다르면 export를 차단한다.

## 완료 조건

- [x] 한국어·영어 text ID를 같은 registry에서 로드한다.
- [x] 누락 ID와 placeholder 불일치가 자동 검사에서 실패한다.
- [x] locale 변경 뒤 기존 대화 기록이 현재 언어로 다시 표시된다.
- [x] production scene·script의 사용자 노출 직접 문자열이 허용된 예외 외 0건이다.
