## 문제와 재현

실제 F3 재선택 복사본의 완료된 표시 커서 또는 커서 없는 월드 상태를 저장한다. 원본 크레딧 화면에서 같은 복사본으로 재진입하고 안내를 닫으면 정상 초기화가 같은 월드를 그리면서 이미 기록한 자료를 다시 관찰한다.

한영 각각 언어를 바꾸지 않은 실행에서도 다음 세 content ID의 버전·변형·segments가 이전 항목과 같은데 새 기록이 추가됐다.

- `NB_FINAL_EDC_SCREEN_NOTICE`
- `NB_FINAL_EDC_SCREEN_REALITY`
- `NB_FINAL_EDC_SCREEN_STAY`

`--notebook-reselect-presentation-smoke --reselect-same-locale --ggb-dev-notebook-v2`의 `completed`, `no_cursor` 사례에서 `RESELECT_KNOWN_DUPLICATE_SURFACE`로 확인한다. `%TEMP%/ggb-reselect-final2-20261004/` 실행은 322개 복원 검사 PASS와 별개로 이 중복을 출력했다. 복원 검사 통과를 중복 방지 검사 통과로 해석하지 않는다.

대화·선택 대기 상태 복원에서는 재현되지 않았다. 이전 기록의 삭제·변조나 퍼즐·지식·관계·엔딩 변화는 관찰되지 않았다. 다른 모든 방에서도 발생한다고 단정하지 않으며 후속 회귀 범위를 넓힌다.

## 원인과 영향

새 컨트롤러가 현재 월드 표면을 다시 등록할 때 메모리상의 요청·발생 토큰도 새로 만들어진다. 동일한 저장 화면의 재표시와 플레이어의 새로운 조사 행동을 구분하는 영속 공개 영수증이 부족하다.

반복 재진입은 같은 자료의 이력을 늘려 검색·페이지 탐색을 혼잡하게 하고 보호 기록 저장량을 불필요하게 키울 수 있다. 실제 용량·지연은 아직 측정하지 않았다. 표시 커서를 정상 복원하는 PA08 수정과는 독립적인 문제다.

## 권장 해결안

1. 현재 월드에서 실제로 공개된 표면의 영수증을 관찰 기록과 원자적으로 저장한다. 실패한 관찰을 공개 완료로 표시하지 않는다.
2. 같은 슬롯·run·원본·분기·장소·표시 문맥의 재개에서만 기존 발생 토큰을 복원한다. 다른 로드의 지연 콜백이 쓰지 못하게 한다.
3. 실제 새 조사, 다른 방 방문 후 복귀, 퍼즐 값·표시 변형 변경은 새로운 발생으로 보존한다. content ID 전체에 대한 전역 중복 제거는 사용하지 않는다.
4. 언어 전환·원문 버전 변경·레거시 영수증 누락의 정책을 명시한다. 기존 공개 범위를 확대하거나 보호·미분류 기록을 소급 삭제하지 않는다.
5. 재시작·재선택·수첩 열고 닫기·저장 실패를 실제 화면 경로로 검사한다.

## 완료 조건

- [ ] 동일 화면의 재시작·재선택으로 새 중복 항목이 생기지 않는다.
- [ ] 새로운 조사·방 재방문·동적 표시 변경은 새 발생을 유지한다.
- [ ] 저장 실패 후 공개 영수증과 기록이 어긋나지 않는다.
- [ ] 슬롯·원본·분기·이전 load scope의 격리를 유지한다.
- [ ] 한국어·영어 및 언어 전환·구 저장 fallback을 검증한다.
- [ ] 기존 기록·책갈피·출처 링크·보호 정책과 게임 snapshot을 보존한다.
