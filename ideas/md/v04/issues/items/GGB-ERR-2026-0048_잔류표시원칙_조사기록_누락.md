## 원인과 영향

`_build_stay_charter`의 `STAY_MODE_NEUTRAL` 버튼은 기억·결정 보존이라는 서사 규칙을 표시하지만 queue에 포함되지 않았다. 클릭 설명도 `_set_status`로만 보여 기록 writer를 거치지 않았다. 설명에는 내부 상태명 `S5`가 노출됐다. 기존 카탈로그에는 해당 두 원고가 없고 잔류 테스트는 버튼을 누르지 않아 다른 ID 전체 커버리지 PASS로 누락을 발견할 수 없었다.

## 해결

`NB_STAY_APPEARANCE_NEUTRAL_LABEL`과 `NB_STAY_APPEARANCE_NEUTRAL_DETAIL` 두 NP19 authored 원고를 추가한다. 라벨은 실제 표시, 상세는 실제 클릭의 상태줄 표시만 획득한다. 기존 118개 ID의 원고는 의미 내용 불변이다. 과거 미분류 문자열은 소급 매핑하지 않는다. 설명만 내부 단계명이 없는 공개 표현으로 바꾼다.

기존 surface 원자 writer·receipt·명시 재시도를 사용한다. 명시적 반복 조사와 재그리기를 구별하며 generation/live scope/정확한 엔딩 노드로 stale callback을 막는다. 실제 외형 방식·기억·관계·정책·엔딩 결정·대사 커서는 바꾸지 않는다.

## 검증과 남은 범위

수정 전 한영의 라벨 누락·상세 누락·내부 ID 노출 6개 실패 단언을 재현했다. 수정 후 집중 112개 PASS. 전체 잔류 suite 10,578개 PASS, 120개 ID의 한영 240조합과 segment 한영 350조합 실행. 디스크 복원, 실패 시 snapshot/슬롯 바이트 보존, 응답 유실 재시도 1회 기록, 클릭 전 상세 미공개, 반복/재그리기, 외부 로드 후 stale 거부 및 원문 언어 변경 재생을 확인했다.

이 항목은 해결됐지만 공개 명칭 전체 ERR-0026과 NP21/생산자 전수 감사는 미완료다. headless 회귀이며 OS 입력/성능 인수가 아니다. [검증 보고서](../validation/2026-10-07_잔류표시원칙_누락조사_수정검증.md).
