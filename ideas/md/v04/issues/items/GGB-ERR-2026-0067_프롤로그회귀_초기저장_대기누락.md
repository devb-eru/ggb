# GGB-ERR-2026-0067: 프롤로그 회귀 검사의 초기 저장 대기 누락

| 항목 | 값 |
| --- | --- |
| 유형 | 오류 ERR |
| 심각도 | 중간 |
| 해결 상태 | VERIFIED |
| 작업 상태 | DONE |
| 우선순위 | P2 |
| 담당자 | Codex |
| 목표 마일스톤 | `FULL_00_CONTENT_COMPLETE` |
| 최초 확인 | 2026-10-10 |
| 영역 | 검사 장치 / 프롤로그 비동기 회귀 |

## 증상과 범위

동일한 고정 제품 소스에서 프롤로그 집중 회귀가 native 1로 끝났다. 검사 장치가 화면 생성 직후 시작되는 비동기 표시 저장을 기다리지 않고 다음 슬롯 seed, 저장소 교체 또는 테스트 대사를 시작한다. 로그에 `seed disk and backup` 실패와 실패한 load 결과의 `snapshot` 접근 오류가 남았다. 초기 실패는 42조건 합격에 포함하지 않는다.

이는 현재 검사 순서의 결함으로 조사한다. 실제 제품의 동시 writer 거부 규칙을 제거하거나 실패 저장을 성공으로 취급하는 수정은 하지 않는다. 화면과 SaveManager 작업이 모두 종료된 뒤 다음 조건을 시작하도록 검사 장치만 보완한다. 실제 제품 결함이 별도로 확인되면 해당 증상은 분리한다.

## 수정·검증 기준

- [x] 최초 실패 stdout/stderr, native 종료 코드와 실행 소스 지문 보존.
- [x] deferred 시작을 포함해 화면 요청·저장 작업의 연속 idle 확인.
- [x] 한영 42조건·486단언/native 0, 기존 원자 저장·재시도·불변 단언을 삭제하지 않고 재검사.
- [x] 같은 265제품 소스의 9회귀/native 0, 독립 56,660확인에서 최초 실패를 구분.
- [ ] develop 선택 전달·사용자 변경 보존.

제품 265개 스크립트의 수정 범위와 검사 장치의 수정 범위를 따로 기록한다. HEADLESS 회귀를 실제 Windows 입력이나 전체 완주로 집계하지 않는다.

검사 장치 수정 중 `pending`의 타입 추론 오류로 중단한 실행도 `before-prologue-parse` 자료로 보존한다. 명시적인 `bool`을 사용한 새 실행의 42조건 PASS와 합산하지 않는다. 연속 idle의 추가 프레임은 worker 진행 프레임 수에 포함하지 않는다.
