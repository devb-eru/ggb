## 재현

기준 develop `121a506`에서 실제 수면 worker 대기 중 세션을 바꾸면 저장 guard는 후보를 거부하지만 `_sleep_now`가 이전 요청의 실패 모달과 상태 문구를 교체 화면에 표시한다. 마지막 내구 단계는 보존되어도 UI 소유권은 보존되지 않는다.

동일 경계에서 저장 서비스를 즉시 제거하면 완료 경로의 `_async_history_enabled`가 해제된 저장 서비스의 `is_inside_tree`를 호출하는 스크립트 오류도 발생한다. 기존 한영 baseline 8조건 중 재진입/세션 교체/서비스 제거의 6조건에서 실패했다. 재진입 저장 문제는 ERR-0060으로 별도 추적한다.

## 조치와 검증

수면 완료 결과에서 행정적 저장 실패와 소유자 만료를 분리한다. 수명 세대·세션·슬롯·actor·epoch가 달라진 경우는 `retired=true`로 반환하고 기존 수면·D6 UI 호출부는 조용히 종료한다. 반면 살아 있는 동일 요청의 실제 저장 실패·언어 전환은 기존 명시 retry 경로를 유지한다. 저장 gate도 actor 생존·삭제 예약을 확인한 뒤 메서드를 호출한다.

- [x] 실제 콜백에서 교체 화면의 상태/모달 오염과 해제 서비스 접근 재현.
- [x] 완료 소유권과 retired 결과를 구분하고 D6에도 적용.
