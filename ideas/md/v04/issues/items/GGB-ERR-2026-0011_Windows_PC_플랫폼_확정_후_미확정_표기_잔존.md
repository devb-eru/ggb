## 문제

Windows PC 데스크톱이 목표 플랫폼으로 확정되고 문서 16에 해상도·DPI·마우스·키보드 기준이 정의되었지만, 상위 문서에는 다음 구식 표현이 남아 있었다.

- 문서 00: `목표 플랫폼 | 미확정`.
- README: 플랫폼 전체를 범위 밖으로 분류.
- 문서 18: `플랫폼·엔진 | 추후 확정 / Godot 예정`.

이 상태에서는 UI·입력·창 생명 주기의 상세 계약이 참고안으로 오해되며, 실제로 아직 미확정인 최소 Windows 버전·하드웨어 사양과 플랫폼 자체가 구분되지 않는다.

## 채택 해결안

- 목표 플랫폼을 `Windows PC 데스크톱`으로 확정한다.
- 기본 입력을 마우스+키보드로 정의하고 키보드 전용 필수 진행을 보장한다.
- 기준 화면 1920×1080, 최소 레이아웃 1280×720, Windows 표시 배율 100~200%를 문서 세트에 반영한다.
- `플랫폼 미확정` 항목은 제거한다.
- 아직 미확정인 항목은 `Windows 최소 지원 버전`과 `최소·권장 하드웨어`로 한정한다.
- 진행 저장 schema 12와 Windows 표시·접근성 프로필 v1을 분리한다.

## 회귀 방지 규칙

1. 플랫폼 자체와 최소 지원 OS·하드웨어 사양을 같은 미확정 항목으로 묶지 않는다.
2. Windows 화면·입력 수치는 문서 16을 기준으로 한다.
3. 실행 플랫폼을 바꾸려면 `00`, `README`, `16`~`18`과 QA 범위를 같은 변경 단위로 갱신한다.
4. 접근성 프로필 변경으로 진행 세이브 schema를 불필요하게 올리지 않는다.
