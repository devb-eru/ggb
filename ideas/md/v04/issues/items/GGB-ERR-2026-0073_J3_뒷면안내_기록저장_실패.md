# GGB-ERR-2026-0073: J3 뒷면 안내의 기록 저장 실패

| 항목 | 값 |
| --- | --- |
| 유형 | 오류 ERR |
| 심각도 | 높음 |
| 해결 상태 | VERIFIED |
| 작업 상태 | DONE |
| 우선순위 | P1 |
| 담당자 | Codex |
| 목표 마일스톤 | `FULL_00_CONTENT_COMPLETE` |
| 최초 확인 | 2026-11-03 |
| 영역 | BlackMirrorController / j3_flip_page / 작성된 관찰 출처 |

## 문제

기준 `33596b3`에서 실제 Controller로 J3 뒷면을 펼치고 안내를 기록하면 저장 오류가 나며 대사 진행이 막힌다. Session은 `NB_EP02_SYS_UI_J3_LIMIT`의 작성된 descriptor를 반환하지만, Controller의 EP02 문장 처리 목록에는 `j3_flip_page`가 빠져 있다. 일반 피드백 경로가 실제 EP02 문장 노드가 아닌 J3 진행 노드로 관찰을 생성하여 작성된 출처 계약과 충돌한다.

새 공개 경계 검사에서 두 언어·세 기억 조건의 여섯 J3 경로가 같은 안내 저장 실패로 중단되었다. 이 결과를 문 기억 복원 버그의 직접 실행 근거로 대신하지 않는다. 뒷면 처리만 교정한 대조군으로 ERR-0072를 분리 재현한다.

## 조치

- [x] 실제 UI 피드백 경로의 공통 저장 실패와 누락된 분기 확인.
- [x] 뒷면 안내를 다른 J3 안내처럼 실제 EP02 행 컨텍스트로 표시·기록.
- [x] 원본/뒷면만 교정한 대조군/최종 후보 및 한영·동기/비동기 검사.
