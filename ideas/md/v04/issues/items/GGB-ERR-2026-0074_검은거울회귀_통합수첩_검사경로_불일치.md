# GGB-ERR-2026-0074: 검은 거울 회귀의 통합 수첩 검사 경로 불일치

| 항목 | 값 |
| --- | --- |
| 유형 | 오류 ERR |
| 심각도 | 중간 |
| 해결 상태 | VERIFIED |
| 작업 상태 | DONE |
| 우선순위 | P2 |
| 담당자 | Codex |
| 목표 마일스톤 | `FULL_00_CONTENT_COMPLETE` |
| 최초 확인 | 2026-11-05 |
| 영역 | black_mirror_smoke / NB-R05 / 통합 수첩 회귀 |

## 문제

`black_mirror_smoke.gd`의 `_validate_view`가 개발 통합 수첩 모드에서도 구형 모달의 `HistoryTranscript`를 즉시 역참조한다. 실제 메뉴는 비동기로 준비하는 통합 수첩을 열기 때문에 해당 라벨이 없다. 최신 후보의 실행에서 `Invalid access to property or key 'text' on a base object of type 'null instance'`가 발생했다.

같은 fixture는 등록되지 않은 `Mirror history shown/unseen` 대사를 엄격한 작성 ID 검사에 넣어 `mirror records only presented line`도 실패했다. 작성된 표시만 수록해야 하는 제품 규칙을 해제할 문제가 아니라, 테스트가 현재 표시 계약을 따라야 하는 문제다. 스크립트 오류가 있는 실행은 다른 검사 결과나 정상 종료 코드로 덮어 통과 처리하지 않는다.

## 조치

- [x] 최신 후보에서 native 실패·스크립트 오류 및 표시 대사 단언 실패 확인.
- [x] 기존 표시/미표시 대사 구분 검사를 실제 등록된 작성 대사로 구성.
- [x] 구형 모달 및 통합 수첩의 실제 진입·준비·본문·닫기 경로를 각각 검사.
- [x] 읽기 전용, 200% 글자, 힌트·세정제 양 비교, 합성 키 입력 및 퍼즐 상태 보존 단언 실행 확인.
- [x] 사용자 확정: C3 5단계·현재 C4 4단계. 구형 H5 정의와 기존 기록은 유지하고 새 H5 요청/관찰이 생기지 않도록 검사한다.
- [x] 보완된 테스트를 포함한 고정 소스로 전체 관련 회귀와 독립 감사 재실행. PCK의 통합 수첩 경로와 기본 모드 실제 시작 씬도 각각 통과.

```yaml
resolved_in:
  - game/scripts/tests/black_mirror_smoke.gd
resolution_summary: 실제 작성 대사와 통합 수첩·C4 확인 절차·제품 Bootstrap을 검사
verification_ids:
  - NB-SHEET-20261105
verified_on: 2026-11-05
```

테스트를 통과시키기 위해 통합 수첩·엄격 작성 ID 검사를 끄거나, 실제 실패를 기대 성공으로 바꾸지 않는다. [검증 기록](../validation/2026-11-03_시트선택_비동기저장_및_공개경계_검증.md)의 중간 실패로 보존하며 최종 성공 실행에 합산하지 않는다.
