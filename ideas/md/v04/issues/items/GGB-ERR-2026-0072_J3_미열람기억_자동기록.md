## 문제

기준 develop `33596b3`에서 기억 선택을 건너뛰어도 `j3_restore`는 차 기억 `MEM_FATHER_TEA_HAND_FRAGMENT`만 보고 문 기억 플래그와 `J3_MEMORY` 원문을 기록한다. 열람 자격이 실제 열람 증거로 사용되었다. 기존 skip 검사는 이후 다시 기억을 읽고 복원하므로 skip-only 경로를 입증하지 못한다.

## 조치

- [x] 독립 정적 검토와 직접 호출 경로 확인.
- [x] 건너뛰기→미열람 복원→재로드의 부정 대조 및 실제 열람의 정상 대조.
- [x] Controller와 Session의 실제 장면 관찰/완료 판정 공유. 건너뛴 새 기억의 획득·원문 자동 생성을 제한.
- [x] 정당한 과거 기억·원문 보존, 같은 후보의 관련 회귀와 독립 감사.

resolved_in:

  - game/scripts/chapters/black_mirror_controller.gd
