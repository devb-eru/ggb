# F0~F2 핵심 서사 현지화 현황

## 1. 범위

2026-09-14 기준으로 F0-A~F0-E, F1·J5, F2의 실제 플레이 화면에 `ko-KR`·`en-US` 표시 계층을 연결했다. 퍼즐 판정, 정답, 이벤트 ID, 상태 플래그와 저장된 한국어 정본은 변경하지 않는다.

포함 범위:

- F0-A 방·방위·포트·회로 조작과 약한 신호 피드백
- F0-B 표본명·조사 기록·유지/연출 판정 피드백
- F0-C 중첩 설명·조작·진단 결과
- F0-D 기록명·역할 슬롯·검증 결과
- F0-E 과거 표시·현재 작성자·세 가지 비구속 임시 의향
- F1 아버지의 마지막 기록 8개 구간과 기록실 조사
- J5 마지막 페이지와 주인공의 두 줄
- F2 다섯 질문, 필수 사실, 관계 상태별 이리스 공개 수준, 종료 문장
- F0~F2 코어 접근로·기록실 위치 머리글
- 위 구간에서 실제 표시된 영문 화자명과 문장의 대화 기록 저장

## 2. 표시 계약

`game/scripts/ui/core_story_texts.gd`가 표시 문자열을 소유한다. 시스템 규칙은 기존 한국어 정본을 반환하고, `BasementController`가 현재 언어에 따라 표시 직전에 변환한다.

- 저장 상태에는 퍼즐 키·선택 키·정본 문장을 그대로 보존한다.
- 언어 전환은 퍼즐 배열, 관계 수치, 일지 단계와 엔딩 의향을 변경하지 않는다.
- F0-E의 `reality`, `stay`, `undecided`는 영어에서도 모두 동등하게 노출한다.
- F1의 원본 음성, 사후 시스템 기록과 편집 이력의 출처 구분을 번역에서도 유지한다.
- F2의 관계 분기는 공개 수준만 바꾸며 필수 사실 여섯 개와 다음 단계 진입 가능 여부는 바꾸지 않는다.
- 번역 사전에 없는 문장은 임의 번역하지 않고 정본 문자열을 그대로 반환한다. 회귀 검사는 정상 경로의 모든 핵심 서사 문자열을 번역 대상으로 등록했는지 확인한다.

## 3. 자동 검증

`BASEMENT_SESSION_SMOKE`가 다음을 검증한다.

1. F0~F2 UI ID의 한·영 값이 모두 존재한다.
2. F0-A 방·포트, F0-B 여덟 표본, F0-D 다섯 기록, F0-E 표시 조각과 세 임시 의향을 영어로 표시한다.
3. F1 여덟 기록 구간과 J5, F2 다섯 질문과 여섯 필수 사실을 영어로 표시한다.
4. 실제 F0-A~F0-E, F1, F2 화면의 목표와 조작 버튼이 영어로 다시 그려진다.
5. 실제 성공 피드백과 J5·F2 종료 문장이 영어 대화 기록에 `viewed_locale=en_US`로 저장된다.
6. 한국어 표시와 퍼즐·관계·엔딩 상태는 기존 정본을 유지한다.

검증 결과:

- Godot 4.7.2 프로젝트 가져오기: 통과
- `BASEMENT_SESSION_SMOKE`: 통과

## 4. 남은 현지화

이 작업만으로 전편 영어 완료를 선언하지 않는다. 프롤로그 후반, 1~3장의 일부 동적 오류·공통 상호작용, E 구간 후속 반응과 전편 수첩·대화 기록을 같은 방식으로 전수 대조해야 한다. 이후 영어 연속 완주에서 한국어와 같은 진행·관계 결산·두 엔딩에 도달하는지 확인한다.

## 5. 현재 작업 중단선

현재 개발 순서는 다음 세 단계까지만 진행한다.

1. 전편 영어 진행 완성
2. 관계 `LOW`, `MID`, `HIGH`, `ALL` 경로 검증
3. Windows에서 마우스 전용·키보드 전용 실제 완주

최종 아트·BGM·SFX 교체와 해당 리소스를 전제로 한 연출 보강은 외부 리소스가 준비된 뒤 재개한다. 이 대기는 최종 제품 범위 삭제가 아니라 현재 작업 순서의 경계다.
