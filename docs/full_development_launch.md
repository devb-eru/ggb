# 본편 개발 실행

Godot 편집기 실행 파일로 프로젝트를 실행할 때만 다음 인자를 사용할 수 있다.

```powershell
& 'C:/경로/Godot.exe' --path 'C:/Beru/Projects/Games/ggb/game' -- --ggb-dev-full
```

- `--` 뒤는 게임 사용자 인자다. 프로젝트 설정 파일은 저장하거나 변경하지 않는다.
- 실행 중에만 full 모드로 동작하며, 다음 일반 실행은 기존 설정을 따른다. 기본 demo 실행은 그대로 유지한다.
- 본편 저장은 `user://saves_full`, 데모 저장은 `user://saves`를 사용한다. 새 게임은 P1에서 시작하며, 완료한 데모는 타이틀의 명시적 가져오기 절차를 거쳐 D6로 이어진다.
- 일반 로드로 데모 저장을 직접 불러오지 않는다. 가져오기는 데모 원본과 기존 본편 슬롯을 덮어쓰지 않는다.
- 기존 본편 저장이 있으면 이 개발 실행에서도 보인다. QA는 APPDATA/LOCALAPPDATA를 별도 임시 프로필로 지정한 격리 환경에서 진행한다.
- `editor` 기능이 없는 내보낸 게임은 이 인자를 무시한다. 정식 본편의 flavor·배포·권한 설정을 대체하는 기능이 아니다.
- 엔딩까지 초기 코드 경로가 존재하지만 최종 콘텐츠, 아트·음향, 영어, 입력별 완주 검증은 미완료다. 크레딧 제작진은 미정이다.
