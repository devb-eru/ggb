# 타이틀 데모 저장 가져오기

- full 타이틀에서만 가져오기 버튼을 제공한다. 검증 가능한 제품 데모 슬롯을 선택하고 원본 보존·빈 슬롯 사용·D6 재개를 확인한다.
- 초기 포커스는 닫기이며 취소는 파일과 게임 상태를 변경하지 않는다.
- 확정 직전에 백엔드 검증을 다시 실행한다. 성공한 새 슬롯만 정규 불러오기 신호로 전달한다. 실패하면 원본 보존 안내와 오류 ID를 표시한다.
- 타이틀 테스트: demo 진입 차단, full 확인창, 취소 기본 포커스, 취소 시 상태 보존.
- 복제·D6 로드·원본 바이트 보존은 demo_import_validation의 백엔드 회귀 범위다. 실제 제품 슬롯의 전체 클릭 성공 경로와 해상도별 시각 검증은 후속 QA다.
- 현재 기본 실행 flavor는 여전히 demo다. 공개 빌드 전환을 임의로 수행하지 않는다.

## 확인 버튼 성공 경로 회귀

- `basement_session_smoke.gd`에서 실제 퍼즐 진행으로 만든 D5 완료 테스트 저장을 사용한다.
- full 타이틀 생성 후 가져오기 버튼을 누르고, 제품 슬롯을 보호하기 위해 후보 목록만 `__test_` 저장으로 교체한다. 확인 버튼의 실제 신호와 저장 백엔드는 교체하지 않는다.
- 확인 버튼이 불러오기 신호를 정확히 한 번 보내고 확인창을 닫는지 검사한다. 전달된 슬롯을 정규 LoadCoordinator로 불러와 D6 재개와 데모 원본 바이트 보존을 검사한다.
- 결과: `BASEMENT_SESSION_SMOKE: PASS`. 생성된 테스트 복제본은 제거한다.
- 확인 버튼의 불러오기 신호는 실제 bootstrap에 연결한다. 생성된 `Basement` 화면이 복제 슬롯을 사용해 D6로 진입하고 타이틀이 숨겨지는지 확인한다. 타이틀 복귀 후 화면 복구도 검사한다.
- 이 검증은 제품 후보 검색부터 실제 입력 장치 클릭까지의 종단간 검증을 대신하지 않는다. 해당 범위와 해상도별 시각 검증은 남아 있다.
