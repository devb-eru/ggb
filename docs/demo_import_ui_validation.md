# 타이틀 데모 저장 가져오기

- full 타이틀에서만 가져오기 버튼을 제공한다. 검증 가능한 제품 데모 슬롯을 선택하고 원본 보존·빈 슬롯 사용·D6 재개를 확인한다.
- 초기 포커스는 닫기이며 취소는 파일과 게임 상태를 변경하지 않는다.
- 확정 직전에 백엔드 검증을 다시 실행한다. 성공한 새 슬롯만 정규 불러오기 신호로 전달한다. 실패하면 원본 보존 안내와 오류 ID를 표시한다.
- 타이틀 테스트: demo 진입 차단, full 확인창, 취소 기본 포커스, 취소 시 상태 보존.
- 복제·D6 로드·원본 바이트 보존은 demo_import_validation의 백엔드 회귀 범위다. 실제 제품 슬롯의 전체 클릭 성공 경로와 해상도별 시각 검증은 후속 QA다.
- 현재 기본 실행 flavor는 여전히 demo다. 공개 빌드 전환을 임의로 수행하지 않는다.
