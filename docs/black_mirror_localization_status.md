# 검은 거울 구간 현지화 현황

## 기준일

2026-09-14

## 범위

`C_SLEEP~J3_COMPLETE`의 필수 진행 화면을 한국어와 영어로 표시한다. 검은 거울 세션의 한국어 원문, 5:1:2 배합 정답, 90도 회전·비반전·하단 고정·네 구간 경로 정답, 물리 실패와 수면 복구 조건은 변경하지 않는다.

## 구현 구조

- `black_mirror_display_texts.gd`가 목표, 공간·버튼, 재료·경로·채널 명칭, 동적 상태판과 세션 피드백을 담당한다.
- `BlackMirrorController`는 현재 언어로 표시한 뒤 입력 ID와 저장 값은 원래 값을 사용한다.
- `ChapterOneController._display_feedback()`을 표시 전용 확장점으로 두어, 상속된 이동·일과 문구는 1장 사전을 사용하고 검은 거울 문구는 전용 사전을 사용한다.
- 수첩은 저장된 한국어 정본을 읽을 때만 번역한다. 알 수 없는 과거 문자열은 원문으로 남긴다.

## 영어 표시 범위

| 구간 | 포함 내용 |
| --- | --- |
| C_SLEEP~C2 | 다음 아침 조건, 거울 금지, 에드가의 경고, 청소 기록과 약품 라벨 |
| C3 | 8단위 상태판, 세 재료, 투입·확산·혼합·침전·시험·폐기, 시험지 결과 |
| C_BELL | 대시계 설명, 열세 번째 신호 재현, 다음 목적지 |
| C4/CF | 중첩 상태, 회전·반전·기준점, 다섯 경로 조각, 마른 시험, 순찰 대응, 되돌릴 수 없는 실행과 수면 복구 |
| C5_INFO | 진단면·수첩 사본, 다섯 인격 채널의 이름·문양·음향, 대조 완료와 기록 |
| J3 | 네 문장 조각, 중첩 모순, 배열·복원, 아버지의 문 윤곽 기억 조각 |
| 공간 | 거울 회랑, 청소도구실, 주방 조합대, 색분해실 외부와 각 복귀 동선 |

색 채널은 영어에서도 이름, 선·문양과 음향을 함께 표기한다. 색상만으로 출처나 정답을 판단하게 하지 않는다.

## 검증 기준

`BLACK_MIRROR_SMOKE`는 기존 고난도 퍼즐의 유일해, 실패 뒤 수면과 `CSHORT`, 고경계 순찰, C5 다섯 채널, J3 복원을 유지하면서 다음을 추가 검사한다.

1. C4 실제 화면의 위치, 목표, 비교·실행 버튼과 확인창이 영어로 표시된다.
2. 모든 목표·UI·재료·경로·채널·고정 세션 피드백에 영어 대응이 있다.
3. 마른 시험의 동적 접두어와 수첩 진단면의 채널 출처가 영어에서도 보존된다.
4. 저장된 J3 한국어 원문은 영어 수첩에서 번역되며 게임 상태는 변하지 않는다.

## 한계

이 문서는 검은 거울 구간의 표시·회귀 완료 근거다. 최종 거울·약품·투명지 아트와 실제 음향을 완료로 판정하지 않는다. 전편 영어 완주를 위해서는 지하창고와 D5~E6의 남은 동적 문구를 계속 대조해야 한다.
