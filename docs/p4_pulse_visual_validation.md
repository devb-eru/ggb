# P4 전조 개발용 시각 연출

검토일: 2026-09-13

## 연결

우림 단계의 세 감각 대사에 `p4_pulse` 연출 메타데이터를 추가했다. 첫 문장에서 주전자 바닥과 쥐 모양 귀의 반응을 동시에 두 번 표시한다. 각 반응은 0.65초의 완만한 곡선이며 시작 시점은 0초와 0.9초다. 바닥 반응은 2.05초에 한 번 시작한다. 자동 진행이나 시간 제한은 없다. 빠르게 다음 문장을 읽으면 정적 귀·바닥 강조로 전환한다.

`prologue_pulse_art.gd`는 개발용 도식이다. 최종 주방 오브젝트·루카 초상화 위의 연출 완료가 아니다. 수첩, 관계값, 정답, 저장 구조는 변경하지 않는다. 최종 음원 없는 기존 `AUD_SIG_LUCA` 요청을 유지하며 실제 음향 완성으로 간주하지 않는다.

색 외에 귀 윤곽 변화와 주전자 아래 이중 선, 바닥 반원으로 대응을 표현한다. 움직임 감소/정지 설정은 정적 도식이며 기존 감각 문장으로 순서와 의미를 전달한다. 도식은 마우스 입력을 가로채지 않고 무관한 대화에서는 숨긴다. 운영체제 포커스 이탈은 기존 게임 트리 일시정지 규칙을 따른다.

## 검증

- 프롤로그 Windows OpenGL smoke PASS: 두 맥박 최대값, 바닥 반응 지연, 정적 모드 처리 중단, 다른 대화에서 숨김, 진행 상태 불변.
- 1280×720·본문 200% 정적 도식 캡처 확인: 대화창·마침 버튼과 겹치지 않는다. 테스트는 이미 진행한 장면 위에 대화를 주입한 배치 검증이며 주방 전체 아트 승인 근거가 아니다.
- 1장 headless smoke PASS: 공유 컨트롤러 회귀.
- 인증서 저장소 경고 외 SCRIPT ERROR 없음.

남은 작업: 최종 주방·루카 리소스에 부착, 주전자 두 음과 늦은 바닥 응답 실제 청취 검증, 전체 접근성·입력 완주. 본 검증은 전편 콘텐츠 완료 판정이 아니다.
