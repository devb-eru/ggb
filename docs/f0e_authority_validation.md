# F0-E 현재 권한 인증 초기 구현

## 연결 범위

F0-D 이후 A1 표시 재현→현재 작성자 확인→비공개 비구속적 의향으로 진행한다. 문장·집 도형·잉크 유형을 저장된 self_authored_mark.type에서 읽는다. 유형이 없는 손상·구형 기록은 임의로 다른 표시로 바꾸지 않고 안내한다. 완료 뒤 F1_PENDING으로 합류한다.

문장은 당시 조각, 집은 지붕→몸체→문, 잉크는 세 접촉 순서를 재현한다. 현재 작성자는 주인공 직접 작성만 인정하며 외부 기록은 국소 재시도한다. 현실·잔류·미정 의향은 모두 같은 진행과 보상을 제공하고 ending_run 및 사용인 관계 상태를 변경하지 않는다. 인증·의향 단계와 완료 이력은 캠페인 저장에 포함된다.

## 검증

basement-session-smoke: 표시 3유형×의향 3종, 단계 우회 거부, 외부 작성자 3종 거부, 직접 작성, 부분·완료 저장 재개, 최종 결정·관계 상태 불변, 세 의향 버튼 존재. 캡처 user://f0e_intent.png.

## 미완료 범위

현재 직접 작성과 획순은 버튼·문장 조각을 사용하는 초기 표현이다. 연필 입력·필기음·종이 질감·동일 길이 15~25초의 의향 연출은 미완료다. 잉크 세 접촉의 실제 위치 원자료도 A1과 함께 정밀화해야 한다. 최종 선택 화면의 중립 포커스는 향후 EDC에서 별도 검증한다. F1/J5·F2/F3·두 엔딩은 아직 구현 대상이며 F0 전체 경험 완성을 의미하지 않는다.
