# 감상 기록 열람 화면

## 현재 연결 범위

- 크레딧 완료 화면의 `감상 기록 · 마지막 장면과 조사` 버튼으로 진입한다.
- 보존된 사본만 목록에 나오며 4개 단위 페이지를 지원한다. 미래 버전·손상 파일은 저장소 검증에서 제외한다.
- 현실은 실제 조사한 시설 오브젝트와 마지막 시선, 잔류는 실제 조사한 홀·식탁 오브젝트, 작성한 문장과 마지막 자리만 텍스트 페이지로 열람한다.
- 식탁 관계 대사는 해당 오브젝트 감상 이력이 있을 때만 당시 상태로 구성한다. 다른 분기나 ALL 장면을 추정하지 않는다.
- 순수 페이지 생성 함수와 기존 모달 UI를 사용하며 GameState 설치, session 행동 호출, 파일 저장은 하지 않는다.
- 닫기·목록 복귀·이전·다음 버튼을 제공한다.

## 검증

- 미조사 오브젝트·미작성 문장을 제거한 사본은 최종 프레임 한 페이지만 생성한다.
- 실제 완료 사본의 페이지 생성과 모달 열람 후 GameState 및 원본 progress 바이트 불변을 검사한다.
- 기존 챕터 및 기반 회귀를 함께 실행한다.

## 미완료 범위

- 이것은 전체 엔딩 영상 재생기가 아니다. 엔딩 도입·작별·현실 수첩 전체·ALL 의식 등은 아직 갤러리 페이지에 포함하지 않는다. UI에도 범위를 명시한다.
- 현재 목록 진입점은 크레딧 완료 화면이다. 타이틀 갤러리, 최종 배경·캐릭터 연출, 녹음된 소리·영상 재생, 최대 글자 크기 및 화면 크기별 시각 QA는 남아 있다.
- 세부 상태 차이로 여러 보존 사본이 존재할 수 있으며 목록의 중복 장면 묶기는 후속 작업이다.
