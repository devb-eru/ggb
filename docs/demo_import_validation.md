# 데모 저장 본편 복제 기반

- full 실행에서만 데모 저장을 명시적으로 검사한다. 일반 로드의 flavor 거절은 유지한다.
- 기존 읽기 검증으로 schema·design revision·checksum을 확인하고 source app·slot·demo flavor·D5 boundary를 추가 확인한다. 상태 정규화 후 D5 완료, 파열 후 수면 미실행, 엔딩 미선택을 요구한다.
- 본편의 비어 있는 제품 슬롯에만 복제한다. 기존 폴더가 있으면 손상·빈 폴더라도 자동 덮어쓰지 않는다. 모든 제품 슬롯이 있으면 거절한다.
- 복제본은 SAVE_FRACTURE_CONFIRMED로 저장해 D6로 재개한다. 데모 원본은 읽기만 하며 D5 종료점을 바꾸지 않는다.
- debug 테스트 슬롯은 별도 __test_import_ 목적지를 사용해 실제 제품 슬롯을 건드리지 않는다.
- 검증: 정규 본편 로더 통과, D6 재개, 사용인 상태 보존, 원본 바이트 불변, 경로 이탈 입력 거절.
- 가져오기 확인 UI·슬롯 선택 정책 확장·손상 및 미래 버전의 사용자 안내·백업만 존재하는 데모 복구는 후속 작업이다. 현재 UI에는 아직 연결하지 않았다.
