# 플레이어 안내와 내부 식별자 분리

2026-11-02 사용자 승인: 일반 플레이에는 자연어 안내를 표시하고, 내부 식별자가 포함된 원문은 개발자 확인용으로 보존한다. Google Sheets와 가져온 원문 데이터는 수정하지 않는다.

## 표시 원칙

- 내부 식별자를 정규식으로 일괄 삭제하지 않는다. 명시적인 문구 대응표를 사용한다.
- 수식의 `A`, `S`, `W`나 세계 안에서 보이는 `LIFE SUPPORT` 표기는 개발용 식별자로 취급하지 않는다.
- 실패 원인은 감각적 반응과 자연어 원인으로 전달한다. 내부 category는 실패 데이터와 개발자 확인 자료에 그대로 남긴다.
- 기존 수첩 관측의 내용과 버전을 덮어쓰지 않는다. 새 플레이어 문구는 별도 버전으로 추가하고, 새 공개부터 사용한다.
- 원문 보존과 플레이어용 표현은 구분한다. 원문을 유지했다는 이유만으로 일반 플레이 화면에 내부 ID를 노출하지 않는다.

## 후보 구현

`sync_ep02_player_text.py`는 위 16개 노드의 원문 한국어·영어 상태를 대조한 뒤 플레이어용 정의를 `ep02_player_versions.json`에 추가한다. 원문이 바뀌면 검토 없이 대응표를 재사용하지 않고 오류를 낸다. 원본 `ep02_runtime.json`과 `ep02_sheet_v1.json`은 수정하지 않는다.

새 공개의 `Ep01Script.text`, `line`, 세션 조사 문구 및 상태 안내는 해당 내용의 최신 버전을 사용한다. 저장된 관측은 기록 당시의 버전을 유지한다. 실제 실패 category나 아이템 ID는 표시 문구와 별개이며 바꾸지 않는다.

일반 플레이에서 숨긴 원문은 개발자가 원본 런타임 및 원문 카탈로그에서 확인할 수 있다. 별도의 원문 표시 메뉴를 일반 플레이에 추가하지 않는다.

최신 EP02 전체 동기화 검사 3,347개와 생성·원문·과거 버전 보존 검사 14개가 통과했다. J3 실제 확인·재로드·저장 거절·기억 건너뛰기/재생 검사는 47개가 통과했다. C5와 J3 완료 안내는 실제 기록 및 원문 대화 완료에 연결한다. 안내만 읽어서는 조사나 물질, 복원, 후속 공간을 획득하지 않는다. 이 수치는 실제 OS 입력이나 최종 아트·음원 검증을 뜻하지 않으며, 실제 프로젝트 배포 및 전체 목표 완료는 별도 확인한다.
