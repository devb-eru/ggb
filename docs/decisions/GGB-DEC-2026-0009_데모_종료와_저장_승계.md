## 결정

데모의 플레이 가능 범위는 D4 완료까지다. 이후 본편 D5의 2~3분 전환을 `presentation_variant=demo_stinger`의 60~90초 비상호작용 스팅어로 축약해 보여 주고 `SAVE_D5_COMPLETE`를 만든 뒤 `DEMO_END_SCREEN`으로 이동한다. 본편 D5와 같은 완료 상태를 사용하므로 내용을 두 번 완료 처리하지 않는다.

데모와 정식판은 별도 `build_flavor`와 AppID를 사용한다. 정식판은 데모 원본을 보존한 채 호환 검사, 미리보기, 슬롯 충돌 확인과 migration을 거쳐 저장을 가져온다. 자동 공유를 전제로 하지 않는다.

## 결과

- D5는 데모에서 3장 플레이 분량으로 계산하지 않는다.
- 데모 registry는 E1 이후 사건을 실행하지 않는다.
- 데모에서 `SAVE_D5_COMPLETE`를 불러오면 `DEMO_END_SCREEN`, 본편에서 생성하거나 승인된 import로 변환한 같은 경계는 `D6_FREE_INSPECTION`으로 재개한다.
- 저장 헤더에 flavor, build, 콘텐츠 경계와 출처 AppID를 기록한다.
- 초반 안전 지점과 정상 리셋 완료 저장을 제품 계약에 포함한다.
