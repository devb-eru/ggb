## 결정과 이유

1. 개인 자유 메모는 이번 범위에 넣지 않는다. 사용자 노트의 별도 수명·초안 복구 구현을 분리해 자료 재열람을 우선한다. 기존 A1 자기 표식·SUBJECT 인증·사건 가설 작성은 제거하지 않는다.
2. 보호되지 않은 일반 대사는 최신 2,000개를 유지한다. 보호 기록과 기존 미분류 legacy는 별도 페이지로 모두 보존하며 일반 창의 수량을 차지하지 않는다. 보호만 2,001개여도 새 일반 대사가 즉시 삭제되어서는 안 된다. 구형 기록을 이관했다고 normal로 간주해 일괄 삭제하지 않는다.
3. 비교 자료는 여러 개 담고 두 개씩 본다. B4/C5/D4 세 자료를 모두 담아 교체할 수 있어야 하며, 수첩 비교는 읽기 전용이다. 실제 회전·배선·중첩·정답 판정은 원 퍼즐에서 수행한다. 낮은 해상도·200%에서는 A/B 전환 열람을 제공한다.

## 영향과 경계

- [데이터 계약](../data_contract.md) 7.1절 등의 기존 전체 2,000개 표기는 구현 2단계에서 새 기준으로 동기화한다. 승인된 미래 정책과 현재 적용 중인 코드/계약을 혼동하지 않는다.
- 책갈피와 비교 자료의 보존 이유는 슬롯의 원자 저장 대상이다. 스크롤·신규 배지 같은 비필수 UI 상태와 분리한다.
- 보호/legacy 증가로 저장량이 늘 수 있다. 목록 페이징·선택 본문 렌더링·성능 계측을 실시하되 저장 실패를 성공으로 표시하거나 원문을 몰래 폐기하지 않는다.
- DEC-0006의 확인한 대사/선택 보존, ID 기반 현재 언어 표시, 미래 내용 금지 규칙은 유지한다. 전체 기록 무제한 보존 약속으로 확대 해석하지 않는다.
- 초기 책갈피 50개·비교 묶음 12개·페이지 50개는 구현 계획의 권장값이며 이번 사용자 선택의 핵심 정책과 구분한다. 수치를 조정해도 정보 공개·기록 보호 원칙을 바꾸지 않는다.
