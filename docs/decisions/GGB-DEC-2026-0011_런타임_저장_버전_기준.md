## 결정

첫 배포 가능한 런타임 저장은 `schema_version=1`로 시작한다. 기존 문서의 `schema 12`는 기획 상태 모델의 열두 번째 개정이므로 `design_revision=v0.4-state-r12`로 분리한다.

실제 배포한 저장 형식이 바뀔 때만 `schema_version`을 올리고 migration fixture를 보존한다. 존재하지 않는 런타임 schema 1~11을 지원하는 변환 코드는 만들지 않는다.

저장 헤더에는 `game_version`, `build_id`, `build_flavor`, `content_revision`, `content_boundary_id`와 `source_app_id`를 분리해 기록한다. 대화 기록은 진행 슬롯의 명시적 상태 루트로 저장한다.
