## 결정

v0.4 접근성 규칙을 데모와 정식판의 제품 기준으로 승격한다.

- 마우스 전용과 키보드 전용 필수 경로를 모두 지원한다.
- 최소 1280x720, UI 90~220%, 텍스트 100~200%를 지원한다.
- 색, 소리와 모션에 의존하는 필수 정보에는 대체 표현을 둔다.
- 키 재지정, 포커스 복원, 첫 실행 접근성 설정을 필수로 둔다.
- 게임패드, 터치와 콘솔은 1.0 범위에서 제외한다.

## 이유

이 기능들은 후반에 덧붙이는 옵션이 아니라 UI 구조, 퍼즐 데이터와 포커스 순서에 영향을 준다. 제품 문서의 축소된 약속을 유지하면 v0.4를 구현한 뒤 다시 구조를 바꿔야 한다.

## 검증

문서 정합성만으로 완료하지 않는다. 버티컬 슬라이스와 데모 빌드에서 입력별 완주, 200% 레이아웃, 색·음향·모션 대체를 각각 검증한다.
