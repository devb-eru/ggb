# GGB-DEC-2026-0013: EP01 수정 대사 재생 시점

시트의 A1 표식 작성 직후에 배치된 ‘남아있어, 어제 그 흔적...’ 독백은 Godot에서 다음 아침의 표식 확인 때 재생한다. 사용자는 ‘다음 아침의 표식 확인 때 재생’을 선택했다. 표식 작성 직후에는 해당 독백 직전에서 멈춘다. 시트의 행 순서와 한국어 대사는 변경하지 않는다.

프롤로그의 첫 취침부터 EP01의 새 대사와 선택지를 적용한다. 사용자는 ‘첫 취침부터 반영·미번역은 한국어 표시’를 선택했다. 첫 아침 선택지는 실제 정상 리셋이 끝난 다음 표시하며, 답변을 읽은 뒤 챕터를 인계한다. 영어 번역이 비어 있는 새 대사는 한국어 원문을 표시한다.

이전 저장 파일이 참조하는 대사·수첩 버전은 유지한다. 새 문장 표식은 버전 3으로 기록한다. 정상 리셋 순서와 퍼즐 판정은 기존 Coordinator 및 Session을 사용한다. 선택지와 읽던 문장의 저장·불러오기, 첫 리셋과 챕터 인계는 `ep01_sheet_smoke.gd` 및 프롤로그 회귀 검사로 확인한다.

근거는 2026-10-27 이 대화의 두 질문에 대한 사용자 답변과 [작업·검증 기록](../implementation/ep01-sheet-sync/work-item.md)이다.
