## 결정

2026-11-20에는 공개 데모 콘텐츠 락 하나만 주요 제작 게이트로 둔다. 같은 날이던 전편 콘텐츠 완료 목표는 분리하고 기술 기반선, 버티컬 슬라이스, 1장 알파, 데모 기능 완료, 현지화 락, 전편 콘텐츠 완료와 출시 후보를 독립 게이트로 관리한다.

마일스톤 날짜는 구현 전 잠정치다. 버티컬 슬라이스 완료 뒤 실제 공수와 팀 가용시간으로 전부 재산정한다. 공개 일정과 품질이 충돌하면 범위를 숨기지 않고 정식 출시일을 이동한다.

## 용량 원칙

- 주 7일·56시간을 공통 가용시간으로 가정하지 않는다.
- 개인별 실제 가용시간은 확인된 값만 사용한다.
- 계획 가능 시간의 최대 70%만 신규 제작에 배정하고 나머지는 검토·수정·휴식·차단에 둔다.
- 주말과 초과 근무는 일정 복구 수단으로 선반영하지 않는다.
