## 반영 내용

- 프롤로그 P3 질문의 공식 응답 7줄·4줄과 P4 아버지 차 질문 6줄을 끝까지 재생한다. 화자·초상화 메타데이터와 중간 줄 저장을 지원하며, P4는 마지막 응답 이전에 완료되지 않는다.
- EP01의 일상 허브, 에드가 대화, 표시 조건, 선택지 기록, 마지막 행 이후의 완료 효과를 연결한다. 수첩 표식 작성과 다음 아침 확인을 구분한다.
- EP02의 C0 선택 응답, C1~J3 진행·문서·오브젝트 조사·짧은 관계 반응·숏컷·성공/실패 목격 분기를 연결한다. 원본에서 ID가 없었던 보충 행은 승인받은 내부 ID로 보존한다.
- 지원은 `bond >= 4`, `alert < 4`를 기준으로 한다. 직접 개입한 에드가를 우선하며 다른 목격자는 실제 현장에 있어야 한다.
- 마라 1은 거울 회랑, 마라 2는 색분해실 외부, 이리스는 온실에서 대화한다. C5 정보 기록 후 온실 일반 구역만 열며 기능실은 D5 이후 조건을 유지한다.
- C3의 물 없는 첨가제, 안정제 미확산 상태의 원액 투입은 소비 없이 차단한다. 잘못된 양·과교반·잘못된 젖은 실행은 실제 실패로 유지한다.
- C4 확인의 기본 선택은 실행이 아닌 재검토다. 실제 동작과 기록 저장을 분리하지 않으며 저장 거절·재로드로 실행이나 선택이 중복되지 않도록 한다.
- C5는 신체와 인격 채널 확인을 필수로 하고 다섯 사용인 채널 조사는 선택으로 둔다. SUBJECT를 여섯 번째 사용인으로 취급하지 않는다. 실제 조사·기록 이전에 완료나 영구 해금을 부여하지 않는다.
- J3에 세 기준점, 앞뒤 페이지 비교, 조각 집기·놓기를 추가한다. 정밀 방향 확정은 D0에 남긴다. 선택 기억 조사는 건너뛰거나 다시 읽을 수 있고 퍼즐 정답이나 진도를 대신 부여하지 않는다.
- 내부 ID가 포함된 상태 문구는 일반 플레이에서 자연어로 표시한다. 감각 자막·문양/이름 대체·저소음 안내는 실제 접근성 설정과 상태에 연결한다.

## 재검증

`sheet_sync_smoke.tscn`과 `sheet_legacy_choice_smoke.tscn`은 게임 프로젝트의 테스트 씬이다. `sheet_sync_regression.tscn`은 `--sheet-regression=notebook_mirror_smoke`, `--sheet-regression=full_campaign_smoke`로 실행할 검사를 선택한다. 실제 플레이 저장과 분리한 사용자 데이터 경로에서 실행한다.

`scripts/sync_*_sheet.py`와 보조 생성기는 읽기 전용 CellData 스냅샷을 입력으로 받는다. 인증 정보나 Google Sheets 쓰기 권한을 요구하지 않는다. 새 버전 반영 시 이전 카탈로그와 baseline을 전달하고 과거 기록을 보존한다.
