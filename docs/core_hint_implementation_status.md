# F0 메타퍼즐 직접 요청형 힌트

## 범위

v0.4 이벤트 상세 08의 F0-A~E와 `24-3_메인퍼즐_고난도개정안.md`를 기준으로, 실제 판정 코드의 포트·변환·기록 역할·자기 인증 규칙과 대조했다. 기존 수첩 지원을 확장하여 현재 F0 단계의 한·영 힌트만 제공한다.

| 단계 | H1에서 H5까지 좁혀 가는 정보 |
| --- | --- |
| F0-A | 방 기능·출입력 → 북·서 고정 포트 → 유지와 피드백 순환 → 기준 방 → 온실·주방·침실·내실의 방위와 출력 |
| F0-B | 표층과 유지 데이터 구분 → 장면 정지 후에도 남는 신호 → 연결 장치 → 생체·기억 인덱스 → 네 유지 표본 |
| F0-C | 세 자료 역할 → 고유 기준점 → 변환 구분 → B4·C5 방향 → 완전 중첩과 PATH·SPLIT·AUTH 조사 |
| F0-D | 출처와 역할 구분 → 다섯 기능 → 생성·관리·거주·자동 실행 → 주인공 직접 기록 → 다섯 기록 역할 대응 |
| F0-E | 과거·현재 확인 분리 → 실제 A1 유형 → 작성 주체 → 직접 작성 → 세 임시 의향의 동등성과 최종 선택 분리 |

## 플레이어 선택 보호

- 색을 끄거나 소리가 없어도 문장과 자료 의미로 읽을 수 있다. 색은 출처이며 역할 정답의 근거로 취급하지 않는다.
- F0-D에서는 연구원 개인 기록을 모으지 않았을 때 익명 기능 인덱스를 사용할 수 있음을 안내한다. 관계 이벤트 완료 수를 새로운 통과 조건으로 만들지 않는다.
- F0-E는 현실·잔류·미정 모두 같은 다음 단계로 합류한다고 명시한다. 특정 임시 의향을 추천하거나 최종 결말로 확정하지 않는다.
- A1 표시 유형을 다른 것으로 바꾸거나 누락된 과거 기록을 힌트로 만들어 주지 않는다.
- 자동 퍼즐 입력·인증·권한·엔딩 변경은 하지 않는다. 더 강한 내용은 직접 요청할 때만 표시한다.
- 실제 읽은 문장만 기존 슬롯 대화 기록에 남긴다. 읽기 메뉴만 열거나 닫아도 해답 전체가 저장되는 구조가 아니다.

## 검증 범위

후반 회귀 테스트의 F0 단계별 진행 사이에 수첩 지원 검사를 추가했다. 각 단계에서 버튼으로 5개 힌트를 읽고 표시 원문과 영구 기록 수를 비교한다. 대화 기록 외의 GameState가 불변인지 검사하므로 퍼즐 입력·관계·임시 의향·최종 엔딩 값도 비교 대상이다.

기존 F0-E의 A1 세 유형과 임시 의향 세 종류 조합, F0 이후 두 엔딩 회귀는 유지한다. 이는 자동 세션·버튼 신호 테스트이지 모든 마우스·키보드 실입력이나 영어 전편 검수를 대신하지 않는다.

격리 프로젝트의 `BASEMENT_SESSION_SMOKE`가 신규 F0 힌트 검사와 기존 후반 회귀를 포함해 통과했다.

## 남은 지원 기능

- 반복 가설·오답 유형별 자동 제안과 선택적 구성 요소 고정.
- 관계 퍼즐의 단계형 지원 및 이전 자료를 직접 나란히 보는 통합 화면.
- 전체 힌트의 사용자 난이도·인지 부담·플레이타임 측정.
- 영어 화면과 큰 글자·입력 장치별 실제 검증.

단계형 지원의 직접 요청 문장은 추가했으나, 전체 게임 또는 힌트 시스템의 모든 기획 요구가 완료된 것은 아니다.
