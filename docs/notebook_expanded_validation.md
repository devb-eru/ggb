# 현장 수첩 상세 본문 열람 이력

- UI의 읽기 확인 버튼은 `{page, expanded}`를 전달한다. 단순히 펼치거나 닫는 것으로 감상 완료를 추정하지 않는다.
- 상세 본문에서 읽기 확인을 누르면 `FIELD_NOTEBOOK.expanded_pages`에 중복 없이 기록한다. 요약 확인과 필수 페이지 진행 조건은 그대로 유지한다.
- 기존 문자열 페이지 ID 입력은 요약 확인으로 호환한다. 예전 저장의 pages를 상세 본문 감상으로 소급 해석하지 않는다.
- 갤러리는 pages와 expanded_pages에 모두 있는 페이지에만 기존 상세 본문·관계별 인계 부기를 표시한다. 나머지는 요약이다.
- 테스트: 기존 저장 요약 유지, 명시적 상세 확인, 중복 확인, 잘못된 플래그 거절, 갤러리의 정확한 본문 선택.
- 전체 엔딩 영상·ALL 의식 및 최대 텍스트 크기 시각 QA는 별도 잔여 작업이다.
