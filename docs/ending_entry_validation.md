# 전원 의식 및 엔딩 진입부 구현

검증 결과: 격리된 Godot 4.7.2에서 `BASEMENT_SESSION_SMOKE: PASS`, `FOUNDATION_SMOKE: PASS`. 스크립트 오류 없이 완료했으며 서명 화면을 시각 확인했다. Windows 루트 인증서 저장소 읽기 경고는 별도 환경 경고다.

## 범위

`ED_ALL_CEREMONY`, `EDR_ENTRY`, `EDR_ARCHIVE_STATUS`, `EDS_ENTRY`, `EDS_STABILIZE`를 구현했다. 최종 결정 이후 단계이므로 결정 변경이나 관계 보상은 없다.

전원 의식은 EDC에서 다섯 핵심 관계 완료 시에만 배정된다. 인물별 이름·문양·소리 설명, 마라 2의 분산 백업 확인, 에드가의 SUBJECT 우선권 확인, 서명 순으로 진행한다. 인물 대사를 끝까지 확인한 시점에 인덱스를 저장한다. 대사 도중 종료하면 해당 인물부터 다시 시작하며 완료 인물은 반복하지 않는다.

서명은 마우스로 한 번 선을 긋거나 자동 서명 버튼으로 진행한다. 글자 인식·오답·제한 시간은 없으며 짧은 움직임 뒤 다시 그려도 실패하지 않는다. 비활성 창에서는 안내 시간이 흐르지 않으며 입력 없는 4초 뒤 자동 서명을 제안한다. 자동 서명은 키보드로 선택할 수 있고 처음부터 사용 가능하다. 실제 필기 자국은 현재 장면의 임시 시각 정보이며 저장 복원 시 다시 긋는다. 선택 자체는 다시 묻지 않는다.

현실과 잔류의 서명 후 변형은 현재 텍스트로 표현한다. 서명색 애니메이션·실제 인격별 음향·전용 코어 배경은 최종 리소스 작업으로 남아 있다.

## 엔딩 진입

| 분기 | 적용 | 다음 미구현 노드 |
| --- | --- | --- |
| 현실 | 자동 저전력 보존 안내, 삭제 선택 없음, 다섯 채널 `low_power` | `EDR_FAREWELL` |
| 잔류 | S5 안정화, 현재 기억 유지, 다섯 채널 `active`, 정상 리셋 미복구 | `EDS_MEMORY_CHARTER` |

보존 상태는 `meta_progress.knowledge_entries.ending_resident_channels`에 다섯 ID와 함께 기록한다. 현재 데이터 기반 상태이며 연구원과의 장기 대화 시스템이나 현실 시설 시뮬레이션을 구현한 것으로 간주하지 않는다. 잔류의 `fracture_state.world_phase`는 S5이고 필터 파열 및 수면 잠금을 유지한다. 엔딩 장면에서 실제 수면을 실행하지 않는다.

## 저장

- 기존 확정 저장과 호환되며 첫 엔딩 행동 시 `ending_run.completed_nodes`와 `all_ceremony_seen`을 추가한다.
- `completed_nodes`는 중복 없는 문자열 집합으로 정렬 저장한다.
- 의식의 인물 인덱스와 권한 확인은 `loop_state.event_local_states.ED_ALL_CEREMONY`에 보관한다.
- 매 완료 단위는 `SAVE_ENDING_NODE`로 저장한다. 실패 시 기존 세션 커밋의 전체 롤백을 사용한다.
- 이전 노드의 늦게 도착한 확인 입력, 다른 분기의 노드, 인증 단계 건너뛰기를 거부한다.

## 검증 범위

`basement_session_smoke.gd`의 `_validate_ending_entry`는 두 분기 각각 의식 없음/전원 의식의 네 경로를 검증한다. 인물별 저장·불러오기, 중복 확인 거부, 관계와 결정 불변, 마우스 서명/자동 서명, 엔딩 노드 재개, 다섯 채널 보존, 잔류 S5를 확인한다. `FOUNDATION_SMOKE`는 확장된 저장 스키마 회귀 검증이다.

의식의 화면 캡처는 `user://ending_signature.png`다. 기본 해상도에서 서명 영역과 자동 서명 버튼을 확인한다. 모든 해상도, 실제 음향·연기, 필기 애니메이션 및 접근성 설정 전수 검증을 의미하지 않는다.

## 후속 구현

다음은 현실의 관계 합성 작별·연결 해제·신체 기상·현실 수첩·시설/지표 조사, 잔류의 기억/외형/자율성 원칙·식탁 후속 이야기다. 이후 크레딧, 엔딩 메타, 재선택 사본, 갤러리까지 연결해야 한다. 현재 경계 화면은 `ENDING_BODY_PENDING`이며 게임 완성을 뜻하지 않는다.
