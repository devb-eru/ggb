# 지하창고 숏컷 상태 구분

## 의도와 수정

지하창고 접근 숏컷은 성공 후에도 정상 리셋으로 닫힌 문을 다시 여는 기능이다. 완료 후 영구 폐기하는 시계·거울 실패 재준비와 구분한다.

기존 UI는 실패 기록이나 접근 권한의 존재만으로 버튼을 표시했다. 실행부도 이미 열린 문과 해결된 실패를 명시적으로 제외하지 않았다. `can_use_basement_shortcut()`을 UI와 실행부가 공유하도록 변경했다.

- 실패 재준비: 같은 침실, 검증한 도면, 활성 실패, 닫힌 문, 당일 잠금 해제일 때만 허용한다. 검증된 깊이만 준비하고 축 밀기는 직접 한다.
- 성공 후 재개방: 접근 경로를 이미 검증했으며 정상 수면으로 물리 문이 닫힌 경우 허용한다. 실패 기록이 해결되었더라도 이용할 수 있다.
- 이미 열린 문, 파열로 위장 필터가 해제된 상태, BROKEN_RESET 이후에는 두 경로를 재실행하지 않는다.
- J3 복원 당일에는 원래처럼 먼저 잠든다.

## 검사 범위

후반부 회귀에 실패 당일 차단, 수면 뒤 준비 허용, 문 개방 후 두 경로 차단, 거절 시 상태 보존, 다시 수면한 뒤 성공 접근 숏컷으로 재개방하는 경로를 추가했다. 기존 파열 이후 이전 장치 절차 거절과 엔딩 경로도 같은 회귀 실행에서 확인한다.

이 검사는 세션 행동과 상태 전이를 다룬다. OS 입력으로 지하·관계·엔딩 전편을 완주했다는 의미는 아니다.

최종 `BASEMENT_SESSION_SMOKE` 실행은 통과했다. 최초 실행에서 테스트 스냅샷 변수의 타입 추론 오류로 검사가 시작되지 않았으며, `Dictionary`를 명시한 뒤 다시 실행한 결과다.
