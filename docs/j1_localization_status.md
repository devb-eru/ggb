# J1 일지 복원 현지화

## 적용 범위

- 압지 세 조각의 단서, 앞뒤 표시, 뒤집기, 배열 초기화, 눌림선 확인, 선택 순서와 복원 페이지를 기존 한·영 카탈로그에 연결했다.
- 준비 부족, 이미 복원됨, 잘못된 조각, 순서 불일치, 앞뒤 불일치에는 표시용 텍스트 ID를 반환한다.
- 성공 피드백은 한국어 원문과 `CH1_J1_RESTORED`를 함께 저장한다. 재실행 시 표시 언어에 맞게 렌더링한다.
- 기존 수첩의 J1 원문은 정확히 일치할 때만 열람 언어로 변환한다. 저장 원문이나 표시 당시의 대화 기록을 다시 쓰지 않는다.
- 정답은 원래 조각 ID 순서 `0, 1, 2`와 세 조각 앞면이며 변경하지 않았다. 영어 번역도 시간 표면을 불신하는 단서, 전달 역할, 완료 뒤 한 칸의 소리를 보존한다.

## 검증과 한계

1장 회귀에서 영어 조각·조작 표시, 한국어 정본과 카탈로그 일치, 원문 보존, 표시 과정의 상태 불변, 복원 저장 재개를 검사한다. 기반 시스템 회귀는 추가 텍스트 레지스트리와 카탈로그를 포함해 통과했다.

서재 일반 오브젝트 관찰, B3와 J2 이후 전체 본문, 각 언어 200% 화면·실제 입력 완주까지 완료했다는 뜻은 아니다. 번역은 개발 구현본이며 최종 편집 검토가 필요하다. 임시 아트와 원래 퍼즐 배치는 유지했다.
