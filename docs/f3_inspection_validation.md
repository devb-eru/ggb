# F3 마지막 확인 초기 구현

저장 스키마는 fracture_state.final_sleep_lock을 선택적 불리언으로 허용한다. 이전 저장에는 필드가 없어도 유효하며, F3 진입 시 true를 원자 저장한다. 잘못된 타입과 다른 미등록 필드는 계속 거부한다.

기상 장치·안정화 장치·수첩 3종 조사, 균형 요약, 최종 선택 확인 진입을 연결했다. 두 장치는 같은 크기로 배치하며 임시 의향을 레이아웃에 사용하지 않는다. 수첩에서만 임시 의향을 사실·불확실성과 구분해 표시한다. 마지막 조사 장치의 반대쪽부터 균형 요약을 제공한다.

세계 내 수면은 final_sleep_lock으로 막고 저장·불러오기는 유지한다. 3종 조사와 요약 전에는 선택 확인을 열 수 없다. F3_complete는 SAVE_F3_COMPLETE에 기록한다. 취소하면 조사로 돌아가고 ending_run은 변경하지 않는다.

검증 범위: 조사 순서 6종, 선택 우회 거부, 수면 잠금, 부분·완료 저장 재개, 화면 요약·진입 버튼, 취소 뒤 최종 결정 미정 유지. 화면 캡처 user://f3_inspection.png.

현재 EDC_PENDING 개발 경계까지 연결했다. EDC 확정 트랜잭션과 두 엔딩은 아직 구현하지 않았다. 전용 코어실·장치 아트와 공기·코일·음향 연출은 남아 있다. 현재는 기존 기록실 배경과 텍스트를 사용한다. 전편 완성이나 최종 선택의 동작을 의미하지 않는다.
