# 엔딩 이후 재선택 UI

## 플레이 경로

1. 원본 슬롯의 크레딧을 마친다.
2. `다른 선택 확인 / 사본 이어하기`를 누른다.
3. 새 사본 생성은 취소가 기본인 별도 확인창을 거친다.
4. F3 당시 상태로 만든 새 슬롯을 정규 LoadCoordinator로 불러온다. 이후 저장 대상도 새 슬롯으로 변경한다.
5. 종료 후에는 원본 슬롯을 불러와 같은 메뉴에서 해당 사본을 이어간다. 목록은 한 페이지에 4개이며 이전·다음 페이지를 지원한다.

## 원본 보호

- 재선택 사본의 knowledge에 원본 슬롯 ID와 원본 run_id를 기록한다. 목록은 두 값이 현재 원본과 일치하는 별도 슬롯만 표시한다.
- 임의의 기존 슬롯을 목적지로 지정하지 않는다. 로드 직전에도 허용된 사본 목록에 속하는지 다시 확인한다.
- 크레딧 완료 전에는 이 화면에서 생성·이동할 수 없다. 사본 출처를 검증할 수 없으면 새 사본 버튼을 노출하지 않는다.
- 재선택은 세계 내 리셋이 아님을 설명한다. 원본 관계와 엔딩 결과를 수정하지 않는다.

## 검증

- Godot import 검사 및 basement-session 회귀 테스트에 메뉴 열기·취소, 생성 확인, 새 슬롯 이동, 사본 행동 후 원본 progress 바이트 불변, 목록 재발견을 포함한다.
- 정규 로더가 스냅숏과 헤더를 검증한다. 깨진 사본은 자동으로 고친 것처럼 표시하지 않는다.

## 남은 범위

- 현재 이어하기 진입은 원본 엔딩 완료 화면을 경유한다. 타이틀의 재선택 전용 목록은 없다.
- 목록은 개발용 저장 지점 ID로 진행 위치를 표시한다. 최종 한국어 진행명, 시각 QA 및 최대 텍스트 크기 검증은 남아 있다.
- 현재 목록은 유효한 primary가 있는 사본만 표시한다. 백업만 남은 사본의 별도 복구 UI는 미구현이다.
- 갤러리, 최종 리소스 및 최종 엔딩 연출은 별도 잔여 작업이다. 크레딧 제작진은 미정 유지한다.
