# 잔류 기억·외형·자율성 원칙 구현

검증 결과: 격리 Godot 4.7.2에서 `BASEMENT_SESSION_SMOKE: PASS`, `FOUNDATION_SMOKE: PASS`. 외형 선택 화면의 중립 포커스와 표시 안내를 시각 확인했다. 스크립트 오류는 없으며 Windows 인증서 저장소 경고는 별도 환경 경고다.

## 구현 범위

`EDS_MEMORY_CHARTER → EDS_APPEARANCE_CONTROL → EDS_AUTONOMY_CHARTER → EDS_CENTRAL_HALL`을 연결한다. 중앙홀의 후속 조사는 다음 구현 경계다.

세 기억 원칙을 개별로 읽고 유지한다. 시뮬레이션이라는 사실, 연구원 인격과 감금 책임, 수면·기상·기억 변경의 명시적 확인 원칙이다. 기억 삭제 선택지는 없고 실제 다음 수면도 실행하지 않는다.

외형은 `layered`와 `contextual` 중 명시적으로 선택한다. 기본 포커스는 중립 안내 영역이다. 전자는 시설 프레임과 출처 라벨을 항상 표시하고, 후자는 조사 표시를 켰을 때만 프레임을 보인다. `FILTER: DISPLAY ONLY`와 가역성 안내를 유지한다. 현재 시설 골격은 임시 선과 라벨이며 최종 고딕/SF 레이어 아트가 아니다.

다섯 사용인 역할을 고정에서 제안으로 전환한다. 관계 미완료 인물도 포함하며 주 공간·휴식 선택, 경고와 이동 봉쇄의 분리, 에드가의 일정 제안, 다른 인격의 기억·이름 단독 삭제 금지를 명시한다. 자율성 확인은 관계 보상을 주지 않는다.

## 상태와 저장

- 읽은 원칙과 제안으로 바꾼 owner는 `loop_state.event_local_states.STAY_CHARTER`에 중복 없이 저장한다.
- 세 완료 오브젝트는 `ending_run.required_interactions_seen`, 완료 노드는 `completed_nodes`에 기록한다.
- `EDS_truth_memory_confirmed`, `EDS_servant_autonomy_confirmed`는 지식 상태에 기록한다.
- 외형은 `ending_run.ending_appearance_mode`이며 미존재/`unset` 저장도 읽는다. 확정 외형 값은 잔류 분기에만 허용한다.
- 외형 재선택은 표시 값만 바꾸고 최종 선택·관계·파열 상태를 변경하지 않는다. 단계 완료 뒤에도 시스템 API로 재선택 가능하며 현재 자율성 화면에는 재선택 UI가 있다. 이후 중앙홀·식당에도 이 UI를 이어 붙여야 한다.
- 각 원칙·스위치·완료 전환은 `SAVE_ENDING_NODE`로 저장한다.

## 검증 범위

관계 미완료와 전원 완료의 두 조건에서 세 원칙 읽기·부분 저장 재개, 원칙 생략 거부, 외형 중립 포커스, 두 외형 선택과 변경, 미선택 진행 거부, 다섯 역할 확인과 부분 저장 재개, 다음 중앙홀 노드, 수면 잠금, 관계·파열·최종 결정 불변을 확인한다. `unset` 호환과 잘못된 외형 거부도 검사한다.

외형 화면 캡처는 `user://stay_appearance.png`다. 실제 후속 일과의 NPC 자율 행동, 전용 레이어 아트·애니메이션·음향, 모든 해상도 및 접근성 조합은 아직 구현/검증 범위 밖이다.

## 후속 작업

중앙홀 선택 조사, 식당의 관계별 좌석·대화·작은 오브젝트 이야기, 필수 수첩 펼치기, 잔류 최종 프레임을 이어야 한다. 양쪽 크레딧·엔딩 메타·재선택·갤러리 및 전편 최종 QA도 남아 있다.
