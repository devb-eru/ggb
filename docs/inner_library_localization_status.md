# 기록 내실 조사 현지화

## 적용

책상·색인함·서랍·숨을 벽감·일지 여백·초상화 뒤 걸쇠의 조사점 이름과 관찰 문장을 한·영 카탈로그에 연결했다. 걸쇠를 연 뒤의 숏컷 기억 설명도 별도 문구로 제공한다.

조사 결과에 에드가의 방문 전조가 붙는 경우 `CH1_INNER_*_VISIT`로 두 내용을 함께 표시한다. 본문 번역 때문에 발소리나 잠금쇠 묘사가 사라지지 않는다. 정상 조사와 방문 동반 조사는 원문과 표시 ID를 함께 저장하며 불러온 뒤에도 구분한다.

방문 임계치, 마라 2 기록의 보조 효과, 중복 조사 경계 누적 방지, 숨기·대면 이후 조사 재개는 변경하지 않았다. 발견에 강제 실패를 추가하지 않았다. 새로운 단서나 정답도 추가하지 않았다.

## 검증

- 1장 회귀: 평상시 색인 조사와 방문을 동반한 서랍 조사 구분, 방문 전조 저장 재개, 영어 벽감·걸쇠 조사점, 일곱 관찰의 본문과 발소리 결합.
- 기존 검사: 정상·높은 경계에서 에드가 대면 후 실패 없이 합류, 숨기 후 재합류, 반복 조사 경계 누적 방지.
- 기반 시스템·검은 거울 회귀와 함께 확인한다.

이 문서는 1장 전체 현지화 완료를 의미하지 않는다. 시계망·후속 일지 본문, 영어 편집 검토, 고배율 화면과 실제 입력 완주는 별도 확인 대상이다.
