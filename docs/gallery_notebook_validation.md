# 감상 기록: 현장 수첩·출입 점검

- 보존된 `FIELD_NOTEBOOK.pages`에 포함된 페이지의 요약만 기존 FieldNotebook 데이터로 표시한다.
- 기존 저장은 요약과 펼친 본문을 구분하지 않으므로 상세 본문과 관계별 인계 부기는 추정해서 공개하지 않는다. 상세 본문 재생은 별도 열람 이력 추가 후 연결해야 한다.
- `required_interactions_seen`에 실제 존재하는 전력·외기·수동 해제 점검만 재생한다.
- 페이지 순서는 신체 확인, 수첩, 출입 점검, 시설 조사, 마지막 시선이다. 저장 이력이 없는 항목은 생략한다.
- 회귀 테스트는 수첩 미열람 숨김, 한 페이지 확인 시 한 페이지만 추가, 상세 본문 미공개, 출입 점검 한 항목 추가를 검사한다.
- 전체 엔딩 영상·ALL 의식·잔류 합의·수첩 상세 본문 재생은 아직 미완료다.
