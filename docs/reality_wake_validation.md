# 현실 작별·연결 해제·신체 기상 구현

검증 결과: 격리된 Godot 4.7.2에서 `BASEMENT_SESSION_SMOKE: PASS`, `FOUNDATION_SMOKE: PASS`. 신체 확인 화면을 캡처해 버튼·완료 표시를 확인했다. 이후 추가한 현실 수첩 우회 차단까지 챕터 테스트를 재실행해 통과했다. 스크립트 오류는 없으며 Windows 인증서 저장소 읽기 경고는 별도 환경 경고다.

## 구현 노드

`EDR_FAREWELL → EDR_DISCONNECT → EDR_WAKE_BODY → EDR_BODY_CHECK → EDR_FIELD_NOTEBOOK`로 연결한다. 마지막 노드는 다음 구현 경계이며 현실 수첩 본문은 아직 열리지 않는다.

## 작별 합성

- 다섯 사용인의 기록을 모두 제공하며 관계 미완료 시 전문 기능 또는 관찰 가능한 행동만 보여 준다.
- 관계 완료 시 공통 작별에 두 outcome별 인계 행동을 합성한다. bond·alert는 연기 지문에만 사용하며 관계 수치를 변경하지 않는다.
- 이리스는 F2와 같은 읽기 전용 고백 상태 계산기를 사용한다. 사적 고백을 공개적으로 다시 낭독하지 않으며 엔딩 선택으로 고백을 승격하지 않는다.
- 마라 2는 병합/분리 인덱스와 이름 기록에 따라 인계 문구를 달리한다.
- outcome, 완료 이력, 연구원 기록 상태가 어긋나면 일반 완료 대사를 유지하고 `ENDING_OUTCOME_INTEGRITY_WARNING` 및 owner별 경고를 기록한다. 엔딩을 차단하지 않는다.
- `EDR_ARCHIVE_STATUS`에서 이미 저전력 전환했으므로 이후 작별은 **연결 해제 전에 남긴 인계 기록의 마지막 재생**으로 명시한다. 보존 인격과 실시간 질의응답을 하는 것으로 연출하지 않는다.

## 저장 및 상호작용

인계 대사를 끝까지 확인한 뒤 owner 인덱스를 저장한다. 대사 도중 종료하면 해당 인물부터 재개한다. 저장 실패 시 기존 상태를 유지한다. 이미 확인한 인물의 늦게 도착한 확인 입력은 거부한다.

연결 해제는 난로 열기 소실, 귀의 압력, 금속 맛을 텍스트로 순서대로 보여 준 뒤 총 1초의 화면 페이드를 거친다. 이후 `location_id=R0_CRYO_CHAMBER`, `world_phase=R0`로 저장한다. 첫 호흡은 자동 성공이며 QTE·연타·타이밍 판정이 없다. 물리 공간에서는 저택 배경 대신 임시 중성 배경을 사용한다. 최종 냉각실 아트와 음향·호흡 애니메이션은 남아 있다.

신체 확인은 손, 호흡 표시기, 고정 벨트 중 고유 2개가 필요하다. 재조사 시 짧은 감각 문장으로 바뀌고 중복 보상을 주지 않는다. 2개를 확인한 뒤에도 세 번째를 조사할 수 있으며 수첩으로 진행하는 입력을 따로 둔다.

`ending_run.required_interactions_seen`에 오브젝트 ID를 중복 없이 정렬 저장한다. 완료 시 `EDR_BODY_CHECK`를 `completed_nodes`에 추가하고 수첩 노드로 전환한다. 각 단계는 `SAVE_ENDING_NODE`를 사용한다. 기존 확정 저장과도 호환된다.

현실 공간에서 공통 수첩 단축키를 누르면 시뮬레이션 수첩이 아니라 별도의 물리 수첩을 찾아야 함을 안내한다. 가상 수첩 페이지를 현실에서 그대로 펼치는 우회는 차단한다.

## 검증 범위

- 각 사용인의 두 outcome별 읽기 전용 합성.
- 관계 미완료/전원 완료 시 다섯 인물 작별 UI와 인물별 저장·재개.
- 끝까지 읽기 전에는 인계 인덱스가 증가하지 않음.
- 연결 해제 페이드 후 실제 공간 ID·R0 상태 전환.
- 세 대상 중 가능한 두 개의 조합 3종, 중복 조사, 확인 부족 시 진행 거부.
- 완료 저장 재개와 현실 수첩 경계 진입, 관계·최종 결정 유지.

전체 엔딩 완성, 모든 bond/alert·고백 조합의 연기 QA, 최종 리소스 품질을 뜻하지 않는다. 호흡 묘사는 게임 내 허구 장면이며 현실의 의료 지침으로 제공하는 UI가 아니다.

## 후속 구현

현실 현장 수첩의 표지·초기 72시간·연구원 인계·작은 일화, 출입 패널과 시설·지표 조사, 최종 프레임이 남아 있다. 잔류 기억/외형/자율성 원칙과 후속 이야기, 양쪽 크레딧·재선택·갤러리도 미완성이다.
