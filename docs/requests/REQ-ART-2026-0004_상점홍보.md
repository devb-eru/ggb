## 4. 제작 기준

- 게임 화면을 사용하는 항목은 원본 장면의 `location_id`와 `source_event_id`를 납품표에 기록한다.
- 실제 Steamworks 규격은 착수 시 `beru`가 관리자 화면에서 확인해 작업표에 첨부한다. 확인 전 픽셀 수치를 최종값으로 고정하지 않는다.
- 캡슐과 스크린샷은 승인된 게임 캐릭터·공간·UI를 사용하며 별도 가짜 플레이 화면을 만들지 않는다.
- 구체 색상은 아트팀이 제안한다. 작은 크기에서도 로고·실루엣·고딕/기계 재질 차이로 식별돼야 한다.
- 주인공과 마라 2의 성적 대상화, 현실/잔류 엔딩의 우열 암시, D5 이후 핵심 스포일러를 금지한다.
- 한국어와 영문 로고의 고유명사는 확정 명칭을 사용하고, 그 외 납품·상태 설명은 한국어로 기록한다.
