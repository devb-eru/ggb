## 2. F0 공통 원문

각 단계는 `enter`, 대상 조사, 입력, 유효/무효, 힌트 3단, 로컬 재시도, 접근성 대체, 검토, 확정, 성공, 반복 요약을 가진다. 이전 퍼즐을 그대로 반복하지 않고 그 결과를 새로운 분류·교차 검증에 사용한다.

| stage | 필수 원문·정보 |

| F0-A | 입력·중계·출력·제외 회로, 타일 회전/교환, 피드백 충돌. B3 역할 카드 이름을 그대로 답으로 쓰지 않음 |

| draft segment_id | 내용 | 검증·주의 |
| --- | --- | --- |
| `DRAFTDOC_EP06_F1_01` | 지구 환경 붕괴와 복구 불확실성 | 정확한 연도·현재 생존자 유무는 미확정으로 남김 |
| `DRAFTDOC_EP06_F1_02` | 주인공을 냉각 장치에 보관한 이유 | 보호·치료·미래 기상 의도와 동의 부재를 함께 기록 |

| `DRAFTDOC_EP06_F1_04` | 연구원들에게 “미래에 새로 살아갈 수 있다”고 설명 | 동의 문구의 범위와 모호함을 원문으로 보여 줌 |

각 구간은 재생·일시정지·이전/다음·수첩 대조·사용인 기록 링크가 있다. 아버지 기록만으로 사실이 확정되지 않고 `REC_*`, J1~J4, 기계 로그와 대조해 필수 사실을 구성한다.

## 5. J5 역할

- J4가 연구원 전환과 책임을 결산한다면 J5는 아버지 기록의 빈칸·모순과 주인공의 현재 문장을 연결한다.
- `journal_stage=5`는 모든 사람이 화해했다는 뜻이 아니다.
- J5 새 항목: 확정된 사실, 여전히 모르는 사실, 아버지가 주장한 것, 연구원 기록이 반박한 것, 주인공이 직접 정할 것.
- E3 기록 0~5개에 따라 출처 표시가 달라져도 F2 필수 사실 6개는 최소 recap으로 보장한다.

## 7. 분량·완료 조건

- 원문 후보 700~1,000행: F0 피드백 360~520, F1 180~260, J5·조사 90~130, 자막·UI 70~90.
- F0-D는 기록 0~5개·E3_5 미완료에서 모두 해결 가능하고 없는 사실을 생성하지 않는다.
- F0-E 3입력의 길이·시각/음향 비중·확인 횟수·F1 진입 결과가 같다.
- F1 8구간의 주장마다 출처·확실성·대조 링크가 있고 아버지의 설명을 자동 진실로 취급하지 않는다.
