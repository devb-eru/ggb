## 4. 퍼즐 원문

### D0-A

- 저택 지도·지하 도면·거울 추적지 선택, 회전, 반전, 기준점 고정, 부분 일치, 모순 표시, 성공.
- C5를 기억하지 못하는 플레이어를 위한 수첩 링크, 자동으로 답을 놓지는 않음.

### D1

- 축 선택·깊이·압력 시험·검토·비가역 실행·HARD FAILURE·성공.
- 실패 시 “처음부터”가 아니라 확인된 축과 압력 관계가 수첩에 남고 `DSHORT`가 열린다고 안내.
- `DSHORT`는 서재 단서와 이동을 축약하지만 D1의 새 입력은 플레이어가 한다.

### D4

- 손잡이·기어열·XII·+1 기동부를 이전 퍼즐의 문법으로 읽게 한다.
- 로컬 재시도 가능, 최종 기동은 별도 확인. “확정 실패”가 아니라 `위장 필터 해제`라는 내부 의미.
- 성공 문구는 장치 정상 기동까지만. 이어지는 D5가 세계를 갈라 놓는다.

## 5. D5 전환 문구

| 순간 | 화면 텍스트·자막 방향 |
| --- | --- |
| 기동 | “기어가 맞물린다”보다 XII 옆 빈 홈이 한 칸을 받아들였음을 구체적으로 표현 |
| 필터 박리 | 벽·피부·의상이 부서지는 게 아니라 외피가 투명해지고 고정구·배선이 드러남 |
| 사용인 잔상 | 각자의 문양·소리·명칭 병행; 색만 나열 금지 |
| 입력 회수 | 플레이어 조작이 잠시 회수됨을 시스템 자막으로 고지 |
| 데모 | 저장 상태와 본편 인계 지점을 명확히 표시, “실패”·“나쁜 결말” 금지 |
| 본편 | `D6`로 이어질 수 있는 자유 조사 상태임을 표시하되 데모 빌드에는 노출하지 않음 |

## 6. 목표 분량·완료 조건

- 원문 후보 330~500행: 대사 80~120, 조사 70~100, 퍼즐 110~170, 문서 30~50, D5/데모 UI·자막 40~60.
- D1 실패 4단과 DSHORT, 성공이 같은 사실을 모순 없이 공유한다.
- D5는 폭발·죽음·게임 오버가 아니라 세계 규칙 전환이며, demo/full 문구만 다르고 정본 사건 결과는 같다.
- 데모 종료는 저장 승계·피드백·상점 이동을 제공하되 본편 미구현 구간에 진입시키지 않는다.
