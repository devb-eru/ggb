## 1. ID 정책

정식 registry가 있는 `REC_*`, `FIELD_NOTEBOOK_COVER`, `FIELD_NOTEBOOK_FIRST_72_HOURS`, `SUBJECT_HANDOFF_PAGE`는 그대로 사용한다. 나머지는 승인 전 `DRAFTDOC_*`이며 콘텐츠 락 때 정식 `DOC_*`를 발급한다.

## 5. 문서 완료 조건

- 모든 문서에 발견 위치, 작성자, 페이지, 필수/선택 정보, first/repeat, 수첩 요약이 있다.
- 필수 단서는 읽지 못한 경우 힌트·recap으로 얻을 수 있지만 문서를 읽으면 비용 없이 이미 안다고 표시한다.
- 진행 무관 일화는 “쓸모없음”으로 평가하지 않는다.
- 아버지 단독 기록이 연구원 기록보다 자동으로 높은 진실 등급을 갖지 않는다.
