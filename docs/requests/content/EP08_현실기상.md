## 2. 작별·저전력 보존

- 인격 채널은 별도 선택창 없이 모두 저전력 보존한다. 관계 LOW에서도 삭제하지 않는다.
- 다섯 사용인의 현실 반응은 관계 완료/미완료, outcome, bond/alert, 이리스 고백, 마라 2 이름 상태를 합성한다.
- 완료 인물은 떠나는 결정을 존중하며 개인적인 보존 표식을 남긴다. 미완료 인물은 친밀한 고백 없이도 길을 막지 않는다.
- 에드가는 마지막까지 다나까체로 절차를 보고하고 가지 말라는 감정을 직접 명령으로 바꾸지 않는다.
- “우리는 영원히 살고 넌 늙어 죽는다” 같은 독한 농담은 애착을 숨기는 한 문장으로만 쓰고 현실 위험을 조롱하지 않는다.

## 6. 마지막 프레임·크레딧

- 주인공은 수첩을 한 손에 들고 다른 손으로 문틀과 실제 바람 압력을 확인한다.
- 마지막 자유 시점 8초 동안 신호를 자동 확대하지 않는다.
- 문구: `ED_A 현실 기상`, `FINAL DECISION: REALITY`.
- 어디로 향하는지, 다른 생존자가 있는지, 얼마나 살 수 있는지는 확정하지 않는다.
- 크레딧 뒤 이어하기·엔딩 갤러리·`SAVE_F3_COMPLETE` 사본에서 다른 선택 보기·타이틀을 제공한다.
