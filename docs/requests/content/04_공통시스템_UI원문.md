# GGB 공통 시스템·UI 원문 패키지

## 1. 범위

이 문서는 에피소드 사건과 별개로 모든 빌드에 필요한 메타 UI·시스템·접근성 문구를 소유한다. `source_event_id`가 없는 메타 문구는 `SYSTEM`을 사용하고 `state_writes`는 지정된 시스템 writer만 허용한다.

## 3. 시스템 상태 문구

| content_item_id | trigger·source_event_id | state_reads | state_writes | repeat_policy |
| --- | --- | --- | --- | --- |
| `CNT_SYS_NORMAL_SLEEP` | `NORMAL_SLEEP` | pending event, world phase | none; 확인 뒤 system request | per_loop |
| `CNT_SYS_COMMIT` | `SYS_COMMIT` | pending persistent deltas | transaction commit | per_loop |
| `CNT_SYS_MEMORY` | `SYS_MEMORY` | witnessed/emotion memory | residual memory commit | per_loop |
| `CNT_SYS_NORMAL_RESET` | `NORMAL_RESET` | committed state | loop physical reset | per_loop |
| `CNT_SYS_ROUTE` | `ROUTE` | permanent info·failure·journal | next objective only | per_loop |
| `CNT_SYS_LOCAL_RETRY` | puzzle retry | current local state | puzzle local state only | always |
| `CNT_SYS_HARD_FAILURE` | B3-B/C4/D1 commit | current device state | active failure only | state_variant |
| `CNT_SYS_SHORTCUT` | AS/BSHORT/CSHORT/DSHORT | verified info | shortcut use history | per_loop |
| `CNT_SYS_BROKEN_RESET` | `BROKEN_RESET` | D5·one-shot flag | broken state once | once |
| `CNT_SYS_POST_REST` | `POST_BROKEN_REST` | S3 state | time/fatigue only | always |
| `CNT_SYS_FINAL_SLEEP_LOCK` | `FINAL_SLEEP_LOCK` | F3 entered | final sleep lock | once |
| `CNT_SYS_SAVE` | save transaction | slot/checksum | disk save only | state_variant |
| `CNT_SYS_DEMO_IMPORT` | full build import | demo save/version | cloned full slot | once per import |
| `CNT_SYS_ENDING_COMMIT` | EDC/ending nodes | choice/required nodes | atomic ending state | protected |

## 4. 용어 사전

| 한국어 표시 | 의미 | 섞지 않을 용어 |
| --- | --- | --- |
| 세계 초기화 | D5 전 수면 뒤 물리 상태 reset | 저장 불러오기·퍼즐 재시도 |
| 로컬 재시도 | 현재 퍼즐 조작만 되돌림 | 세계 초기화 |
| 당일 물리 잠금 | reset 전까지 장치가 고정됨 | 영구 실패·게임 오버 |
| 접근 숏컷 | 영구 정보로 준비·동선을 축약 | 체크포인트·스테이지 선택 |
| 저장 | 디스크 슬롯 transaction | 수첩 기록·SYS_COMMIT |
| 다른 아침 | BROKEN_RESET 뒤 S3 | 정상 reset 실패 반복 |
| 최종 선택 확인 | EDC 원자 커밋 전 확인 | F0 임시 의향 |

## 5. 감각 자막 registry 납품

`captions_ko_KR.csv`는 다음 필드를 갖는다.

```text
caption_id,audio_asset_id,cue_part_id,ko_KR,trigger,condition,
distance_or_source,direction_label,repeat_policy,visual_equivalent,notes
```

- BGM은 시작·stem 변화, 앰비언스는 상태 변화, SFX는 결과 변화 때만 표시한다.
- 방향 라벨은 대상·공간명을 함께 쓴다.
- `sensory_caption_id`가 필수 진행 cue인데 caption 또는 비청각 등가물이 없으면 승인하지 않는다.

## 6. 완료 조건

- UI 13종과 시스템 14묶음에 기본·가리킴/초점·확인·취소·오류·복구 문구가 있다.
- Windows 키보드 전용, Alt+Tab, 1280×720·200% UI, ko/en/pseudo 길이 검수를 통과한다.
- 저장·SYS_COMMIT·NORMAL_RESET·로컬 재시도·HARD FAILURE가 용어와 아이콘 모두에서 구분된다.
