# EP01·EP02 스크립트 Sheet 2차 검토

## 1. 검토 범위와 결론

- 대상: `GGB_EP01_반복과시계망_스크립트관리`, `GGB_EP02_검은거울_스크립트관리`
- 검토일: 2026-08-31
- 해결 반영일: 2026-09-01
- 범위: 기존 `00_가이드`~`08_QA`, 보완 `09_Runtime_Master`~`13_Portrait_Vocab`, 현재 Godot 상태 경로 레지스트리
- 원칙: 최초 검토에서는 Google Sheets를 수정하지 않았으며, 이후 사용자 승인에 따라 기존 `ko_KR`을 보존한 schema v3 보완을 반영했다.

결론은 **schema v3 전환 및 P0/P1/P2 조치 완료**다. `09_Runtime_Master`를 행 단위 정본으로 지정하고 Route Edge, State Predicate, State Effect를 분리했다. EP01 341행과 EP02 450행의 `ko_KR` 대조 결과는 변경 0건이며, 기술 검증 결과는 [LINT-20260901-R3.json](lint/LINT-20260901-R3.json)에 기록했다.

## 5. 권장 schema v3 핵심

### 5.1 Runtime Master

```text
package_id, node_id, draft_id, line_id,
approval_status, localization_status, revision,
scene_id, order, content_type, speaker_id,
character_art, portrait_position, portrait_state, direction,
ko_KR, en_US, next_type, next_id,
request_id, content_item_id, document_id, knowledge_id, owner_id,
source_file, source_anchor, source_commit, source_checksum,
location_id, object_id, trigger, route_predicate_id, repeat_policy
```

Runtime Master에는 여러 상태 연산이나 여러 분기 대상을 한 셀에 넣지 않는다.

### 5.2 Route Edge Master

```text
package_id, route_id, edge_order, predicate_id,
target_type, target_id, is_fallback, priority,
source_anchor, validation_status
```

### 5.3 State Predicate·Effect Master

```text
predicate: package_id, predicate_id, state_path, comparator, typed_value
effect: package_id, event_id, node_id, effect_order,
        state_path, operation, typed_value,
        writer, commit_phase, repeat_policy, registration_status
```

## 6. 실행 결과

1. 기존 원문은 Legacy 참고본과 Google revision history로 보존했다.
2. 공용 ID·Vocab·state path registry를 확정했다.
3. EP01·EP02 공통 38열 Runtime schema v3를 적용했다.
4. `node_id`와 package namespace를 적용하고 두 에피소드 그래프를 통합 lint했다.
5. Route Edge와 State Predicate·Effect를 한 행 한 규칙으로 정규화했다.
6. 모든 상태 계약을 registry에 연결하고 Godot Foundation Smoke를 통과했다.
7. Technical Lint를 실제 lint 산출물 기준으로 갱신했다.
8. Script·Readable·String·Token 검수 뷰를 정본 수식으로 연결했다.
9. 공용 Vocab을 Git 정본으로 전환하고 에피소드별 Legacy 사본의 운영 참조를 제거했다.

## 7. 완료 검증 기준

- 한국어 원문 341개·450개가 기존 값과 일치한다.
- 각 `node_id`, route ID, Scene ID가 프로젝트 전체에서 유일하거나 명시된 예약 전역 ID다.
- 모든 route가 한 개 이상의 명시적 edge 또는 명시적 terminal을 가진다.
- 모든 `next_id`와 edge target이 정확히 하나의 대상에 해소된다.
- 시작점에서 모든 필수 노드가 도달 가능하고, 허용 목록 밖 무한 순환이 없다.
- 모든 StateWriter effect가 등록된 path와 타입·연산을 사용한다.
- `PROPOSED` 경로가 남아 있으면 runtime QA는 완료가 될 수 없다.
- 원본 checksum을 바꾸면 생성 뷰와 lint revision이 자동으로 무효화된다.
- 공용 Vocab 제거 상태에서도 에피소드 Sheet가 깨진 참조를 만들지 않는다.
