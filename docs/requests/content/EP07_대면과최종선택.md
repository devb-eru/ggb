## 2. F2 필수 사실 6종

관계 완료가 0명이어도 아래 지식은 모두 `verified`가 된다. 완료한 인물은 개인 책임과 outcome을 자기 말로 덧붙이고, 미완료 인물의 감정을 대신 설명하지 않는다.

| knowledge_id | 표시 순서·필수 내용 |
| --- | --- |
| `KN_F2_PROMISED_FUTURE_BODIES` | 연구원들은 미래에 새 몸으로 살아갈 수 있다는 약속에 동의했다 |
| `KN_F2_RESEARCHERS_CONVERTED` | 실제로는 생체 신경 코어와 인격 프로세스가 결합된 상태로 전환됐다 |
| `KN_F2_RELEASE_NOT_CURRENTLY_EXECUTABLE` | 현재 호환 신체·배양/접속 모듈이 없어 즉시 분리는 위험하며, 영원히 불가능하다는 뜻은 아니다 |
| `KN_F2_FORCED_SUBJECT_ACTIVATION` | 아버지 사후 사용인들이 외로움·배신감·보호 욕구로 주인공을 강제 기동했다 |
| `KN_F2_EXTERNAL_SURVIVAL_UNCERTAIN` | 지구는 황폐하며 장기 생존 가능성·다른 생존자는 확인되지 않았다 |
| `KN_F2_FINAL_AUTHORITY_BELONGS_TO_SUBJECT` | 현재 최종 기상·안정화 권한은 주인공에게 있으며 사용인이 대신 확정할 수 없다 |

`F2_MANDATORY_RECAP`은 플레이어가 질문을 생략한 경우 누락 사실만 순서대로 읽는다.

## 4. F3 세 장치

F3 진입 즉시 `final_sleep_lock=true`이며 정상 수면·휴식으로 돌아갈 수 없다. 첫 포커스는 중앙 수첩대다. 세 장치는 자유 순서로 모두 조사해야 하며 각 설명은 같은 네 항목 구조를 사용한다.

| interaction_id / object_id | 확실한 정보 | 불확실한 정보·실행 시 변화 |
| --- | --- | --- |
| `F3_OBJ_WAKE_DEVICE` / `OBJ_CORE_WAKE_DEVICE` | 현실 몸이 냉각실에 있고 기상 절차·첫 호흡은 자동 보조됨 | 장기 환경·후유증·다른 생존자는 미확인; 시뮬레이션 연결 해제, 인격 저전력 보존 |
| `F3_OBJ_LOOP_STABILIZER` / `OBJ_CORE_LOOP_STABILIZER` | 기억·진실·SUBJECT 권한을 유지한 S5 안정화 가능 | 영구 안전·외부 복구 시점은 미확인; 정상 reset 대신 동의 기반 다음 날 |
| `F3_OBJ_NOTEBOOK` / `OBJ_CORE_NOTEBOOK_TERMINAL` | F0 의향은 임시이고 최종 권한은 현재 주인공에게 있음 | 어느 선택도 아버지·사용인의 용서/처벌을 자동 확정하지 않음 |

first/repeat, 조사 완료 1/3·2/3·3/3, 저장 시작/완료, EDC 개방 문구를 작성한다. F0 의향·관계 등급은 포커스·순서·설명량을 바꾸지 않는다.

## 5. EDC 선택 원문

| 선택 | 확실함 | 불확실함 |
| --- | --- | --- |
| 현실 기상 | 몸을 깨우고 시설 연결을 해제, 공동 인계 수첩과 출구 절차 존재 | 환경 복구·생존 기간·다른 사람·인격의 미래 신체 |
| 안정화 잔류 | 시뮬레이션임을 기억하고 역할 강제를 완화, 기상 권한 유지 | 장기 시설 수명·외부 변화·관계가 계속 나아질지 여부 |

공통 선택 순서:

```text
선택 카드 focus
→ 확실함·불확실함 다시 보기
→ 선택 문장 작성
→ 실행 확인
→ 취소 또는 EDC_FINAL_DECISION 원자 커밋
```

- 기본 포커스는 두 선택 사이의 `정보를 다시 본다`.
- 크기·문장 수·확인 횟수·음량·필기 횟수는 동일.
- 선택 뒤 실행 전 취소하면 F3로 돌아가고 선택은 unset, 수면 잠금은 유지.
- 커밋 뒤에는 현실/잔류 ENTRY에서 재개.

## 6. F0 의향과 최종 관계 6경로

| F0 의향 | 최종 현실 | 최종 잔류 |
| --- | --- | --- |
| reality | `reaffirmed` | `revised` |
| stay | `revised` | `reaffirmed` |
| undecided | `formed` | `formed` |

이 값은 주인공 독백과 사용인 한 문장의 어조만 바꾸며 엔딩 길이·오브젝트·권리·성공 여부를 바꾸지 않는다.

## 7. ED_ALL_CEREMONY

- 다섯 관계 사건 전원 완료일 때 EDC 커밋 뒤, 엔딩 본문 전에 실행한다.
- 다섯 인격이 이름·문양·서명음으로 자신을 차례로 인증하고 주인공이 확인한다.
- 현실에서는 저전력 보존 인덱스로 접히고, 잔류에서는 경계를 유지한 채 저택 각 방향으로 흩어진다.
- 의식은 엔딩을 차단·변경하지 않으며 중단 시 첫 미완료 인물부터 재개한다.

## 8. 분량·완료 조건

- 원문 후보 520~760행: F2 260~380, F3 90~130, EDC 100~140, ALL/자막/UI 70~110.
- F2 6사실이 LOW·기록 0개에서도 누락되지 않고 이미 본 사실은 recap에서 반복하지 않는다.
- F3 장치 6순서 모두 같은 `SAVE_F3_COMPLETE`와 EDC를 연다.
- F0 의향×EDC 6경로, 관계 0~5명, 이리스 6상태, 마라 2 3상태를 검증한다.
