## 3. 핵심 계약

### 3.1 F0 메타퍼즐

- F0-A~E는 이전 퍼즐 정답을 그대로 재입력하지 않고 역할·신호·지도·출처·권한의 의미를 재분류한다.
- 각 단계는 네 조사 오브젝트, 최초·반복 반응, 검토, LOCAL RETRY, 힌트 3단, 성공과 반복 요약을 가진다.
- 잘못된 검토는 현재 단계의 충돌 축만 표시하고 이전 단계·관계 기록·조사 정보를 되돌리지 않는다.
- 색상은 출처 보조 단서이며 문양·선 패턴·명칭·음향을 함께 제공한다.
- 모션 감소 모드에서도 정적 도면과 텍스트로 모든 단계를 해결할 수 있다.

### 3.2 F0-D 익명 대체

- E3_5 완료 시 마라 2 기명 기록을 사용하고, 미완료 시 `UNKNOWN_PURPLE_INDEX`로 합류한다.
- 익명 경로는 체크섬·문양·확인된 기능만 제공하며 이름·자기희생 동기·병합 의향을 생성하지 않는다.
- 익명 경로는 관계 완료로 집계되지 않지만 F0-D와 메인 진행을 차단하지 않는다.

### 3.3 F0-E 현재 권한

- 과거 연속성 인증과 현재 SUBJECT 권한을 별도 칸에서 검증한다.
- 아버지·사용인 토큰 입력은 상태 손실 없는 LOCAL RETRY로 처리한다.
- `reality`, `stay`, `undecided` 세 임시 의향은 모두 F1로 합류한다.
- 임시 의향은 EDC의 선택지, 기본 포커스, 정보량, 확인 횟수와 엔딩 진입 가능성을 바꾸지 않는다.

### 3.4 F1과 J5

- 아버지의 마지막 기록 8구간은 주장, 대조 자료, 확정 사실, 미확인을 분리한다.
- 아버지 기록만으로 사실을 확정하지 않고 `REC_*`, J1~J4와 기계 로그를 대조한다.
- 반복 재생은 상태를 다시 쓰지 않으며 미확인 구간의 내용을 미리 공개하지 않는다.
- J5는 확정 사실·미확인·아버지 주장·연구원 반박·주인공이 정할 것을 분리하고 `journal_stage=5`를 기록한다.
- 관계 기록 0개 상태에서도 EP07 F2가 필수 사실 6종을 최소 recap으로 보장한다.
