## 2. 목적과 전체 방향

버티컬 슬라이스의 사운드는 공포를 직접 선언하기보다 “완벽하게 정돈된 하루가 너무 정확하게 되풀이된다”는 불안을 만든다. 시계·천·종이·목재처럼 고딕 저택에 자연스러운 소리에서 시작해, 실패와 S2 미리보기에서 같은 박자 아래 팬·릴레이·데이터 pulse가 있었다는 사실을 드러낸다.

필수 검증 목표:

1. 화면을 보지 않고도 방 전환과 조작 확정은 알 수 있으나, 방향성 소리만으로 퍼즐을 풀 필요는 없다.
2. NORMAL_RESET 전후 같은 새·시계 박자가 동일해 반복을 감각적으로 확인할 수 있다.
3. B3-B의 실행 전 확인, 비가역 실패, 숏컷 복귀와 성공을 서로 다른 리듬·tail로 구분한다.
4. 에드가의 잔류 기억은 전용 저음 잠금음으로 짧게 새지만 악역 등장 sting처럼 들리지 않는다.
5. S2는 승리·탈출 음악이 아니라 고딕 layer와 기계 layer가 같은 구조였음을 알리는 누수다.
6. BGM·앰비언스·퍼즐 cue의 실제 제작·수정·통합 시간을 측정한다.

## 7. NORMAL_RESET 사운드 시퀀스

```text
SFX_NORMAL_RESET_SLEEP
→ RESET_FADE_MARKER
→ AUD_EVT_NORMAL_RESET.erase
→ SFX_NORMAL_RESET_COMMIT
→ silence 150~300ms
→ 같은 AMB_BEDROOM_SAME_MORNING marker
```

- 디스크 저장 UI는 별도 cue를 사용하므로 commit을 저장 완료음처럼 밝게 만들지 않는다.
- 새소리 marker는 reset 전후 같은 loop 위치에서 재현할 수 있어야 한다.
- 강제 종료 복구 시 transition 전체를 다시 재생하지 않고 commit 뒤 같은 아침에서 시작한다.
- reduced sensory 모드에서는 저역 notch를 약화하고 `환경음이 끊긴 뒤 같은 아침 소리가 돌아온다` 자막으로 대체한다.

## 8. S2 미리보기 믹스

`VS01_S2_PREVIEW`는 정식 C5나 `world_phase=S2`를 쓰지 않는 테스트 장면이다.

1. B3-B 성공 뒤 S0·S1 BGM의 고딕 화성을 유지한다.
2. `BGM_S2_LEAK.machine` stem을 4~6초 동안 -18dB에서 -8dB 안팎으로 올린다.
3. 대시계 앰비언스의 gear 하나가 fan·relay texture와 같은 박자였음을 들려준다.
4. 열세 번째 종 tail을 자르지 않는다.
5. 종료는 해결 종지나 공포 sting 없이 미완성 공명으로 둔다.

이 장면의 실제 dB는 in-engine 비교로 정하며 위 수치는 시작점이다.

## 9. 믹스·접근성 계약

### 9.1 bus와 동시 발음

- `BGM` 2 voice 이하, 상태 전환 crossfade.
- `Ambient` 현재 방 1 + 이전 방 fade 1을 기본으로 한다.
- 퍼즐 확정·실패 cue는 장식 ambient보다 우선한다.
- `SIG_EDGAR_LOCK_TONE`은 B3-B 실패음과 동시에 재생하지 않고 대사 직전 최소 300ms 간격을 둔다.
- 전체 시작 예산 28 voice를 넘지 않는다.

### 9.2 loudness 시작값

| 유형 | 시작 범위 |
| --- | --- |
| BGM | -22~-18 LUFS-I |
| Ambient | -28~-22 LUFS-I |
| UI | -24~-20 LUFS-I |
| master peak | -1 dBTP 이하 |

숫자는 납품 합격값이 아니라 in-engine mix 출발점이다. B3 입력 확인음이 ambient에 묻히지 않고 대화 읽기를 방해하지 않는지를 우선한다.

### 9.3 감각 자막

- `CAP_*`는 들리는 대상과 의미를 짧게 구분한다. 예: `[대시계 내부에서 여러 잠금쇠가 차례로 닫힌다]`.
- `쿵`, `삐`처럼 의미 없는 의성어만 쓰지 않는다.
- 음악 자막은 매 loop마다 반복하지 않고 상태가 처음 변할 때 한 번 제공한다.
- 필수 퍼즐 cue는 화면의 문양·선·상태명과 동시에 발생한다.
- 방향성 오디오를 꺼도 위치 찾기와 정답 판단이 가능해야 한다.

### 9.4 저주파·반복 감소

- 저주파 감소 옵션에서 S2 low pulse stem을 mute하거나 -12dB 추가 감쇠한다.
- UI focus는 100ms cooldown, notebook write는 300ms cooldown을 지킨다.
- 반복 reset에서 sleep·commit cue를 생략할 수 있는 `reduced_repetition` variant 또는 mix preset을 제안한다.
