# GGB 퍼즐·주요 전환 사운드 전수 명세

## 1. 공통 계약

퍼즐 사운드는 입력 결과를 빠르게 알려 주되 정답을 음 높이 하나로만 숨기지 않는다. 각 `asset_id`는 여러 `cue_part_id`를 가진 pack이다. 아래 하위 ID는 납품 추적용이며 정본 runtime ID 등록 전에는 이벤트 데이터에 직접 쓰지 않는다.

| 항목 | 요구 |
| --- | --- |
| 용도 | 선택·이동·검증·무효·로컬 재시도·비가역 확정·성공을 구분 |
| 길이 | 입력 0.08~0.5초, 검증 0.4~1.5초, 결과 1~4초, 전환 8~30초 |
| 악기·음색 | 퍼즐 재질에서 나온 실제음+절제된 UI 층; 공통 검증 SFX와 부모/레이어 관계 유지 |
| 반복 여부 | 기본 `loop=false`; 유지 상태 drone만 loop=true와 명시 |
| 접근성 | 모든 필수 cue에 `sensory_caption_id` 또는 caption prefix와 화면 pulse·문양·상태명 병행 |

## 4. 중복 소유권 규칙

| 의미 | 부모 pack | 공통 레이어 |
| --- | --- | --- |
| 퍼즐 일반 유효·무효 | 각 `AUD_PUZ_*`가 재질별 본체를 소유 | `SFX_PUZZLE_VALIDATE`, `SFX_PUZZLE_REJECT`는 UI 확인층만 |
| HARD FAILURE | B3-B·C4·D1이 장치 결과를 소유 | `SFX_HARD_FAILURE_COMMIT`는 커밋 시점 공통층 |
| 일지 복원 | `AUD_EVT_JOURNAL_RESTORE`가 전체 연출 소유 | `SFX_JOURNAL_RESTORE`는 페이지 결합 1회층 |
| 정상 리셋 | `AUD_EVT_NORMAL_RESET`가 시퀀스 소유 | `SFX_NORMAL_RESET_SLEEP`, `SFX_NORMAL_RESET_COMMIT`는 단계층 |

## 5. 완료 조건

- 퍼즐 14, 주요 전환 8의 부모 `asset_id`가 정확히 한 번씩 존재한다.
- 각 하위 cue에 trigger, stop, 길이, tail, bus, priority, caption과 비청각 신호가 있다.
- 로컬 재시도·HARD FAILURE·정상 리셋·깨진 리셋·디스크 저장이 서로 다르게 들리고 보인다.
- 저장·로드·스킵·강제 종료 재개에서 commit·성공·전환 one-shot이 중복 재생되지 않는다.
