# GGB 공간 앰비언스 전수 명세

## 1. 공통 규칙

모든 공간 앰비언스는 장시간 머물러도 명확한 loop 이음과 짧은 반복 패턴이 들리지 않는 것을 목표로 한다. 아래 길이는 원본 한 주기의 목표치이며, 사건용 one-shot은 별도 SFX/이벤트 cue가 담당한다.

| 필드 | 공통 요구 |
| --- | --- |
| 용도 | 장소의 재질·규모·세계 단계·심리 압박을 전달하되 퍼즐 정답을 단독 전달하지 않음 |
| 길이 | 90~180초 범위, 표의 목표값 ±15초 제안 가능 |
| 악기·음색 | 비음악적 room tone·현장 녹음·가공 기계음 중심; 음정 요소는 BGM과 충돌하지 않음 |
| 반복 여부 | `loop=true`; intro 없이 진입 crossfade 0.5~1.5초, loop 경계 무클릭 |
| 변형 | 실제 도달 가능한 S0~S5·수리 전/후만 stem으로 제작, 39×전 단계를 기계적으로 만들지 않음 |
| 접근성 | 상태 변화 때만 `sensory_caption_id`를 호출하고 loop마다 자막을 반복하지 않음 |

## 4. 공간음 완료 조건

- 39개 `asset_id`가 모두 한 행씩 존재한다.
- 각 공간의 실제 도달 단계만 제작 목록에 분해되고, 사용되지 않는 stem은 만들지 않는다.
- loop 이음, 장시간 반복, BGM과의 음정 충돌, 저장·로드 crossfade를 검사한다.
- 음량 0에서는 공간명·상태명·시각 문양으로 필수 정보가 유지된다.
- 저주파·호흡·반복 감소 상태에서도 퍼즐 신호와 다음 이동을 놓치지 않는다.
