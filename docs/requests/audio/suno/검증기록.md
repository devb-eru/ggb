하위 cue·폴리 수를 부모 97종에 더해 정본 에셋 수를 늘리지 않는다. 같은 승인 재료를 여러 사건에서 재사용하는 것은 누락이 아니라 원전의 부모/공통층 계약이다.

## 실행한 검사

프로젝트 루트에서 실행:

```powershell
& 'docs/requests/audio/suno/validate_prompts.ps1'
& 'scripts/validate_docs.ps1'
git diff --check
```

- 전용 검사: 원전/매니페스트 부모 97개 일치, 각각 1회 정의. 명시 퍼즐 cue 102개와 암시 반복음 2개, 폴리 23개 대응. UTF-8·내부 링크·코드 블록 검사 통과.
- 프로젝트 검사: 문서·ID·에셋·의뢰 참조 검사 통과.
- 자동 검사는 ID와 문서 구조를 증명하며 소리의 적합성을 증명하지 않는다. 위 변형·의미 대조는 원전의 각 표와 작성 문장을 별도로 검토한 범위다.

## 음원 제작 때 확인할 사항

1. Suno가 단발 폴리를 음악화하거나 정확한 음 수·무음을 지키지 않으면 원재료만 추출하거나 직접 녹음·합성한다. 이 문서는 생성 성공률을 보장하지 않는다.
2. `SFX_CLOCK_BELL_13`의 원전 4~7초는 전체 13회 배열인지 핵심 공명 구간인지 해석 여지가 있다. 두 단발 재료를 모두 제공했으며, 실제 전체 재생 길이는 기존 사건 타이밍과 맞춰 확인한다. 원전 자체는 변경하지 않았다.
3. 초 단위 절단·샘플 반복점·믹스·쿨다운·자막·게임 재개·권리는 실제 제작물로 검수한다. 아직 생성·청취·게임 실행·배포 승인은 수행하지 않았다.
4. 사용 모델이나 구독 기능은 사용자가 실제 생성할 때 선택한다. 결과 이력에 모델·날짜·입력문·라이선스 근거를 남긴다.

프롬프트 작성에 필요한 미해결 사용자 질문은 없다. 위 항목은 실제 음원 제작 단계의 확인 사항이다.
