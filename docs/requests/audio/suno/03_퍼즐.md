# Suno 메인 퍼즐 하위 소리

원전: [퍼즐·전환 전수 명세](../03_퍼즐_전환_전수명세.md). [사용법](README.md)의 CUE + 각 절의 재질 입력문 + 하위 행 입력문을 연결한다. 유지 반복음은 CUE 대신 AMBIENCE를 붙인다. 한 행씩 생성·추출하며 한 pack 전체를 한 음원으로 요청하지 않는다.

입력 목표는 대체로 0.08~0.5초, 검증 0.4~1.5초, 결과 1~4초다. 절 제목 아래 범위가 해당 부모의 원전 목표다. 테일은 다음 입력을 가리지 않게 자르고 실제 무음·시간·위상은 편집으로 확정한다. 성공은 절제된 장치 결과, 무효는 손실 없는 되돌림, HARD_FAILURE는 당일 물리 잠금으로 구분한다. 공통 검증 SFX를 본체에 미리 굽지 않는다.

## 공통 납품 검수

- ACTIVE_LOOP·PRESSURE_WAIT_LOOP·COMPLETE_CIRCUIT_LOOP는 8~20초 편집 구간을 우선 시험한다. 원전이 길이를 확정하지 않아 둔 제작용 제안이며, 긴 공간 베드는 해당 AMB가 소유한다.
- PHASE_SHIFT의 -1/0/+1/HALF는 같은 접점 재질을 사용한다. +1에만 밝은 정답음을 붙이지 않는다.
- 실패 뒤 고정 상태에는 반복 충격음을 붙이지 않는다. 단발 실패와 잠긴 상태의 공간 베드를 분리한다.
- cue별 자막은 원전의 CAP 접두어와 실제 화면 상태를 연결한다. Suno가 음성으로 자막을 읽도록 요청하지 않는다.
