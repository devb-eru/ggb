# Suno 주요 전환 8종

[사용법](README.md)의 TRANSITION + 기본 입력문 + 해당 변형 한 개를 사용한다. [원전](../03_퍼즐_전환_전수명세.md)의 단발 시퀀스 8개다. 정확한 컷·커밋·자막 동기화는 승인된 재료로 DAW에서 구성한다. 단계별 재료를 따로 얻을 때는 CUE를 사용한다. BGM과 섞인 결과는 이 전환 본체로 납품하지 않는다.

## 조합 검수

전환 전체 생성은 분위기 후보로만 사용해도 된다. 커밋·단절·복귀 타이밍이 부정확하면 하위 재료로 재구성한다. JOURNAL_RESTORE 전체와 SFX_JOURNAL_RESTORE 페이지 접합을 겹쳐 두 번 강조하지 않는다. D5 BGM·전환·D4 결과의 공명도 각각 소유 구간을 나눈다. 어떤 전환도 저장/로드 재개에서 핵심 단발음을 중복 재생하지 않는다.
