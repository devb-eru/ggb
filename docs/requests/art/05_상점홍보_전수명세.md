# GGB 상점·홍보 아트 전수 명세

## 1. 범위

이 문서는 게임 내부 에셋이 아닌 Steam 상점·라이브러리·트레일러용 9개 매니페스트 행을 다룬다. 실제 픽셀 규격과 파일 제한은 제작 착수 시점의 Steamworks 업로드 화면을 `beru`가 확인해 작업표에 첨부한다. 확인 전 임의 규격으로 최종 내보내기를 승인하지 않는다.

공통 메시지:

- 고딕 저택의 일상과 기계 시설의 균열을 함께 보여 주되 시뮬레이션 정체·아버지의 배신·두 엔딩을 직접 폭로하지 않는다.
- 포인트 앤 클릭, 반복되는 하루, 심리적 불안, 다섯 사용인의 존재감을 실제 게임 화면과 일치하게 전달한다.
- 소녀 주인공과 마라 2를 성적으로 대상화하지 않는다.
- 현실 엔딩을 정답·희망, 잔류 엔딩을 실패·감금으로 색이나 구도에서 판정하지 않는다.
- 최종 로고·정식명 확정 전에는 교체 가능한 텍스트 레이어를 유지한다.

## 3. 검수

- 모든 이미지가 실제 게임의 캐릭터 비율·공간 구조·UI와 일치한다.
- 상점 스크린샷 5장은 `STORE_SCREENSHOTS` 한 행의 `unit_count=5`로 각각 검수한다.
- 트레일러의 음악·효과음·폰트·영상 클립은 승인된 권리 증거와 연결한다.
- 콘텐츠 고지 문구와 실제 장면 강도가 [콘텐츠 고지 기준](../../content_advisory.md)과 일치한다.
- Steamworks 규격 확인 날짜와 캡처를 납품 증거에 남긴다.
