# GGB 전체 아트 의뢰 부속 명세

## 1. 역할

이 폴더는 버티컬 슬라이스 이후의 전체 게임 아트 의뢰를 실제 제작 단위로 나눈 부속 명세다. 부모 의뢰서는 `docs/requests/REQ-ART-2026-0002_*`, `REQ-ART-2026-0003_*`, `REQ-ART-2026-0004_*`이며, 상태·담당·수락은 부모 의뢰와 `request_register.csv`에서만 변경한다.

## 3. 공통 규칙

- 현재 [버티컬 슬라이스 아트 의뢰서](../REQ-ART-2026-0001_버티컬슬라이스.md)의 상대 배치·상태 용어·접근성·납품 계약을 공통 기준으로 사용한다.
- 논리 좌표와 고정 HEX 값은 부속 명세에 넣지 않는다. 구체 배색·명도·채도·재질색은 아트팀 제안으로 검토한다.
- 색은 단독 정답이 될 수 없다. 윤곽·문양·명칭·재질·움직임 중 최소 하나를 함께 제공한다.
- `VSART_*`는 버티컬 슬라이스 내부 부품 ID다. 전체 게임 정식 ID로 승격하지 않는다.
- 부모 의뢰와 부속 명세가 충돌하면 사건 의미는 v0.4 정본, 제작 범위는 부모 의뢰, 세부 외형은 본 부속 명세 순으로 적용한다.
- 매니페스트 한 행 안에 묶인 하위 부품은 [전체 제작 오브젝트 인벤토리](../../game_object_inventory.md)의 `PRDOBJ_*`로 추적한다. 이는 납품 누락 방지용이며 런타임 ID가 아니다.

## 4. 열린 충돌

`GGB-CNF-2026-0018`이 해결되기 전 외부 서고 B3 시계는 `OBJ_LIBRARY_RECORD_CLOCK` 또는 `ART_OBJ_LIBRARY_RECORD_CLOCK` 이름으로 납품하지 않는다. 기록 내실 경계 시계만 해당 정식 ID를 사용한다.
