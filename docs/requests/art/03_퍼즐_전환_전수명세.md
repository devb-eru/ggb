# GGB 퍼즐·전환 아트 전수 명세

## 1. 공통 퍼즐 계약

각 퍼즐 단계는 패널 `ART_PUZ_*`와 상태 피드백 `VFX_PUZ_*` 두 에셋 행을 한 검토 묶음으로 제작한다.

- 패널은 기본·조작 초점·선택·검증·실패·복원·완료 상태와 실제 가동 부품을 포함한다.
- 상태 피드백은 색 없이도 유효·무효·부분 검증·확정 물리 실패·성공을 구분한다.
- 정답 배열은 환경 장식이나 초기 강조로 선공개하지 않는다.
- 비가역 입력은 보호 덮개 또는 별도 확인 단계를 가지며 기본 초점은 안전한 시험에 둔다.
- 모션 감소, 글리치 감소, 음량 0, 키보드 전용 상태를 같은 패널에서 검증한다.

## 5. 상태 표시 용어

버티컬 슬라이스 의뢰서 §7.1의 한국어 표시명과 기술 상태 ID를 그대로 사용한다. 신규 상태는 한국어 표시명, 적용 부품, 진입·이탈 조건을 먼저 합의한 뒤 ID를 발급한다.

## 6. 완전성 검사

- 퍼즐 14단계마다 패널 1행과 상태 시각 1행, 합계 28행이 존재한다.
- 주요 전환 8행이 모두 존재한다.
- `D5_FILTER_BREAK`와 `BROKEN_RESET`은 다른 전환이며, 후자는 한 번만 재생된다.
- `F0_E`의 세 의향 상태는 최종 현실·잔류 선택을 잠그지 않는다.
