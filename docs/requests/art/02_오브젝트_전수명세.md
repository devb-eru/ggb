# GGB 전체 오브젝트 아트 전수 명세

## 1. 공통 제작 계약

정본 63개 오브젝트는 [전체 오브젝트 대장](../../game_object_catalog.md)과 일대일 대응한다. 각 `ART_OBJ_*` 또는 `ART_SERVANT_OBJ_*` 행은 아래를 포함한다.

- 기본 대기·마우스 올림·조작 초점·사용 불가·조사 확대 상태.
- 실제 사건에 필요한 열림·잠김·손상·복원·완료·파열·엔딩 상태.
- 분리 가능한 가동 부품, 전경 가림 부품, 상태 덧씌움 레이어와 그림자.
- 색과 무관하게 상태를 구분하는 윤곽·노치·라벨·재질·위치 변화.
- 1280x720에서 최소 상호작용 영역을 확보할 수 있는 실루엣과 확대 화면.
- 오브젝트가 캐릭터·대화창·수첩 UI에 가려질 때의 대체 배치 기준.

구체 색상·명도·채도와 표면 배색은 아트팀이 제안한다. 아래 외형은 기능과 서사 인상을 정하며 특정 팔레트를 고정하지 않는다.
