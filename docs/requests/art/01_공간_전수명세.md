# GGB 전체 공간 아트 전수 명세

## 1. 공통 공간 카드

모든 공간은 다음 요소를 한 묶음으로 제출한다.

| 항목 | 요구 |
| --- | --- |
| 기본 그림 | 구조·고정 가구·비활성 장식을 포함한 고정 카메라 기준 화면 |
| 월드 단계 | 실제 노출되는 S0~S5만 별도 덧씌움 레이어로 분리. 현실 `R0_*`는 단계 덧씌움 없음 |
| 배치 | 좌·중·우와 전경·중경·후경 관계, 출입 방향, 필수 오브젝트의 상대 위치 |
| 상호작용 | 클릭 가능한 정본 오브젝트와 이동문의 가림 없는 실루엣 |
| 캐릭터 | 사용인 대화·수리·결산 위치가 출입구와 단서를 막지 않는 배치 기준 |
| 접근성 | 모션 감소 정적 상태, 색 제거 상태, 1280x720~4K·UI 200% 확인 이미지 |
| 납품 | 편집 원본, 게임 적용본, 공간 명세표, 레이어 안내, 상태 비교 이미지, 권리 증거 |

세부 위치는 아트팀이 구도 초안에서 제안한다. 특정 색이나 팔레트는 고정하지 않으며 고딕 외피·기계층·현실 시설은 재질과 구조 차이로도 구분돼야 한다.

## 4. 완전성 검사

- 배경 `ART_BG_*` 39개가 모두 한 번씩 등장한다.
- 현실 3곳을 제외한 `ART_OVR_*` 36개가 모두 한 번씩 등장한다.
- 각 공간의 정본 오브젝트는 [전체 오브젝트 대장](../../game_object_catalog.md)과 연결한다.
- 각 공간은 실제 노출되지 않는 단계 이미지를 선제 제작하지 않는다. 필요한 상태 수는 팀 수락 때 `unit_count`로 확정한다.
