# GGB 캐릭터·UI·서명·폰트 아트 전수 명세

## 1. 공통 캐릭터 계약

각 인물은 설정표 1행, 캐릭터 초상 세트 1행, 전신 자세 세트 1행, 파열 외형 세트 1행을 갖는다. 정확한 색값과 화면 점유 면적은 아트팀이 제안하며, 정본 테마색은 인물 정체성을 확인하는 참고로만 사용한다.

- 설정표: 정면·3/4·측면·후면, 키 비교, 종족 특징, 역할 소품, S0·S2·S3·S5 구조.
- 초상: 승인된 표정 토큰, 눈·입·눈썹 합성 범위, 대화창 90~220% 배율 크롭.
- 자세: 기본·업무·경계·상호작용·파열·작별/헌장 6종.
- 파열: 고딕 외피 아래 기계 구조 노출 4단계. 주인공은 3단계.
- 접근성: 128px 회색조 실루엣, 색 제거, 글리치 감소 정적 상태, 소품과 종족 특징으로 식별.
- 금지: 소녀 주인공의 성적 대상화, 마라 2의 성적 뉘앙스, 이리스의 살의를 로맨스·질투 개그로 표현.

## 6. 완전성 검사

- 캐릭터 6명 × 4행 = 24행.
- UI 13행, 데이터 서명 6행, 폰트 3행.
- 합계 46행이 `asset_manifest.csv`와 일치한다.
- 표정·자세 표시명은 CNT 감정 토큰과 일대일 연결하고 같은 의미의 새 토큰을 장면마다 만들지 않는다.
