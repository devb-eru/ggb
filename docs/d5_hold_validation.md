# D5 첫 입력 고정 검증

## 동작

- 본편 D5에서 플레이어가 손잡이를 놓는 입력을 하면 10초 입력 고정이 시작된다.
- 0~3초, 3~7초, 7~10초의 세 감각 문장으로 손바닥 진동, 벽지 박리, 열 소실을 보여 준다.
- 이 구간에는 월드 핫스폿과 대사 진행 버튼이 없다. 시간이 끝난 뒤에만 D5 본문을 연다.
- 메뉴는 열 수 있으며 메뉴, 창 포커스 상실, 애플리케이션 일시정지 동안 시간은 흐르지 않는다.
- 입력 고정 자체는 진행 상태나 저장 파일을 쓰지 않는다. 중단 후 D5를 다시 열면 손잡이를 놓는 입력부터 다시 시작한다.
- 모션 감소 여부와 관계없이 같은 정적 문장과 시간을 사용한다. 카메라 이동이나 화면 흔들림을 필수 정보로 사용하지 않는다.
- 데모 60초 스팅어의 시간과 입력 계약은 변경하지 않는다.

## 자동 검증

격리된 Godot 4.7.2 basement-session 회귀가 다음을 검사한다.

1. 확인 입력 직후 대화와 월드 핫스폿이 열리지 않는다.
2. 메뉴 중 10초를 주입해도 시간이 흐르거나 저장 상태가 바뀌지 않는다.
3. 활성 시간 9.9초에는 입력 고정이 유지된다.
4. 10초에만 D5 본문 14문장과 동결 관계 반응 0~1문장을 연다.
5. 한국어와 영어가 같은 시간·진행 계약을 사용한다.
6. 입력 고정 전후 관계, 퍼즐 결과, 파열 수면 상태는 바뀌지 않는다.
7. 본문 마지막 확인 뒤에만 D6로 진행한다.

## 남은 제작 범위

- 현재 세 단계는 정적 개발용 배경과 문장으로 표현한다.
- 최종 벽지 박리 마스크, 손잡이 손동작, 그림자 지연, 촛불 열 소실, 전용 음향은 리소스 납품 뒤 같은 10초 타임라인에 연결한다.
- 이 검증은 최종 D5 카메라와 전편 실제 입력 완주를 증명하지 않는다.
