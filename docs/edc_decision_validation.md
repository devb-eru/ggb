# EDC 최종 선택 확정 구현 및 검증

검증 결과: Godot 4.7.2 격리 사본에서 `BASEMENT_SESSION_SMOKE: PASS`, `FOUNDATION_SMOKE: PASS`. EDC 화면 캡처를 확인했으며 양쪽 선택과 중앙 중립 포커스가 잘림 없이 표시된다. 테스트 중 나타난 루트 인증서 저장소 경고는 별도 환경 경고이며 스크립트 오류는 없다.

## 구현 범위

- F3 완료 화면에서 EDC로 연결한다. 기상·잔류 버튼은 같은 면적이며 기본 포커스는 중앙 주인공 수첩대다.
- F0-E의 임시 의향과 사용인 관계는 버튼 활성화·배치·포커스에 사용하지 않는다.
- 두 선택 모두 확인창 1회를 거친다. 확인창에서 취소하면 F3로 돌아가고 최종 결정은 미정이다. 앱 포커스를 잃으면 확인창을 폐기하고, 복귀 시 중립 포커스를 회복한다.
- F3 진입 및 EDC 확정의 논리 위치는 `H0_CORE_CHAMBER`다. 현재 배경은 기존 저택 임시 아트를 사용한다.
- F3 완료, 수면 잠금, SUBJECT 권한, 열린 선택 화면, 미확정 결정 상태를 검증한다.
- 결정·임시 의향 비교 결과·분기 ID·커밋 여부·시작 노드를 동일 스냅샷에 반영하여 `SAVE_ENDING_BRANCH`로 저장한다. 기존 StateWriter/SaveManager의 검증·임시 파일 승격·저장 실패 롤백 경로를 사용한다.
- `reaffirmed/revised/formed`는 확인 독백만 바꾼다. 관계값·기존 의향·연구원 기록은 변경하지 않는다.
- 다섯 명 핵심 관계 완료 시 다음 노드는 `ED_ALL_CEREMONY`, 그 외에는 `EDR_ENTRY` 또는 `EDS_ENTRY`다. 관계 미완료는 선택 제한이 아니다.
- 확정 후 F3 취소·재확정·이전 챕터 행동은 거부하고 저장된 분기 진입 상태로 재개한다.

## 저장 호환 범위

기존 `ending_run`의 `final_decision`, `selected_ending`, `reselect_used`는 유지한다. 신규 확정 스냅샷은 `final_choice_relation`, `branch_committed`, `branch_id`, `current_node_id`를 한 묶음으로 추가한다. 하나라도 있으면 전체 묶음과 확정 불변식을 검증하여 부분 저장을 거부한다. 아직 미확정인 기존 스냅샷에는 이 묶음이 없어도 유효하다.

이것은 엔딩 전체 저장 스키마 구현이 아니다. 노드별 완료 집합, 에필로그 조사 이력, 외형 선택, 크레딧, 갤러리와 F3 재선택 사본은 후속 엔딩 구현에 포함해야 한다. 현재 재선택 기능을 제공하지 않으며 기존 백업을 영구 F3 사본이라고 간주하지 않는다.

## 검증 항목

`basement_session_smoke.gd`의 `_validate_edc`:

1. 임시 의향 3종 × 최종 선택 2종 × 전원 관계 완료 여부 2종, 총 12개 조합.
2. 입력 스냅샷 불변, 관계·지식 불변, 시작 노드와 비교 독백 분류.
3. 저장 필드 묶음의 각 필드 누락 거부, 미완료 F3·권한 누락·수면 잠금 누락·잘못된 선택 거부.
4. 중앙 포커스, 두 버튼 면적, 미확정 미리보기, 앱 포커스 복귀, 확인 취소 후 F3 복귀.
5. 잘못된 저장 슬롯을 통한 저장 실패 유도와 런타임 전체 스냅샷 롤백.
6. 두 선택 각각 UI 최종 확인, 저장·불러오기, 확정 분기 재개, 확정 후 취소·중복 확정 거부.

파일 승격 각 단계에서 OS 프로세스를 강제 종료하는 전수 장애 주입은 이번 테스트에 포함하지 않는다. 무결성·롤백 테스트를 그보다 넓은 검증으로 해석하지 않는다.

## 남은 게임 구현

현재 `ENDING_ENTRY_PENDING`은 엔딩 본문 미구현 경계다. 선택 후 크레딧으로 건너뛰거나 완성 엔딩처럼 표시하지 않는다.

- ALL 의식, 현실/잔류 본문, 다섯 인격 보존·활동 상태의 실제 엔딩 적용.
- 관계별 후속 대사, 현실 수첩과 제한형 에필로그, 잔류 합의·감각·외형 연출.
- 노드별 저장·재개, 크레딧, 재선택 사본, seen 메타·갤러리.
- 코어·엔딩 전용 아트, 필기 입력 및 접근성 대체, 최종 음향·연기·해상도 QA.
