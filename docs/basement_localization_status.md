# 지하 장치 구간 현지화 현황

## 기준일

2026-09-14

## 범위

`D_SLEEP~D5`의 필수 진행 화면과 데모 종료 화면을 한국어와 영어로 표시한다. D6의 조사·수면 전환과 D5 본편 14문장 전환은 기존 전용 사전을 유지한다. 평면도 정답, 세 축의 순서·깊이, 태엽 심장 연동과 XIII 보조 입력, 실패 뒤 수면·숏컷 조건은 변경하지 않는다.

## 구현 구조

- `basement_display_texts.gd`가 목표, 지하 공간과 이동, 평면도·압력축·태엽 심장 UI, 동적 상태판, 세션·퍼즐 피드백과 데모 파열 비트를 담당한다.
- `BasementController`는 저장된 한국어 정본을 현재 언어로 표시하되 행동 ID, 퍼즐 값과 저장 값은 바꾸지 않는다.
- 수첩의 D0~D4 기록은 열람 시에만 번역한다. 알 수 없는 문자열은 원문으로 남긴다.
- D5 본편 전환은 `fracture_transition_texts.gd`, D6는 `fracture_rest_texts.gd`와 합성해 기존 영어 문구를 보존한다.

## 영어 표시 범위

| 구간 | 포함 내용 |
| --- | --- |
| D_SLEEP~D0 | 다음 아침 조건, 기록 내실의 세 눌림점, 평면도 획득과 자료 준비 |
| D0_A | 회전·좌우 반전·세 기준점, 동적 고정점과 좌표 검증 피드백 |
| D1/DF | 세 축 명칭·깊이·밀기, 비가역 확인창, 역방향 경고, 잠김과 수면 복구 |
| D2 | 지하창고 네 조사점, 반복 구조와 태엽 심장실 동선 |
| D4 | 세 연동 링의 동적 문양, 아홉 조작, XII 정상 기동, 보조 레버 확인과 XIII 입력 |
| D5 | 본편 입력 고정 전 상태, 데모 6단계 파열 비트·저장 재시도·종료 화면 |
| 수첩 | DF 실패 정보, D2 접근 절차, D4 보조 입력 기록 |

영어에서도 로마 숫자, 직선·분기·환형 역할과 문양 이름을 함께 제시한다. 퍼즐 정답을 색으로 대체하지 않는다.

## 검증

- Godot 4.7.2 프로젝트 가져오기: PASS
- `BASEMENT_SESSION_SMOKE`: PASS
- `FULL_CAMPAIGN_SMOKE`: PASS
- Windows OpenGL `BASEMENT_SESSION_SMOKE`: PASS
- 실제 영어 세 축 화면 캡처: `user://basement_axes_english.png`

스모크는 한·영 카탈로그, 동적 평면도·축·링 상태, 실제 D1 화면의 위치·목표·버튼·확인창, 한국어 정본 보존을 검사한다. 기존 지하 유일해·의도된 실패·수면 재준비·빠른 재개와 전편 엔딩 회귀도 함께 통과했다.

## 남은 범위

이 문서는 D0~D5 표시 완료의 근거다. E1~E6의 관계 허브·다섯 사용인 사건·J4·마지막 저녁·코어 접근 영어 전수 대조, 관계 LOW/MID/HIGH/ALL 검증, Windows 마우스 전용·키보드 전용 실제 완주는 별도 후속 범위다. 최종 지하 아트와 BGM·SFX는 사용자 확정 중단선에 따라 리소스 완성 뒤 진행한다.
