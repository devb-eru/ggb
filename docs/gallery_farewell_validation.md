# 감상 기록: 현실 작별과 신체 확인 확장

- 현실 엔딩 보존 사본의 `EDR_FAREWELL.index`까지만 사용인 작별 기록을 재구성한다. 순서는 기존 RealityWake와 같다.
- 문구를 별도로 복제하지 않고 `RealityWake.farewell`을 재사용한다. 관계 완료·결과·경계·이름 기록·이리스의 고백 조건은 보존 사본을 읽는다.
- `required_interactions_seen`에 있는 손·호흡 표시기·고정 벨트만 다시 보여준다. 신체 확인 완료만 보고 미조사 대상을 추가하지 않는다.
- 재생 페이지 생성은 상태를 변경하지 않는다. 본편이나 감상 프로필에 추가 열람 이력을 기록하지 않는다.

## 검증

- 작별 index 0이면 작별 대사 없음.
- index 1이면 첫 사용인 대사만 생성하며 이리스 대사는 나오지 않음.
- 손만 조사했다면 신체 확인 페이지가 하나만 추가됨.
- 기존 미조사 숨김 및 갤러리 열람 전후 상태·원본 파일 불변 검사를 유지함.

## 남은 범위

- 전체 엔딩 재생, 연결 해제 연출, 현장 수첩의 읽은 페이지, ALL 의식 및 잔류 합의 장면은 후속 범위다.
- 현재 UI는 텍스트 페이지 열람이며 최종 음향·영상 재생기가 아니다.
