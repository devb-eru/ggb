# P4 생명 유지 전조 재개 검증

검토일: 2026-09-13

## 수정

기존에는 우림 단계에서 `p4_life_support_seen`을 저장한 후 세 감각 문장을 표시했다. 이 사이에 종료하면 재진입 때 남은 문장을 표시하지 않았다.

`p4_life_support_pending`을 같은 진행 딕셔너리에 저장한다. 주방 재구성 시 미완료 전조를 우선 재개하고 마지막 문장 확인 후에만 해제한다. 완료 저장 실패 시 pending을 복원한다. 재개는 문장 중간이 아니라 세 문장 처음부터이며, 미완료 장면의 음향 요청도 재발행한다. 완료한 장면은 다시 요청하지 않는다.

기존 `seen`은 사건 발생 의미를 유지한다. 수첩 문구, 차 준비 정답, 관계값, 기억 닻과 질문 분기는 변경하지 않았다. 신규 필드가 없는 과거 저장에는 미완료 여부를 추정해 장면을 강제 재생하지 않는다.

## 검증

- `PROLOGUE_SCENE_SMOKE`: PASS. 최초 표시 후 진행 상태 사본을 보존하고 대화를 중단한 다음 상태 복원·재개, 마지막 확인과 재생 방지를 검사한다. 음향 요청은 최초와 모의 재개 각각 한 번이다.
- `CHAPTER_ONE_SMOKE`: PASS. 공통 컨트롤러 회귀 확인.
- 격리 프로젝트, Godot 4.7.2 headless. 인증서 저장소 경고는 존재하나 SCRIPT ERROR는 없다.

상태 사본 복원 검사는 실제 프로세스 강제 종료와 디스크 재시작 검증을 대체하지 않는다. 전용 주전자·귀·바닥 시각 연출과 최종 음원은 이번 수정 범위 밖이다. 전편 완주 또는 콘텐츠 완료 판정이 아니다.
