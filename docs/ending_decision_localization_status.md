# 최종 선택 화면 현지화

## 적용 범위

`ending_decision_texts.gd`의 한·영 표시 자료를 EDC 화면에 연결한다. 기존 후반 퍼즐 힌트의 독립 표시 자료 패턴을 따르며 게임 규칙의 상수와 저장 분기 ID는 유지한다.

- 목표·장소 이름과 두 절차 미실행 안내.
- 현실 기상·안정화 잔류 버튼의 보장 사항과 불확실성.
- 수첩대, 조사로 복귀 버튼, 두 절차 요약창.
- 각 절차의 최종 확인 본문, 현재 신체 이전 불가 안내, 취소·명시적 확정 버튼.

한국어 요약과 확인 본문은 `FinalInspection.SUMMARIES`와 `EndingDecision.CONFIRMATIONS`를 직접 참조한다. 번역 때문에 한국어 규칙 원문을 복제하거나 상태 ID를 바꾸지 않는다. `en` 계열 로케일은 영어, 그 외 로케일은 기존 한국어를 표시한다. 지원 언어 확장은 별도 작업이다.

## F3 조사와 확정 직후 독백

F3의 목표·장소·진입·기상 장치·안정화 장치·수첩·균형 요약·선택 화면 열기 버튼도 한·영을 제공한다. 두 장치의 감각 묘사, 사실과 불확실성, 세 임시 의향의 수첩 본문, 조사 순서에 따른 두 요약 순서, 안내·거절 문구와 결정 직후 세 의향 관계별 독백을 표시 단계에서 번역한다.

기존 저장은 피드백의 한국어 원문을 포함하므로 `feedback()`이 **완전 일치하는 알려진 원문**을 영어로 대응시킨다. 부분 문자열 추측이나 저장 데이터 교체는 하지 않는다. 원문에 대응이 없으면 그대로 유지하며, 한국어는 무조건 원문을 반환한다. 장치 본문·요약·독백은 규칙 상수로 조회하고 동적 수첩은 세 의향별 전체 문장을 대응한다. 향후 원문 ID 기반 현지화가 도입되면 이 경로는 구형 저장 호환 처리로 남길 수 있다.

컨트롤러는 피드백 사본만 번역한다. 세션 결과, 저장된 사실·임시 의향·최종 분기·퍼즐 조건을 수정하지 않는다. 번역된 주인공 피드백의 화자는 `Protagonist`로 표시한다. 기존 `text_id`가 있는 피드백은 공통 표시 함수의 ID 처리 우선순위를 유지한다.

## 의미와 저장

두 선택 모두 다섯 인격의 보존 방식을 명시하고 외부 생존 또는 시설 지속의 불확실성을 남긴다. 새 신체 이전이 당장 가능하다는 해석이나 어느 선택이 보상·처벌이라는 문구를 추가하지 않는다. 기본 포커스는 계속 중립적인 수첩대이며 양쪽 버튼의 배치·크기·콜백은 유지한다.

열람 기록은 그때 표시된 언어의 문자열로 남는다. 이후 로케일을 바꿔도 이미 읽은 영어를 한국어로 덮어쓰지 않는다. 미리보기나 언어 변경으로 최종 선택·사용인 관계를 변경하지 않는다.

## 검증 범위

`basement_session_smoke.gd`에서 두 분기 각각에 대해 영어 EDC 목표·버튼, 실제 버튼 콜백을 통한 요약·확인 본문, 취소·확정 레이블, 한국어 복귀 후 기존 영어 기록 유지와 진행 불변을 검사한다. 이후 기존 한국어 확인·커밋·불러오기·엔딩 후속 회귀를 계속 수행한다.

F3 추가 검사는 여섯 조사 순서의 요약 순서 보존, 세 임시 의향 수첩의 번역·한국어 원문 불변, 세 확정 독백, 알 수 없는 피드백 비변경과 실제 장치 버튼을 통한 영어 감각 문장 표시·기록을 포함한다.

이 검사는 영어 전체 완주나 네이티브 화면의 모든 글자 배율·해상도 검증이 아니다. 현실 수첩 본문·인계 부기·출구 표시는 후속 [현실 수첩 현지화](field_notebook_localization_status.md)에서 연결했다. 잔류 후속, 기타 후반 대사와 공통 수첩의 후반 문자열은 별도 현지화 대상이다. 시스템 저장 오류 및 기타 미등록 세션 피드백까지 모두 번역한 것은 아니다. 원문 변경 시 전체 일치 대응과 회귀 검사를 함께 갱신해야 한다.
