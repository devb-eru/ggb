# 최종 선택 화면 현지화

## 적용 범위

`ending_decision_texts.gd`의 한·영 표시 자료를 EDC 화면에 연결한다. 기존 후반 퍼즐 힌트의 독립 표시 자료 패턴을 따르며 게임 규칙의 상수와 저장 분기 ID는 유지한다.

- 목표·장소 이름과 두 절차 미실행 안내.
- 현실 기상·안정화 잔류 버튼의 보장 사항과 불확실성.
- 수첩대, 조사로 복귀 버튼, 두 절차 요약창.
- 각 절차의 최종 확인 본문, 현재 신체 이전 불가 안내, 취소·명시적 확정 버튼.

한국어 요약과 확인 본문은 `FinalInspection.SUMMARIES`와 `EndingDecision.CONFIRMATIONS`를 직접 참조한다. 번역 때문에 한국어 규칙 원문을 복제하거나 상태 ID를 바꾸지 않는다. `en` 계열 로케일은 영어, 그 외 로케일은 기존 한국어를 표시한다. 지원 언어 확장은 별도 작업이다.

## 의미와 저장

두 선택 모두 다섯 인격의 보존 방식을 명시하고 외부 생존 또는 시설 지속의 불확실성을 남긴다. 새 신체 이전이 당장 가능하다는 해석이나 어느 선택이 보상·처벌이라는 문구를 추가하지 않는다. 기본 포커스는 계속 중립적인 수첩대이며 양쪽 버튼의 배치·크기·콜백은 유지한다.

열람 기록은 그때 표시된 언어의 문자열로 남는다. 이후 로케일을 바꿔도 이미 읽은 영어를 한국어로 덮어쓰지 않는다. 미리보기나 언어 변경으로 최종 선택·사용인 관계를 변경하지 않는다.

## 검증 범위

`basement_session_smoke.gd`에서 두 분기 각각에 대해 영어 EDC 목표·버튼, 실제 버튼 콜백을 통한 요약·확인 본문, 취소·확정 레이블, 한국어 복귀 후 기존 영어 기록 유지와 진행 불변을 검사한다. 이후 기존 한국어 확인·커밋·불러오기·엔딩 후속 회귀를 계속 수행한다.

이 검사는 영어 전체 완주나 네이티브 화면의 모든 글자 배율·해상도 검증이 아니다. EDC 이전 F3 장치 조사, 세션 피드백·확정 후 독백, 현실 수첩 본문, 잔류 후속과 기타 후반 대사는 별도 현지화 대상이다. 공통 메뉴·수첩의 후반 문자열도 이 문서의 완료 범위에 포함하지 않는다.
