# GGB 퍼즐 오브젝트 목록과 외형 요구사항

2026-10-24 기준. 튜토리얼부터 메인 퍼즐, 단서 조사·일지 복원, 관계 퍼즐, 공간 해금, 최종 선택과 엔딩 후속까지 포함한다. 직접 조작하는 물체와 단서·결과를 보여 주는 물체를 함께 정리했다. 배경 장식만을 위한 소품과 상점·홍보물은 [전체 제작 인벤토리](game_object_inventory.md)에서 관리한다.

**필수 조건**은 현재 기획과 제작 계약에 있는 내용이다. **외형 제안**은 그 조건을 구현하기 위한 시각적 제안이며 확정 디자인이 아니다. 재질·장식·세부 배색은 제안 범위에서 조정할 수 있지만, 추론에 쓰는 홈·문양·눈금·연결선·앞뒷면 차이는 유지해야 한다. 이 문서는 기획·아트 요구사항이며 실제 에셋 제작·게임 반영 완료를 뜻하지 않는다.

동일 물체를 여러 퍼즐에서 다시 사용한다. 표의 행 수는 신규 에셋 수가 아니다. `OBJ_*`·`SERVANT_OBJ_*`는 기존 런타임 ID를 그대로 적었고, 이름만 적은 부품은 해당 부모 오브젝트·패널 아래에서 제작한다. 새 저장 ID를 발급하지 않는다.

## 1. 공통 외형과 구별 기준

| 대상 | 필수 조건 | 외형 제안 |
| --- | --- | --- |
| 저택의 일상 물체 | 고딕 저택의 생활 도구로 읽히고, 이후 같은 물체에서 시설 기능이 드러나야 함 | 목재·도자기·천 외피 아래에 홈·배관·단자가 이어지는 구조. 초기부터 모든 물체에 SF 발광선을 넣지 않음 |
| 조작 가능한 부품 | 실제 움직이는 부분과 고정 장식을 구분. 기본·선택·조작 불가·검증·완료 상태 제공 | 손이 닿는 돌출부, 회전 여유, 접촉 마모를 사용. 선택 효과는 물체 윤곽을 따라 배치 |
| 추론에 사용하는 그림 | 문장으로 설명한 홈·나사·찢김·선의 연결이 실제 확대 그림에도 존재 | 확대해도 같은 원도를 사용. 부분 일치와 완전 일치가 구별되도록 비대칭 구성 |
| 안전 시험과 실제 실행 | B3-B·C4·D1의 실제 실행에는 별도 확인. 이 세 퍼즐만 당일 재시도가 막히는 물리 실패 사용 | 시험부는 노출된 작은 조작부, 실제 실행부는 덮개·분리된 손잡이로 구분. 실패는 핀 휨·코팅 경화·압력 잠김으로 표현 |
| 자료와 문서 | 출처·앞뒤·회전 상태를 확인. 글씨색만으로 방향이나 정답을 알려 주지 않음 | 종이 종류·모서리·섬유·눌림·제본으로 구별. 필요한 기능명·눈금만 표시하고 설명용 보조 레이블은 늘리지 않음 |
| 무음·색 제거·모션 감소 | 문양·선 패턴·명칭·정적 상태로 같은 추론 가능. 드래그는 선택 후 배치로 대체 | 소리 재생 옆에 대응 파형. 점멸 대신 전후 비교. 색 제거 시에도 선과 배경의 명도 차이 유지 |
| 제작 분리 | 가동 부품·가림막·그림자·상태 덧씌움·단서 원도 분리 | 같은 본체에 상태 레이어를 교체. 작은 물체의 클릭 영역은 그림과 별도로 확보 |

화면·납품 수치는 [콘텐츠 제작 규격](content_pipeline_specs.md)을 따른다. 최소 클릭 영역은 44×44 논리 px이며 1280×720에서도 필수 단서를 판독할 수 있어야 한다. 서명은 다음 대응을 유지한다. 색은 출처를 돕고 역할·정답·관계 등급은 대신하지 않는다.
