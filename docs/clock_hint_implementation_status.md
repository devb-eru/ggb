# 시계망 직접 요청형 힌트

## 기준과 구현

기준은 `ideas/md/24-3_메인퍼즐_고난도개정안.md`의 시계망·단계형 힌트와 `ideas/md/v04/08_이벤트상세_03_메인퍼즐.md`의 7.8·23절이다. 퍼즐 정답·검증 함수와 수면 실패 규칙은 변경하지 않았다.

- B3_A, B3_B, BF 단계의 수첩에 `생각을 정리한다`를 추가했다. 다른 챕터에서는 나타나지 않는다.
- 힌트 진입 시 강한 힌트의 해답 노출을 알리고 닫기를 기본 선택으로 둔다. H1부터 각 단계의 읽기 버튼을 눌러야 다음 내용을 볼 수 있다. 시간이 지났다는 이유로 자동 노출하지 않는다.
- B3-A는 나사 구멍 관찰, 침실의 단절, 외부 서고 반전, 대응접실→외부 서고 연결, 전체 경로의 순서다.
- B3-B는 기능 관찰, 배선과 J1 문장 연결, 역할·위상 분리, 기준 시계 지정 안내, 역할별 답과 0/+1 비교의 순서다. 약한 시험으로 위상까지 검증할 수 있다고 안내하지 않는다.
- BF에서도 역할·위상 힌트를 열 수 있다. 힌트가 당일 잠금을 해제하거나 실패 횟수·사용인 관계·엔딩 조건을 변경하지 않는다.
- 한국어·영어 텍스트는 `game/scripts/ui/clock_hint_texts.gd`에 있다. 현재 실제로 보여 준 힌트는 공통 대화 기록을 통해 슬롯에 영구 저장한다. 메뉴만 열었거나 아직 요청하지 않은 강한 힌트는 기록하지 않는다.
- 수첩을 다시 열면 H1부터 재요청한다. 단계별 열람 횟수를 별도 수치로 저장하거나 보상에 반영하지 않는다. 이미 본 힌트는 대화 기록에서 다시 읽을 수 있다.

## 검증

`CHAPTER_ONE_SMOKE`가 통과했다. 실제 수첩 버튼·각 단계 읽기 버튼·대화 다음 버튼으로 5단계를 열고 닫는 경로를 확인했다. 표시한 5개 힌트만 기록에 추가되며, 대화 기록 외의 전체 GameState가 불변임을 검사했다. 영어 반전 단서, 실패 상태의 +1 안내 및 다른 퍼즐에서의 힌트 부재도 검사했다.

이번 테스트의 5단계 UI 경로는 B3-B fixture다. B3-A의 모든 조각 상태, 실제 키보드·마우스 입력, 전체 화면 배율과 난이도·플레이타임은 아직 검증하지 않았다.

## 남은 기획 요구

### 실제 실패 후 선택형 제안

B3-B 실제 작동이 두 번 이상 실패하면 실패 대사를 끝까지 읽은 뒤 지원 모달을 연다. 2회는 H3, 3회는 H4, 4회 이상은 H5를 직접 요청할 수 있다. 기본 선택은 조사를 계속하는 것이며 관찰 힌트부터 시작하는 선택지도 제공한다. 미리 강한 힌트 본문을 표시하지 않는다. 저장에 실패했거나 첫 실패인 경우 이 경로에서 제안하지 않는다.

재생 중인 실패 대사를 닫기 전에 다른 힌트가 끼어들지 않으며, 제안 자체는 진행 상태·실패 횟수·대화 기록을 바꾸지 않는다. 같은 가설 판별이 아니라 영구 B3-B 실제 실패 횟수에 따른 지원이다. 불러오기만으로 자동 제안을 재생하지 않으며 수첩의 직접 요청 경로는 계속 사용할 수 있다.

회귀 테스트에서 1~4회 실패 fixture별 제안 유무·단계, 위상 정답 비노출, 거절 시 전체 상태 불변을 검사했다. 이전 실패 1회 fixture에서 실제 `activate_clock` 행동을 실행하고 실패 대화의 다음 버튼을 끝까지 눌러 H3 제안으로 이어지는 경로도 검사했다. 실제 수면을 세 번 반복한 사용자 입력 검증은 아니다.

1. 같은 가설 반복 및 관련 없는 입력 감지 후 힌트 제안.
2. 실패별 맞은 부분·범주 표시 확장. 2회 이상에서 강한 지원을 선택적으로 제안하는 연결은 추가했다.
3. H4의 실제 구성 요소 고정과 H5의 후보 제한 UI. 현재는 텍스트 안내만 제공하고 플레이어 입력을 자동 수정하지 않는다.
4. C3·C4·D0·D1·D4·F0의 동일 수준 단계형 지원.
5. 최초부터 실제 입력으로 난이도와 강제 수면 횟수를 측정한 뒤 지원 타이밍 조정.

단계형 힌트 전체 완료가 아니라 시계망의 직접 요청형 안내 구현이다.
