# 이리스 고백 분기 대조

## 검토 범위

`ideas/md/v04/12_이벤트상세_07_사용인핵심관계.md` 9.8과 `game/scripts/systems/iris_relationship.gd`, `researcher_confrontation.gd`, `reality_wake.gd`를 소스 수준에서 대조했다.

## 확인 결과

- E3_2는 선택 결과의 관계 변화 적용 후 bond 4 이상 직접 비공개, 2~3 우회 인정, 0~1 및 alert 4 이상 부정, 나머지 보류로 분기한다. 높은 bond와 높은 alert가 공존하면 고백 단계는 bond를 우선하며 어조를 추가한다.
- F2는 전원 관계 완료 시 공개 고백, 이리스 핵심 관계 미완료 시 `inferred_only`, 나머지는 현재 bond·alert로 재계산한다. 별도 전역 고백 상태를 저장하지 않는 기획과 일치한다.
- F2의 환경 인증 기록은 객관적 사실이며 개인 고백과 구분되어 표시된다. 미완료 경로에서 이리스가 살의를 직접 인정하는 대사는 확인되지 않았다.
- 현실 작별은 같은 `iris_state` 계산을 사용한다. 이는 소스 연결 확인이며 모든 변형의 실제 화면 재생을 확인했다는 뜻은 아니다.

## 남은 확인

- 모든 관계 수치 조합과 선택 후 변화의 경계값을 별도 회귀 테스트로 고정한다.
- 잔류 엔딩의 개별 반응과 각 경로의 대사 주체·표정·음향을 대조한다.
- 미완료 관계를 건너뛴 전체 플레이가 두 엔딩에 도달하는지 실제 입력 기반으로 확인한다.
- 본 검토는 사용인 관계 시스템 전체 또는 최종 연출 완료 판정이 아니다. 코드 변경이 필요한 분기 불일치는 이번 범위에서 발견하지 않았다.
