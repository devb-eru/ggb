# 검은 거울 재준비 숏컷 조건 검증

## 수정한 결함

이전 CSHORT는 C4 실패 기록의 존재와 당일 잠금 해제만 확인했다. 거울 회로를 성공적으로 확보한 뒤에도 실패 기록은 채널 해석까지 활성 상태이므로, 수면 후 물리 표면이 초기화되면 이미 끝낸 청소의 재준비 버튼이 다시 나타날 수 있었다.

`can_prepare_mirror_shortcut()`을 UI와 실행부에서 함께 사용한다. 같은 침실, J2 단계, 청소·약품 기록 확보, 활성 실패 기록, 당일 잠금 해제, 미개방 표면, 미획득 거울 회로를 모두 확인한다. 성공 후 영구 정보가 남으면 물리 표면의 리셋 여부와 관계없이 재준비를 종료한다.

원래 수면 리셋·영구 정보·다섯 채널 해석·J3 복원 규칙은 유지한다. 실패 뒤에는 재료만 준비하며 세정액을 자동 제조하지 않는다.

## 검증

- 실패 당일 숏컷 차단 및 수면 이후 허용.
- 거울 회로 확보 후 수면해도 숏컷 차단.
- 채널 해석 전 거절 시 저장 상태와 위치·회로 기록 보존.
- 실제 침실 컨트롤에 CSHORT가 나타나지 않음.
- 기존 세정제 재제작, 고경계 순찰 대응, 다섯 채널 해석과 J3 복원 회귀 유지.

`BLACK_MIRROR_SMOKE`와 `CHAPTER_ONE_SMOKE`가 통과했다. 이는 해당 상태 전이와 UI 생성 검사이며 OS 입력을 통한 전편 완주 증거는 아니다.
