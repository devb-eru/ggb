# D6 파열 수면 전환 검증

검토일: 2026-09-14

## 동작

D6에서 침실 또는 비상 캡슐의 `잠든다`를 확정하면 선택 경로를 먼저 안전 저장하고 6초 `FRACTURE_SLEEP` 입력 고정을 시작한다. 즉시 BROKEN_RESET을 실행하지 않는다.

전환은 0~2초, 2~4초, 4~6초의 세 단계다. 선택한 경로에 따라 캐노피 그림자·침대 아래 곡면 또는 투사 직물·캡슐 덮개의 감각이 달라진다. 두 경로 모두 아래 네 상태를 텍스트로 순차 확인한다.

```text
SUBJECT SIGNAL ........ PERSIST
RESIDENT MEMORY ....... PERSIST
WORLD GEOMETRY ........ DEGRADED
CAMOUFLAGE MASK ....... NO BASELINE
```

색상과 음향 없이 읽을 수 있다. HOLD 중 월드 조사·이동·수면 재입력은 노출하지 않는다. 메뉴와 설정은 사용할 수 있고 메뉴·창 포커스 이탈·다른 모달 중에는 전환 시간이 흐르지 않는다. 정상 루프 관계 기억이나 관계 수치를 추가로 계산하지 않는다.

6초가 끝난 뒤에만 기존 `ResetCoordinator.request_broken_reset`을 호출한다. 성공하면 S3의 같은 침실 E1로 이동하고 선택 경로 로컬 상태를 제거한다. 저장 실패는 D6와 선택 경로를 그대로 롤백해 유지하고 자동 재시도를 중단한다. 플레이어는 `수면 전환 저장 재시도`를 명시적으로 눌러 0초부터 다시 진행한다.

프로세스를 종료해도 확정된 `fracture_rest_route`가 남아 있으면 D6 컨트롤러 재구성 시 `FRACTURE_SLEEP` 0초부터 재개한다. 경과 초는 저장하지 않으므로 중간 프레임을 체크포인트로 오인하지 않는다.

## 검증

- Godot 4.7.2 import와 headless `BASEMENT_SESSION_SMOKE: PASS`를 확인했다.
- 침실·캡슐 두 경로가 확정 직후 D6에 머물고 월드 입력을 제거하는지 확인했다.
- 메뉴에서 6초가 흐르지 않고 5초에는 BROKEN_RESET이 실행되지 않는지 확인했다.
- 경로 저장 재로드 뒤 HOLD가 자동 재개되는지 확인했다.
- 캡슐 경로에 저장 실패를 주입해 상태 롤백, 자동 재시도 없음, 명시적 재시도와 E1 합류를 확인했다.
- 두 경로의 최종 E1 위치, 관계값, D6 로컬 제거가 동일한지 확인했다.
- Windows Compatibility 렌더러에서 `d6_sleep_transition_en_200.png`를 생성했다. 1280x720·영어·텍스트 200%의 마지막 체크 단계에서 감각 문장과 네 상태 줄, 메뉴·수첩 버튼에 잘림이나 겹침이 없음을 육안 확인했다.

GUI 전체 회귀는 해당 캡처를 만든 뒤 후속 J4 확인 타이밍 검사에서 실패했다. D6 캡처 자체와 headless 전체 회귀 통과는 유효하지만, 이를 GUI 전편 회귀 통과로 확대 해석하지 않는다. J4의 프레임·포커스 민감 검사는 별도 안정화 대상이다.

최종 캐노피·캡슐 덮개 애니메이션, 실제 시스템음과 저사양 프레임 계측은 별도 제작·검증 대상이다.
