# ALL 의식 및 엔딩 도입 감상 기록

- 최종 프레임 완료된 분기만 페이지를 구성한다.
- ALL 인증은 감상 플래그, 완료 노드, 다섯 인격 인증, 권한 확인 및 전원 관계 완료를 모두 요구한다. 관계 완료만으로 미감상 의식을 열지 않는다.
- 기존 EndingEntry의 다섯 인격 대사와 실제 권한 확인 문구를 사용한다.
- 완료한 분기의 도입·저전력 보존 또는 안정화 상태 설명만 추가한다. 반대 분기 설명은 표시하지 않는다.
- 테스트: 전원 관계만 완료한 경우 숨김, 완료 노드 없는 seen 플래그 숨김, 모든 증거가 있는 경우 6페이지 추가.
- 이 기능은 텍스트 감상 기록이다. 서명 애니메이션 재생, 전체 엔딩 영상·사운드와 타이틀 진입은 잔여 작업이다.
