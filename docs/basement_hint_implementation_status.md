# 지하 구간 직접 요청형 힌트

## 정본과 적용

`ideas/md/24-3_메인퍼즐_고난도개정안.md`의 9~11절과 v0.4 이벤트 상세 08을 기준으로 한다. 현재 지원 단계는 D0_A·D1·DF·D4다. 앞뒤 이야기나 엔딩을 미리 설명하지 않고, 현재 퍼즐의 관찰·변환·입력 절차를 안내한다.

| 트랙 | 약한 관찰에서 직접 지원까지 |
| --- | --- |
| D0_A | C5의 출처 → 세 기준점 → 좌우 반전 → 반시계90도 → 대시계 고정과 II·I·III 판독 |
| D1·DF | 순서와 깊이 분리 → 직선·분기·고리 흐름 → 밀기 전 가역성 → 첫 축과 깊이 기준 → 2·1·3 및 중앙 손잡이 시계방향 반 바퀴 |
| D4 | 연동 관찰 → 손잡이 영향 → 목표 문양 → XII의 STABLE과 추가 동작 → 초기 상태 기준 A1·B1·C2 및 보조 레버 |

각 트랙은 수첩의 `생각을 정리한다`로 요청한다. 강한 단계는 버튼으로 직접 요청해야 보여 주며, 닫기가 기본 선택이다. 한국어·영어 자료를 제공하고 실제 읽은 문장만 기존 대화 기록에 영구 저장한다.

## 유지하는 제약

- C4의 파형 변환과 D0_A의 도면 변환을 명시적으로 구분한다.
- D1에서 이미 밀린 축은 힌트로 빼거나 깊이를 바꿀 수 없다. DF는 잠든 뒤 다시 준비해야 한다.
- D4 조작 횟수는 초기 위치 기준임을 명시한다. 현재 상태에 무조건 같은 횟수를 추가하라고 안내하지 않는다.
- 링 고정·축 밀기·중앙 손잡이·보조 레버 실행을 대신 확인하지 않는다.
- 힌트는 파열 플래그, 관계, 엔딩, 시간대 및 인벤토리를 변경하지 않는다.
- D0 준비 조사, D2 창고 조사, D5 이후와 현실의 물리 수첩에는 이 지원을 노출하지 않는다. 기존 현실 수첩 분리는 유지한다.

## 검증 범위

`BASEMENT_SESSION_SMOKE`의 기존 진행 중 D0_A·D1·실제 깊이 오류 후 DF·D4에서 화면을 열어 검사한다. 수첩 버튼과 각 단계 읽기·다음 버튼으로 5단계를 읽고, 그 5개 문장만 기록에 추가되며 나머지 전체 GameState가 불변인지 비교한다.

이 검증은 자동 세션 행동·버튼 신호 기반이다. 마우스·키보드 각각의 실제 완주, 전체 고배율 화면, 난이도와 플레이타임은 별도 검증 대상이다.

격리 프로젝트의 `BASEMENT_SESSION_SMOKE`가 통과했다. 신규 4개 상태의 힌트 검사와 기존 후반 진행·엔딩 회귀를 함께 실행했다.

## 미완료

- D1 실제 반복 실패 횟수·유형에 따른 지원 제안.
- 구성 요소 고정 및 후보 제한의 실제 조작 UI.
- F0와 사용인 관계 퍼즐의 단계형 지원.
- 영어 전체 장면 및 접근성 실입력 QA.

퍼즐 정답 리소스와 물리 리셋 규칙은 변경하지 않았다.
