# 엔딩 감상 프로필 초기 구현 검증

## 구현 범위

- `EndingMetaStore`가 `user://profile/ending_meta.json`에 두 분기의 감상 여부와 ALL 의식 감상 여부를 저장한다.
- 최종 프레임 완료를 본편 슬롯에 저장한 직후 프로필을 자동 저장한다. 본편 저장 실패 시 프로필은 쓰지 않는다. 프로필 저장만 실패하면 본편 완료 상태는 롤백하지 않는다.
- 재진입 시 크레딧 시작 전 프로필 저장을 확인한다. 실패하면 오류와 재시도 버튼을 표시한다. 크레딧 행동도 저장을 다시 확인하므로 UI를 우회해도 저장 실패 중 크레딧을 시작할 수 없다.
- 크레딧 완료 여부와 감상 기록은 분리한다. 본편 슬롯을 되돌려도 프로필은 롤백하지 않는다.
- 기본 5개 메타 플래그는 문서 14 계약을 유지한다. 선택적 `reality_all_seen`, `stay_all_seen` 필드를 추가하며 기존 profile 1 파일에는 false로 해석한다.
- 기본·백업·임시 파일의 유효한 seen을 OR 결합한다. 임시 파일 검증 후 백업, 기본 파일 순서로 동일 문서를 기록한다. 중간 중단 시 살아 있는 유효한 사본으로 복구한다. 이는 파일 세 개를 묶은 원자적 트랜잭션이나 하드웨어 전원 차단 보장이 아니다.
- 지원하지 않는 미래 버전이 어느 사본에든 있으면 쓰기를 거절한다. 읽기 불가도 쓰기로 덮어 숨기지 않는다.
- 전체 사본 손상 시 복구할 수 있는 것은 현재 완료 엔딩뿐이다. 소실된 다른 엔딩의 감상 여부를 추측하지 않는다.
- 크레딧 제작진 명단은 사용자 요청대로 미정 유지한다.

## 검증

- 전용 `ending_meta_smoke.gd`: 미완료 거절, 두 분기 누적, 반복 저장, ALL 분리, 기본 파일 손상 복구, 미래 버전 거절 및 원문 보존.
- 격리 Godot 프로젝트에서 `ENDING_META_SMOKE: PASS` 확인.
- 최종 프레임 이후 크레딧 진입은 기존 basement-session 회귀 테스트로 확인한다.

## 남은 작업

- 자동 커밋은 구현되었다. 저장 재시도 화면은 현재 개발용 완료 화면을 사용하며, 최종 아트 장면 위 오버레이로 표현하는 작업은 남아 있다.
- 회귀 테스트는 분기마다 비어 있는 격리 프로필에서 최종 프레임 완료 직후 seen을 검사한다. 의도적으로 메타 저장을 실패시켜 본편 완료 보존, 크레딧 진입 거절, 재로드 뒤 재시도를 검증한다.
- 갤러리·챕터 선택의 해금 플래그는 저장되지만 해당 화면은 아직 없다. F3 독립 재선택 사본도 별도 작업이다.
- 저장 장애 주입, 실제 강제 종료 타이밍 및 전원 차단 테스트는 미실시다. 제작용 최종 QA 통과를 뜻하지 않는다.
