# 공통 음향 런타임 구현 상태

## 적용 범위

- `game/scripts/systems/game_audio.gd`를 타이틀 bootstrap의 `GameAudio` 자식으로 생성한다. 승인 음원이나 자동 재생 cue는 아직 등록하지 않는다.
- `play_cue(cue_id, stream, channel)`은 `BGM`, `AMB`, `SFX`만 받는다. 빈 ID, 없는 스트림, 잘못된 채널은 false로 거부하며 게임 진행 상태를 바꾸지 않는다.
- BGM과 공간음은 각각 한 개, 효과음은 최대 26개로 전체 최대 28개를 유지한다. 채널별 플레이어 음량을 사용하며 AudioServer 버스·효과 체인은 아직 만들지 않았다.
- 같은 활성 cue ID는 다시 시작하지 않는다. 효과음 한도 초과는 신규 재생을 거부한다. 우선순위 탈락·완료 후 cooldown은 후속 작업이다.
- 공간음·BGM 교체는 즉시 정지 후 새 재생이다. 크로스페이드는 아직 없다. 반복은 공급받은 AudioStream의 승인된 loop 설정을 따른다. 공유 리소스를 런타임에 변형하지 않는다.
- 자연 종료 또는 명시적 정지 시 플레이어를 해제한다. 타이틀 복귀·캠페인 전환·프롤로그 진입에서 기존 재생을 정리한다.
- 포커스 이탈 시 일시정지하고 입력 복구 지연이 끝나면 해제한다. pause reason을 집합으로 관리하므로 다른 사유가 남아 있으면 재생하지 않는다. 메뉴 사유 API는 제공하되 실제 모든 메뉴에는 아직 연결하지 않았다.
- master와 채널별 선형 음량을 곱한다. 0 및 음소거는 실제 0 출력이다. NaN·무한대·0~1 밖의 설정은 기존 값을 유지한 채 거부한다.

## 타이틀 음향 설정

- 타이틀의 설정에서 별도 음향 패널로 진입한다. 전체·배경 음악·공간음·효과음을 각각 0~100%의 1% 단위 슬라이더로 조정하고 전체 음소거를 선택한다. 한국어·영어 라벨과 수치가 표시된다.
- 기존 접근성 프로필에 선택적 `audio` 사전을 저장한다. 이전 버전처럼 항목이 없는 프로필은 기본 음량으로 읽는다. 항목이 있다면 숫자 타입·유한성·범위 및 음소거 boolean을 검증한다.
- 적용 전 조작은 임시 값이다. 뒤로·취소는 재생 상태를 변경하지 않으며 저장 성공 후에만 프로필과 재생 시스템에 전달한다. 실패하면 패널에 오류를 표시하고 재시도할 수 있다. 접근성 옵션만 다시 적용해도 저장된 음향 값은 보존한다.
- bootstrap 시작 시 저장된 프로필 값을 전달하며 이후 성공한 음향 변경도 신호로 반영한다. 게임 진행 슬롯을 수정하지 않는다.
- 스크롤 패널은 포커스를 따라 이동한다. 1280×720·글자 200% 네이티브 캡처에서 영어 설정 항목과 버튼 표시를 확인했다. 전체 DPI·해상도·키보드 실입력 QA를 완료한 것은 아니다.
- `START_SCREEN_SMOKE`에 구버전 프로필, 잘못된 숫자 타입·NaN, 취소, 저장·재읽기, 저장 실패, 접근성 재적용 시 보존, 영어 라벨과 게임 상태 불변 검사를 추가했다. `FOUNDATION_SMOKE`도 통과했다.

## 확인한 테스트

Godot 4.7.2 headless의 `game_audio_smoke.gd`에서 누락 스트림, 잘못된 채널, 중복 ID, 공간음 교체, 효과음 26개 제한, 복수 일시정지 사유, 음량 곱, NaN 거부, 음소거, 정지 후 노드 정리를 확인했다. 최종 실행에 객체 누수 경고는 없었다. 기존 `START_SCREEN_SMOKE`도 통과했다.

테스트 스트림은 런타임 생성 무음 스트림이며 납품 에셋이 아니다. 자연 종료 타이밍, 실제 오디오 드라이버·포커스 전환, 루프 경계, 청취 균형, 장치 변경 및 엔딩까지 음향 품질을 증명하지 않는다.

## 다음 필수 작업

1. 승인 리소스 경로·cue 파트·접근성 캡션 레지스트리와 장면별 연결.
2. 게임 플레이 중 메뉴에서도 동일 음향 설정을 열고 복귀할 수 있도록 연결. 타이틀 화면의 설정·저장은 구현되어 있다.
3. P4 맥박·B3 종·D5 전환·양쪽 엔딩 및 나머지 전수 의뢰 cue 적용.
4. 심박 감소 등 대체 모드, 메뉴 일시정지, 반복 간격, 우선순위, 크로스페이드.
5. 승인 음원으로 실제 청취와 Windows 입력·포커스·장치 QA.

`audio_integration_readiness.md`의 재생 시스템 부재 관찰은 이 문서 이전 상태다. 승인된 음원 접수 및 최종 크레딧 미정 정책은 그대로 유지한다. 게임 전체 또는 음향 완료로 판정하지 않는다.
