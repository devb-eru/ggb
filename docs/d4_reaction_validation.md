# D4 관계 반응 동결과 D5 소비 검증

## 구현 계약

- CHK_D4_REACT는 D4 보조 레버가 위장 필터를 해제하는 같은 트랜잭션에서 한 번만 판정한다.
- 에드가의 bond 4 이상을 우선한다.
- 에드가 조건이 없으면 마라 1, 루카, 이리스, 마라 2 중 bond 또는 alert가 4 이상인 대상을 고른다.
- 강도가 같으면 높은 bond를 우선하고, 다시 같으면 마라 1→루카→이리스→마라 2 순서를 사용한다.
- 결과는 loop_state.event_local_states.D5.D4_REACTION에 owner, mode, 당시 bond와 alert를 함께 저장한다.
- D5는 저장된 결과만 읽는다. D5 진입 뒤 관계값이 달라져도 반응자를 다시 고르지 않는다.
- 조건을 만족한 사용인이 없거나 이전 버전의 D4 저장에 동결값이 없으면 추가 대사를 만들지 않는다.
- 이 반응은 bond, alert, 관계 완료, 연구원 기록, 퍼즐 결과를 변경하지 않는다.

## 화면 동작

- 본편 D5의 다섯 진단 투사 다음에 선택된 사용인의 한 줄을 삽입한다.
- 데모 60초 스팅어는 네 번째 구간에 같은 한 줄을 붙인다. 재생 시간과 완료 경계는 바꾸지 않는다.
- 한국어와 영어에서 인물명 및 bond/alert 어조를 각각 제공한다.
- D5의 선택적 시선 기록 D5_FOCUS_OWNER와 D4 반응 동결값은 같은 D5 로컬 상태에서 서로를 덮어쓰지 않는다.

## 자동 검증

basement-session smoke가 다음을 검사한다.

1. 관계값이 0~3이면 반응이 없다.
2. 다섯 사용인의 높은 bond를 각각 선택할 수 있다.
3. 다른 사용인의 높은 alert도 반응 조건이 된다.
4. 에드가의 높은 bond, bond 우선, 고정 동률 순서가 결정적이다.
5. 판정기가 입력 스냅숏을 변경하지 않는다.
6. D4 완료 저장과 재로드 뒤 같은 owner가 남는다.
7. D4 저장 실패는 필터 해제와 반응 동결을 함께 롤백하고 명시적 재시도에서 함께 저장한다.
8. D5 전에 관계값을 바꾼 테스트 스냅숏에서도 동결된 owner가 유지된다.
9. 본편은 기존 14문장에 정확히 한 줄만 추가하며, 무반응·구버전 상태는 14문장을 유지한다.
10. 데모 스팅어가 같은 동결 반응을 사용한다.
11. D5 반응과 시선 선택이 관계값을 변경하지 않는다.

캡처 모드는 1280x720, 영어, 글자 200%의 반응 대사를 user://d4_reaction_en_200.png에 저장한다.

2026-09-14 검증 결과:

- 격리 복제본의 헤드리스 basement-session 전체 회귀는 PASS다.
- Windows Compatibility 렌더러에서 새 캡처를 생성해 화자명과 두 줄 본문이 1280x720, 글자 200%에서 잘리지 않는 것을 확인했다.
- 같은 GUI 캡처 실행의 후반 전체 회귀는 기존 포커스·실시간 타이머 민감 항목에서 실패했으므로 전편 GUI PASS 근거로 사용하지 않는다. D4 기능 판정은 헤드리스 전체 회귀와 생성된 화면의 직접 확인을 근거로 한다.

## 남은 제작 범위

- 현재 반응은 대사와 기존 개발용 투사 화면으로 표현한다.
- 레이피어를 거두는 동작, 진단 잡음에서 한 채널만 선명해지는 믹싱, 인물별 최종 투사 아트와 실제 음원은 에셋·사운드 납품 뒤 연결한다.
- 이 검증은 D5 전체 최종 시청각 연출이나 전편 수동 완주를 증명하지 않는다.
