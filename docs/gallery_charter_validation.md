# 잔류 합의 감상 기록

- 잔류 엔딩의 실제 확인한 기억 원칙, 확정한 외형 표시, 제안으로 전환한 사용인을 감상 기록 앞부분에 추가한다.
- 원칙과 표시 방식은 기존 StayCharter 데이터를 사용한다. 외형 모드 값만 있고 확인 이력이 없으면 페이지를 생성하지 않는다.
- 사용자별 역할 전환은 proposed 목록으로 제한한다. 완료 엔딩이라는 이유로 누락된 과거 이력을 채우지 않는다.
- 테스트: 이력 없는 경우 최종 장면만 유지, 원칙 1개·사용인 1명만 기록한 경우 해당 두 페이지만 추가, 확인 전 외형 숨김 및 확인 후 표시.
- 전체 영상 재생, ALL 의식 및 타이틀 갤러리 진입은 아직 남아 있다.
