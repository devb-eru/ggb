# 접근성 프로필 타입 검증

버전·글자 배율의 변환 전 타입을 검사한다. JSON 숫자로 읽힌 정상 정수·실수 값은 허용하지만 문자열·boolean·배열·사전·null·NaN·무한대와 지원하지 않는 수치는 거절한다. 소수 버전을 정수로 잘라 현행 버전으로 받아들이지 않는다. 서명·움직임 모드는 문자열과 허용 목록을 모두 확인한다.

타이틀 회귀에서 잘못된 필드 32개 조합과 JSON 왕복 정상 프로필을 검사했다. 검증은 입력 사전을 변경하지 않는다. 기존 백업·기본값 복구와 음향 설정 동작은 유지한다.

## 사용자 확정 키 재지정 정책

- 새 키는 해당 기본 키를 교체한다. 기본값 복원을 제공한다.
- Escape·Tab·Shift+Tab도 재지정할 수 있다.
- 설정 화면에서 마우스로 취소·기본값 복원에 접근할 수 있어야 한다.
- 설정 UI·저장·재시작 적용·중복 키 검사는 후속 구현 대상이다. 이 문서의 프로필 검증 수정만으로 키 재지정 완료를 선언하지 않는다.
