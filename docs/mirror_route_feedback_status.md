# 거울 회랑 경로 피드백

기준일: 2026-09-30

## 이용 흐름

1. 세정제 준비 후 대시계에서 열세 번째 종 신호를 다시 보낸다.
2. 거울 회랑에서 회전, 반전, 하단 고정과 경로 조각을 선택한다.
3. `마른 천으로 시험`을 누르면 시험 결과와 이동 경로 창이 열린다. 젖은 천 확인창에서 마른 시험을 선택해도 동일하다.
4. 빛의 머리와 작은 잔상이 선택한 경로를 순차적으로 이동한다. 한 구간은 0.95초이며 정상 네 구간은 약 3.8초다.
5. 결과를 확인한 뒤 현재 배치로 돌아가 수정하거나, 기존 순서대로 계획을 확정하고 젖은 천을 사용한다.

## 결과 표시

| 상황 | 표시 |
| --- | --- |
| 회전·반전·고정 불일치 | 투명지의 출발점에서 거울 진동점 쪽으로 접근하다가 멈춘다. 회로 내부로 진입하지 않는다. |
| 경로를 놓지 않음 | 하단 진입점에 X 표시와 기존 원인 설명을 표시한다. |
| 올바른 경로의 일부만 입력 | 입력한 구간까지 이동한 후 끝점에 X를 남긴다. |
| 분기 순서 또는 고리 방향 오류 | 검증된 앞 구간을 이동한 뒤 처음 잘못 선택한 구간의 일부에서 멈춘다. 이후 구간을 자동 재생하지 않는다. |
| 전체 정답 | 진입, 짧은 분기 왕복, 긴 분기, 시계 방향 고리를 이동한 뒤 원과 확인 표식을 남긴다. |

이동 길이와 속도, 잘못된 구간의 45% 지점에서 멈추는 표현은 표시 연출이다. 판정은 기존 `BlackMirrorPuzzle.inspect_trace()`의 `ok`, `category`, `verified_prefix`를 그대로 사용한다. 새로운 퍼즐 정답, 시간 제한, 세이브 상태는 추가하지 않는다.

## 조작과 접근성

- `같은 신호 다시 보기`는 시각화만 재시작한다. 재료 소모, 경로 변경, 시험 재판정은 없다.
- 재생 도중에도 마우스 또는 키보드로 닫을 수 있다. 닫힌 창에서는 연출 시간이 진행하지 않는다.
- 모션 `reduced`와 `static`은 움직이는 입자 없이 같은 이동 궤적, 화살표, 도달·멈춤 표식을 즉시 표시한다.
- 선과 화살표, 원·확인·X 표식, 선택 순서와 원인 문장을 함께 제공한다. 색만으로 판정하지 않는다.
- 한국어·영어를 지원하며, 큰 글자에서는 설명을 스크롤한다. 도면과 닫기·재생 버튼은 화면 안에 유지한다.
- 신호 미발생 등 세션이 시험을 거부한 경우에는 기존 거부 안내만 표시한다. 성공 시각화를 만들지 않는다.
- 결과 창의 내용과 선택은 기존 대화 기록 체계에 남는다. 게임의 퍼즐·물리 상태를 바꾸는 동작은 원래의 `c_dry`뿐이다.

## 구현과 검증

- `game/scripts/chapters/black_mirror_controller.gd`: 마른 시험의 확정 결과를 시각화 창에 연결한다.
- `game/scripts/chapters/mirror_route_feedback.gd`: 기존 확대 도면을 기반으로 궤적, 입자, 방향, 멈춤·도달 표시를 그린다.
- `game/scripts/ui/black_mirror_display_texts.gd`: 안내 문구와 버튼의 한국어·영어 대응을 관리한다.
- `game/scripts/tests/black_mirror_smoke.gd`: 빈 경로, 부분 경로, 진입 누락, 분기 순서, 고리 역방향, 정답, 모든 중첩 조합, 모션 설정, 키보드 닫기, 재생 시 상태 보존, 신호 미발생 거부, 화면 내 배치를 검사한다.

실행: `Godot --headless --path game -- --black-mirror-smoke`

그래픽 실행에 `--mirror-route-capture`를 추가하면 `user://mirror-route-*.png`로 각 결과와 이동 중 화면을 저장한다. 이는 격리된 테스트 프로필에서 실행한다.

Godot 4.7.2의 헤드리스 스모크 및 Windows OpenGL 렌더링 스모크로 검사한다. 원래 C4의 유일해, 물리 실패·수면 복구, 사용인 순찰, C5 기록과 J3 복원도 같은 테스트에서 확인한다.
