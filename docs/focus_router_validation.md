# 포커스 입력 등록·수정키 검증

게임 전용 `focus_next`·`focus_previous`가 키코드 4194308(Backspace)로 등록되어 있었다. 4194306(Tab)으로 교정했다. Godot 기본 `ui_focus_next`·`ui_focus_prev`와 별도 등록이므로 기본 UI에서 Tab이 동작해도 이 오류는 남아 있을 수 있었다.

입력 라우터는 `focus_next`부터 수정키를 무시하고 매칭했다. 키 등록 교정 후 기존 라우터를 사용한 재현에서 Tab·Shift+Tab이 `[1, 1]`로 전달됐다. 두 포커스 액션에 정확한 수정키 매칭을 적용해 `[1, -1]`로 구분한다. 등록하지 않은 Ctrl+Shift+Tab과 키 반복 이벤트는 이동을 추가하지 않는다.

초기 테스트는 잘못된 키 등록 때문에 빈 결과를 받았고, 키 등록을 수정한 뒤 라우터의 방향 문제를 별도로 재현했다. 최종 기반 시스템·1장 회귀가 통과했다. 라우터 검사는 호스트 창의 포커스 상태와 분리한 단위 검사이며, 실제 OS 키보드 완주나 설정 UI의 키 재지정 완료가 아니다.

프로젝트 파일은 두 키코드만 커밋 대상으로 삼는다. 사용자가 수정 중인 다른 프로젝트 설정은 보존한다.
