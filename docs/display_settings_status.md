# 화면 모드·해상도 설정 구현

## 사용 경로

제목 화면의 설정 > 화면, 게임 중 메뉴 > 화면 설정에서 변경한다. 창 모드·테두리 없는 전체 화면·전체 화면을 제공한다. 처음 실행하거나 구형 프로필에 화면 항목이 없으면 테두리 없는 전체 화면을 기본값으로 적용한다.

- 창 크기: 1280x720, 1600x900, 1920x1080, 2560x1440, 3840x2160.
- 전체 화면 두 모드는 현재 모니터의 기본 해상도를 사용한다. 이때 창 크기 선택을 비활성화하고 그 이유를 표시한다.
- 모니터 작업 영역에 창 테두리까지 들어가지 않는 창 크기는 거절한다. 이전 화면을 유지하며 문구를 표시한다.
- 창 모드의 최소 크기는 1280x720이다. 처음 진입할 때 작업 영역 중앙에 배치한다.
- 저장된 창 크기가 다른 모니터에서 들어가지 않으면 시작 시 테두리 없는 전체 화면으로 복구한다. 기존 저장 설정을 임의로 덮어쓰지는 않는다.

## 15초 확인 트랜잭션

1. 미리보기 전에 실제 창의 모드·위치·크기·모니터·테두리·최소 크기를 보관한다.
2. 선택한 모드를 임시 적용하고 단조 증가 시간 기준의 15초 카운트다운을 표시한다. 게임 일시정지와 별개로 시간이 흐른다.
3. 기본 포커스는 **이전 화면으로 복구**다. 유지하고 저장을 명시적으로 선택해야 설정 파일에 남는다.
4. 시간 초과, 취소/뒤로, 재지정한 취소 키, 패널 닫기·제거는 이전 화면을 복구한다. 미확인 변경은 디스크에 쓰지 않는다.
5. 유지 입력이 기한 안에 들어온 경우 현재 프로필의 다른 항목을 유지해 저장한다. 디스크 기록 실패 시에도 이전 화면으로 복구한다.
6. 확인된 설정은 프로그램 재시작 때 다시 적용한다. 미리보기 중 프로그램이 종료되면 이전에 확인한 프로필만 다음 실행에 사용된다.

`accessibility.json`의 선택 항목 `display`는 `mode`, `width`, `height`로 구성한다. 잘못된 타입·비정상 숫자·지원하지 않는 모드와 크기는 프로필 검증에서 거절한다. 진행 슬롯, 수첩·사용인 기억, 퍼즐 상태는 변경하지 않는다.

첫 실행 접근성 화면에서 기본값으로 시작해도 그 전에 확인한 화면·음향·키 설정은 유지한다. 첫 실행 기본값 버튼은 해당 화면의 글자·모션·색상 서명·자막 항목에만 적용한다.

## 검증과 한계

이번 변경에서 START_SCREEN, PROLOGUE_SCENE, FOUNDATION, CHAPTER_ONE, BLACK_MIRROR, BASEMENT_SESSION 검사와 네이티브 화면/재시작 두 프로세스가 PASS였다. 환경의 루트 인증서 읽기 경고는 남았으나 최종 검사에서 스크립트 오류는 없었다.

- `start_screen_smoke.gd`: 시간 경계 14.999/15초, 기한 지난 확인 거절, 중복 미리보기 방지, 부분 적용 실패 복구, 프로필 저장 실패, 미확인 설정 비저장, 일반 접근성 설정에서 화면 항목 유지, 창 닫기와 카운트다운 복구.
- `display_settings_smoke.gd`: 실제 Windows/OpenGL 창에서 테두리 없는 전체 화면·전체 화면 전환, 실제 15.2초 대기 후 이전 창 크기·모드 복구, 작은 모니터에서 불가능한 4K 창 거절, 확인 저장과 별도 엔진 프로세스 재시작 적용을 검증한다. 읽기 단계는 `--verify-display-restart`를 사용한다.
- `prologue_scene_smoke.gd`: 플레이 중 설정 열기·확인 저장, 재지정한 취소 키로 복구, 기존 키 설정과 퍼즐 진행 불변을 검증한다. 창 백엔드는 이 테스트에서 대역을 사용하므로 실제 창 동작은 위 네이티브 테스트를 근거로 한다.
- 영어 200% 글자 크기의 네이티브 확인 화면을 캡처해 확인했다. 테스트 장비는 2560x1600 모니터이며, 3840x2160 실제 화면·모든 Windows DPI·다중 모니터 탈착까지 검증한 것은 아니다.
- 별도의 UI 배율 90~220% 조절, 전체 UI·텍스트 200% 조합과 16:9 밖 여백 정책의 전편 검증은 여전히 남아 있다. 화면 모드 설정으로 해당 제품 조건을 완료 처리하지 않는다.
