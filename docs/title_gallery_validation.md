# 타이틀 감상 기록 진입

- 타이틀에 감상 기록 버튼을 추가했다. 본편 슬롯 불러오기 없이 보존된 엔딩 상태로 페이지를 구성한다.
- 기록 선택, 이전·다음 페이지, 닫기를 제공한다. 긴 본문은 세로 스크롤로 열람한다.
- 감상 기록이 없으면 미감상 내용을 생성하지 않고 빈 상태를 안내한다.
- 게임 상태 설치·수정·저장은 호출하지 않는다. 기존 입력 중단 대상에 새 컨트롤도 포함한다.
- start-screen 회귀에서 진입, 닫기, GameState 불변을 확인했다.
- 최종 시각 디자인, 확대 글꼴별 레이아웃 및 전체 엔딩 영상 재생은 미완료다. 현재는 보존된 텍스트 기록을 열람한다.
