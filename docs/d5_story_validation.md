# D5 본편 서술 전환 검증

검토일: 2026-09-13

## 변경

본편의 `D5_CONFIRM`이 즉시 완료를 쓰던 동작을 변경했다. 손잡이를 놓는 입력 이후 XIII 정상 기동, 완료 패널, 필터 박리와 촉감, 다섯 진단 투사, 지하 천장 하늘, 취침 방송, 휴식 방향 안내의 14개 문장을 읽는다. 마지막 문장을 확인한 뒤 기존 `d_fracture` 트랜잭션으로 D6에 진입한다.

한국어·영어는 `fracture_transition_texts.gd`에서 같은 순서와 문장 수를 제공한다. 사용인들을 같은 방으로 이동시키지 않고 진단 투사로 묘사한다. 새 관계 판정·퍼즐 실패·파열 수면을 실행하지 않는다. 기존 대화 기록 저장 실패 시 확인 차단을 사용한다. 중도 이탈 후에는 D5의 시작 입력에서 다시 읽는다. 데모의 60초 비상호작용 스팅어는 변경하지 않았다.

## 검증

`BASEMENT_SESSION_SMOKE`: PASS, Godot 4.7.2 headless.

- 실제 D4 완료 상태를 본편 D5 테스트에 설치한다.
- D5 버튼으로 두 언어의 14문장 표시, 첫 문장 확인 후 D5 유지, 중단 후 재열기를 검사한다.
- 마지막 확인 뒤 D6, 관계값 불변, `broken_reset_triggered=false`를 확인한다.
- 기존 데모 60초 경계·메뉴 일시정지·완료 저장 실패 복구·본편 가져오기·관계·엔딩 회귀도 통과한다.

이는 자동 상태 주입과 컨트롤러 조작 검증이다. 실제 프로세스 종료 전 조합, OS 입력 전편 완주를 대체하지 않는다. 인증서 저장소 경고 외 SCRIPT ERROR는 없다.

## 남은 범위

정본의 2~3분 연출, 첫 8~12초 HOLD, 다섯 투사 시선 선택, CHK_D4_REACT 한 줄 소비, 마스크 박리·그림자·별 레이어·방송 음원은 미완료다. D6 비상 캡슐 방향 안내는 서술에 포함했으나 실제 목적지·조사 동선의 정본 일치는 별도 대조가 필요하다. 단순 서술 추가를 D5 연출 완성이나 전편 콘텐츠 완료로 판정하지 않는다.
