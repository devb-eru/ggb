# D5 선택 시선

검토일: 2026-09-13

본편 D5의 다섯 진단 투사 서술 구간에 선택 컨트롤을 표시한다. 에드가·마라 1·루카·이리스·마라 2의 이름과 비색상 선·문양, 현재 바라보는 대상 표시를 병행한다. 한국어·영어와 글자 배율을 지원한다. 실제 진단 아바타가 아닌 개발용 선택 UI다.

각 선택은 `loop_state.event_local_states.D5.D5_FOCUS_OWNER`에 기록한다. 대사 배열·커서·관계·엔딩을 변경하지 않는다. 선택하지 않고 계속 읽어도 D6로 진행한다. 같은 구간에서 다른 대상을 다시 선택할 수 있다. 데모와 다른 단계의 세션 요청은 거부한다. 대화 구간 밖의 UI 콜백도 무효다. 수면 후에는 다른 로컬 상태와 함께 제거된다.

저장 실패 시 마지막 성공한 선택을 유지하고 재선택 또는 대사 계속 읽기를 허용한다. 선택 기록을 영구 수첩 정보로 승격하지 않는다. 현재 상태의 임시 감상 표시만 제공하며 수첩 내 별도 임시 열람 패널은 후속 범위다.

재선택 저장에 성공하면 이전 실패 안내를 제거한다. 재시도 버튼 입력은 같은 시선 선택 버튼을 사용하며, 선택 대상만 바꾸고 현재 읽는 문장을 다시 시작하거나 다음 문장으로 넘기지 않는다.
