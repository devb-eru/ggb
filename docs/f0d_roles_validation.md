# F0-D 기록 역할 분류 구현

## 진행 상태

F0-C 완료 후 F0-D 기록 분류 화면으로 진행한다. 기록 카드 조사, 다섯 슬롯 배치, 카드 교환, 일괄 검증을 제공한다. 완료 뒤 F0_E_PENDING에서 현재 권한 인증 구현을 기다린다. 기존 구현 현황의 F0-D 미연결 설명은 이 범위로 대체한다.

## 규칙

정답은 CREATOR=아버지 일지, CUSTODIAN=에드가 암구호, RESIDENT=연구원 인덱스, SYSTEM=D4 복구 명령, SUBJECT=주인공 수첩이다. 카드 내용을 조사해 역할을 판단하며 색상을 답으로 쓰지 않는다. 마라 2 기록이 없으면 익명 인덱스의 동일 기능 설명을 제공하고 관계 보상은 지급하지 않는다.

첫 실패는 맞은 수만 표시한다. 두 번째부터 깨진 역할 라벨의 행동 문장을 제공한다. 세 번째부터 현재 맞는 슬롯 하나만 고정할 수 있다. 고정 후에는 해당 슬롯과 카드를 이동하지 못한다. 나머지는 자유롭게 재배치한다. 빈 슬롯은 검증하지 않는다.

## 검증 범위

basement-session-smoke: 빈 슬롯 거부, 세 번 비교 후 고정, 고정 카드 이동 거부, 부분 저장 재개, 화면의 일괄 검증 버튼, 완료 저장 재개, 익명 경로의 관계 상태 불변. 캡처: user://f0d_roles.png.

## 남은 사항

현재는 기능 문장과 버튼으로 구성한 초기 화면이다. 최종 기록 원문 패널·사용인 개인 음성 주석·서명 연출·번역 ID·난이도 검증은 남아 있다. F0-E, J5, F2/F3와 엔딩 역시 아직 구현 대상이다. 퍼즐 완료는 현재 권한 복원 또는 최종 선택을 의미하지 않는다.
