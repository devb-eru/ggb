# 파열 후 공통 진행 현지화 현황

## 기준일

2026-09-14

## 범위

`E1_ENTRY`, `LUCA_GUIDE`, `LUCA_S2`, `E2_INTRO`, `E_HUB`의 필수 진행 화면과 피드백을 한국어와 영어로 표시한다. 첫 아침 조사 3종 게이트, 네 번째 선택 조사, 루카 선행 선택의 관계 변화, 선택형 다섯 관계 사건과 바로 결산 기능은 변경하지 않는다.

## 구현

- `fracture_common_display_texts.gd`가 첫 아침의 목표·네 조사점·완료 표시, 루카 선행 장면, E2 보고·세 질문, 다섯 목적지와 관계 허브 문구를 담당한다.
- E1의 침대·창문·거울·호출끈 감각 서술과 E2 보고·질문 응답은 저장된 한국어 정본을 화면과 수첩에서만 번역한다.
- 색 명칭을 제거해도 `paired-pulse`, 기능실 이름, 사용인 이름으로 진행을 판독할 수 있다.
- 관계 사건을 미완료로 남긴 채 `J4_CONFIRM`을 선택하는 기존 비차단 계약을 유지한다.

## 검증

- Godot 4.7.2 프로젝트 가져오기: PASS
- `BASEMENT_SESSION_SMOKE`: PASS
- `FULL_CAMPAIGN_SMOKE`: PASS
- Windows OpenGL `BASEMENT_SESSION_SMOKE`: PASS
- 실제 영어 E2 질문 화면: `user://e2_questions.png`

자동 검사는 한·영 카탈로그, E1 실제 위치·목표·오브젝트와 감각 대사, E2 실제 목표·질문·응답, 대화 기록의 표시 문장 보존을 확인한다. 기존 E1 고유 조사 수, 루카 bond 변화와 중복 보상 방지, 질문 생략·임의 순서, 익명 마라 2 인덱스와 관계 허브 진입도 함께 통과했다.

## 남은 범위

다섯 사용인의 개별 관계 사건, J4·E5·E6의 전체 영어 표시와 후속 전편 잔여 문자열 검사가 남아 있다. 관계 LOW/MID/HIGH/ALL과 Windows 입력 방식별 실제 완주는 영문 진행 완성 뒤 수행한다.
