## 범위

- 공통 기록 모달의 표시 목록·선택 보류·완료를 schema 3 커서로 저장한다. schema 1/2 읽기는 유지한다.
- 선택 기록 저장과 게임 진행 저장을 구별한다. 후자가 실패하면 원래 목록에서 명시적으로 재시도하거나 다른 답을 고른다.
- 제한된 컨트롤러 동작만 직렬화한다. Callable/Node/임의 스크립트 경로는 저장하지 않는다.

- J4 확인 지연과 현실 수첩의 표시/읽기 확인 분리를 유지한다.
- 퍼즐 정답·관계 조건·원고 JSON·사용자 편집 씬/리소스·기본 수첩 활성화 정책은 변경하지 않는다.

## 재현

Godot 4.7.2 Windows, 격리 APPDATA/LOCALAPPDATA, 빈 실행 디렉터리와 Windows Desktop Debug PCK를 사용한다.

1. `--notebook-modal-presentation-smoke --ggb-dev-notebook-v2 --cursor-phase=seed`: 각 선택창의 실제 저장/로드, 실패/응답 유실, 같은 답 재시도와 A-B-A를 검사한 뒤 미완료 A1 선택을 저장한다.
2. 별도 프로세스의 `--cursor-phase=resume`: 한국어 선택을 영어로 복원하고 자동 실행 없이 같은 답을 명시적으로 재시도한다.
3. 다시 별도 프로세스의 `--cursor-phase=completed`: 성공한 게임 진행과 닫힌 선택창이 재실행되지 않는지 확인한다.

엔진 함수/신호 구동은 실제 마우스·키보드 입력 검사와 구분한다. 모든 필수 PASS 마커, 종료 코드, 파싱/스크립트 오류를 확인한다. 테스트 프로세스 시간은 p95 성능 수치가 아니다.
