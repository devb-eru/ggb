# 최종 선택 영어 화면 시각 검증

## 실행 환경과 범위

- Windows, Godot 4.7.2, OpenGL Compatibility, Intel Iris Xe.
- 실제 렌더링 캡처 크기: 2560x1600.
- EDC 영어 선택 보드와 현실·잔류 확인창을 각각 촬영해 확인했다.
- 확인창은 `_apply_reading_text_scale(2.0)`로 글자 크기 200%를 적용했다. 게임 규칙이나 저장 프로필을 바꾸는 테스트가 아니다.
- `BASEMENT_SESSION_SMOKE: PASS`. 루트 인증서 저장소 경고는 있었으나 스크립트 오류는 없었다.

## 확인한 내용

1. 선택 보드의 양쪽 절차 버튼이 겹치거나 잘리지 않는다. 같은 크기와 배치를 유지하며 초기 포커스는 중립적인 수첩대에 있다.
2. 두 확인창의 제목과 취소·확정 버튼이 보인다. 자동 검사에서도 두 버튼의 전체 사각형이 확인창 안에 포함되는지 확인한다.
3. 200% 본문은 별도 스크롤 영역으로 배치되며 버튼은 그 영역 밖에 남는다. 첫 화면에 모든 문장이 한꺼번에 표시된다는 의미는 아니다.
4. 영어 확인 본문은 두 절차 각각의 보존 방식과 불확실성을 유지한다. UI 언어 변경으로 저장된 선택을 바꾸지 않는 기존 회귀도 함께 수행한다.

## 재현

`basement_session_smoke.gd`를 기존 bootstrap의 `--basement-session-smoke --capture-basement-session` 인수로 네이티브 실행한다. 테스트 전용 사용자 데이터 경로를 사용해야 하며 실제 사용자 저장 경로로 실행하지 않는다.

해당 테스트는 `user://` 아래에 다음 PNG를 생성한다.

- `edc_english_board.png`
- `edc_english_200_reality.png`
- `edc_english_200_stay.png`

현재 검증은 격리된 `.tmp-chapter-one-validation` 프로젝트에서 수행했다. 캡처는 생성 산출물이며 게임 배포 리소스에 포함하지 않는다.

## 남은 검증과 수정 대상

- 1280x720 최소 창, 1920x1080, 실제 4K, Windows DPI별 반복 검증.
- 스크롤 하단의 최종 안내까지 마우스 휠·키보드 각각으로 읽는 입력 기반 검증. 스크롤 영역과 스크롤바가 보인다는 사실만으로 입력 접근성 완료를 판정하지 않는다.
- 독립 UI 배율과 전체 보드·오브젝트 문구의 글자 배율 적용. 이번 200% 검사는 확인창에 한정되며 보드 전체를 200%로 검증한 것이 아니다.
- 최초 캡처에서는 화면 생성 후 영어로 전환했을 때 공통 메뉴·수첩 버튼이 한국어로 남았다. 후속 조사에서 번역 부재가 아니라 언어 변경 알림 미처리로 확인했다. 아래 수정과 전편 현지화 완료를 구분한다.
- 코어실 배경·연출의 최종 에셋 승인과 정본 충실도. 배경이 표시된다는 것만으로 최종 아트 완료를 판정하지 않는다.

이번 범위에서 확인창 레이아웃 변경은 필요하지 않았다. 테스트와 시각 검증 기록을 추가하며 위 미완료 조건을 완료 처리하지 않는다.

## 후속 수정: 공통 버튼 언어 갱신

`PrologueController._notification()`이 `NOTIFICATION_TRANSLATION_CHANGED`를 받으면 이미 생성된 메뉴·수첩 버튼의 기존 번역 ID를 다시 표시한다. 컨트롤 생성 전 알림은 유효성 검사로 무시한다. 방 렌더링·대화 재생·세션 저장은 호출하지 않는다. 이 동작은 후속 챕터에도 상속된다.

`CHAPTER_ONE_SMOKE`에서 영어→한국어→영어 전환 후 두 버튼의 정확한 문구, 게임 스냅샷 불변과 핫스폿 개수 유지를 검증했다. `PROLOGUE_SCENE_SMOKE`, `APPLICATION_FOCUS_SMOKE`도 통과했다. 이전 PNG는 수정 전 관찰 자료이며 이번 수정 후 네이티브 재촬영 결과로 간주하지 않는다.

수첩의 `N` 안내는 후속 [키 설정 수정](keyboard_settings_status.md)에서 실제 InputMap 기반으로 교체했다. 기타 고정 UI의 언어 변경 갱신과 긴 조합키의 전 해상도 검증은 별도 대상이다. 위 최초 캡처를 수정 후 화면으로 해석하지 않는다.
