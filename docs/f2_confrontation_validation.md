# F2 대면 초기 구현

J5 이후 도입, 다섯 선택 질문, 누락 사실 요약, 권한 반환 확인을 연결했다. 질문을 생략해도 필수 사실 6종을 모두 제공한다. 실행 불가능한 해방은 현재 시설의 한계이며 미래 가능성을 영원히 부정하는 표현을 사용하지 않는다. 임시 의향은 읽지 않고 관계 수치·최종 결정은 변경하지 않는다.

이리스 반응은 현재 상태에서 계산한다. 전원 완료가 public, 이리스 미완료가 inferred_only, 이후 bond 4/2, alert 4 순서로 direct_private/indirect/denied/withheld를 판정한다. 공개 고백은 전원 완료에만 나온다. 환경 관리자 인증 도용과 책임 전가, 주인공이 결정 당사자가 아니라는 사실은 공통이다.

검증: 32가지 관계 완료 조합에서 전체 질문 또는 생략 후 필수 정보 보장, 요약 전 완료 차단, 부분·완료 저장 재개, 실제 요약·완료 버튼, 관계 및 엔딩 상태 불변. 완료는 SAVE_F2_COMPLETE에 저장한다. 화면 캡처는 user://f2_questions.png.

현재 F3_PENDING까지 연결한 초기 구현이다. 사용인별 outcome 세부 삽입, 등급별 집단 연출, 전용 대면 공간·화자 표현, 60~90초 요약 페이싱, 원문 재열람 패널은 추가 구현 대상이다. 현재 도입·질문은 기존 기록실 화면과 텍스트를 사용한다. F3·EDC·엔딩과 최종 시청각 QA는 미완료다.
