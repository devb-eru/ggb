# GGB 완성본 정의

## 1. 콘텐츠 범위

| 항목 | 기준 |
| --- | --- |
| 전체 구간 | 프롤로그~4장·현실·잔류 엔딩 |
| 필수 진행 | 3시간 30분~5시간 45분 |
| 권장 진행 | 4시간 15분~7시간 30분 |
| 다섯 사용인 핵심 관계 포함 | 4시간 45분~8시간 |
| `build_flavor` | `full` |
| 전편 콘텐츠 완료 잠정 목표 | 2027-01-15 |
| 전편 콘텐츠·현지화 락 잠정 목표 | 2027-01-29 |
| 출시 형태 | 정식 버전 1.0 |
| 출시 시점 | Next Fest 종료 후 최소 72시간 안정화, 게이트 통과 시 가장 빠른 목표 2027-03-05 03:00 KST |

공통 제품 약속은 [제품 계약](product_contract.md)을 따른다. `2027-01-15`와 `2027-01-29`는 버티컬 슬라이스 실측 전의 `PROVISIONAL` 날짜다. 실제 용량과 제작 속도가 맞지 않으면 범위나 품질을 숨기지 않고 일정을 재산정한다.

Next Fest 데모 공개 범위는 [GGB-DEC-2026-0004](decisions/GGB-DEC-2026-0004_Next_Fest_데모_공개_범위.md), 행사 후 정식 1.0 출시는 [GGB-DEC-2026-0005](decisions/GGB-DEC-2026-0005_Next_Fest_후_정식_1_0_출시.md)를 따른다.

## 2. 제품 기준

- Windows 10/11 64-bit PC를 지원한다.
- `ko-KR`, `en-US` 텍스트를 지원하고 음성은 제공하지 않는다.
- 마우스 전용과 키보드 전용으로 필수 경로를 각각 완주할 수 있다.
- 기준 1920x1080, 최소 1280x720과 Windows 표시 배율 100~200%를 검증한다.
- UI 90~220%, 텍스트 100~200%, 창 모드·테두리 없는 창·전체 화면을 제공한다.
- 색, 소리와 모션에만 의존하지 않는 퍼즐·상태 표현을 제공한다.
- 표시한 대사와 선택지를 다시 읽는 대화 기록을 슬롯에 영속 저장한다.
- 첫 실행 접근성 설정, 키 재지정과 포커스 복구를 제공한다.
- 정식 버전 1.0에는 임시 아트·사운드를 허용하지 않는다.
- 게임패드, 터치, 콘솔과 음성은 1.0 지원 범위에서 제외한다.

## 3. 데모와의 관계

| 항목 | 데모 | 완성본 |
| --- | --- | --- |
| 플레이 종료점 | D4 | 4장·선택한 엔딩 |
| 에필로그 | D5 비상호작용 스팅어 | 해당 없음 |
| 시간 | compact/extended 비교 후 확정 | 필수 3시간 30분~5시간 45분, 권장 4시간 15분~7시간 30분, 전원 4시간 45분~8시간 |
| 저장 경계 | `SAVE_D5_COMPLETE` | `SAVE_ENDING_COMPLETE` |
| 저장 승계 | 원본 보존·검사 대상 | 승인 뒤 새 슬롯 또는 선택 슬롯으로 가져오기 |
| Steam 배포 | 기본 상점과 연결된 데모 AppID | 기본 게임 AppID |

정식판은 데모 저장의 `schema_version`, `build_flavor`, `content_boundary_id`, `source_app_id`와 checksum을 검사한다. 가져오기 실패는 데모 원본이나 기존 본편 슬롯을 손상시키지 않는다. 승인된 복제 슬롯의 `SAVE_D5_COMPLETE`만 `D6_FREE_INSPECTION`으로 재개하며, 원본 demo 슬롯은 계속 `DEMO_END_SCREEN`을 가리킨다.

## 4. 콘텐츠 완료와 콘텐츠 락

`FULL_00_CONTENT_COMPLETE`는 다음을 뜻한다.

- 프롤로그부터 두 엔딩까지 필수 경로가 연결된다.
- 모든 핵심 관계 이벤트에 진입·완료·건너뛰기 경로가 있다.
- 임시 대사·에셋을 포함할 수 있으나 모두 manifest에 등록돼 있다.
- 알려진 진행 차단 결함이 없다.

`FULL_00_CONTENT_LOCK`는 다음을 추가로 요구한다.

- 신규 사건·퍼즐·분기와 대사 의미 변경을 중단한다.
- 한국어·영어 원문과 말투 검수가 끝난다.
- 최종 에셋, 크레딧과 콘텐츠 경고가 잠긴다.
- 이후 변경은 결함 수정, 성능, 접근성, 법적·상점 대응으로 제한한다.

## 5. 완료·출시 게이트

### 콘텐츠

- [ ] 프롤로그~4장·두 엔딩을 처음부터 끝까지 진행한다.
- [ ] 관계 이벤트를 모두 건너뛰어도 F0와 두 엔딩에 도달한다.
- [ ] 관계 LOW, MID, HIGH, ALL 결산을 각각 검증한다.
- [ ] 필수·권장·전원 경로 플레이타임의 중앙값과 분포가 있다.

### 제품 품질

- [ ] 한국어·영어에서 같은 진행과 결말에 도달한다.
- [ ] 마우스 전용·키보드 전용 필수 완주를 통과한다.
- [ ] 1280x720, 1920x1080, 4K와 Windows 100~200% 표시 배율을 검사한다.
- [ ] UI·텍스트 200%, 색 제거, 음량 0, 모션 감소 조합을 검사한다.
- [ ] 대화 기록, 저장·복구와 데모 저장 가져오기를 검증한다.
- [ ] 정식 에셋 100%와 크레딧·라이선스 manifest를 확인한다.

### 출시

- [ ] Windows 10/11 64-bit 공개 빌드 QA를 통과한다.
- [ ] Steam 상점과 빌드 심사를 통과한다.
- [ ] Next Fest에서 발견한 출시 차단 문제를 해결한다.
- [ ] `P0`, `P1` 문제가 없다.
- [ ] 가격, 출시 할인, 지원 채널과 법적 고지가 확정됐다.
- [ ] Next Fest 종료 뒤 72시간 이상 안정화하고 차단 문제를 재검증한다.

행사 종료 시각이나 가장 빠른 목표일은 자동 출시 약속이 아니다. 하나라도 게이트를 통과하지 못하면 `beru`가 출시를 보류하고 새 목표를 기록한다.

## 6. 후속 검증 항목

- 렌더러와 최소·권장 사양은 `TECH_01_FOUNDATION`과 버티컬 슬라이스에서 임시 기준을 만든다.
- Steam Cloud, 도전 과제, crash reporting, telemetry와 지원 채널은 출시 기능표에서 각각 포함·제외를 확정한다.
- 정식명, 사용인 최종 이름과 캐릭터 비율은 현지화·에셋 잠금 전에 결정한다.
