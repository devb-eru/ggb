# 세정제·검은 거울 직접 요청형 힌트

## 연결 범위

`24-3_메인퍼즐_고난도개정안.md`의 C3·C4 및 v0.4 이벤트 상세 08의 입력·힌트 조건을 기준으로 한다. 시계망과 동일한 수첩의 `생각을 정리한다`를 재사용하되 현재 퍼즐에 맞는 제목과 내용을 제공한다.

- C3: 총량·비율·순서 분리 → A=2S → W=S+A+2와 총량 8 → S=1 검산 → 물5·안정제1·원액2와 확산·혼합·시험.
- C4: B4/J2와 문양 대응 → 중첩·기준점 분리 → 반전과 회전 비교 → 반전 없음·시계방향90도·하단 기준점 → 직선·짧은 분기·긴 분기·시계방향 고리.
- CF에서는 C4의 안내를 사용할 수 있지만 이미 굳은 코팅은 복구하지 않는다. 수면과 재준비가 필요하다는 경고를 H5에도 남긴다.
- C2 자료 수집 전과 C_BELL 신호 재생 단계에는 이 퍼즐 지원 버튼을 표시하지 않는다. 아직 준비되지 않은 퍼즐의 강한 힌트를 자동 노출하지 않는다.
- 각 단계는 읽기 버튼을 직접 눌러야 공개된다. 한국어·영어를 지원하며 실제 표시 문장만 기존 영구 대화 기록에 저장한다.
- 퍼즐 입력·재료·잠금·관계·엔딩 조건은 변경하지 않는다. H4는 기준값 안내이지 입력을 대신하거나 고정하는 기능이 아니다.

## 구현 경계

`ChapterOneController`의 기존 힌트 메뉴와 읽기 처리에 지원 단계·제목·텍스트 선택 함수를 분리했고 `BlackMirrorController`에서 현재 퍼즐의 자료를 제공한다. 공통 메뉴의 기존 내부 함수·노드 이름은 호환을 위해 유지했다. 판정 리소스와 정답은 수정하지 않았다.

## 검증

`BLACK_MIRROR_SMOKE`에서 C3와 C4 상태를 각각 구성해 수첩 버튼과 5단계 읽기·대화 다음 버튼을 실행했다. 각 트랙의 표시 내용과 영구 기록 5개 증가를 확인했고, 기록 이외의 전체 상태가 불변임을 검사했다. CF 영어 힌트의 수면 경고도 확인했다.

기존 조합·중첩 해답 유일성 검사와 검은 거울 진행 회귀도 통과했다. `CHAPTER_ONE_SMOKE`로 시계망의 기존 지원 경로를 재검사했다. fixture·버튼 신호 테스트이며 실제 사용자 입력 전편 완주, 난이도 및 플레이타임 증거는 아니다.

## 남은 작업

- 반복한 가설과 실패 유형에 따른 자동 제안.
- C3의 가능한 정수 조합 표와 조건별 비교 UI.
- H4 실제 조각·값 고정 및 H5 후보 제한 UI.
- C4의 2회 이상 실제 실패 후 선택형 지원 제안.
- 후반 D·F 퍼즐의 단계형 지원과 실제 입력 QA.
