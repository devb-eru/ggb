# 관계 티어별 전편 경로 검증

검증일: 2026-09-19
실행 인자: `--full-campaign-smoke`

## 판정

LOW·MID·HIGH·ALL 네 관계 경로가 실제 E_HUB 저장에서 출발해 J4·E5·F0~F3와 현실·잔류 엔딩, 크레딧 완료 저장까지 도달한다. 관계 사건은 완료 플래그를 주입하지 않고 각 사용인의 퍼즐·기록·대면 선택을 세션 행동으로 해결한다. 관계 미완료는 어떤 티어에서도 메인 진행이나 엔딩 선택을 차단하지 않는다.

## 경로 행렬

| 티어 | 완료 인원 | 실제 완료 사건 | J4 | E5 | 추가 확인 |
| --- | ---: | --- | --- | --- | --- |
| LOW | 0 | 없음 | `J4_BASE` | `LOW` | 에드가 `E3_4M` 최소 절차, 관계 보상 없음 |
| MID | 2 | 마라 1, 루카 | `J4_EXPANDED` | `MID` | 미완료 에드가 최소 절차 뒤에도 2명 상태 보존 |
| HIGH | 4 | 마라 1, 이리스, 루카, 에드가 | `J4_EXPANDED` | `HIGH` | 에드가 선택형 E6 후속, 미완료 마라 2가 진행을 막지 않음 |
| ALL | 5 | 마라 1, 이리스, 루카, 에드가, 마라 2 | `J4_FULL` | `ALL` | 마라 2 이름 후속과 양쪽 엔딩의 전원 인증 의식 |

MID는 권장 인원 범위의 하한 2명, HIGH는 정확히 4명, ALL은 정확히 5명을 사용한다. 기존 기능별 회귀가 32개 완료 마스크 전체를 검사하므로 3명 MID의 등급 판정과 각 미완료 조합은 그 검사에 남긴다.

## 실제로 통과한 관계 퍼즐

- 마라 1: 세 배선 출처 추적, 브리지 연결, 동의→실패→명령 기록 복원, 원본 작성자 귀속.
- 이리스: 세 센서의 아홉 출처 분리, 기록 연대 복원, 자격 소유자와 실행자 구분, 외부 진실 보존.
- 루카: 주·보조 배관 연결, 네 압력 위상 배치, 생명 유지 기록 확인, 전체 공개.
- 에드가: 명령 연대 감사, 보호·선택·기록·집행 권한 소유자 배치, 권한 반환.
- 마라 2: 다섯 색 채널 출처 분리, 초상화 열화 순서·파형 정렬, 분산 백업·체크섬 복원, 분리 인격 보존.

네 경로를 합쳐 관계 사건 11회를 실제로 해결한다. 각 사건 완료 뒤 `core_event_complete`, 연구원 기록, 결과 ID가 세이브를 거쳐 유지되고, EDC와 엔딩 완료 뒤에도 완료 인원 수가 변하지 않는지 확인한다.

## 엔딩 검증

각 티어에서 다음을 모두 수행한다.

1. F0-A~E 메타퍼즐과 `undecided` 현재 의사 인증.
2. F1 여덟 기록, J5, F2 필수 사실, F3 양쪽 장치 조사.
3. 원본 슬롯의 현실 엔딩과 `SAVE_ENDING_COMPLETE`.
4. 제품의 F3 재선택 사본으로 진행한 잔류 엔딩과 `SAVE_ENDING_COMPLETE`.
5. 완료 저장 재로드 뒤 최종 선택, 관계 인원, E5 티어 보존.

ALL은 `ED_ALL_CEREMONY`에서 에드가→마라 1→루카→이리스→마라 2의 이름을 순서대로 인증하고 SUBJECT 권한과 서명을 확인한 뒤 두 엔딩으로 진행한다. LOW·MID·HIGH는 이 전원 전용 장면에 잘못 진입하지 않는다.

- Godot 4.7.2 프로젝트 가져오기: PASS
- `FULL_CAMPAIGN_SMOKE`: PASS
- `BASEMENT_SESSION_SMOKE`: PASS
- 현실 엔딩 완료: 4개 티어 모두 PASS
- 잔류 엔딩 완료: 4개 티어 모두 PASS
- 루트 인증서 저장소 경고 외 `SCRIPT ERROR`: 없음

## 한계와 다음 게이트

이 검증은 제품 세션 행동과 실제 저장 API를 사용하는 자동 연속 회귀다. Windows가 전달한 마우스 입력만 또는 키보드 입력만으로 화면을 조작한 사용자 완주 증거는 아니다. 다음 게이트는 Windows PC에서 마우스 전용 실제 완주와 키보드 전용 실제 완주를 각각 수행하고, 입력 불가·포커스 손실·스크롤·드래그·저장 재개 문제를 수정하는 것이다.

최종 아트·BGM·SFX 교체와 리소스 의존 연출 보강은 사용자 확정 중단선에 따라 리소스 완성 뒤 진행한다. 크레딧 제작진 명단은 미정으로 유지한다.
