# 시계망 단서와 조작 화면 현지화

## 적용 범위

- 네 방의 관찰 단서에 표시 ID를 부여했다. 원문과 표시 ID를 저장하고 재실행 후에도 유지한다.
- 이미 저장된 수첩 단서는 정본과 정확히 일치할 때만 열람 언어로 변환하며 저장 원문은 수정하지 않는다.
- 탁본 수집 안내, 당일 잠금 설명, 조각의 방·방향·앞뒤·선 패턴, 교환·회전·반전 조작을 한·영으로 표시한다.
- 역할 선택, 네 위상 후보, 약한 시험의 범위, 실제 작동 확인과 수면 재도전 경고를 번역했다.
- 정답과 원래 시계망 데이터 리소스는 변경하지 않았다. 방 서명과 기능을 구분하는 원래 단서를 유지한다.

## 검증

1장 회귀에서 네 방의 저장·재개 ID, 한국어 정본 일치, 기존 수첩 표시 변환, 영어 조립·역할·위상·확인창과 화면 열람의 상태 불변을 검사했다. 기존 1,024개 역할·위상 조합 및 실패 후 수면 검사도 유지한다. 기반 시스템과 검은 거울 회귀를 함께 실행했다.

Godot 4.7.2 네이티브 OpenGL의 1280×720 캡처에서 영어 역할 선택·위상·시험·작동 버튼의 표시를 확인했다. 이 캡처는 기존 완료 상태에 조작 패널을 구성한 UI fixture이므로 헤더와 배경을 포함한 영어 전편 화면 증거가 아니다. OS 키보드 완주와도 구분한다.

## 남은 범위

탁본 배치 검사의 동적 오류 설명, 실행 선행조건 일부, B4 기록 문구, J2와 후반 텍스트, 고배율·DPI·전체 선택 항목의 레이아웃, 최종 영어 편집은 별도 작업이다. 이 변경은 시계망 전체 현지화 완료가 아니다.

## 역할·전달 시점 판정 후속 적용

역할 네 종류의 오류와 전달 시점 오류를 카테고리별로 번역했다. 약한 시험 성공은 전달 시점을 검증하지 않는다는 원래 제한을 명시하며 실제 작동 성공과 구별한다. 실제 실패 본문에는 판정 근거, 봉인핀 파손, 수면 복구, 에드가의 점검 반응이 모두 포함된다. 수첩에는 원래와 같이 에드가 발언 전까지의 실패 기록을 보존하며, 열람 시에만 번역한다.

1장 회귀에서 카테고리별 한국어 정본 일치, 영문 복구 안내와 에드가 반응, 실제 실패의 표시 ID와 저장 재개, 성공과 약한 시험의 서로 다른 ID를 검사했다. 판정 리소스와 실패 횟수·물리 잠금·사용인 기억 규칙은 수정하지 않았다.
