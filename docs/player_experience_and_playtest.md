# GGB 타깃 플레이어·포지셔닝·플레이테스트 계획

## 1. 제품 경험 가설

GGB는 반복을 이용해 물리 퍼즐의 실패를 정보로 바꾸고, 기억하는 사용인과의 관계를 통해 거짓 저택의 의미를 다시 판단하는 2D 포인트 앤 클릭 심리 SF 어드벤처다.

플레이어에게 약속하는 경험:

1. 반복할수록 같은 노동이 줄고 추론 가능성이 늘어난다.
2. 퍼즐 정답은 관찰한 규칙으로 설명할 수 있다.
3. 공포는 전투나 점프 스케어보다 익숙한 감각의 불일치에서 온다.
4. 관계 콘텐츠는 정답을 판매하지 않고 감금자의 책임과 애정을 함께 보여 준다.
5. 현실과 잔류는 선악이 아니라 서로 다른 비용을 가진 선택이다.

## 2. 플레이어 세그먼트

### 핵심 플레이어

서사 중심 포인트 앤 클릭·추론 퍼즐을 즐기며, 수첩을 읽고 10~20분 동안 한 기믹의 규칙을 시험하는 데 거부감이 적은 플레이어다. 전투 없이도 심리적 긴장과 캐릭터의 모순된 감정을 즐긴다.

기대:

- 정답 이유가 납득되는 중상 난도 퍼즐.
- 루프마다 새 정보나 짧아진 동선.
- 고딕에서 SF로 변하는 강한 미술 대비.
- 캐릭터 관계가 엔딩의 정보와 후속 장면을 풍부하게 함.

### 인접 플레이어

캐릭터 중심 비주얼 노벨·심리 호러를 즐기지만 전통 퍼즐에는 익숙하지 않은 플레이어다. H1~H5 힌트, 대화 기록, 키보드·접근성 옵션을 통해 진입할 수 있어야 한다.

### 비대상 플레이어

- 빠른 액션, 전투, 성장 수치, 랜덤 반복을 핵심으로 기대하는 플레이어.
- 모든 관계 선택이 큰 메인 분기로 갈라지는 연애·호감도 게임을 기대하는 플레이어.
- 감금, 의료 장치, 인격 손상 소재를 피하고 싶은 플레이어.
- 짧은 세션마다 즉시 보상을 요구하고 장문 기록 읽기를 원하지 않는 플레이어.

비대상에게 억지로 맞추기보다 상점 카피와 데모 초반 20분이 실제 장르를 정확히 보여 주게 한다.

## 5. 가격 가설

- 정식 1.0의 초기 미국 정가는 `USD 14.99~19.99` 범위를 가설로 둔다.
- 무료·에피소드 판매·앞서 해보기는 현재 범위가 아니다.
- 지역 가격은 특정 환율을 문서에 고정하지 않고 Steam의 출시 시점 권장 체계와 팀 판단을 사용한다.
- 최종 가격은 데모 선택안, 실제 전체 중앙 플레이타임, 아트 완성도, 비교작의 **출시 시점이 아닌 결정 시점** 정가를 2026-12-18에 다시 조사해 잠근다.
- 할인율은 가격과 별도 승인하며, 가격을 올리기 위해 콘텐츠를 인위적으로 늘리지 않는다.

## 6. 표본 계획

같은 사람이 반복 참가해 학습 효과를 만드는 경우와 신규 사용성 검사를 분리한다.

| 단계 | 최소 고유 인원 | 구성 | 목적 |
| --- | ---: | --- | --- |
| 기획·전문가 워크스루 | 4 | 퍼즐 설계 2, 내러티브 1, 접근성 1 | 규칙 모순·민감 표현 사전 제거 |
| 버티컬 슬라이스 | 12 | 핵심 6, 인접 4, 비대상 2 | 리셋·숏컷·기억 시스템 이해 |
| 데모 편집 A/B | 24 | compact 신규 12, extended 신규 12 | 길이·피로·D5 도달 비교 |

| 정식판 경로 | 16 | 필수 6, 권장 관계 6, 전원 관계 4 | 저장·후반 감정·엔딩 중립 |

## 7. 모집 태그

사전 설문:

- 최근 2년 내 포인트 앤 클릭·탈출 퍼즐 플레이 수.
- 퍼즐 중 외부 공략을 찾기까지 기다리는 시간.
- 심리 호러·감금·의료 장치 소재 허용 여부.
- 마우스·키보드 선호와 재지정 필요 여부.
- 색각, 광과민, 모션, 청각, 텍스트 확대 설정 사용 여부.
- 주 사용 언어와 영어·한국어 독해 수준.

민감 콘텐츠를 피하고 싶다고 응답한 사람을 공포 내성 검증에 강제로 배정하지 않는다.

## 8. 핵심 지표와 합격선

### 버티컬 슬라이스

| 지표 | 합격선 |
| --- | ---: |
| 수면 RESET과 디스크 저장을 구분 | 12명 중 10명 이상 |
| 실패 뒤 영구 정보가 남는다고 설명 | 12명 중 10명 이상 |
| 최종 성공자가 정답 이유 설명 | 성공자 80% 이상 |
| 같은 노동이 그대로 반복된다고 평가 | 25% 이하 |
| 사용인이 기억해도 즉시 막지 않는 이유 이해 | 75% 이상 |
| 마우스·키보드 전용 완주 | 각 경로 차단 0건 |

### 데모 A/B

| 지표 | 선택 기준 |
| --- | --- |
| D4·스팅어 도달률 | compact가 extended보다 15%p 이상 높으면 compact 우선 |
| 반복 피로 | 5점 중 4~5 응답 20% 이하 |
| 세션 중단 | 원인별로 퍼즐 정체·피로·외부 일정 분리 |
| 본편 의향 | `계속 플레이하고 싶다` 5점 중앙값 4 이상 |
| 장르 기대 일치 | 상점 초안 뒤 실제 경험 불일치 20% 이하 |

compact와 extended 차이가 작으면 제작·현지화·QA 비용이 낮은 compact를 기본으로 한다. extended를 택하려면 추가 길이가 캐릭터 애착이나 퍼즐 이해를 유의미하게 높였다는 관찰 근거가 필요하다.

### 엔딩 중립

- F3에서 두 선택의 정보 회상률 차이가 15%p 이내다.
- “게임이 정답으로 민 선택” 응답이 어느 분기에서도 25%를 넘지 않는다.
- F0 임시 의향을 바꾼 참가자가 배신·오답 페널티를 느끼지 않는다.

## 9. 세션 기록

필수 기록:

- build ID, locale, 입력 방식, 접근성 설정.
- 시작·종료 시각과 사건별 체류 시간.
- 힌트 단계와 요청 시점.
- 실패 원인과 재시도 수.
- 참가자의 think-aloud 원문과 관찰자의 추론을 구분한 메모.
- P0/P1 결함, 멀미·광과민·심리 중단 여부.
- 종료 설문과 24시간 뒤 기억 회상 3문항.

개인 식별 정보와 화면 녹화는 필요한 최소 범위만 수집하고 사전 동의를 받는다. telemetry 도입 전에는 테스트 시트의 수동 기록을 사용한다.

## 10. 의사결정 출력

각 테스트 라운드는 다음 중 하나로 끝난다.

```text
KEEP       현재 설계 유지
TUNE       수치·힌트·문구 조정
REWORK     규칙 또는 흐름 재설계
CUT        비용 대비 가치가 낮아 제거
RETEST     표본·결함 때문에 판정 보류
```

데모 길이, 렌더러, 가격, 공포 고지와 퍼즐 삭제는 테스트 메모만으로 자동 변경하지 않는다. 결과 요약과 변경 비용을 `GGB-DEC`에 기록한 뒤 정본 문서를 갱신한다.
