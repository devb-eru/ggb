# F0-C 중첩 판정 모듈 검증

## 현재 범위

`core_overlay.gd`는 순수 판정 모듈이다. BasementSession과 화면에 연결되어 F0-B 이후 F0-C를 플레이할 수 있다. 회전·반전·기준점·투명도, 중첩 확인, PATH→SPLIT→AUTH 조사를 제공한다. 선택 상태와 조사 진척은 일반 캠페인 저장 트랜잭션에 포함된다. 완료 후 경계는 F0_D_PENDING이다.

## 규칙

- D4는 고정 기준판이다. B4·C5는 회전과 좌우 반전을 조작한다.
- 기준점 고정과 해제, 불투명도 20~100 조절을 지원한다.
- 세 기준점, B4 추가 파동, C5 분기선, C5 비대칭 고리 기준을 각각 검사한다.
- B4 180도, C5 좌우 반전 후 반시계 90도만 여섯 조건을 만족한다.
- 완전 중첩 시 고정되며 PATH→SPLIT→AUTH 조사 뒤에만 완료된다.
- 화면 좌표는 오른쪽 x 증가·아래쪽 y 증가다. 회전 한 번은 시계 방향 90도이며 반전은 원본 기준으로 먼저 적용한다.

## 검증 결과

Godot `core_overlay_smoke.gd` 실행: CORE_OVERLAY_SMOKE: PASS.

검사 범위: 64개 변환 조합 유일해, 입력 사본 불변성, D4 회전 거부, 기준점만 일치한 경우 미완료, 중첩 후 조사 요구, 순서 우회 거부, JSON 직렬화·복원 뒤 조사 완료.

도형 좌표는 판정용 임시 비대칭 형상이다. 최종 B4·C5·D4 자료 아트와 통합할 때 시각 위치·선 연결을 별도 검증해야 한다. 이 결과는 F0-C 전체 구현이나 실제 난이도 검증 완료를 의미하지 않는다.

## 화면 및 저장 연결

`core_overlay_board.gd`가 B4 점선·C5 굵은 선·D4 가는 선과 문자를 함께 그린다. 회전과 반전은 판정 모듈의 동일 좌표 함수를 사용한다. 완전 중첩 이후에는 조사 버튼을 표시하고 완료 시 `f0_overlay_complete`와 `F0_C` 완료 이력을 저장한다.

`basement-session-smoke`에 F0-B→C 진입, 부분 저장 재개, 실제 중첩 확인과 세 조사 버튼, 완료 저장 재개 검사를 추가했다. 화면 캡처는 `user://f0c_overlay.png`이다. 이전 보고서의 F0_C_PENDING 설명은 이 구현 범위로 대체한다.

남은 작업: 실제 수첩의 B4·C5·D4 원자료를 여는 패널, 기준점별 명칭·시각 범례, 최종 자료 모양과 판정 좌표의 정합성, 중첩 난이도·접근성 플레이테스트. 현 화면은 자료 이름과 임시 도형을 제공하며 전체 자료 경험이 완성된 상태는 아니다.
