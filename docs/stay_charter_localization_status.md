# 잔류 합의 구간 현지화

## 적용 범위

`stay_charter_texts.gd`를 통해 다음 세 노드의 표시를 한·영으로 연결한다.

| 노드 | 내용 |
| --- | --- |
| `EDS_MEMORY_CHARTER` | 시뮬레이션의 진실, 연구원 인격과 감금 책임, 명시적 확인 없는 수면·기억 변경 금지의 세 원칙 |
| `EDS_APPEARANCE_CONTROL` | 고딕 외피와 시설 골격의 동시 표시 또는 조사 시 표시, 가역성·기억 불변 안내 |
| `EDS_AUTONOMY_CHARTER` | 다섯 사용인의 역할을 강제에서 제안으로 전환, 각자의 공간·휴식·이름·기억 보호 |

각 화면의 장소·목표·버튼·구조 표시 안내, 원칙을 읽는 대화와 외형 설정 재선택 창을 포함한다. 한국어 원칙·인물 이름·모드 이름은 기존 `StayCharter` 상수를 참조한다. 후속 장면에서 같은 외형 설정 창을 다시 열어도 해당 창의 문구는 현재 언어를 따른다.

## 유지하는 조건

- 세 원칙 확인과 다섯 역할 전환의 기존 조건을 유지한다. 관계 완료 수가 적어도 다섯 명을 모두 포함한다.
- 외형 변경은 표시만 바꾼다. 기억·관계·최종 결정·파열 상태를 복구하거나 초기화하지 않는다.
- 원칙 세 번째 문장은 실제 다음 수면을 실행하지 않는다는 한계를 유지한다.
- 에드가가 일정을 다시 강제하거나 다른 인격을 일방적으로 삭제할 수 있다는 의미를 추가하지 않는다.
- 문자열은 표시 자료이며 `layered`, `contextual`, 사용인 ID, 노드 ID와 저장 자료를 번역하지 않는다.

## 검증

`basement_session_smoke.gd`의 잔류 합의 경로를 영어로 실행한다.

- 실제 원칙 버튼을 눌러 표시한 영어 본문과 열람 기록을 확인한다.
- 한국어 원칙은 정본 상수와 정확히 일치한다.
- 두 표시 선택지, 중립 기본 포커스, 외형 설정 다시 열기와 현재 표시 유지의 상태 불변을 확인한다.
- 다섯 사용인의 영어 이름과 역할 전환 버튼, 부분 저장 후 재개를 확인한다.
- 기존 관계 무보상, 파열 불변, 외형 재변경, 실제 수면 금지, 중앙홀 후속 진입 회귀를 유지한다.

이 검사는 Godot 화면 컨트롤과 세션을 통한 기능 검사다. 영어 전체 완주나 모든 글자 크기·해상도에서의 시각 검증을 뜻하지 않는다.

## 남은 범위

잔류 중앙홀 이후의 선택 조사, 사용인 후속 반응, 저녁·마지막 장면·크레딧, 관련 갤러리와 미등록 시스템 오류 문구는 별도 현지화 대상이다. 영어 긴 자율성 안내의 작은 창·큰 글자 조합과 OS 입력 완주 검증도 남아 있다. 크레딧 인명은 계속 미정이다.
