# 공통 UI 변경 후 후반부 회귀 검증

## 대상

- 기준 코드: `8a2edc683b1af8d061f9427603ff070856d41477`.
- 실제 저장소: `C:/Beru/Projects/Games/ggb`, `develop`.
- 실행 환경: 별도 사용자 저장 경로를 사용하는 격리 Godot 4.7.2 프로젝트.
- 목적: 프롤로그에서 상속되는 대화·수첩·메뉴·인벤토리 코드의 최근 현지화·글자 배율 변경이 후반 세션 회귀를 깨뜨렸는지 확인한다.

## 결과와 근거

| 검사 | 결과 | 해석 |
| --- | --- | --- |
| 추적된 `game/scripts` 156개 파일 비교 | 차이는 `.gd.uid` 파일에 한정 | 검사 시점의 코드 파일 내용은 원본과 일치한다. UID·임포트 환경 일치까지 증명하지 않는다. |
| `BASEMENT_SESSION_SMOKE` | PASS, 종료 코드 0 | 해당 테스트에 작성된 퍼즐·전환·관계·엔딩 상태와 UI 검사 통과 |
| 스크립트 실행 오류 | 출력에서 없음 | Windows 루트 인증서 저장소 읽기 오류는 별도 환경 경고로 남았다. |

테스트 정본은 `game/scripts/tests/basement_session_smoke.gd`이다. 현실 엔딩의 신체 확인 조건, 마지막 장면의 선택·관계 불변, 잔류 후속의 선택·관계 불변, E5/E6의 일부 UI 입력, 데모 종료 경계 등을 포함한다. 세션 직접 호출과 주입된 상태를 사용하는 테스트이므로 처음부터 두 엔딩까지의 사용자 완주 증거가 아니다.

## 남은 검증

1. 원본 프로젝트의 UID·리소스 임포트와 공개 내보내기 빌드를 검사한다. 격리본의 UID 차이를 원본 파일의 결함으로 단정하거나 원본 UID를 임의 재생성하지 않는다.
2. 실제 마우스만·키보드만으로 필수 경로를 각각 완주한다. 이번 검사는 입력 장치별 완주를 대체하지 않는다.
3. 후반 대사 본문·오브젝트·저장 기록의 영어화를 계속한다. 공통 메뉴 번역이 후반 콘텐츠 전체의 번역을 뜻하지 않는다.
4. 큰 글자·해상도·DPI·움직임 감소 조합의 실제 화면을 확인한다. P2 개발 화면 검사만으로 후반 화면을 승인하지 않는다.
5. 최종 아트·BGM·효과음·목표 플레이타임과 제품 계약 게이트는 별도 미완료 상태로 유지한다.

전체 완료 판정은 [완성본 정의](full_game_definition.md)와 [제품 계약](product_contract.md)을 따른다. 크레딧 명단은 미정이다.
