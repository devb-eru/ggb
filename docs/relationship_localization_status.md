## 구현

- `relationship_display_texts.gd`가 다섯 사건의 위치·목표·버튼·상태판·확인창·피드백·수첩 기록을 번역한다.
- 정적 문구와 함께 선택 수, 배치 슬롯, 현재 토큰, 열화 단계, 기준점, 결손 칸, 체크섬, 위상 순서처럼 실행 중 조합되는 상태 문구를 영어로 합성한다.
- 저장 상태와 연구원 기록의 한국어 정본은 유지하고, 화면 및 수첩 열람 시에만 선택 언어를 적용한다.
- 색상 외에도 문양·선·맥박·꽃잎·이중 윤곽·음향 명칭을 유지해 색상만으로 단서를 판정하지 않는다.
- 모든 관계 선택창의 기본 포커스는 기존의 보류 또는 재검토 항목을 유지한다. 영어화가 선택 결과나 엔딩 성향을 유도하지 않는다.
