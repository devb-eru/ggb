# 전편 영어 진행 검증

## 기준일

2026-09-19

## 판정

P1부터 현실·잔류 엔딩과 크레딧까지 이어지는 연속 캠페인을 `en_US` 로캘에서 완료하는 코드 경로를 확정했다. 이 판정은 영어 문구 연결과 진행 차단 여부에 대한 것으로, Windows 마우스 전용·키보드 전용 실제 완주 판정은 아니다.

## 잔여 감사에서 수정한 항목

- 프롤로그 P2의 세 창 버튼, 대응접실 시계, 시계 관찰문, 확대 조사 안내와 세 영역 이름을 `prologue_text.tres`와 `text_registry.json`에 등록했다.
- 프롤로그 내부 연속 시나리오 검사가 한국어 표시문을 직접 비교하던 부분을 현재 로캘의 문구 ID 비교로 바꿨다. 한국어 정본과 퍼즐 상태는 변경하지 않았다.
- 구버전 또는 지원하지 않는 엔딩 노드에서 열리는 복구 화면의 목표, 본문과 타이틀 복귀 버튼을 한·영 표시로 분리했다. 진단 노드 ID는 문제 확인을 위해 그대로 표시한다.
- 마라 2의 보조 저장 영역에서 `EDGAR`, `MARA1`, `LUCA`, `IRIS` 내부 소유자 ID가 노출되지 않도록 영어 인명으로 표시한다.

## 자동 검증

- Godot 4.7.2 프로젝트 가져오기: PASS
- `PROLOGUE_SCENE_SMOKE`: PASS
- `BASEMENT_SESSION_SMOKE`: PASS
- `FULL_CAMPAIGN_SMOKE`: PASS

`FULL_CAMPAIGN_SMOKE`는 실행 시작부터 종료까지 `en_US`를 유지하고 종료 후 원래 로캘을 복구한다. 프롤로그는 실제 컨트롤러 상호작용을 사용하며, 이후 구간은 동일 원본 슬롯에서 B3·C4·D1의 의도된 실패, 정상 리셋과 숏컷, D5 파열, D6 파열 수면, J4, E5, F0~F3, 현실 원본과 잔류 재선택 사본, 양쪽 크레딧까지 진행한다.

개별 화면 회귀는 다음을 추가 확인한다.

- P2 창과 시계에 한국어가 남지 않는다.
- 엔딩 복구 화면에 한국어가 남지 않고 진행 상태를 변경하지 않는다.
- 마라 2 보조 저장 영역의 소유자 이름과 확인 접미사가 영어로 표시된다.
- 기존 관계 사건, J4·E5·E6, F0~F3와 두 엔딩의 영어 화면 검사가 계속 통과한다.

## 남은 범위

- Windows PC에서 마우스만 사용한 실제 완주
- Windows PC에서 키보드만 사용한 실제 완주
- 최종 아트·BGM·SFX 교체와 해당 리소스를 전제로 한 연출 보강은 리소스 완성 뒤 진행

관계 완료 수에 따른 LOW·MID·HIGH·ALL 전편 경로는 [관계 티어별 전편 경로 검증](relationship_tier_campaign_validation.md)에서 후속 완료했다.

크레딧 제작진 명단은 사용자 지시에 따라 미정으로 유지한다.
