# GGB 전체 이벤트 반응·정답 레퍼런스

최종 갱신: 2026-09-20
대상 빌드: `develop` / Godot 본편(`--ggb-dev-full`)
문서 성격: **기획·개발·QA용 전체 스포일러 문서**

## 1. 목적과 판정 기준

이 문서는 새 게임의 `P1`부터 두 엔딩의 `POST_CREDITS`까지 다음 정보를 한곳에서 찾기 위한 내부 정본이다.

- 사건의 진입 조건과 필수 상호작용
- 퍼즐의 실제 정답과 입력 순서
- 성공·오답·실패 시 핵심 반응
- 수면 리셋, 영구 정보, 숏컷의 상태 변화
- 사용인 관계 선택의 수치 변화와 후속 반응
- 엔딩 선택과 관계 단계별 차이

판정 충돌 시 우선순위는 다음과 같다.

1. 현재 `develop`의 세션·퍼즐 판정 코드
2. `docs/*_validation.md`의 통과 조건
3. `ideas/md/v04/06`~`15`의 감각·대사·연출 상세
4. `ideas/md/v04/04_전체이벤트리스트_상태표.md`의 기획 레지스트리

따라서 이 문서의 "정답"은 현재 게임이 실제로 받아들이는 값이다. 관계 사건의 결말과 현실·잔류 선택은 정답이 아니라 **선택 결과**로 표기한다.

### 1.1 표기

| 표기 | 의미 |
| --- | --- |
| `필수` | 다음 메인 사건을 열기 위해 반드시 완료 |
| `선택` | 생략해도 메인 진행 가능 |
| `로컬 재시도` | 세계 리셋 없이 같은 화면에서 다시 입력 |
| `당일 잠금` | 해당 장치가 잠기며 수면 리셋 필요 |
| `영구` | 수면 리셋 이후에도 유지 |
| `당일` | 정상 리셋 시 초기화 |
| `BROKEN_RESET` | D5 이후의 비가역 전환. 정상 루프로 돌아가지 않음 |

### 1.2 전체 진행축

```text
P1~P6 → NORMAL_RESET → A1/A2 → B1~J2 → C0~J3
→ D0~D6 → BROKEN_RESET → E1/E2/E_HUB → J4/E5/E6
→ F0-A~E → F1/J5 → F2/F3 → EDC
→ 현실(EDR_*) 또는 잔류(EDS_*) → CREDITS → POST_CREDITS
```

## 2. 리셋·기억·실패 공통 규칙

| 항목 | 규칙 | 플레이어에게 보이는 반응 |
| --- | --- | --- |
| 정상 수면 | D5 이전에 잠들면 같은 침실의 같은 아침으로 복귀 | 종소리, 낮은 맥박, 빠른 세 음 일부가 겹친 뒤 방의 물리 상태 복원 |
| 물리 상태 | 청소, 배합, 시계 배치, 지하 장치 조작 등은 초기화 | 장치가 원상복구되지만 이전 실패에서 확인한 정보는 수첩에 남음 |
| 영구 정보 | 수첩 표식, 일지 단계, 검증된 역할·깊이, 실패 정보, 사용인 기억·관계 | 반복 대사가 축약되고 이미 해결한 일과를 숏컷으로 넘길 수 있음 |
| 사용인 기억 | 사용인은 이전 날을 기억하되 역할 제약, 접근권한, 감시 책임 때문에 즉시 모든 행동을 막거나 돕지 못함 | 같은 질문에 미세한 말투 변화, 경계·관계 수치에 따른 경고와 양보 |
| 하드 실패 | B3-B, C4, D1의 일부 강행 입력 | 당일 장치 잠금 → 남은 조사 가능 → 수면 → 숏컷으로 복귀 |
| D5 이후 | 위장 필터 해제는 의도된 성공이며 이후 수면은 `BROKEN_RESET` | 같은 침실이지만 금속·냉각·광섬유가 드러난 "다른 아침" |
| 최종 구간 | F3 진입 후 세계 내 수면 금지, 저장·불러오기는 허용 | 두 절차와 수첩을 조사한 뒤에만 최종 선택 가능 |

상태 라우터에서는 정상 실패 수면을 `SYS_COMMIT → SYS_MEMORY → NORMAL_RESET → MORNING → ROUTE`로 처리한다. A1 뒤 축약 일과와 수면은 `AS`, B3-B 실패 당일은 `BF`, C4 실패 당일은 `CF`, D1 실패 당일은 `DF`로 표시한다. 이 ID들은 별도 퍼즐이 아니라 수면·재진입 상태다.

#### 기억 닻

6단계 뒤 주인공이 지시 없이 손잡이를 왼쪽 자리로 돌린다. 플레이어가 다시 돌려도 손을 떼는 순간 한 번 원위치한다.

```text
엄지가 손잡이 안쪽 홈을 찾음
→ 도자기가 받침을 짧게 긁음
→ 찻잎 향과 더 큰 손의 잔상이 겹침
→ 얼굴과 대사는 떠오르지 않음
```

주인공은 "왜 이쪽이어야 하지?"라고 묻고, 루카는 "그렇게 두시면... 늘 맞았어요"라고만 답한다. 퍼즐 점수나 숨은 정답은 아니며 F1의 아버지 기록과 연결되는 첫 기억 닻이다.

#### 생명 유지 전조

주전자 바닥의 낮은 맥박 2회 → 루카 귀의 보조등 2회 → 바닥 아래의 늦은 응답음 순서로 발생한다. 수첩에는 `주방의 규칙적인 진동`만 기록된다.

#### 질문 1개 선택

| 질문 | 루카 반응 |
| --- | --- |
| 아버지가 좋아한 차인가요? | 비슷한 향을 좋아했지만 이제 정확히 같은지는 자신 없다고 답함 |
| 이 저택은 언제부터 있었나요? | 주인공이 기억하는 만큼 오래됐다고 들었다고 답함 |
| 루카는 여기서 오래 일했나요? | 아주 오래였으나 며칠로 세면 늘 같은 수가 나온다고 말하다 스스로 멈춤 |

질문은 모두 유효하고 하나만 선택한다. 이후 필수 하위 장면 `P4_IRIS_GREETING`이 자동 재생된다. 저장이 그 사이에 중단되면 차 준비를 다시 시키지 않고 이 하위 장면부터 복구한다.

### 3.6 P5 잠긴 온실과 날씨 모순

| 상태 | 조사 반응 |
| --- | --- |
| 복도 | 맑고 마른 상태 |

### 3.7 P6 취침과 첫 정상 리셋

취침을 직접 확인하면 세계의 물리 상태가 초기화된다. 낮은 시계음, 두 번의 맥박, 빠른 세 음 중 마지막 음이 잘리는 소리가 이어지고 같은 침실의 같은 아침으로 돌아온다.

## 4. 반복 발견 A·B 구간

### 4.1 A1 수첩 표시와 A2 지속 확인

| 표시 유형 | 정확한 구성 순서 |
| --- | --- |
| 문장 | `내일 아침, → 이 문장을 → 읽어.` |
| 집 문양 | `지붕 → 몸체 → 문` |
| 모서리 잉크 | `모서리 첫 접촉 → 안쪽 두 번째 접촉 → 마지막 잉크점` |

- A1에서 하나를 선택하면 `self_authored_mark`로 영구 저장된다.
- 일과 숏컷 후 잠들어 정상 리셋한다.
- A2에서 같은 표시가 남아 있음을 확인하면 수첩이 물리 리셋 대상이 아님을 알게 된다.
- 세 유형은 난이도·엔딩에 우열이 없다. 선택한 유형은 F0-E와 F1 인증에서 그대로 다시 사용한다.

### 4.2 B1 사용인 시간표 조사

| 조건 | 정답 |
| --- | --- |
| 핵심 문서 | 에드가·루카·마라 1 문서 중 서로 다른 2개 이상 확인 |
| 빈 시간대 | `오후 차 정리 뒤, 저녁 종 전` (`after_tea_before_bell`) |

다른 시간대를 고르면 기록 내실 감독·반납 서명과 충돌한다는 피드백이 나온다. 하드 실패는 없다.

### 4.3 B2 기록 내실 잠입과 에드가 대응

| 조사 대상 | 효과·반응 |
| --- | --- |
| 책상 | J1 압지 조각을 여는 필수 대상 |
| 색인·서랍 | 추가 기록을 얻지만 에드가 경계가 상승 |
| 숨을 자리 | 이후 에드가 진입 시 숨기 가능 |
| 벽 틈·연결문 | J1 이후 내부 걸쇠 숏컷 후보 확인 |

주의도가 오르면 `B2_EDGAR_ENTRY`로 에드가가 들어오지만 실패하지 않는다.

| 대응 사건 | 결과 |
| --- | --- |
| `B2_HIDE` · 숨는다 | 에드가가 방을 점검하고 일정 시간 뒤 나감 |
| `B2_CAUGHT` · 대화한다 | 보고 싶은 책이 있는지 묻고, 사용 후 제자리에 돌려놓으라고 한 뒤 나감 |
| `B2_CAUGHT` · 높은 경계 | "우연이라면 반복되지 않겠지요"처럼 의심을 돌려 말하지만 진행은 유지 |

### 4.4 J1 일지 1단계

| 항목 | 정답 |
| --- | --- |
| 압지 조각 순서 | `0 → 1 → 2` |
| 앞뒤 | 세 조각 모두 앞면 |

- 순서 오답: 눌린 문장이 이어지지 않는다고 반응한다.
- 뒤집힘 오답: 잉크는 묻지만 문장이 드러나지 않는다.
- 성공: 시계망의 역할과 `+1` 전달 간격 단서를 영구 획득하고 내실 연결문 숏컷이 열린다.

### 4.5 B3-A 시계 탁본 연결

| 항목 | 정답 |
| --- | --- |
| 제외 방 | 침실 |
| 연결 순서 | 대응접실 → 외부 서고 → 대시계 |
| 서고 탁본 | 반전하여 사용 |

오답은 끊긴 배선과 방향 불일치를 표시하며 로컬 재시도한다. 여기서는 당일 잠금이 발생하지 않는다.

### 4.6 B3-B 시계망 역할·위상

| 역할 | 정답 |
| --- | --- |
| 기준 | 대응접실 |
| 중계 | 외부 서고 |
| 출력 | 대시계 |
| 제외 | 침실 |
| 위상 | `+1` |

잘못 확정하면 시계망 잠금핀이 파손되고 당일 실패 상태 `BF`로 전환된다. 실패 정보와 검증된 역할은 수첩에 영구 기록된다. 남은 조사를 한 뒤 잠들어야 한다.

### 4.7 BSHORT와 B4·B5·J2

| 사건 | 필수 행동·정답 | 반응·결과 |
| --- | --- | --- |
| BSHORT | 이미 해결한 일과·탁본·배치를 축약 | 역할 정보는 자동 복원되지만 위상 확정은 플레이어가 다시 수행 |
| B4 | 열세 번째 종의 파형 기록 | 파형을 수첩에 영구 보존 |

| J2 | 파형 회전 `0°` | 거울 창·파형 구간 단서 획득, 검은 거울 구간 개방 |

## 5. 검은 거울 C 구간

### 5.1 C0 금지된 거울과 C1 가설

- 거울 표면을 조사하면 에드가는 "보존 표면"이라며 청소를 금지한다.
- 경계가 높으면 도구와 목적을 한 번 더 확인하지만 사건을 강제로 실패시키지 않는다.
- C1에서 오염이 아니라 코팅이라는 가설을 세우고 청소 기록과 약품장을 교차 조사한다.

### 5.2 C2·C2-1 정보 정답

| 출처 | 핵심 정보 |
| --- | --- |
| 마라 1 청소 기록 | 강한 용제는 코팅을 굳힘. 중성 세정제와 부드러운 천 사용 |
| 루카 약품장 | 전체량 8, 활성제는 안정제의 2배, 물은 두 첨가제 합보다 2 많음 |
| 혼합 순서 | 물 → 안정제 완전 분산 → 활성제 |

### 5.3 C3 중성 세정제

| 재료 | 정답량 |
| --- | --- |
| 물 | 5 |
| 안정제 | 1 |
| 활성제 | 2 |

정답 순서는 `물 → 안정제 → 활성제`다. 혼합은 한 번만 한다. 두 번 섞어 거품이 생기면 가라앉을 때까지 기다린 뒤 중성 시험을 다시 한다. 수량·순서 오답은 로컬 재시도이며 이 단계 자체는 세계 리셋을 요구하지 않는다.

### 5.4 C4 열세 번째 종의 검은 거울

| 항목 | 정답 |
| --- | --- |
| 중첩 반전 | 반전하지 않음 |
| 회전 | `90°` |
| 기준점 | 아래쪽 진동점 고정 |
| 경로 | 입구 → 짧은 가지 → 긴 가지 → 시계방향 고리 |
| 실행 | 마른 시험 성공 → 계획 검증 → 젖은 천 실행 |

에드가 순찰은 기다리기·질문하기·천 감추기 중 어느 대응도 진행 가능하다. 단, 경계가 높고 관계가 낮은 상태에서 순찰 처리를 무시하면 천을 회수당해 당일 실패가 된다. 잘못된 젖은 실행은 코팅 경화 또는 도구 회수로 당일 잠금된다.

P4 기억 닻을 확인했다면 J3에 아버지가 그린 문 조각이 추가된다.

## 6. 지하창고·태엽 심장 D 구간

### 6.1 D0과 D0-A 지도 중첩

| 항목 | 정답 |
| --- | --- |
| 눌림점 | 침실·온실·대시계 3곳 모두 조사 |
| 반전 | 가로 반전 |
| 회전 | 반시계 `90°` (`270°`) |
| 기준점 | 대시계 |

오답은 세 기준점이 같은 구조를 가리키지 않는다고 반응하며 로컬 재시도한다.

### 6.2 D1 지하창고 조합 퍼즐

| 순서 | 축 | 정답 깊이 | 확정 행동 |
| --- | --- | --- | --- |
| 1 | 선 축 | 2 | 밀기 |
| 2 | 가지 축 | 1 | 밀기 |
| 3 | 고리 축 | 3 | 밀기 |
| 4 | 중앙 손잡이 | 시계방향 반회전 | 확정 |

- 잘못된 축 순서나 깊이를 확정하면 압력핀이 잠겨 당일 실패 상태 `DF`로 전환된다.
- 중앙 손잡이를 반시계로 처음 돌리면 경고만 나온다.
- 같은 역방향을 다시 강행·확정하면 당일 잠금된다.
- 실패 뒤 DSHORT는 검증된 깊이만 표시한다. 실제 밀기와 손잡이 조작은 다시 수행한다.

### 6.3 D2 접근 숏컷

D1 성공 뒤 지하창고 접근 숏컷이 영구 해금된다. 이후 아침에는 반복 복도 대신 빠른 경로를 사용할 수 있다. 지하 공간의 오브젝트 조사는 태엽 심장의 링 구조와 전력 흐름을 설명한다.

### 6.4 D4 태엽 심장

#### 연동 링

| 손잡이 | 최소 조작 횟수 |
| --- | --- |
| A | 1회 |
| B | 1회 |
| C | 2회 |

최종 링 상태가 목표와 같으면 4회전을 더한 동치 해법도 받아들인다.

#### 기동 절차

```text
링 고정
→ 정상 레버를 XII까지 감기
→ 진동 안정화 확인
→ 보조 레버 조사
→ +1 / XIII 보조 레버를 당김
```

XII에서 끝내면 "끝 다음 한 칸"이 남았다는 반응이 나오며 필터는 해제되지 않는다.

### 6.5 D5 세계의 파열

`+1 / XIII`는 운영상 의도된 **위장 필터 해제 성공**이다. 플레이어에게 실패라고 표시하지 않는다.

- 고딕 표면 아래 배선·시설 프레임·밤하늘 투영·다섯 인격 채널이 드러난다.
- D4 직전 관계와 경계에 따라 사용인 한 명의 짧은 동결 반응이 삽입될 수 있다.
- 본편에서는 입력 고정 연출 뒤 D6로 이동한다.
- 공개 데모에서는 `DEMO_END_SCREEN`으로 이동하며 D6 이후 진행을 차단한다.
- 이 시점부터 정상 수면 리셋은 다시 작동하지 않는다.

### 6.6 D6 파열 공간 조사와 수면

| 조사 대상 | 핵심 반응 |
| --- | --- |
| 벽체 | 벽지가 아니라 패널과 배선이 드러남 |
| 표지 | 저택 방 이름 아래 시설 기능명이 겹침 |
| 색 흔적 | 사용인의 색이 장식이 아니라 데이터 채널 잔상으로 보임 |
| 캡슐 | 침실 침대와 같은 곡면·고정구·냉각 구조 확인 |
| 수첩 | 리셋 뒤에도 남은 글씨와 현재 세계 상태를 대조 |

침실 또는 비상 캡슐에서 쉬는 `FRACTURE_SLEEP` 경로를 고를 수 있다. 두 경로 모두 `BROKEN_RESET`으로 이어지며 서사 우열은 없다. 단발 처리 뒤 `SYS_SYNC`가 파열 상태와 약화된 역할 고정을 생성한다.

### 7.1 E1 같은 침실의 다른 아침

| 대상 | 핵심 반응 |
| --- | --- |
| 침대 | 매트리스 아래 캡슐 곡면, 손목 고정구, 느린 냉각 펌프 |

| 거울 | 호흡 반사가 반 박자 늦고 유리가 얇은 막처럼 밀림 |
| 호출끈 | 광섬유, 루카 생체음, 마라 2의 세 음, 주방 쪽 연두 보조등 |

### 7.2 LUCA_S2와 E2 합의

루카의 상태를 물으면 사건은 종료되지 않는다.

| 선택 | 관계 변화 | 반응 |
| --- | --- | --- |
| 손을 잡는다 | 루카 `bond +1` | 떨리는 생체 신호가 잠시 안정됨 |
| 손을 거둔다 | 변화 없음 | 루카가 거리를 존중하고 안내를 계속함 |

E2에서는 사용인의 기억이 정상 리셋 대상이 아니었고, 주인공의 외부 몸이 냉각 장치에 있으며, 위장 필터를 복구할 수 없다는 사실을 확인한다.

| 질문 | 답변 핵심 |
| --- | --- |
| 저택은 무엇인가요? | 장치가 저택을 대체한 것이 아니라 줄곧 그 아래에 있었음 |
| 내 몸은 어디 있나요? | 냉각 장치의 생존 신호는 유지되지만 기상 후 안전은 미보장 |
| 왜 여러분은 기억하나요? | 생체 신경 코어·인격 프로세스는 물리 리셋 대상이 아니었음 |

질문은 선택이며 `E2_INTRO`의 `마침`으로 관계 허브 `E_HUB`를 연다.

## 8. 다섯 사용인 핵심 관계 사건

다섯 사건은 선택형이다. 완료 수는 J4·E5·F2·엔딩의 대사와 배치를 바꾸지만 F0 및 두 엔딩을 잠그지 않는다.

### 8.1 E3_1 마라 1 배선 수리

| 단계 | 정답 |
| --- | --- |
| 출처 단자 | 각 자료를 `MAINT`, `CONSENT`, `AUDIT` 원래 출처에 연결 |
| 위험 연결 | 무단 우회 브리지 제거 |
| 로그 순서 | 동의 → 실패 → 명령 |

| 최종 선택 | 변화 | 후속 의미 |
| --- | --- | --- |
| 원본 책임자명을 남김 (`original_attribution`) | `bond +2`, `alert +1` | 모든 책임자 이름이 감사 기록과 엔딩 인계에 남음 |
| 보호 대상 식별자를 가림 (`protected_identifiers`) | `bond +1`, `alert -1` | 공개 사본은 가리되 원본 해시와 책임 기록은 유지 |

둘 다 사건 성공이며 `REC_MARA1`을 획득한다.

### 8.2 E3_2 이리스 계절 센서 교정

| 채널 | 위에서 아래 정답 출처 |
| --- | --- |
| 온도 | 기억 → 외부 → 투영 |
| 습도 | 외부 → 투영 → 기억 |
| 빛 | 투영 → 기억 → 외부 |
| 로그 순서 | 경고 → 명령 → 손실 → 감사 → 전환 |
| 감사 책임 정답 | `credential_owner_not_executor` / 인증 소유자는 실행자가 아님 |

| 최종 선택 | 변화 | 후속 의미 |
| --- | --- | --- |
| 외부 관측값 우선 (`external_truth`) | `bond +2` | 실제 센서값을 투영보다 먼저 표시 |
| 보호 투영 유지 (`shelter_projection`) | `alert +1` | 투영임을 표시하고 끌 권한을 주인공에게 반환 |

고백은 관계에 따라 달라진다.

| 조건 | D5 이후/F2 반응 |
| --- | --- |
| `bond >= 4` | 주인공에게 직접·사적으로 죽기를 바랐던 감정을 인정 |
| `bond >= 2` | "당신이 없으면 끝날 거라 생각했다"는 간접 인정 |
| 낮은 bond, `alert >= 4` | 로그가 의도까지 증명하지 않는다고 부인 |
| 그 외 | 감금 책임은 인정하지만 감정은 말하지 않음 |
| 전원 완료 | F2에서 모두 앞에 공개적으로 인정 |

주인공은 아버지가 이리스 인증을 도용해 생태 복구 전력을 냉각·시뮬레이션으로 돌렸고, 표본 손실과 감사 책임이 이리스에게 전가됐음을 확인한다. 주인공에게 분노를 돌린 것은 부당하지만 감정과 가담 책임은 삭제되지 않는다.

### 8.3 E3_3 루카 생명 유지 장치 안정화

| 단계 | 정답 |
| --- | --- |
| 배관 선택 | 주 배관 + 보조 배관 선택, 장식 배관 제외 |
| 위상 순서 | `main_1 → main_2 → aux_1 → safety` |
| 로그 | 안정화 뒤 세 로그 모두 확인. 로그끼리의 순서는 자유 |

| 최종 선택 | 변화 | 후속 의미 |
| --- | --- | --- |
| 위험까지 즉시 공개 (`full_disclosure`) | `bond +2`, `alert +1` | 위험표 전부를 같은 높이로 제시 |
| 안정화 결과를 먼저 설명 (`stabilize_first`) | `bond +1`, `alert -1` | 안정 완료 시각을 먼저 보여도 위험 기록은 삭제하지 않음 |

둘 다 같은 사실과 `REC_LUCA`를 남긴다.

### 8.4 E3_4 에드가 코어 권한 복원

| 단계 | 정답 |
| --- | --- |
| 로그 순서 | 동의 → 프로토콜 → 공석 → 연장 |
| `PROTECTION` | `SYSTEM` |
| `SURVEILLANCE` | `CUSTODIAN` |
| `MEMORY` | `RESIDENT` |
| `CHOICE` | `SUBJECT` |

오답 카드는 해당 자리에서만 빠지고 로컬 재시도한다.

| 최종 선택 | 변화 | 후속 의미 |
| --- | --- | --- |
| 책임 기록 (`responsibility_recorded`) | `bond +1`, `alert -1` | 감금 결정을 운영 기록에서 지우지 않음 |
| 권한 반환 (`authority_returned`) | `bond +2`, `alert +1` | 빈 SUBJECT 슬롯을 주인공에게 돌림 |

둘 다 `CHOICE=SUBJECT`, `REC_EDGAR`를 유지한다. E3_4를 생략하면 J4 뒤 `E3_4M` 최소 접근 절차가 발생하며 코어 길만 열리고 관계 완료·연구원 기록은 주지 않는다.

### 8.5 E3_5 마라 2 인격 아카이브

| 단계 | 정답 |
| --- | --- |
| 소유자 채널 | 초상화 3장 × 소유자 5명, 총 15개를 실제 소유자별 분리 |
| 초상화 처리 순서 | `C → A → B` |
| A 정렬 | 시작 `1`, 윤곽 `2` |
| B 정렬 | 시작 `2`, 윤곽 `0` |
| C 정렬 | 시작 `0`, 윤곽 `1` |
| 체크섬 기본열 | 선, 점, 호, 점, 선, 호, 선, 점, 호, 선, 점, 호 |
| 결손 칸 | 화면 기준 3·7·11칸 |
| 결손 정답 | 3=`호`, 7=`선`, 11=`점` |
| 선행 확인 | 에드가·마라 1·루카·이리스 백업 4개 모두 조사 |

| 최종 선택 | 변화 | 후속 의미 |
| --- | --- | --- |
| 한 인덱스로 병합 (`merged`) | `bond +2`, `alert +1` | 현재 기억과 손상 주석을 한 목소리로 유지 |
| 원본·복사본 분리 (`separated`) | `bond +1`, `alert -1` | 두 인덱스를 별도 보존하고 교차 링크 |

둘 다 마라 2를 원본 인격으로 인정하고 `REC_MARA2`를 획득한다. 미완료 시 메인 진행에는 익명 보라 인덱스만 제공된다.

## 9. J4 결산·마지막 저녁·코어 접근

### 9.1 J4 일지 4단계

J4 진입 확인은 남은 관계 사건을 `superseded`로 보존하며 실패나 완료로 처리하지 않는다.

| 항목 | 정답 |
| --- | --- |
| 페이지 순서 | 약속 → 전환 → 역할 고정 → 주인공 기동 |

| 기록 수·완료 상태 | 변형 |
| --- | --- |
| 연구원 기록 0~1개 | `J4_BASE` |
| 연구원 기록 2~4개 | `J4_EXPANDED` |
| 기록 5개 + 관계 사건 5명 완료 | `J4_FULL` |

J4_FULL은 마라 2가 타인의 기억을 지키기 위해 자기 이름 확인 영역부터 비웠다는 내용을 추가한다. 관계 3명 이상은 권장 진행일 뿐 게이트가 아니다.

### 9.2 E5 마지막으로 정상인 저녁

| 완료 인원 | 결산 단계 |
| --- | --- |
| 0~1 | LOW |
| 2~3 | MID |
| 4 | HIGH |
| 5 | ALL |

식탁과 좌석을 조사하고 주인공의 북쪽 정면 자리에 앉는다. 관계 완료 인물은 자신의 책임과 사건 결과를 언급하며, 미완료 인물은 업무·안전 정보만 전달한다.

공동 질문은 하나만 선택하며 정답은 없다.

| 질문 | 핵심 답변 |
| --- | --- |
| 나한테 무엇을 바라고 있어요? | 안전을 바라지만 주인공의 답을 대신할 권리는 없다고 인정 |
| 내가 떠나면 어떻게 돼요? | 인격 코어가 즉시 사라지진 않지만 기간과 미래 이전은 보장 불가 |
| 내가 남으면 무엇이 달라져요? | 강제 기동을 정당화하지 않으며, 진실을 알고 동의한 새 규칙이어야 함 |

직접 준비 완료를 확인하면 E5를 잠그고 관계 허브로 돌아갈 수 없게 된다.

### 9.3 E6 후속 반응과 코어 문

| 사건 | 선택 | 변화·반응 |
| --- | --- | --- |
| `MARA2_FU` | 이름을 수첩에 씀 | `bond +1`, `mara2_name_written=true`, 현실 수첩 이름 필드 강조 |
| `MARA2_FU` | 이름을 부름 | `bond +1`, 두 윤곽이 같은 속도로 맞물림 |
| `MARA2_FU` | 장난으로 답함 | 수치 변화 없음, 마라 2가 허세 섞인 웃음으로 넘김 |
| `EDGAR_S3` | 이유를 묻는다 | `bond +1`, 자신이 지킨 것이 문인지 주인공인지 확신하지 못한다고 답함 |
| `EDGAR_S3` | 명령한다 | 높은 bond면 권한 반환의 책임으로 받아들임 |
| `EDGAR_S3` | 기다린다 | 수치 변화 없이 에드가가 스스로 잠금을 해제 |

두 후속 사건은 선택이다. `문 열기 → 진입 확인`만으로도 F0에 들어갈 수 있으며 미완료 후속은 `superseded` 처리된다. F0 진입은 일방향이다.

## 10. F0 코어 메타퍼즐

### 10.1 F0-A 방 연결 회로

| 방위 슬롯 | 방 | 출력 |
| --- | --- | --- |
| 북 | 온실 | 동 |
| 동 | 주방 | 남 |
| 남 | 침실 | 서 |
| 서 | 기록 내실 | 북 |

추가 조건은 서쪽 기록 내실이 중앙 코어 요청 포트에 응답하는 것이다. 결과 경로는 `온실 → 주방 → 침실 → 기록 내실 → 온실`이다. 오답 시 각 출력과 수신 기능이 맞지 않는 지점을 구체적으로 표시한다.

### 10.2 F0-B 물질·정보 표본

각 방의 첫 번째 표본이 정답이다.

| 방 | 정답 표본 |
| --- | --- |
| 온실 | 외부 대기 수치 |
| 주방 | 생명 유지 유체 흐름 |
| 침실 | 현재 생체 신호 |
| 기록 내실 | 지속 기억 인덱스 |

향기 설정, 차 메뉴, 침실 배경음, 책 정리 규칙 등 장면 연출 표본은 오답이다. 검증 시 실제 물질·생체·기억 흐름과 장면 연출의 차이를 보여 준다.

### 10.3 F0-C 과거 중첩 자료

| 레이어 | 정답 |
| --- | --- |
| D4 포트 잔상 | 기준 상태 유지, 회전·반전 없음 |
| C5 거울 회로 | 반전 + 반시계 `90°` |
| B4 열세 번째 종 | `180°` |
| 모든 기준점 | `0` |
| 조사 순서 | `PATH → SPLIT → AUTH` |

D4는 기준판이라 회전·반전 입력을 거부한다. 오답은 로컬 재시도하며 레이어별 정합성 피드백을 준다.

### 10.4 F0-D 기록 역할

| 기록 | 역할 정답 |
| --- | --- |
| 아버지 일지 | `CREATOR` |
| 에드가 접근 암구호 | `CUSTODIAN` |
| 연구원 기록 묶음 | `RESIDENT` |
| D4 복구 명령 | `SYSTEM` |
| 주인공 수첩 | `SUBJECT` |

- 마라 2 기록이 없으면 `F0-D-ANON`이 익명 보라 인덱스를 제공한다. 기능 정보는 유지되지만 개인 음성과 감정 주석은 표시하지 않는다.
- 첫 오답 검증: 일치 개수만 표시.
- 두 번째 이후: 역할 문장의 빠진 글자와 정의 힌트 표시.
- 세 번째 이후: 현재 올바른 슬롯 하나를 선택해 고정 가능.
- 오답 카드는 로컬 재배치 가능하며 진행을 영구 잠그지 않는다.

### 10.5 F0-E 과거·현재 이중 인증

1. A1에서 고른 표시 유형의 조각을 정확한 순서로 재구성한다.
2. 과거 자기 연속성을 확인한다.
3. 현재 작성자를 `SUBJECT`로 선택한다.
4. 임시 의향을 하나 기록한다.

| 임시 의향 | 반응 | 최종 선택 영향 |
| --- | --- | --- |
| 현실 지향 | 밖을 직접 보고 싶다고 기록 | 잠금 없음 |
| 잔류 지향 | 이곳에 남는 것도 자신의 선택일 수 있다고 기록 | 잠금 없음 |
| 미정 | 모든 것을 본 뒤 정하겠다고 기록 | 잠금 없음 |

세 입력 모두 F0-E 성공이다. 이 기록은 사용인에게 전달되지 않으며 최종 선택을 편향하거나 기본 선택으로 만들지 않는다.

## 11. F1·J5·F2·F3

### 11.1 F1 아버지의 마지막 기록과 J5

| 단계 | 정답·조건 |
| --- | --- |
| 기록실 진입 | F0-E 완료 후 `H0_CORE_RECORDS` 진입 |
| 인증 | A1에서 고른 표시 유형 입력 |
| 재생 | 8개 기록을 `0 → 1 → ... → 7` 순서로 최초 재생 |
| J5 | 원본 기록 뒤 페이지를 읽고 작성자 `subject`로 씀 |

기록은 외부 붕괴, 냉각 동의 부재, 낙서 저택, 연구원 전환, 마라 2의 자기 영역 희생, 신체 이전 설비 상실, 사용인의 강제 기동, 미완성 권한을 차례로 밝힌다. 이전 조각을 다시 듣는 것은 가능하지만 아직 열리지 않은 뒤 조각을 건너뛸 수 없다.

J5 성공 시 "마지막 결정은 아직 확정하지 않는다"고 쓰며 `journal_stage=5`가 된다.

### 11.2 F2 연구원들과의 대면

| 질문 | 확보 사실 |
| --- | --- |
| 아버지와 어떤 동의를 했나요? | 미래 신체 약속 + 실제 생체 신경 코어 전환 |
| 왜 나를 강제로 깨웠나요? | 외로움·원망·보호 욕구가 섞인 강제 기동 |
| 밖은 어떤 상태인가요? | 신체 생존 신호는 있으나 외부 안전 미보장 |
| 연구원들을 해방할 수 있나요? | 현재 호환 신체·배양 모듈이 없어 즉시 분리는 인격 소실 위험 |
| 지금 무엇을 바라나요? | 최종 권한은 주인공에게 있으며 누구도 대신 확정하지 않음 |

질문은 원하는 순서와 수로 확인할 수 있다. `요약`은 빠진 여섯 필수 사실을 모두 채우며, 여섯 사실과 요약을 확인해야 `마침`이 열린다.

이리스의 발언은 8.2의 관계 상태에 따라 공개·사적 인정·간접 인정·부인·보류 중 하나로 바뀐다.

### 11.3 F3 마지막 확인

| 조사 대상 | 반드시 확인할 내용 |
| --- | --- |
| 기상 장치 | 외부 신체 연결과 인격 저전력 보존은 확정, 장기 생존·타인·미래 이전은 불확정 |
| 안정화 장치 | 기억·인격 활동은 유지, 시설 수명·자원·장기 심리 변화는 불확정 |
| 수첩 | 사실과 불확실성, F0-E 임시 의향. 임시 문장은 결정이 아님 |

세 대상을 모두 본 뒤 비교 요약을 읽어야 선택창을 열 수 있다. 선택창을 취소하면 조사 화면으로 돌아가며 최종 결정은 `unset`으로 유지된다.

## 12. EDC 최종 선택

| F0-E 임시 의향과 최종 선택 관계 | 기록값 | 독백 |
| --- | --- | --- |
| 같은 선택 | `reaffirmed` | 그때 기울었던 쪽을 지금 선택함 |
| 다른 선택 | `revised` | 생각이 달라졌고 지금의 선택을 확정함 |
| 임시 의향 미정 | `formed` | 이제 결정함 |

현실과 잔류는 언제나 둘 다 선택 가능하며 정답·보상 우열이 없다. 선택을 확정한 순간 `branch_committed=true`가 저장되고 이전 구간으로 돌아가지 않는다.

전원 관계 완료라면 어느 분기든 먼저 `ED_ALL_CEREMONY`가 열린다.

```text
에드가 → 마라 1 → 루카 → 이리스 → 마라 2
→ SUBJECT 권한 확인 → 주인공 서명
```

각 인격은 이름·문양·음향·기록 소유권을 직접 인증한다.

## 13. 현실 엔딩

### 13.1 진입·보존 상태·작별

| 노드 | 필수 행동 | 반응·결과 |
| --- | --- | --- |
| `EDR_ENTRY` | 현재 기록 계속 | 기상 결정은 다시 묻지 않음 |
| `EDR_ARCHIVE_STATUS` | 보존 상태 확인 | 다섯 인격 저전력 보존, 무정비 18개월·정기 정비 12~20년 추정, 신체 이전 불가 |
| `EDR_FAREWELL` | 에드가→마라 1→루카→이리스→마라 2 순서 | 완료 관계면 개인 작별, 미완료면 기능적 인계 기록 |

관계 완료 시 사건 결과 오버레이가 붙는다. 예를 들어 루카의 `full_disclosure`는 위험표 전체를 현실 수첩에 전송하고, 에드가의 `authority_returned`는 빈 CUSTODIAN 슬롯 옆 SUBJECT 서명을 남긴다.

이 반응은 사용인별 `EDGAR_ED_REALITY`, `MARA1_ED_REALITY`, `LUCA_ED_REALITY`, `IRIS_ED_REALITY`, `MARA2_ED_REALITY` 합성 사건으로 취급한다.

| 관계 상태 | 공통 작별 연출 |
| --- | --- |
| `bond < 2` | 공식 인계 위치에 머묾 |
| `bond 2~3` | 시선을 유지한 채 인계를 마침 |
| `bond >= 4` | 손에 직접 물건을 건네고 말끝이 늦어짐 |
| `alert < 2` | 한 걸음 물러남 |
| `alert 2~3` | 절차를 한 번 확인하되 추가 확인을 요구하지 않음 |
| `alert >= 4` | 가까이 남지만 제어권에는 손대지 않음 |

### 13.2 연결 해제와 신체 확인 (`EDR_DISCONNECT`~`EDR_BODY_CHECK`)

| `EDR_BODY_CHECK` | 아래 세 대상 중 서로 다른 2개 이상 조사 |

| 대상 | 반응 |
| --- | --- |

### 13.4 출입 점검과 지표 (`EDR_EXIT_PANEL`~`EDR_FINAL_FRAME`)

출구 패널에서 다음 세 항목을 모두 확인해야 수동 해제가 가능하다.

| 항목 | 반응 |
| --- | --- |
| 시설 전력 | 제한 전력, 생명 유지와 인격 보존이 공유 설비 사용 |
| 외기 | 호흡 가능 범위이나 장기 노출 미검증 |
| 수동 해제 | 문은 수동 개방 가능, 마지막 점검자 표시 존재 |

`EDR_FACILITY_FREE_LOOK`의 시설 자유 조사 대상 `캡슐 유리`, `빈 보존대`, `공구함`, `투명 화분`, `벽면 이름 목록`은 모두 선택이다. 빈 자리나 판독 불가 이름을 다른 생존자의 증거로 확정하지 않는다.

`EDR_AIRLOCK_CONFIRM`은 취소해 내부 조사로 돌아갈 수 있다. `EDR_SURFACE_THRESHOLD`의 지표 문턱에 나가면 `EDR_DISTANT_SIGNAL`의 멀리 점멸하는 빛을 선택 조사할 수 있으나 사람·자동 장치·센서 오류 중 무엇인지 확정하지 않는다. `EDR_FINAL_FRAME`에서 좌·중앙·우 시선을 움직일 수 있고 8단계 시간이 지나면 `CREDITS_REALITY`로 이동한다.

## 14. 잔류 엔딩

### 14.1 안정화와 세 합의

| 노드 | 필수 행동 | 결과 |
| --- | --- | --- |
| `EDS_ENTRY` | 잔류 확정 기록 계속 | 고딕 외피와 시설 프레임을 동시에 인정 |
| `EDS_STABILIZE` | 안정화 상태 확인 | S5, 진실 기억·기상 권한 유지, 강제 역할 완화, 다음 수면 확인제 |
| `EDS_MEMORY_CHARTER` | 기억 원칙 3개 모두 읽고 유지 | 진실 삭제 금지 |
| `EDS_APPEARANCE_CONTROL` | 외형 표시 방식 하나 선택 | 이후에도 변경 가능 |
| `EDS_AUTONOMY_CHARTER` | 다섯 사용인 모두의 역할을 강제에서 제안으로 전환 | 사용인 자율 확인 |

외형 표시 선택은 정답이 아니다.

| 방식 | 의미 |
| --- | --- |
| `layered` | 고딕 외피와 시설 골격을 항상 함께 표시 |
| `contextual` | 평소 외피, 조사할 때 시설 골격 표시 |

### 14.2 중앙홀과 후속 식탁 (`EDS_CENTRAL_HALL`~`EDS_FINAL_FRAME`)

`EDS_CENTRAL_HALL`의 대시계, 일정표, 현관문, 카펫, 호출끈은 선택 조사다. 호출끈은 강제 소환이 아니라 상대가 응답 여부를 고르는 공용 통신 채널로 바뀐다. 이후 `EDS_DINING_ROOM`에서 자리를 확인하고 `EDS_TABLE_OBJECTS`로 이동한다.

식탁에서는 다섯 사용인의 후속 오브젝트를 선택 조사할 수 있다.

이 반응은 사용인별 `EDGAR_ED_STAY`, `MARA1_ED_STAY`, `LUCA_ED_STAY`, `IRIS_ED_STAY`, `MARA2_ED_STAY` 합성 사건으로 취급한다.

| 소유자 | 오브젝트 | 완료 관계 반응 |
| --- | --- | --- |
| 마라 1 | 지워지지 않은 얼룩 | 얼룩을 기록으로 남기고 닦지 않음 |
| 루카 | 매번 달라지는 차 | 온도를 주인공이 정하고 틀리면 다시 데우면 된다고 말함 |
| 이리스 | 창밖의 계절 | 투영임을 표시하고 실제 관측과 구분 |
| 마라 2 | 초상화 이름표 | 위치를 바꿔도 원본 인덱스와 이름을 보존 |
| 에드가 | 내려놓은 레이피어 | 취침 시각 확정을 주인공에게 묻고 무기를 내려놓음 |

차 온도 `warm`·`hot`은 모두 유효하다. 수첩에는 다음 두 문장을 모두 직접 써야 한다.

```text
내일도 같은 날일 수 있다.
하지만 같은 선택일 필요는 없다.
```

세 합의 완료와 두 문장 작성 뒤 `EDS_FINAL_FRAME`으로 간다. 마지막 장면을 2단계 이상 지켜본 뒤 `CREDITS_STAY`로 이동한다.

## 15. 크레딧과 엔딩 후

현실·잔류 마지막 프레임에서 `ENDING_META_COMMIT`이 먼저 분기 감상 이력을 프로필에 보관한다. 그 뒤 두 분기 모두 세 크레딧 페이지를 순서대로 확인한다.

1. 개발용 크레딧
2. 제작 도구와 리소스
3. 끝난 장면, 남은 기록

마지막 페이지에서 종료하면 `credits_completed=true`, `current_node_id=ENDING_POST_CREDITS`가 저장된다. 제작진 명단과 개별 리소스 권리 표기는 사용자 지시에 따라 아직 미정이다.

## 17. 관계 결과와 후속 반응 빠른 표

| 사용인 | 관계 사건 | 결과 A | 결과 B | 핵심 후속 |
| --- | --- | --- | --- | --- |
| 에드가 | E3_4 | 책임 기록 `+1/-1` | 권한 반환 `+2/+1` | 문 앞 점검, 현실 감사 서명 또는 SUBJECT 슬롯 |
| 마라 1 | E3_1 | 원본 귀속 `+2/+1` | 식별자 보호 `+1/-1` | 현실 감사 사본, 잔류 삭제 금지 규칙 |

수치는 `bond / alert` 변화다. 높은 `alert`는 악성 점수가 아니라 경계와 절차 확인의 강도를 바꾼다. 어느 결과도 엔딩 선택지를 차단하지 않는다.

## 18. 구현 상태 주의표

v0.4 레지스트리의 짧은 반응 ID 중 현재 런타임에서 독립 사건으로 직접 호출되는 것은 `LUCA_S2`, `MARA2_FU`, `EDGAR_S3`다.

| 기획 ID | 현재 구현 처리 |
| --- | --- |
| `EDGAR_S1`, `EDGAR_S2` | B2 잠입·C0 금지 반응 및 경계 대사에 흡수 |
| `MARA1_S1`, `MARA1_S2` | P2 도구 반응·C2 청소 기록·D 구간 잔류 기억 반응에 흡수 |
| `LUCA_S1` | P4 차·맥박 전조에 흡수 |
| `IRIS_S1`, `IRIS_S2` | P5 날씨 모순·E3_2/F2 고백 상태에 흡수 |
| `MARA2_S1`, `MARA2_S2` | P3B 이름표 기억·C5 채널 스캔에 흡수 |
| `LUCA_S2` | E1 뒤 독립 선택 사건 |
| `MARA2_FU` | E6 독립 후속 사건 |
| `EDGAR_S3` | E6 독립 후속 사건 |

따라서 흡수된 ID를 별도의 필수 런타임 노드처럼 QA하지 않는다. 해당 감정·정보가 통합된 본 사건에서 나타나는지를 확인한다.

- [ ] 색상 없이도 이름·문양·선 패턴·음향으로 모든 정답을 판별할 수 있다.
