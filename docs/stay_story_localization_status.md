# 잔류 저녁 본문 현지화

## 적용 범위

`stay_story_texts.gd`를 통해 잔류 중앙홀·식당의 다음 서사 표시를 영어로 연결한다.

- 중앙홀 조사 대상의 제목·본문. 호출끈은 기존 통신 채널 메뉴를 여는 동작을 유지한다.
- 식탁 오브젝트 제목과 다섯 사용인의 관계 완료·미완료 본문.
- 원본이 선택한 관계 outcome 부기와 이리스의 고백 상태별 응답.
- 관계 완료 조합에 따른 착석 설명과 다섯 인물 각자의 자리 선택.
- 주인공이 직접 쓰는 두 문장과 작성 여부 접두어.
- 마지막 저녁의 초기 자세·자율적 자리·감각 묘사.

## 분기와 책임

`StayStory.table_lines()`가 먼저 선택한 대사 배열을 복사한 뒤 표시 문장과 화자 이름을 번역한다. 번역 함수는 관계·고백 상태를 새로 판단하지 않으며 대사 행을 추가하지 않는다. 미완료 관계를 완료형으로 바꾸거나 이리스의 사적 고백을 공개형으로 바꾸지 않는다.

착석도 `StayStory.seating()`이 생성한 문단을 완전 일치 표로 번역한다. 한국어는 원본 함수를 그대로 사용한다. 예상하지 못한 원문은 임의 해석 없이 원문으로 남으며, 원문 변경 시 대응표와 테스트를 함께 갱신해야 한다.

정본에 있는 미완료 인물의 서술형 반응과 각자의 이동·착석 선택권을 유지한다. 과거의 양옆에 서 있는 구도에서 각자의 선택으로 전환되는 시간 조건은 변경하지 않는다. 마지막 두 문장을 직접 쓰는 조건, 선택 조사 비필수, 관계 무보상, 크레딧 진입 조건도 그대로다.

## 검증

`basement_session_smoke.gd`의 잔류 저녁 경로를 영어로 실행한다.

- 32개 관계 완료 조합에서 착석 문단 수·다섯 영어 이름·한국어 정본 일치.
- 원본이 선택한 식탁 대사와 번역 배열의 행 수 일치, 번역 호출 전후 상태 불변, 표시된 분기 문장의 영어 대응.
- 실제 중앙홀·식탁 버튼을 통한 영어 조사 본문·관계 대사 표시.
- 기존 수첩 작성 순서와 재개·중복 방지, 선택 조사 비필수, 마지막 자세 전환, 관계·최종 결정 불변과 크레딧 경계 진입.

## 남은 범위

이번 작업은 서사 본문 중심이다. 잔류 화면의 일부 이동·차 온도·마지막 장면 종료 버튼, 통신 채널 선택창, 목표·위치·상태 안내와 미등록 오류 문구에는 한국어가 남는다. 이 문서는 잔류 엔딩 전체 현지화 완료를 뜻하지 않는다.

큰 글자·작은 창에서의 마지막 프레임 전체 가독성, OS 입력 완주, 갤러리 재열람 언어 정책, 크레딧·최종 아트·사운드도 별도 대상이다. 크레딧 인명은 계속 미정이다.
