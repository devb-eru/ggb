# 현실 수첩 현지화

## 적용 범위

`field_notebook_texts.gd`는 현실 엔딩의 물리 수첩 표시 자료다. 시뮬레이션 수첩의 데이터 이전을 뜻하지 않으며, 기존 `FieldNotebook`의 페이지 ID·필수 조건·읽기 완료·저장 규칙을 바꾸지 않는다.

- 9개 색인의 제목, 요약, 펼친 본문.
- 다섯 연구원의 각 두 관계 결과에 대응하는 인계 부기 10종.
- SUBJECT 인계 페이지의 실제 획득 출처 목록과 출처가 없는 경우의 설명.
- 수첩·출구의 장소와 목표, 읽음·필수 표시, 요약·펼침·다음 색인·읽기 확인 버튼.
- 출구 전력·외기·수동 해제의 점검 제목과 설명, 출구 잠금 해제 버튼.

한국어 페이지는 `FieldNotebook.page_text()`를 그대로 사용한다. 영어 부기 조건은 기존의 핵심 관계 완료, 연구원 기록 획득, 유효한 완료 outcome을 모두 요구하며 `RealityWake.farewell().warning` 판정을 함께 사용한다. 잘못되거나 미완료인 기록에 대한 부기를 영어에서 선행 노출하지 않는다. 이 조건을 원본에서 변경하면 번역 표시 함수와 회귀 검사도 함께 갱신한다.

## 의미 보존

표지의 제작 참고 메모와 SUBJECT 출력물의 구별을 유지한다. 전체 시뮬레이션 수첩이 물리적으로 이전되었다고 설명하지 않는다. 아버지 서문은 판단권을 남기는 자료이며 연구원들에 대한 책임을 지우는 사과나 면죄로 바꾸지 않는다.

‘첫 72시간’은 게임 속 시설 문서다. 실제 복용량·치료법을 추가하지 않았으며 오래된 문서가 현재 몸을 판정할 수 없다는 한계를 유지한다. 체크섬·인덱스만으로 의식을 복제하거나 새 신체를 만들 수 없다는 한계도 유지한다.

표지와 첫 72시간만 필수다. 영어 본문을 열었다는 사실은 대화 기록에 남지만, 게임 진행의 읽기 완료는 기존 확인 버튼 트랜잭션이 담당한다. 선택 페이지를 새 필수 조건으로 만들지 않는다.

## 검증

`basement_session_smoke.gd`에서 다음을 검사한다.

- 정본의 9개 페이지와 영어 표시 목록 일치.
- 10개 관계 outcome별 영어 부기와 한국어 원문 일치, 연구원 기록이 없을 때 부기 비노출.
- 실제 수첩 화면의 영어 색인과 9개 페이지 각각의 요약·펼침 표시 및 열람 기록.
- 영어 열람만으로 읽기 완료·관계·진행이 변하지 않음.
- 기존 한국어 읽기, 필수·선택 조건, 저장 실패 재시도, 재개, 현실 출구와 후속 엔딩 회귀.

## 남은 항목

이 범위는 수첩·출구 표시이며 현실 엔딩 전체 현지화 완료가 아니다. 앞선 연결 해제·사용인 인계 대사, 냉각 장치와 몸 확인, 외부 자유 조사, 갤러리 표시, 잔류 엔딩 본문과 시스템 오류 일부는 별도 작업이다. 갤러리의 저장 원문은 이번 번역으로 교체하지 않는다.

긴 영어 본문과 관계 부기의 최소 해상도·전체 페이지 조합 검증은 별도로 필요하다. 아래 공통 읽기창 검증을 전편 시각·입력 완주로 확대 해석하지 않는다.

## 후속 검증: 큰 글자 키보드 읽기

`chapter_one_smoke.gd`에서 실제 영어 ‘첫 72시간’ 펼친 본문을 공통 읽기창에 표시하고 글자 배율 200%를 적용했다. 텍스트가 실제로 스크롤 영역을 넘는지도 확인한다.

1. 기본 포커스가 닫기 버튼에 있는 상태에서 `Input.parse_input_event`로 Tab을 입력하여 본문 스크롤 영역에 진입한다.
2. PageDown을 반복 입력해 스크롤 범위의 마지막 위치에 도달한다.
3. PageUp으로 처음에 돌아온다.
4. Tab으로 닫기 버튼에 복귀하고 Enter로 창을 닫는다.
5. 이 읽기 보조 동작 전후 게임 스냅샷이 동일함을 확인한다.

헤드리스와 실제 Windows/OpenGL `CHAPTER_ONE_SMOKE`가 모두 PASS였다. 기존 스크롤 기능이 이 경로를 지원하므로 런타임 변경 없이 회귀 검사만 추가했다. 환경의 루트 인증서 경고는 남았으나 스크립트 오류는 없었다.

범위는 **실제 수첩 본문을 사용한 공통 읽기창의 Godot 키 이벤트 검사**다. 실제 현실 엔딩에서 해당 페이지를 찾는 전체 동선, OS 수준 키보드 입력, 마우스 휠, 재지정된 스크롤 키, 모든 페이지·관계 부기·해상도는 아직 이 테스트가 증명하지 않는다. 실제 수첩의 열람 기록·필수 읽기 조건은 별도의 Basement 회귀 검사 근거를 따른다.
