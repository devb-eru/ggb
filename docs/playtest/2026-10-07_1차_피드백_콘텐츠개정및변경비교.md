## 3. 프롤로그와 루프의 원고 차이

### 3.1 P1 수첩 압흔

이전 실행 원고:

> 고딕 저택 낙서와 빈 페이지. 연필 압흔은 내가 쓰기 전부터 다음 장까지 이어져 있다.

개정 원고:

> 관찰: 저택 그림 다음은 빈 페이지다. 글씨는 없는데, 종이를 비스듬히 기울이자 눌린 선이 드러난다. 한 장을 더 넘겨도 같은 자국이 남아 있다.

> 주인공의 생각: 여기에도 무언가 적었던가? 그림을 그린 기억은 나는데, 이 자국은 낯설어.

차이: 시간 순서의 모호함을 제거했다. 자국의 주인과 기억은 확정하지 않으므로 심리적 불안은 남는다. 이 자국과 A1에서 새로 고르는 표식은 다르다.

### 3.2 P6 밤 창문

이전 실행 데이터는 P6 원고 참조가 낮 문장으로 이어져 정원·햇빛을 반복했다. 고정된 외부 빛 자체는 기존 연출 의도다.

개정 원고:

> 관찰: 복도 등은 저녁빛인데, 창밖의 정원은 아침처럼 밝다. 가지 끝의 새가 아침에 보았던 높이에서 울고 있다. 유리에 닿는 빛도 달라지지 않았다.

> 주인공의 생각: 방 안은 어두워졌는데, 바깥은 왜 그대로지? 낮에 내가 시간을 잘못 본 걸까?

차이: 실내/실외의 변화를 대조한다. 낮 창문 미조사라면 과거 관찰을 인용하지 않는 별도 문구를 쓴다. 창밖을 정상적인 밤으로 교체하지 않았다.

### 3.3 A1·A2

이전: 새 표식을 작성하고 유지 여부를 확인하는 목표는 있었지만 일지 조사로 넘어가는 이유가 짧았다.

개정: A1은 물리 상태와 종이 흔적의 차이를 의심해 **새 표식**을 선택한다. A2는 자기 표식 검증 후 `그 잠긴 일지도, 오늘은 다르게 읽을 수 있을까?`라고 생각한다. 보지 않은 주름·기존 수첩 압흔을 기억한 것으로 처리하지 않는 조건 대사도 명시했다.

차이: 소녀가 시스템을 이미 아는 사람처럼 명령하지 않고 자신이 관찰한 차이를 시험한다. 표시 세 종류 모두 유효하며 F0-E 권한/의향 및 마지막 엔딩 선택은 변경하지 않는다.

## 4. B1 시간표와 발화 종류

정정 전: `정정: 오후 차 회수 직후부터 저녁 종 직전까지`는 어느 업무가 바뀌었는지 누락됐다.

개정 핵심:

```text
오후 차 회수 확인 뒤: 서쪽 대시계 점검.
점검 시간 정정: 오후 차 회수 직후부터 저녁 종 직전까지.
저녁 종이 울린 뒤: 기록 내실로 복귀, 장부 정리.
```

루카의 대시계실 수령 서명, 마라 1의 복도 작업 종료를 독립 문서로 제공한다. 실제 읽은 두 문서 조합에 따라 주인공의 생각을 다르게 작성했다. B1의 접근 창은 초기 조사 기회이지 에드가가 절대 들어오지 않는다는 보증이 아니다. B2 숨기·발각 대화·경고와 비실패 진행은 보존한다.

모든 신규 원고는 다음 분류를 사용한다.

| 분류 | 담는 것 | 담지 않는 것 |
| --- | --- | --- |
| 관찰 | 표면·소리·위치·감촉 | 검증하지 않은 원인 |
| 생각 | 주인공의 의문·가설·시험 이유 | 사용인에게 실제 말한 대사로 위장 |
| 발화 | 실제 말한 문장과 화자 | 객관 관찰의 자동 설명 |
| 문서 | 출처·작성자·원문 | 현재 주인공의 결심으로 전용 |
| 시스템 | 기록·검증 결과 | 인물의 감정 판정 |

## 5. J1~J3와 퍼즐의 구체적 개정

### 5.1 J1: 첫 두 문장도 증명할 수 있게 한다

기존 문장 세 조각과 앞면 정답을 보존한다. 상단 외곽 테두리부터 갈고리형 압흔 연결, 꺾인 이중선 연결, 하단 테두리로 이어지는 하나의 종이를 설계했다. 두 종류의 연결은 서로 바꿔 끼워도 맞아 보이면 안 된다. 마지막 마침표와 잉크점 사이의 한 칸은 별도 위상 단서로 남긴다.

차이: `문장이 자연스러운 것 같다`만이 아니라 `이 가장자리와 눌림선이 이어진다`로 배열을 설명할 수 있다. 번호를 그림에 인쇄하거나 새 실패 패널티를 추가하지 않았다.

### 5.2 B3: 세 판단의 증거를 분리한다

```text
설치 홈 + 나사쌍 + 흑연 앞뒤 → 종이 방향
선의 시작 / 통과 / 모임 / 단절 → 시계 역할과 신호 연결
정상 열두 번 뒤 떨림 + XII 뒤 홈 + 일지 여백 → +1 전달 시점
```

침실 종이는 배선이 끊겨도 설치 흔적이 있으므로 방향을 판단할 수 있다. 역할 카드의 좌우 배치는 공간 방위도가 아니다. 조작 예시의 `좌우 반전`·`앞/뒤`도 외부 서고 조각의 한 동작으로 정리해 별개의 두 반전처럼 보이지 않게 했다. 위 문법은 B3-A와 B3-B 상세 및 통합본 내부 정답 설명에 동기화했다.

차이: 기존의 어려운 조합 수를 줄이는 대신 판단 대상마다 독립 증거를 제공했다. 종이 회전 정답 네 장 0도, 서고 뒷면, 대응접실 기준·서고 중계·대시계 출력·침실 제외와 +1은 유지한다. 약한 시험은 역할 연결까지만 검증하며 위상을 미리 알려 주지 않는다.

### 5.3 B4·B5/J2: 그림이 문제 본체다

공명통에 남은 선을 반투명 장으로 옮기는 동작과 `열세 번째 종 파형 투명지`라는 이름을 추가했다. 페이지와 투명지는 하나의 원도로 제작해 다음 세 특징을 공유한다.

1. 긴 시작선과 비대칭 갈고리.
2. 간격이 다른 두 짧은 마루.
3. 완만히 돌아 닫히며 한쪽이 열린 잔류 끝선.

정답은 기존 `wave_rotation=0`이며 최초 제시는 90도다. 다른 회전은 세 특징 중 최소 두 곳이 어긋나야 한다. 좌우 반전 입력·새 실패 제한은 추가하지 않는다. 원도 제작 전에는 유일해를 실측 확인했다고 쓰지 않는다.

차이: `긴 선이 맞는다`는 글을 읽고 각도를 찍는 것이 아니라 세 비교 지점의 동시 일치를 확인한다. J2 원문은 유지하고 주인공의 표면·세정 방법 의문을 복원 뒤에 덧붙였다.

### 5.4 C3: 논리는 유지하고 암기를 분리한다

8단위, 원액=안정제 두 배, 물=첨가제 합+2와 5:1:2 해는 유지한다. 발견한 원문을 다시 읽을 수 있고 두 자료씩 교체 비교한다. 성공 전에는 제약만 요약하고, 성공 후에는 비율과 실제 제조 순서를 verified 기록에 함께 남긴다.

차이: 외부 메모를 잘하는 능력이 조제 난도를 대신하지 않는다. 자유 메모 기능, 세 자료 동시 비교, 수첩에서의 자동 조제 판정은 새로 요구하지 않는다.

### 5.5 C4: 짧은 반사와 짧은 가지는 다른 개념이다

거울에 다음 물리 근거를 추가하는 명세를 확정했다.

| 현재 카드 | 독립 근거 |
| --- | --- |
| 직선 진입 | 진동점부터 갈림점까지 단일 홈 |
| 짧은 분기 | 막힌 끝과 갈림점으로 돌아오는 복귀 홈 |
| 긴 분기 | 막히지 않은 끝과 고리 입구의 연결 |
| 고리 시계 방향 | 진행 방향에 따라 매끈함/걸림이 다른 겹친 홈 덮개 |

마른 시험은 선택한 경로만 보여 주고 첫 불일치에서 멈춘다. 아직 선택하지 않은 다음 정답 구간은 공개하지 않는다. 짧은 가지 왕복은 기존 카드 하나의 의미이며 추가 입력이 아니다. 계획 확정은 이 시험의 결과를 기록하는 단계다.

차이: `두 짧은 반사니까 짧은 분기 먼저`라는 단어 대응을 제거하고 복귀 경로·고리 연결로 순서를 추론한다. 중첩 90도 시계·반전 없음, 직선→짧은→긴→시계 고리, 실제 닦기의 비가역성은 유지한다.

### 5.6 C5·J3: 자료 정체와 미해결 방향을 드러낸다

`거울 회로 투명지`는 C5에서 회로와 기준점을 베낀 별도 장이다. B3의 배선 탁본이나 B4의 파형 장을 개명하지 않는다. 기존 `C5_MIRROR_TRACING` ID와 플래그도 유지한다.

J3은 이 장을 페이지의 눌린 기준점과 비교해 한 점이 맞아도 나머지 두 점은 벗어나는 상황을 실제로 보여 주는 명세다. 네 문장 조각에는 서로 다른 세 연결 압흔과 바깥 테두리를 추가한다. J3 페이지는 평면도가 아니므로 지도 전체·정확한 변환 조작·축 깊이는 제공하지 않는다.

차이: 어떤 종이를 꺼내야 하는지, 왜 다음에 평면도를 찾아야 하는지 분명해진다. D0-A의 좌우 반전+90도 반시계 변환과 세 점 일치 과제는 그대로 남는다. 기억 닻 `낙서 속의 문`도 정답 힌트로 바꾸지 않았다.
