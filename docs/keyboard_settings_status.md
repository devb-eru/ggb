# 키보드 재설정 구현 현황

## 적용 범위

- 제목 화면의 설정 > 키보드, 게임 중 메뉴 > 키보드 설정에서 같은 패널을 사용한다.
- 선택/상호작용, 취소/메뉴, 다음/이전 포커스, 수첩, 소지품, 방향키 네 개, 페이지 스크롤 두 개를 변경한다.
- 새 키는 해당 동작의 기존 키보드 입력을 교체한다. 선택 기본값의 Enter/Space도 새 키 하나로 교체한다. 마우스·컨트롤러 이벤트는 삭제하지 않는다.
- Godot GUI 동작과 게임 동작을 함께 변경한다. 예: 다음 포커스는 `ui_focus_next`와 `focus_next`에 동시에 적용한다.
- 소지품 단축키는 상시 표시된 소지품 칸으로 포커스를 옮긴다. 대화·퍼즐 확인창을 무시하거나 아이템을 자동 사용하지 않는다.
- Escape, Tab, Shift+Tab도 입력 대기 중에는 취소/이동이 아닌 지정할 키로 처리한다. 수정 키와 조합키는 함께 기록한다.
- 제목 화면 하단의 확인/뒤로 키 안내는 현재 설정을 표시한다.

## 저장·복구 정책

`accessibility.json`의 선택 항목 `key_bindings`에 논리 동작별 키 코드 배열을 기록한다. 기존 프로필에 항목이 없으면 기본값을 쓴다. 게임 저장 슬롯·관계·퍼즐 진행에는 영향을 주지 않는다.

입력 대기와 변경은 패널의 임시 사전에만 반영한다. 저장하고 적용을 누르면 전체 프로필 검증과 저장을 먼저 수행하고, 성공한 경우에만 InputMap을 변경한다. 저장 실패 시 이전 설정을 그대로 쓰며 오류 문구를 표시한다. 음향·일반 접근성 설정을 변경해도 키 항목을 보존한다.

- 취소/뒤로: 이번 패널의 미적용 변경 폐기.
- 키 입력 취소: 대기만 종료, 이전에 지정해 둔 임시 값 유지.
- 기본값 복원: 임시 값을 기본값으로 변경. 저장하고 적용해야 영구 반영.
- 마우스 취소·복원 버튼은 스크롤 목록 밖에 항상 배치한다.
- 창 포커스를 잃으면 키 입력 대기를 취소한다.
- 중복 키/잘못된 구조/잘못된 숫자/단독 수정 키는 거절한다. 충돌한 기존 동작을 조용히 지우거나 자동 교환하지 않는다.

## 검증 항목

이번 변경으로 START_SCREEN, PROLOGUE_SCENE, FOUNDATION, CHAPTER_ONE, BLACK_MIRROR, BASEMENT_SESSION 회귀가 통과했다. 재시작 테스트의 기록·읽기 두 프로세스도 각각 PASS를 확인했다. 환경의 루트 인증서 저장소 읽기 경고는 출력되었으나 이 키 입력 테스트에서 스크립트 오류는 발생하지 않았다.

- `start_screen_smoke.gd`: 실제 키 이벤트로 재지정, 중복 거절, Escape 및 Shift+Tab 캡처, F9/F10 GUI 포커스 이동, 미적용 취소, 저장 실패, 기존 기본 키 제거, 마우스 입력 보존, 일반 설정과의 왕복.
- `prologue_scene_smoke.gd`: 게임 메뉴 진입·저장·새 취소 키로 복귀, 퍼즐 진행 불변. 챕터 화면은 같은 PrologueController의 설정 구현을 상속한다.
- `key_binding_restart_smoke.gd`: 첫 엔진 프로세스에서 테스트 프로필 저장 후 종료, 별도 엔진 프로세스에서 프로필을 읽어 F8/F9/F10 InputMap 적용과 이전 Escape 제거를 검증한다. `--write-key-profile`은 기록 단계이고 인수 없는 실행은 읽기 단계다.
- 1280x720, 글자 배율 200%에서 키 목록은 스크롤하고 취소/복원/적용은 목록 밖에 남는다. 이것은 모든 해상도와 DPI에 대한 검증을 의미하지 않는다.

## 남은 제품 검증

- 전체 게임의 키보드 전용·마우스 전용 엔딩 도달을 실제 플레이로 다시 검증해야 한다. 개별 입력 회귀 테스트로 대체하지 않는다.
- 일부 기존 설명 문구에 N, Escape 등 기본 키 표기가 남을 수 있다. 동작은 InputMap을 따르지만 모든 안내 문구의 동적 키 표시 동기화는 별도 전수 검토 대상이다.
- Windows가 선점하는 시스템 단축키를 게임이 항상 캡처할 수 있다고 보장하지 않는다. 사용자 지정 컨트롤러 UI 및 여러 키보드 레이아웃·IME·고배율 DPI 전수 검증은 이번 범위에 포함하지 않는다.
- 이 작업으로 최종 아트·음향, 전체 번역, 실제 플레이 타임, 배포 빌드 검증이 완료되지는 않는다.
