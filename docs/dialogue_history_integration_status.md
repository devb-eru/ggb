# 대화 기록 연결 현황

검토 기준: `90178a9`까지의 구현. 전편 완료 판정이 아니라 제품 기준 중 대화 기록의 적용 범위와 남은 작업을 정리한다.

## 적용 범위

| 화면 | 자동 기록 | 열람 |
| --- | --- | --- |
| 1장·검은 거울 | 공통 대화창에 실제 표시한 문장 | 메뉴의 대화 기록 |
| 지하창고·관계·코어·엔딩 진행 | 공통 대화창에 실제 표시한 문장 | 메뉴의 대화 기록 |
| 데모 D5 스팅어·데모 종료 | 쓰기 제외 | 기존 기록 열람 |
| 크레딧·엔딩 완료 후 | 쓰기 제외 | 기존 기록 열람 |
| 프롤로그 | 미연결 | 미연결 |

선택지와 별도 퍼즐·연출 패널의 본문은 아직 자동 기록하지 않는다. 수첩과 감상 기록 갤러리는 대화 기록과 별도다.

## 저장과 표시

- `ChapterOneController._present_dialogue_line()`에서 표시 직후 기록한다. 미표시 문장은 기록하지 않고 동일 대화 실행에서 같은 문장을 다시 그릴 때 중복 추가하지 않는다.
- `ChapterOneSession.record_viewed_line()`은 `meta_progress.dialogue_history`의 `next_sequence`로 순번을 할당하고 `StateWriter`·`SaveManager`로 저장한다. 현재 챕터의 `_save_point(state)`를 사용하며 퍼즐·아이템을 수정하는 커밋 훅을 재실행하지 않는다.
- 실패하면 상태를 롤백하고 현재 문장을 유지한다. 계속 버튼으로 재시도하며 복구 후에만 다음 문장으로 이동한다.
- 열람은 상태 설치·저장을 호출하지 않는다. 엔딩 완료 후 열람은 저장 파일 바이트 불변까지 검사했다.
- 공용 형식은 `CH1_HISTORY_TRANSCRIPT`와 문자열 변수 `speaker`, `text`다. 이 ID는 원래 대사의 콘텐츠 ID가 아니다.
- 기록은 읽었던 언어의 화자·본문을 보존한다. UI 언어를 바꿔도 과거 본문은 재번역하지 않는다. 원문 ID·문장 구간·변수 기반 재번역은 후속 작업이다.
- 대화 커서 재개는 미구현이다. 마지막 피드백을 재표시하면서 재열람 기록이 추가될 수 있다. 다른 상호작용으로 같은 대사를 다시 보는 것도 새 열람이다.

## 검증 근거

| 자동 검사 | 검증 범위 |
| --- | --- |
| `chapter_one_smoke.gd` | 실제 표시 문장 저장, 미표시 제외, 재표시 중복 방지, 불러오기, 실패 롤백, 계속 버튼 재시도, 메뉴 열람·닫기 |
| `black_mirror_smoke.gd` | 기록 저장·불러오기, 퍼즐·엔딩 상태 보존, 읽기 전용 열람 |
| `basement_session_smoke.gd` | E1 조사 버튼 기록, J4·E6 취소 시 진행 보존, 엔딩 후 열람과 저장 파일 바이트 불변 |
| `foundation_runtime_regression.gd` | 정상 한·영 렌더링, 잘못된 변수·순서 거부, 원본 데이터 불변 |

격리된 개발 프로젝트의 자동 회귀 검사다. 버튼 신호 검증은 운영체제 수준의 마우스·키보드 완주 검사가 아니다. 후반 검사는 문장별 저장 추가 후 120초를 초과할 수 있어 로컬 검증기의 해당 모드 제한을 300초로 늘렸다. 실제 입력 지연·프레임 시간·장시간 저장 성능 검증은 남아 있다.

## 후속 작업

1. 프롤로그 표시 시점 기록을 연결한다. 첫 수면의 저장 경계와 기존 진행 자동 저장을 덮어쓰지 않는다.
2. 표시된 선택지 목록과 선택 결과를 구분해 기록한다. 미공개 분기는 노출하지 않는다.
3. 관계·아버지 기록·엔딩의 별도 본문 패널을 실제 열람 시점에 연결한다. 읽기 전용 갤러리에는 쓰기 경로를 추가하지 않는다.
4. 원문 ID 기반 재번역과 대화 커서 재개 정책을 완성한다. 현재 문자열 기록은 호환 읽기로 보존한다.
5. 장시간 목록의 가독성·페이지 분할·파일 크기·문장별 저장 지연을 측정한다. 기록을 임의로 삭제하거나 개수를 제한하지 않는다.

최종 기준은 [완성본 정의](full_game_definition.md)다. 현재 구현만으로 전편 대사·선택지 기록 기준을 충족한 것은 아니다.
