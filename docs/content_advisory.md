# GGB 콘텐츠 고지·심리 안전 기준

## 1. 목적과 상태

본 문서는 GGB의 민감 콘텐츠를 장면별로 분류하고, 상점·게임 시작·설정 화면에서 어느 수준까지 고지할지 정한다. 등급 기관의 최종 판정을 대신하지 않으며, 실제 제출 전 최신 빌드를 기준으로 Steam 콘텐츠 설문과 지역별 등급 요구를 다시 확인한다.

현재 기준:

- 직접 전투, 플레이어가 수행하는 살해, 노골적 유혈·고어는 없다.
- 성적 콘텐츠와 로맨틱한 미성년 대상화는 없다.
- 공포는 점프 스케어보다 반복, 감금, 감각 불일치, 신체·인격의 불안에 집중한다.
- 소녀 연령대로 보이는 주인공을 향한 과거의 살의가 관계 상태에 따라 언급될 수 있으나, 현재의 위해 시도나 공격 장면은 없다.

## 2. 고지 단계

| 단계 | 노출 위치 | 내용 | 스포일러 수준 |
| --- | --- | --- | --- |
| A | Steam 상점·데모 설명 | 심리적 공포, 감금·강제 통제, 신체·인격 보존 불안, 죽음·살의의 비그래픽 언급 | 낮음 |
| B | 첫 실행·새 게임 확인 | 반복되는 감금, 의료·냉각 불안, 기억 손상, 호흡·심박음, 점멸·화면 왜곡 | 중간 |
| C | 타이틀 `콘텐츠 상세` | 아래 장면 인벤토리와 발생 구간, 직접 폭력 여부 | 높음 |
| D | 장면 직전 | 광과민·멀미 위험이 큰 D5에만 짧은 시스템 전환 예고 | 서사 스포일러 없음 |

- A와 B는 처음부터 제공한다.
- C는 타이틀과 설정에서 언제든 다시 열 수 있다.
- D는 공포 내용을 설명하는 경고가 아니라 접근성 설정을 확인할 기회다.
- 고지를 닫거나 다시 보았다는 사실은 세이브 진행과 관계 상태에 영향을 주지 않는다.

## 3. 상점용 짧은 문구

한국어:

> 심리적 공포, 감금과 강제 통제, 신체·인격 보존에 관한 불안, 죽음과 살의에 대한 비그래픽 언급이 포함됩니다. 직접적인 고어, 전투, 성적 내용은 없습니다.

영어:

> Contains psychological horror, confinement and coercive control, anxiety involving bodily and identity preservation, and non-graphic references to death and homicidal thoughts. Contains no graphic gore, combat, or sexual content.

이 문구는 임시 번역 키 `CONTENT_ADVISORY_STORE_SHORT`로 관리한다. 상점 등록 시 실제 빌드와 문구가 일치하는지 다시 승인한다.

## 4. 첫 실행용 상세 문구

```text
이 게임은 다음 내용을 다룹니다.

- 반복되는 하루와 탈출이 제한된 환경
- 동의 없는 냉각 보존·가상세계 접속과 통제
- 생체 신경 코어, 신체 상실, 기억 손상에 관한 비그래픽 묘사
- 멸망과 죽음, 특정 인물을 향했던 과거의 살의에 관한 대화
- 호흡·심박음, 의료 장치, 감각 불일치와 심리적 압박
- 화면 왜곡과 제한적인 점멸

직접적인 전투, 유혈·고어, 성적 내용은 없습니다.
점멸·화면 흔들림·심박음은 접근성 설정에서 줄이거나 대체할 수 있습니다.
```

버튼은 `계속`, `접근성 설정`, `콘텐츠 상세`, `타이틀로` 네 가지다. `계속`을 위험을 감수한다는 동의 문구로 표현하지 않는다.

## 6. 표현 한계

### 6.1 허용

- 금속 맛, 건조함, 무거운 손, 지연된 감각처럼 비그래픽 신체 감각.
- 살의와 원망을 과거 감정과 현재 책임의 언어로 다루기.
- 생체 신경 코어를 캡슐·파형·진단 라벨로 표현하기.
- 멸망한 세계를 빈 시설, 오염 수치, 끊긴 신호로 암시하기.

### 6.2 금지

- 노출된 뇌 조직, 절단, 유혈을 상세히 보여 주기.
- 이리스의 살의를 로맨스, 질투 개그, 보상 가능한 애정으로 표현하기.
- 주인공의 소녀 이미지를 성적으로 대상화하기.
- 호흡·심박 입력 실패로 기상 실패나 사망을 만들기.
- 광과민 보호를 켰는데 필수 단서가 사라지게 하기.
- 콘텐츠 경고를 공포 연출의 일부처럼 갑자기 점멸시키기.

## 8. QA와 승인

| QA ID | 검증 | 통과 기준 |
| --- | --- | --- |
| `QA-CONTENT-01` | 상점 문구와 실제 장면 비교 | 누락된 민감 범주 없음 |
| `QA-CONTENT-02` | 첫 실행 고지 | 새 게임 전 열람·설정 진입 가능 |
| `QA-CONTENT-03` | D5 광과민 보호 | 점멸 없이 필수 의미 유지 |
| `QA-CONTENT-04` | 이리스 전 경로 | 살의가 로맨스·코미디·현재 공격으로 변질되지 않음 |
| `QA-CONTENT-05` | 신경 코어 시각 자료 | 고어 없이 존재 방식 이해 가능 |
| `QA-CONTENT-06` | 심박·호흡음 감소 | 필수 정보와 첫 호흡 진행 유지 |
| `QA-CONTENT-07` | 한·영 문구 | 의미·강도·부정문 범위 일치 |

승인 순서:

1. 내러티브 담당이 장면 인벤토리를 갱신한다.
2. 접근성 QA가 대체 표현을 확인한다.
3. Steam 콘텐츠 설문 직전에 실제 빌드와 다시 대조한다.
4. `beru`가 상점·게임 내 최종 문구를 승인한다.

새로운 민감 장면을 추가하면 이벤트 문서, 본 인벤토리, 한·영 문자열, Steam 설문 검토 항목을 같은 변경에서 갱신한다.
