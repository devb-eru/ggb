# 현실 기상 구간 현지화 및 검증

## 범위

`EDR_FAREWELL` → `EDR_DISCONNECT` → `EDR_WAKE_BODY` → `EDR_BODY_CHECK` → `EDR_FIELD_NOTEBOOK` 경계까지의 표시 문구를 한국어·영어로 연결한다.

- 다섯 사용인의 완료·미완료 인계 기록, 관계 결과별 추가 문장 10종.
- 관계·경계 단계에 따른 시선과 거리 묘사, 마라 2 이름 기록 표시.
- 이리스의 추론·부정·유보·간접·사적·공개 반응 6종.
- 위치·목표·버튼·확인 표시, 연결 해제의 열기 → 압력 → 금속 맛 순서.
- 손·호흡 표시기·고정 벨트의 최초 조사와 재조사 문장.
- 현실에서 시뮬레이션 수첩을 열 수 없다는 안내.

한국어 정본은 유지한다. `reality_wake_texts.gd`는 표시 계층이며 `RealityWake`의 진행 판정·저장 ID·인계 순서를 변경하지 않는다.

## 분기 보존

`RealityWake.farewell()`이 먼저 대사와 무결성 경고를 결정한 뒤, 복사본의 표시 문장과 화자 이름만 번역한다. 기록 부족 또는 미완료 상태에서 관계 추가 문장을 보충하지 않는다. 미완료 마라 1·마라 2의 서술은 `SYSTEM`으로 남는다. 사적인 이리스 고백을 공개 고백으로 번역하지 않는다.

인계 장면은 연결 해제 전 남긴 기록의 재생이다. 현재 보존 중인 인격과 실시간으로 질문을 주고받는 장면이 아니며, 번역에서도 이 구분을 명시한다.

신체 확인은 기존처럼 서로 다른 두 대상이면 충분하다. 재조사는 중복 가산하지 않는다. 호흡 표시기는 묘사 대상이며 제한 시간·연타 성공 판정을 추가하지 않는다. 현장 수첩은 시뮬레이션 수첩과 다른 물리적 물건이다.

## 회귀 검사

`basement_session_smoke.gd`의 현실 기상 경로에 다음 검사를 추가한다.

1. 다섯 사용인 각각에 대해 완료 여부, 관계 0·2·4, 경계 0·2·4, 기록 정상·누락·미완료 상태 조합을 확인한다.
2. 이리스 6종 반응과 사용인 결과별 추가 문장 10종에 한국어 정본과 영어 대응이 있는지 확인한다.
3. 번역 전후 상태 및 무결성 경고가 같고, 대사 수·순서·익명 화자 구분이 보존되는지 확인한다.
4. 실제 컨트롤러의 다섯 인계 버튼을 실행하고, 선택된 영어 문장을 끝까지 읽어야 진행 상태가 저장되는지 확인한다.
5. 감각 전환 순서, 최초 호흡, 신체 최초·반복 조사와 열람 기록을 확인한다.
6. 저장 후 재개, 임의 두 대상 조합, 중복 조사 방지, 현실 수첩 진입, 관계 무보상과 현실 결정 유지를 검사한다.

실행: 격리된 Godot 검증 프로젝트에서 `--basement-session-smoke`.

검증 결과: Godot 4.7.2의 headless 및 Windows OpenGL 실행 모두 `BASEMENT_SESSION_SMOKE: PASS`. Windows 2560×1600 캡처에서 영어 위치·목표, 신체 조사 세 버튼, 현장 수첩 진입 버튼이 영역 안에 표시되는 것을 확인했다. 실행 환경의 루트 인증서 저장소 경고는 별도로 출력되었으나 스크립트 오류는 없었다.

## 남은 범위

이 문서는 현실 엔딩 전체 현지화 완료를 의미하지 않는다. 지표 선택 조사·최종 프레임, 크레딧·갤러리, 공통 오류 문구는 별도 검토 대상이다. 영어 문장의 캐릭터 말투 최종 감수도 필요하다.

자동 검사는 컨트롤러 입력과 상태를 검증하며 OS 수준 마우스·키보드 전편 완주 또는 모든 배율의 가독성을 증명하지 않는다. 최종 아트·사운드와 감각 연출의 완성도 역시 별도 검증한다. 크레딧 인명은 미정으로 유지한다.

캡처에서 공통 수첩 버튼의 영어 `Notebook`이 단어 중간에서 줄바꿈되는 기존 레이아웃 문제를 확인했다. 이번 기상 구간 번역과 별개로 공통 버튼의 너비·줄바꿈 및 긴 재지정 키 표기를 함께 보완해야 한다. 해당 화면은 아직 최종 배경 대신 임시 패널을 사용한다.
