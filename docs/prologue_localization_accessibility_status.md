# 프롤로그 현지화·읽기 접근성 현황

## 범위와 기준

- 기준 커밋: `f22898f` 및 그 선행 변경.
- 제품 범위는 [제품 계약](product_contract.md)과 [완성본 정의](full_game_definition.md)를 유지한다.
- 이 문서는 프롤로그의 부분 구현·검증 기록이다. 전편 영어화, 최종 시각 품질, 입력별 완주, 출시 준비 완료를 승인하지 않는다.
- 크레딧 명단은 미정이며 이번 변경에 포함하지 않는다.

## 저장과 호환성

1. P1/P2 완료 플래그, 아이템 ID, 청소 판정과 진입 조건은 번역과 분리한다.
2. 기존 수첩은 문자열을 저장한다. 현재 번역 어댑터는 알려진 한국어 문장을 카탈로그와 대조하고, 미확인 문장은 삭제·대체하지 않는다.
3. 저장 문자열 구조를 새 텍스트 ID 구조로 바꾸는 작업은 아직 하지 않았다. 향후에는 기존 저장의 중복 제거·챕터 전달·되읽기를 포함해 별도 마이그레이션을 검증해야 한다.
4. 한국어 카탈로그의 수첩 원문을 개작하면 기존 저장과의 대응이 끊길 수 있다. 개작할 때는 이전 원문에 대한 호환 목록 또는 마이그레이션을 함께 제공한다.

## 검증을 해석하는 범위

- `FOUNDATION_SMOKE`: 등록된 번역 ID·언어·변수 대응을 검사한다. 코드에 남은 한국어 문자열까지 자동 탐지하는 완성도 검사는 아니다.
- `PROLOGUE_SCENE_SMOKE`: 일부 버튼 신호와 컨트롤러 호출, 테스트 상태 주입을 사용한다. 마우스만 또는 키보드만으로 처음부터 끝까지 플레이했다는 증거가 아니다.
- `CHAPTER_ONE_SMOKE`와 `BASEMENT_SESSION_SMOKE`: 공유 코드의 회귀 근거다. 이번 프롤로그 수정으로 이후 챕터의 영어 본문이 완성되지는 않는다.
- P2 시각 확인은 개발 리소스의 영어 200% 캡처다. 1280×720 출력 이미지 하나가 모든 실제 창 크기·4K·Windows DPI 조합을 입증하지 않는다.
- 캡처 재현 인자: `--prologue-smoke --capture-p2-window --capture-english --capture-large-text`. 테스트 전용 저장 환경에서 실행한다.

## 다음 작업 순서

1. P3 책 정리와 일지 질문을 한·영으로 연결한다. 책·선반 ID, 정리 순서, 질문 완료 상태는 유지한다.
2. P3B·P4·P5·P6을 이어서 번역하고 핵심 선택지와 반복·저장 재개를 검증한다. 현실 진실을 앞당기지 않는 기존 대사 의미를 보존한다.
3. 방 이름·메뉴·이동·창 닫기와 같은 공통 UI 누락을 전수 대조한다. 실행 중 언어 변경의 즉시 반영 여부도 따로 확인한다.
4. 실제 입력 시나리오로 프롤로그 전체를 검증하고, A~F 및 두 엔딩까지 같은 기준을 확장한다.
5. 최종 에셋·음향·목표 플레이타임·전체 제품 게이트는 별도 미완료 항목으로 유지한다.
