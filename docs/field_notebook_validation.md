# 현실 현장 수첩 및 출입 패널

검증 결과: 격리 Godot 4.7.2에서 `BASEMENT_SESSION_SMOKE: PASS`, `FOUNDATION_SMOKE: PASS`. 인계 출력물의 확장 본문과 세 버튼을 시각 확인했다. 스크립트 오류는 없고 Windows 루트 인증서 저장소 경고는 별도 환경 경고다.

## 구현 범위

`EDR_FIELD_NOTEBOOK → EDR_EXIT_PANEL → EDR_FACILITY_FREE_LOOK`를 연결한다. 마지막 노드의 자유 조사는 다음 구현 경계다.

물리 수첩은 표지, 첫 72시간, 아버지 서문, 마라 1·이리스·에드가·마라 2 탭, SUBJECT 인계 출력물, 공동 뒤표지의 아홉 탭이다. 모든 페이지에 요약과 펼쳐 읽기를 제공한다. 표지와 첫 72시간만 필수이며 다른 페이지는 선택적이다. 원본이 현실로 이동한 가상 수첩으로 설명하지 않는다.

기본 생존·운용 자료는 관계 미완료 상태에도 제공한다. 유효한 관계 outcome이 있는 경우 각 담당자의 인계 부기를 추가한다. 인계 출력물은 완료된 연구원 원문의 전체 복사가 아니라 출처 ID 목록이다. 공구 정정, 큰 글씨로 다시 쓴 제목, 여백의 장난 등 기능과 무관한 작은 일화도 포함한다.

인계 출력물의 시설 시각은 현재 동기화 미검증으로 표시한다. 실제 프린터 애니메이션, 확정된 시설 시계 모델, 필압 이미지 렌더링은 아직 구현하지 않았다. 필압 흔적은 텍스트 묘사다. 이러한 표현을 완료된 물리 매체 렌더링으로 간주하지 않는다.

## 상태 및 동선

- 필수 페이지와 출입 점검은 `ending_run.required_interactions_seen`에 중복 없이 저장한다.
- 선택 페이지를 포함한 읽기 이력은 `loop_state.event_local_states.FIELD_NOTEBOOK.pages`에 정렬 저장한다.
- ‘읽기 확인 후 닫기’에서만 읽기 이력을 저장한다. 단순 페이지 미리보기는 완료 처리하지 않는다.
- 표지와 첫 72시간 확인 뒤 진행 입력으로 `R0_FACILITY_EXIT`에 이동한다.
- 출구는 전력, 외기, 수동 해제 세 항목을 확인한 뒤 잠금을 해제한다. 오답이나 숨은 정답은 없다.
- 출구에서도 수첩 단축키로 물리 수첩을 열고 다음 색인으로 순환 열람한다. 가상 수첩 페이지는 열지 않는다.
- 각 전환은 기존 `SAVE_ENDING_NODE` 경로로 저장하며 최종 결정·관계 수치에 영향이 없다.

## 검증

`_validate_field_notebook`에서 아홉 페이지의 요약/확장 열기와 저장 재개, 필수 누락 거부, 선택 페이지 없이 진행, 실제 출구 위치, 세 점검 전 잠금 해제 거부, 해제 후 노드 재개, 관계 불변을 확인한다. 인계 출력물 화면은 `user://field_notebook_page.png`로 캡처한다.

최종 원화·음향, 모든 해상도와 글자 확대, 실제 읽기 시간 목표의 플레이 테스트는 별도 검증이 필요하다. 다음은 시설 자유 조사·에어록·지표·현실 최종 프레임이며 잔류 엔딩 및 크레딧/메타 진행도 계속 구현해야 한다.
