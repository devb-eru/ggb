# 후반 챕터 설정 메뉴 누락 수정

## 원인과 영향

프롤로그에 키보드·화면 패널을 추가했지만 ChapterOneController가 별도로 재정의한 메뉴에는 음향 설정만 남아 있었다. 설정 기능 자체를 상속해도 메뉴 버튼이 자동 추가되지는 않아 1장과 해당 메뉴를 상속하는 검은 거울·지하 구간에서 두 설정에 접근할 수 없었다.

기존 키보드·화면 구현 현황의 게임 중 메뉴 지원 설명은 이 누락이 수정되기 전에는 프롤로그에 한정되었다. 기존 챕터 회귀 테스트의 PASS도 당시 두 버튼의 존재를 검증하지 않았다.

## 수정

- PrologueController의 `_settings_menu_actions()`가 음향·키보드·화면 순서와 콜백을 제공한다.
- 프롤로그의 기록 지원 여부별 메뉴와 ChapterOneController 메뉴가 같은 목록을 사용한다.
- 계속하기·대화 기록·제목으로 이동 등 각 메뉴의 기존 항목과 순서는 유지한다.
- 설정 패널이나 설정 파일 형식, 게임 저장 데이터는 변경하지 않는다.

## 검증

- `CHAPTER_ONE_SMOKE`: 실제 메뉴 버튼의 레이블, 버튼 콜백을 통한 패널 표시, 기존 메뉴 패널 숨김, 뒤로 복귀, 진행·대화 기록 불변.
- `PROLOGUE_SCENE_SMOKE`: 공통 목록 추출 이후 기존 프롤로그 설정 동작 회귀.
- `BLACK_MIRROR_SMOKE`: 변경된 메뉴를 상속하는 검은 거울 구간 회귀.

위 검사는 격리된 Godot 4.7.2 프로젝트에서 수행했다. 루트 인증서 저장소 읽기 경고는 남았으나 스크립트 오류는 없었다. 이 수정은 전체 게임의 키보드 전용 완주나 모든 해상도·DPI의 접근성 검증 완료를 뜻하지 않는다.
