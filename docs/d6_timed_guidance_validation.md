# D6 시간별 안내

검토일: 2026-09-13

## 동작

본편 D6의 실제 탐색 프레임에서만 안내 시간이 흐른다. 창 포커스 이탈, 메뉴·수첩·조사 대화·수면 확인 중에는 기존 입력 차단과 일시정지 규칙에 따라 멈춘다. 3분에 깨진 열한 번 취침 종의 자막, 5분에 에드가 방송 문구, 8분에 두 휴식 경로 목표 강조를 표시한다. 자동 대화창, 강제 이동·수면, 관계 변화는 없다. 탐색과 수면 버튼은 계속 사용할 수 있다.

실제 종·방송 음원은 미연결이다. 현재 자막은 음원 완성이나 실제 청취 검증의 증거가 아니다. 동행 사용인 반응 변형은 후속 범위이며 기본 에드가 방송을 사용한다.

`loop_state.event_local_states.D6.guidance_checkpoint`는 180, 300, 480 순서로 저장한다. 완료 안내 단계만 저장하므로 재실행 시 마지막 단계부터 시간을 다시 센다. 단계 사이 경과 초 전체를 복구하지는 않는다. 첫 파열 수면 뒤에는 D6 로컬 상태와 함께 제거된다.

저장 실패 시 자동 재시도를 중단하고 명시적인 안내 저장 재시도 버튼을 제공한다. 안내 실패로 필수 탐색·휴식 입력을 잠그지 않는다. 완료 단계 이후에는 안내 저장을 반복하지 않는다. 기존 화면 재구성의 초점 복구를 사용한다.

## 검사

2026-09-13 격리 Godot 4.7.2 headless `BASEMENT_SESSION_SMOKE` PASS. 기존 데모·본편 전환·관계·엔딩 회귀를 함께 실행했다. 인증서 저장소 경고 외 SCRIPT ERROR 없음.

후반 세션 smoke에 179초 이전 무안내, 메뉴·조사 대화 중 시간 정지, 180·300·480초의 순차 진행, 8분 후 D6 유지, 추가 시간에 중복 저장 없음 검사를 추가했다. 테스트는 델타를 직접 주입하며 실제 8분 OS 입력 검증을 대체하지 않는다. 각 접근성 조합의 별도 UI 검증은 남는다.

### 안내 저장 실패·재개

2026-09-13 추가 검사 포함 `BASEMENT_SESSION_SMOKE` PASS. 최종 실행에 SCRIPT ERROR 없음.

첫 안내 직전에 잘못된 슬롯 경로를 주입한다. 실패 시 전체 상태 롤백, 자동 처리 중단, 추가 델타에도 저장 재시도 없음, 경로 이동 버튼과 명시적 재시도 버튼 공존을 검사한다. 슬롯 경로 복원 후 실제 재시도 버튼을 눌러 180초 체크포인트 저장, 오류 버튼 제거, 타이머 재활성화를 확인한다.

실제 슬롯 재로드 후 컨트롤러 누적 시간을 0으로 되돌려 화면을 재구성하면 저장된 180초부터 재개해야 한다. 이후 조사 대화 동안 멈추고 300·480초 안내로 이어지는지 확인한다. 잘못된 경로 실패는 디스크 단절·저장 공간 고갈 전체를 대체하지 않으며, UI 버튼 호출 검사는 OS 마우스·키보드 입력 검증과 구분한다.
