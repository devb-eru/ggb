# 1장 잔여 표시 현지화 현황

## 기준일

2026-09-14

## 범위

이 작업은 1장 `A1~J2`에서 대화 카탈로그 밖에 남아 있던 방 이름, 이동 버튼, 마라 2의 잔류 기억 반응, 세션 오류와 시계 배치의 동적 검사 결과를 한·영 표시 계층에 연결한다. 퍼즐 정답, 한국어 정본, 수첩 원문, 저장 상태와 이벤트 진행 조건은 변경하지 않는다.

## 구현 계약

- `chapter_one_text.tres`의 기존 189개 한·영 ID는 그대로 사용한다.
- ID가 없는 1장 표시 문자열만 `chapter_one_display_texts.gd`가 번역한다.
- 세션은 계속 한국어 정본과 안정적인 `location_id`를 저장한다.
- 컨트롤러는 화면에 내보내기 직전에 현재 언어를 적용한다.
- 정의되지 않은 행동 ID, 일치 구간 수, 잘못 놓인 슬롯 번호처럼 실행 중 조합되는 값은 번역 뒤에도 보존한다.
- 알 수 없는 과거 저장 문자열은 임의로 바꾸지 않고 원문을 표시한다.

## 표시 범위

| 영역 | 영어 표시 |
| --- | --- |
| 방 머리글 | 침실, 중앙홀, 사용인 공용실, 대응접실, 외부 서고, 기록 내실, 서쪽 대시계, 북쪽 기록 회랑 |
| 이동 | 중앙홀 목적지 6개, 기록 내실문, 북쪽 연결문 상태, 외부 서고·중앙홀 복귀 |
| 짧은 반응 | 첫 반복 아침, 이동, 자기 표식, 축약 일과, 수면 조건 |
| 마라 2 | 이름표 질문 버튼과 전날의 정리를 기억하는 대사 |
| 시계 배치 | 준비 조건, 자리 교환·회전 오류, 0~4 일치 구간, 슬롯별 단선·회전 오류, 서고 탁본 반전 단서, 배치 성공 |
| 시계 작동 | 선행 배치, 당일 작동 종료, 역할·위상 입력 오류, 봉인핀 확인 |
| 공통 실패 | 저장 오류와 정의되지 않은 행동 ID |

## 검증 기준

`CHAPTER_ONE_SMOKE`는 다음을 검사한다.

1. 모든 방 이름과 1장 전용 UI 용어에 영어 대응이 있다.
2. 카탈로그 밖의 고정 피드백 전부가 영어에서 원문과 달라진다.
3. 시계 배치의 일치 수, 슬롯 번호와 서고 반전 단서가 영어에서도 보존된다.
4. 실제 컨트롤러가 기록 내실 머리글, 복귀 버튼, 일반 오류와 저장 오류를 영어로 표시한다.
5. 표시 번역은 게임 상태와 퍼즐 입력을 변경하지 않는다.

## 완료 판정의 한계

이 작업으로 프롤로그와 1장 필수 경로의 한·영 표시가 이어지지만, 전편 영어 실제 완주 판정은 아니다. 다음 검토 대상은 검은 거울 `C0~J3`, 지하창고 `D0~D6`, 파열 이후 관계·결산 `E0~E6`의 카탈로그 밖 동적 문구다. 운영체제 수준의 마우스 전용·키보드 전용 완주도 별도 증거로 남긴다.
