## 목적과 범위

플레이어가 직관적으로 이해할 수 있도록 수첩을 포함한 완성작 GUI·UX를 디자인한다. 사용자는 이번 작업의 결과물을 이미지 시안 중심으로 선택했으며, 기존 고딕 저택 분위기와 밝은 종이 수첩의 조합을 승인했다.

포함: 최신 시안 보드 10개, 타이틀 배경 및 커서 반응 HTML 미리보기, 46개 화면·상태 목록, 핵심 UX 설명, 생성 프롬프트, 정적 검토. HUD·Rusty Lake 상호작용·마노사바 대화·실제 스탠딩과 오브젝트 그림체·평면도 지도 지시를 반영했다.

제외: Godot 적용, 실제 게임의 입력·배율·성능 인수, 확정 퍼즐 도식, 확정 UI 리소스 납품. 이미지 시안이 기본 범위이며, 후속 커서 움직임 요청에 한해 독립 타이틀 미리보기를 추가했다.
