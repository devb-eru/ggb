# 완성작 화면별 설계표

이미지 시안으로 방향을 고르는 단계의 화면 목록이다. 아래 `변형`은 공통 컴포넌트로 설계한 상태이며, 각각의 완성 이미지를 제작했다는 뜻은 아니다. 제품 계약 파일을 수정하지 않았다. 직접 아이템 사용과 최신 시각 방향은 사용자 요청에 따른 제안이며 승인 후 계약에 반영할 대상이다. 그림체는 [최신 기준](art-direction.md)을 따른다.

## 수첩 세부 상태

| 상태 | 표시 | 행동 |
| --- | --- | --- |
| 처음 / 0건 | `아직 기록한 단서가 없습니다` | `닫기`. 아직 모르는 자료 제목·총량 없음 |
| 검색 결과 0건 | `일치하는 자료가 없습니다` + 검색어/활성 필터 | `검색어 지우기`, `필터 초기화` |
| 정리 중 | `자료를 정리하고 있습니다` | 닫기 가능, 준비 전 결과를 0건으로 단정하지 않음 |
| 새 자료 발생 | `새 기록이 있습니다` | 명시적 `새 기록 반영`. 현재 목록 정렬을 갑자기 바꾸지 않음 |
| 상세 열림 | 선택 행과 원본 제목 연결 | `목록으로`, `고정하기`, `비교에 담기`, `크게 보기` |
| 고정 저장 실패 | 상태가 저장되지 않았다는 한 문장 | `다시 시도`, `취소`. 성공처럼 핀을 확정하지 않음 |
| 비교 묶음 1개 | 첫 자료 썸네일, 두 번째 칸 안내 | `자료 추가`. 비교 실행은 불가 이유 표시 |
| 비교 묶음 여러 개 | 썸네일 목록과 A/B 선택 | 두 칸에서 각각 자료 교체. 같은 항목 선택 상태 명시 |
| 좁은 화면 / 큰 글자 | 목록→상세 단일 열, 비교 A/B 전환 | 닫기·뒤로·작업줄은 접근 가능하게 고정 |
| 과거 일반 대사 정리됨 | 필요한 경우 `오래된 일반 대화 일부는 보관되지 않습니다` | 남은 원문만 열람. 없는 문장 복원·생성 금지 |

최대 50행 페이지와 고정 snapshot 원칙을 유지한다. 일반 최근 2,000개 보관 정책·보호 항목·기존 미분류 보관은 DEC-0012를 따른다. UI를 단순하게 만든다고 데이터 보존 규칙을 줄이지 않는다.

| F0-A/B | 피드백 회로 / 신호 표본 | 타일 배치 또는 표본 비교. 범주와 근거를 함께 보여 줌 |
| F0-C | 세 원본 레이어와 기준점 | 세 레이어 켜기·끄기와 변환. 수첩의 두 자료 열람과 다른 실제 퍼즐 화면 |
| F0-D | 기록 역할·행동 문장·출처 | 인물색과 권한 범주를 분리. 분류 카드에 텍스트와 형태 |
| F0-E | 과거 인증 / 현재 권한 / 의향 | 독립된 단계. 비구속적 의향을 엔딩 확정으로 보이게 하지 않음 |
| J1~J5 | 각 복원 단계의 실제 자료·문장 | 정본의 찢김·압흔·중첩·원문 관계를 반영. 그림 장식이 증거를 대신하면 안 됨 |

## 구현 인계 원칙

- 래스터 시안의 글자·버튼·퍼즐 도형을 한 장의 배경으로 잘라 쓰지 않는다. Godot Label/Button/Container와 데이터 기반 도식으로 분리한다.
- 본문과 원본 문서 그림은 역할이 다르다. 원본에 필수 문자가 포함되면 선택 가능한 전사 텍스트와 확대 경로를 함께 제공한다.
- `Tab/방향키` 이동, `Enter` 확정, `Esc` 한 단계 취소를 공통으로 사용한다. 검색창의 N/H/I는 입력 글자다.
- 페이지 닫기 때 키 해제가 원래 화면까지 전달되어 대사 진행·아이템 사용을 일으키지 않게 한다.
- 기본 우선순위: 입력창/IME → 최상위 팝업/원본 확대 → 상세 → 검색 상태 → 수첩 → 원래 화면. 각 화면에 마우스로 누를 수 있는 뒤로/닫기도 제공한다.
- 월드/오브젝트 확대 상태의 Esc는 `선택 아이템 해제 → 가까이 보기에서 뒤로 → 일시정지`다. 수첩·설정 등 모달을 열면 모달의 입력 우선순위가 먼저 적용된다.
- 200% 대응은 전체 그림 확대가 아니라 재배치다. 글자 크기와 UI 배율을 동시에 올려도 정보 접근성을 유지한다.
- KO/EN은 같은 정보와 확인 횟수를 제공한다. 긴 번역은 세로로 늘리며 버튼 글씨를 임의 축소하지 않는다.

## 후속 검토 방법

방향 확정 전에 시안을 보여 주고 설명 없이 다음 행동을 물어본다. 현재 문서는 이 검사를 시행한 결과가 아니다.

1. 수첩 첫 화면에서 다른 자료를 찾고 비교를 시작할 수 있는지.
2. 비교가 실제 장치를 조작하는 것으로 오해되지 않는지.
3. `관찰`과 `생각`의 차이, 물건 사용의 다음 단계를 이해하는지.
4. 실패 후 남는 것과 다시 해야 하는 것을 말할 수 있는지.
5. 두 엔딩 중 UI가 특정 선택을 권한다고 느끼는지.

그 뒤 구현 단계에서 실제 Windows 입력, 1280×720, UI·텍스트 200%, 한·영, 색 제거·음량 0을 검증한다.

기존 메타 UI의 `사용하기` 단계 생략은 사용자 추가 요청을 구체화한 디자인 제안이다. 실제 적용 전 계약 갱신 범위는 [참조·차이 문서](rusty-lake-reference.md)에 명시했다.

### 대사 영역 가로 확장 · 2026-10-21

08-v4와 10-v2를 기준으로 본문과 이름표를 왼쪽으로 확장하고 우측 인벤토리 앞에서 끝낸다. 글자 크기는 유지하며, 하단 스탠딩 위의 어두운 그라데이션으로 가독성을 확보한다. 선택지·수첩 기록과 고정 HUD의 위치는 유지한다.

## 수첩 분류 탭 수정 · 2026-10-21

상단 가로 분류 탭을 제거하고 수첩 왼쪽 바깥 가장자리에 종이 책갈피 네 장을 위에서부터 단서·대화·기록·인물 순서로 붙인다. 글자는 가로 방향이며 페이지 안 자료 목록과 분리한다. 왼쪽 위 모서리가 비스듬히 잘린 닳은 흑자주색 종이, 밝은 글자를 사용한다. 선택 탭은 더 길게 돌출시키고 자주색과 작은 마름모를 함께 써서 색 없이도 구별한다. 각 탭은 충분한 클릭 영역과 선명한 키보드 포커스를 확보한다. 참고 이미지의 지도·규칙 분류는 추가하지 않는다. 자료 비교 같은 별도 하위 화면은 기존 돌아가기 동선을 유지한다.
