# 불러오기 창 재설계

2026-10-23 · 디자인 검토본. load-preview.html에서 확인한다. 새 이미지·아이콘·텍스처 에셋은 제작하지 않았다. 배경과 썸네일은 프로젝트의 기존 이미지를 재사용한다. 게임 코드와 저장 파일은 변경하지 않았다.

## 구성

참고 이미지의 넓은 종이 장부, 최상단 자동 저장 구획, 아래에 이어지는 저장 행, 왼쪽 미리보기와 오른쪽 시각 정렬을 적용한다. 주황색 선·원·설명 번호와 슬롯 번호는 넣지 않는다. 참조 이미지의 영문 장식 문구, 난이도, 하단 설명문도 사용하지 않는다.

1920×1080에서 중앙 종이 패널 1320px, 수직 중앙 정렬. 제목은 ‘불러오기’만 표시한다. 배경은 기존 고딕 저택을 어둡게 눌러 종이에 집중시킨다. 각 행은 미리보기 / 장소·공개된 사건 / 저장 날짜·시각·플레이 시간 순서다. 자동 저장은 상단 별도 행, 수동 저장은 세 행으로 제안한다. 숫자는 실제 날짜·시간 정보에만 쓰며 참고 이미지의 설명 번호는 재현하지 않는다.

선택은 옅은 자주색 면과 왼쪽 짙은 선으로 표시한다. 선택한 행을 다시 요약하는 보조 패널은 두지 않는다. 비어 있는 슬롯은 옅은 썸네일 윤곽과 ‘비어 있음’만 표시하고 선택할 수 없다. 오른쪽 아래 ‘불러오기’로 실행하며, 왼쪽의 ‘뒤로’와 우상단 닫기로 나간다. 샘플 날짜·문구는 시안용이다.

## 동작과 상태

- 클릭 또는 위·아래 방향키로 유효한 기록 선택. 포커스와 선택만으로 불러오지 않는다.
- 불러오기 → 선택 기록 이름을 보여 주는 확인창. 기본 포커스는 취소. 실제 게임 실행 대신 시안임을 알리는 결과만 표시한다.
- 유효한 저장이 전혀 없으면 모든 행과 불러오기 버튼 비활성. 빈 목록 안내는 한 번만 표시한다.
- 손상된 저장은 해당 행에 ‘불러올 수 없음’을 표시하고 실행을 막는다. 복구 가능한 경우에만 해당 행에 복구 동작을 노출한다.
- 작은 화면에서는 날짜·시간을 장소 아래로 내려 같은 행에 묶는다. 추가 설명 레이블은 넣지 않는다.

## 적용 시 확인할 사항

현재 start_screen.gd의 화면은 슬롯 세 개만 표시한다. 자동 저장을 독립 행으로 노출하는 부분과 미리보기·저장 시각·플레이 시간은 이번 디자인 제안이며 실제 저장 시스템과 연결하지 않았다. 런타임 적용 때 해당 데이터 지원 여부를 확인해야 한다. 난이도는 현재 화면 정보에 필요하지 않아 생략했다.

## 검증

브라우저 1280×720에서 전체 패널과 하단 버튼이 스크롤 없이 표시되는 것을 확인했다. 기존 배경과 썸네일 로딩, 저장 행 선택 표시, 빈 행 비활성, 확인창의 선택 기록 표시와 취소 기본 포커스를 확인했다. load-preview-review.png는 검토용 화면 캡처이며 게임 에셋이 아니다.

## 최신 이미지 시안

사용자 요청에 따라 웹 시안 대신 images/13-load-paper-v1.png를 최신 디자인 검토본으로 제작했다. 내장 image_gen을 사용한 완성 화면 이미지이며 별도 부품 에셋은 만들지 않았다. 섬유결·얼룩·접힘·닳은 모서리와 겹친 종이를 표현하고, 본문 아래는 밝게 유지했다. 자동 저장 구획, 아래 세 행, 미리보기·기록·시간 정렬을 유지했으며 주황색 주석과 설명 번호는 제외했다. 한글 제목·슬롯 문구·버튼 문구와 네 행 구성을 육안으로 확인했다. 실제 저장 데이터와 연결되지 않은 시안이다. 생성 프롬프트는 load-paper-prompt.json에 보존한다.

## 시작 화면 색감 및 애니메이션풍 통일

최신 선택 이미지: images/13-load-anime-v2.png(불러오기), images/14-new-game-anime-v1.png(새 게임). 사용자 제공 실제 시작 화면의 남색·보라색·아이보리색을 기준으로 통일했다. 종이 질감은 유지하면서 갈색 실사 얼룩과 반사광을 줄이고 윤곽선·단순화한 명암·회화적인 붓질로 표현했다. 두 화면은 배경과 종이·리본·버튼 언어를 공유한다. 불러오기는 자동 저장 포함 네 행, 새 게임은 수동 저장 위치 세 행으로 구성하며 빈 위치를 선택한 상태다. 기존 기록에 새 게임을 시작할 경우 별도 덮어쓰기 확인을 거치는 기존 UX 원칙은 유지한다. 이번 결과는 전체 화면 이미지 시안 두 장이며 새 부품 에셋이나 웹사이트를 제작하지 않았다. 두 이미지의 한글·행 수·선택 상태·색감 및 PNG 디코딩을 확인했다. 생성 기록은 load-new-anime-prompts.json에 보존한다.
