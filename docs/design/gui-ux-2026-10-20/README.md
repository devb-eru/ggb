# GGB GUI·UX 시각 방향 제안

2026-10-20 · 이미지 시안 중심 · **디자인 검토본 / 게임 적용 전**

현재 게임의 고딕 저택 분위기는 유지하고, 읽는 화면에는 밝은 종이와 선명한 흑연색 활자를 사용한다. 사용자가 이번 대화에서 선택한 범위는 **이미지 시안으로 방향 결정**이다. 이 폴더는 런타임 에셋 납품이나 Godot 구현 완료를 의미하지 않는다.

작업 중 추가된 사용자 배치 지시를 우선 적용한다. **좌상단 메뉴·현 위치 / 오른쪽 세로 인벤토리 / 좌하단 수첩 / 왼쪽 스탠딩 / 하단 대화창**이 기본 HUD다. [사용자 참고 이미지](references/user-layout.png)의 배경은 참조하지 않는다.

상호작용은 추가 요청에 따라 Rusty Lake 시리즈의 공식 조작 안내를 참조했다. **대상 클릭 → 가까이 보기 → 아이템 선택 → 대상 클릭 → 결과 확인 → 뒤로**를 기본 제안으로 삼는다. 세부 근거와 기존 계약과의 차이는 [Rusty Lake 참조](rusty-lake-reference.md)를 본다.

[이미지 모아 보기](gallery.html) · [커서 반응 시작 화면](title-preview.html) · [그림체와 최신 참고 기준](art-direction.md). 모든 시안은 로컬 파일이며 외부 게시하지 않았다.

실제 **마라 2·이리스·에드가·주인공** 스탠딩과 책 오브젝트를 기준으로 선·명암·종이 질감을 통일했다. 대화는 마노사바식 하단 그라데이션과 이름 장식, 지도는 손그림 건축 평면도와 **검은 현 위치 점**을 사용한다. 지도 오른쪽 목록과 하단 리스트는 제외했다.

## 디자인의 중심

1. **지금 할 수 있는 행동을 말로 쓴다.** 아이콘만 보여 주지 않고 `탁본 살펴보기`, `비교에 담기`, `자료 바꾸기`처럼 대상과 동사를 붙인다. 핵심 행동 하나에 강한 강조를 준다.
2. **추론의 근거를 눈앞에 둔다.** 홈·눌림선·파형·회전 기준점은 원본 그림에서 확인하게 한다. 수첩 자료명과 퍼즐에서 부르는 이름을 통일한다.
3. **읽기와 실행을 구분한다.** 수첩 비교는 열람용이다. 장치에 적용하는 버튼은 퍼즐 화면에만 둔다. 원본 확대와 비교로 실패·관계·진행 판정이 바뀌지 않는다.
4. **수첩은 돌아오기 쉬운 도구다.** 닫으면 이전 대사·선택·퍼즐 초안으로 돌아간다. 검색과 필터, 읽던 위치도 유지한다. 수첩을 여는 동안 진행을 멈춘다는 상태를 표시한다.
5. **분위기는 테두리와 월드가 맡는다.** 장식은 외곽에, 필수 문장은 깨끗한 면에 놓는다. 필수 정보에는 장식 필기체를 사용하지 않는다.

## 화면이 전달하는 순서

`어디인가 → 무엇을 살펴볼 수 있나 → 무엇을 관찰했나 → 어느 자료와 비교하나 → 무엇을 시험하나 → 결과에서 무엇이 남았나`

현재 목표는 정답 지시가 아니라 발견한 의문 한 줄이다. 예: `시계의 흔적을 조사한다`. 자동으로 다음 정답을 알려 주거나, 미발견 방·인물·자료 수를 표시하지 않는다.

### 수첩

- 분류 탭은 **단서 / 대화 / 기록 / 인물** 순서로 수첩의 왼쪽 바깥 가장자리에 세로로 붙인다. 짙은 종이 책갈피의 글자는 가로로 읽으며, 선택 탭은 자주색·돌출 길이·작은 마름모로 구별한다. 고정과 비교는 탭이 아닌 자료 작업이다.
- 기본 목록은 제목·썸네일·짧은 상태만 보여 준다. 긴 분류 설명은 `필터`에 넣는다.
- 첫 `N` 진입은 최근 단서, 첫 대화 기록 진입은 최신 대화다. 재진입은 각 진입 범위에서 읽던 위치를 복원한다.
- 단서 상세는 `자료명 → 발견 장소/출처 → 원본 → 관찰 → 작업 버튼` 순서다.
- 관찰·가설·검증은 칩 모양과 텍스트로 구분한다. 가설을 확정 사실처럼 표시하지 않는다.
- 여러 자료를 비교 묶음에 담고 두 개씩 바꿔 읽는다. 좁거나 크게 확대된 화면에서는 A/B로 전환한다.
- 자유 필기 기능은 추가하지 않는다. 게임이 작성한 가설과 실제 발견한 기록을 재열람한다.

### 탐색과 대화

- 평소에는 월드가 화면의 대부분을 차지한다. 좌상단에는 메뉴와 현재 위치, 오른쪽에는 세로 인벤토리, 좌하단에는 수첩을 고정한다. 지도는 좌상단 메뉴에서 접근하며 단축키는 action 설정을 따른다.
- 대화할 때 스탠딩을 왼쪽에 두고, 대사 영역을 화면 가로 약 20% 지점부터 우측 인벤토리 앞까지 넓게 사용한다. 하단 몸통 위에는 충분히 짙은 그라데이션을 깔아 본문을 읽기 쉽게 하고 얼굴은 가리지 않는다. 글자 크기는 유지한다.
- 오른쪽 아이템 클릭은 사용 준비로 바로 이어진다. 상세 설명은 필요할 때 `살펴보기`로 레일 왼쪽에 펼친다. 대화 중에는 레일을 보존하되 사용 동작을 막고 이유를 표시한다. 메뉴와 수첩은 계속 사용할 수 있다.
- 선택 대상은 윤곽과 행동 문구로 표시한다. 키보드 포커스는 별도의 이중 윤곽이다.
- `관찰`, `생각`, 인물명, `문서`, 시스템 알림은 명시적 출처 라벨로 구분한다. 기본 대화에서는 하나씩 표시한다. 최신 08은 `주인공`, 10은 제공된 실제 인물을 반영했다. 대사는 화면 검토용 예시다.
- 읽는 중 배경 조작은 차단하고 수첩·메뉴는 접근할 수 있게 한다. Esc가 대사를 넘기지 않는다.

### 퍼즐과 도움

- 목적 한 줄, 확보한 자료, 실제 조작 대상, 검증 결과, 하단 실행줄의 순서를 통일한다.
- 회전·뒤집기·자리 교환은 각각 무엇이 바뀌는지 그림으로 보인다. 드래그 없이 선택 후 목적지를 고르는 경로도 유지한다.
- `시험`, `계획 확정`, `실행`을 하나의 모호한 `확인`으로 합치지 않는다.
- 힌트는 **관찰 → 연결 → 변환 → 부분 검증 → 직접 지원**으로 구분한다. 다음 단계의 내용은 요청하기 전에 드러내지 않는다.
- 실패 화면은 `틀렸습니다`만 보여 주지 않고, 확인된 부분과 다시 준비할 부분을 분리한다. 세계의 수면과 디스크 저장을 구분한다.

### 후반과 엔딩

- 파열 이후 배경 소재는 바뀌어도 버튼 위치·자료 이름·수첩 사용법은 유지한다.
- 사용인별 색은 기록의 출처를 구분하는 작은 문양 표지다. 호감도 게이지나 정답색으로 쓰지 않는다.
- 최종 두 절차는 동일 크기·밝기·정보량·확인 횟수를 사용한다. 첫 포커스는 가운데 수첩이다.
- 감상 기록은 실제로 경험한 자료만 표시한다. 전체 영상 재생 기능처럼 보이는 재생 버튼은 두지 않는다.

## 이번에 결정할 것

- 밝은 종이의 면적과 장식 밀도.
- 수첩의 목록/원본 비중과 하단 비교 묶음.
- 월드 위 HUD의 크기와 존재감.
- 본문 글꼴의 인상. 실제 폰트는 이미지 생성 글꼴과 별도로 선정한다.

이 네 항목이 정해지면 수첩·대화·퍼즐 공통 컴포넌트부터 Godot 적용용으로 구체화할 수 있다.
