사용자의 후속 지시를 기존 시안보다 우선한다. 방향 결정용 설계이며 Godot 런타임 적용은 별도 작업이다.

캐릭터의 얼굴·복식·실루엣은 원본을 기준으로 보존한다. 이전 화면 예시의 등장인물을 새로운 등장인물로 채택하지 않는다. 마라 1·루카의 스탠딩은 제공되지 않았으므로 임의로 만들어 대체하지 않는다.

오브젝트는 [닫힌 책](references/object-closed-book.png), [펼친 책](references/object-open-book.png), [시계 그림 책](references/object-clock-book.png), [꽃잎 그림 책](references/object-petal-book.png)의 그림체를 기준으로 한다. 책에 그려진 문양을 새 퍼즐 정답으로 채택하지 않는다.

- 선: 균일한 벡터 테두리보다 굵기 변화가 있는 짙은 회갈색 외곽선.
- 면: 넓은 명암 덩어리와 각진 붓자국. 캐릭터와 오브젝트 모두 같은 단계의 명암을 쓴다.
- 재질: 닳은 표지·종이 끝·접힌 리본을 그림으로 표현한다. 사진 같은 종이 잡티와 번쩍이는 금속 테두리는 줄인다.
- 색: 아이보리, 회보라 그림자, 짙은 남색과 흑연색. 캐릭터 고유색은 유지한다. 자주·청록은 배경 조명에 제한한다.
- 읽기 면: 본문 뒤는 매끈한 밝은 종이 또는 충분히 어두운 면. 장식 질감은 가장자리에만 둔다.
- UI 상태: 선택은 선 굵기·이중선·문구로 함께 알린다. 인물 고유색을 정답이나 호감도 신호로 사용하지 않는다.

## 대화와 탐색

좌상단 메뉴·현 위치, 우측 인벤토리, 좌하단 수첩 위치를 고정한다. 스탠딩은 왼쪽을 기본으로 하고 얼굴과 본문 안전 영역을 확보한다.

마노사바 참고는 하단으로 짙어지는 그라데이션, 손으로 그린 어두운 장식, 마름모 이름표와 본문 위계에 적용한다. 캐릭터나 배경을 차용하지 않는다. 오른쪽 인벤토리는 대화 중 같은 자리에 어둡게 남기며 아이템 사용을 막는다. 메뉴·수첩은 접근 가능하다. 선택 대기·수첩 열람 중 자동 진행은 멈춘다.

Rusty Lake 참고는 사물 직접 클릭, 확대 조사, 아이템 선택 후 대상 클릭, 눈앞의 물체 변화에 적용한다. 강제 드래그와 반복 확인창은 피한다. `뒤로`와 아이템 선택 취소를 구분한다.

## 지도

[사용자 지도 참고](references/map-layout.png)의 종이와 건축 평면도 표현을 따른다. **오른쪽 목록과 하단 리스트는 넣지 않는다.**

- 방은 카드나 노드가 아니라 벽·문·복도의 윤곽으로 표현한다.
- **현재 위치는 검은색으로 채운 원 한 개**다. 방 이름 옆의 빈 공간에 두며 이름을 가리지 않는다.
- `● 현 위치` 범례와 현재 방 이름을 함께 읽을 수 있게 한다. 점의 밝기·색 변화로 다른 상태를 표현하지 않는다.
- 이동 포커스는 방 윤곽의 이중선, 잠긴 문은 문의 자물쇠로 구별한다. 검은 점은 현재 위치 전용이다.
- 발견한 공간과 알려진 문 상태만 표시한다. 미발견 방의 윤곽·개수도 노출하지 않는다.
- 큰 글자에서는 지도 확대·이동과 방 이름 읽기 영역을 제공한다. 우측/하단 목록을 다시 도입하지 않는다.
- 11은 시각 표현을 판단하는 공간 배치 예시다. 실제 방 연결은 게임의 정본 데이터로 그려야 한다.

## 시작 화면과 움직임

왼쪽 로고·세로 메뉴, 오른쪽 큰 주인공 구도다. [인터랙티브 시안](title-preview.html)은 실제 주인공 PNG 원본과 새 배경을 분리해 배치한다.

배경 이동 한도는 ±12px/±8px, 인물은 반대 방향 ±4px/±3px. 약 140ms 시정수로 부드럽게 따라간다. 클릭 가능한 메뉴는 고정하며 마우스가 나가면 중심으로 돌아온다. 포커스 상실·창 숨김·대화상자 열림에는 즉시 중심 복귀한다. `움직임 줄이기`와 시스템 모션 감소 설정은 모두 움직임을 끈다. 터치 입력은 시차 이동을 만들지 않는다.

눈동자 변형은 원본을 손상시키지 않도록 이번 시안에서 사용하지 않았다. 사용자가 요청한 ‘눈이나 배경’ 중 배경의 커서 반응을 구현했다. 게임 메뉴·저장 기능은 별도이며 미리보기의 버튼은 화면 시안을 연다.

## 화면별 적용 우선순위

01-v3, 08-v4, 11과 타이틀 미리보기가 최신 그림체 기준이다. 비교·퍼즐·메뉴·설정·후반·직접 상호작용 보드도 같은 기준으로 다시 그렸다. 선택 파일은 갤러리와 README를 따른다. 03의 구형 카드 지도는 11이 대체한다. 타이틀 모션과 원본 캐릭터 배치는 HTML 미리보기가 기준이다.

최종 제작에서 작은 인벤토리 아이콘은 스탠딩과 같은 붓질을 유지하되 장식선을 줄여 실루엣으로 읽히게 한다. 수첩은 닫힌 책, 문서는 접힌 종이로 구별한다. 대화 캐릭터 원본의 전체 모습은 원본 목록에서 확인하며, 생성 화면의 캐릭터 재현본을 원본 에셋 위에 덮어쓰지 않는다.

2026-10-21 대사 폭 수정: 이름표와 본문 시작점을 왼쪽으로 이동하고 우측 인벤토리 직전까지 길게 펼친다. 08-v4 기준 가로 약 20~87%를 사용하며 글자 크기는 유지한다. 하단 몸통과 겹치는 부분은 짙은 그라데이션으로 대비를 확보하고 얼굴과 고정 HUD는 가리지 않는다. 10-v2의 발화·관찰 상태도 같은 원칙을 따른다.

## 수첩 분류 탭 수정 · 2026-10-21

상단 가로 분류 탭을 제거하고 수첩 왼쪽 바깥 가장자리에 종이 책갈피 네 장을 위에서부터 단서·대화·기록·인물 순서로 붙인다. 글자는 가로 방향이며 페이지 안 자료 목록과 분리한다. 왼쪽 위 모서리가 비스듬히 잘린 닳은 흑자주색 종이, 밝은 글자를 사용한다. 선택 탭은 더 길게 돌출시키고 자주색과 작은 마름모를 함께 써서 색 없이도 구별한다. 각 탭은 충분한 클릭 영역과 선명한 키보드 포커스를 확보한다. 참고 이미지의 지도·규칙 분류는 추가하지 않는다. 자료 비교 같은 별도 하위 화면은 기존 돌아가기 동선을 유지한다.
