# Rusty Lake 참조 → GGB 상호작용 제안

2026-10-20 사용자 추가 지시: 상호작용 등을 Rusty Lake 시리즈에서 참조한다. 화면의 기본 위치는 사용자가 첨부한 이미지를 유지한다.

## 확인한 공식 자료

- [Cube Escape: The Lake 공식 소개·조작 안내](https://www.rustylake.com/room-escape-games/cube-escape-the-lake.html): 방향 화살표 이동, 오브젝트 클릭 상호작용, 인벤토리에서 물건을 선택한 뒤 화면의 대상에 사용.
- [개발사 Rusty Lake의 Cube Escape: Paradox 조작 안내](https://rustylake.itch.io/cube-escape-paradox): 사람·사물 클릭, 인벤토리 선택 후 화면 대상에 사용, 일부 오브젝트 드래그 및 환경 이동.
- [Rusty Lake Hotel 공식 소개](https://www.rustylake.com/adventure-games/rusty-lake-hotel.html): 방 중심의 포인트 앤 클릭 퍼즐과 공식 공략 진입점. 이번 검토에서는 공식 웹 문구를 확인했으며 영상을 전편 시청하거나 직접 플레이한 것으로 표현하지 않는다.

공식 자료에서 확인한 핵심은 **화면의 대상에 직접 행동하고, 인벤토리 물건을 골라 화면에 적용하는 방식**이다. 아래 확대 단계·피드백·접근성 규칙은 이를 GGB에 맞춰 구체화한 제안이며 모든 Rusty Lake 작품이 동일하게 동작한다는 설명이 아니다.

## 기본 흐름

`방 전체 → 대상 클릭 → 가까이 보기 → 물건 선택 → 대상 클릭 → 눈앞의 결과 → 뒤로`

| 행동 | 제안하는 GGB 반응 | 플레이어가 알아야 하는 것 |
| --- | --- | --- |
| 오브젝트 클릭 | 조사·열기·가까이 보기 중 문맥상 기본 행동 즉시 수행 | 같은 문 손잡이에 `상호작용` 메뉴를 매번 띄우지 않음 |
| 인물 클릭 | 대화 상태로 전환, 왼쪽 스탠딩과 하단 대사 | 대화 중 월드/물건 사용은 차단. 메뉴·수첩 접근 유지 |
| 단순 수집 물건 클릭 | 짧은 이동 효과로 오른쪽 슬롯에 들어감 | `작은 열쇠 획득`처럼 이름 표시. 확인 팝업 강요 없음 |
| 오른쪽 아이템 클릭 | 즉시 사용 준비, 슬롯 이중선·선택 이름·포인터 옆 작은 아이콘 | 다음 클릭은 물건 사용. 아무 물건도 자동 소비하지 않음 |
| 선택 상태에서 대상 클릭 | 등록된 사용 조합 실행 또는 짧은 실패 이유 | 실패해도 아이템과 선택 유지. 모르는 정답 대상을 미리 강조하지 않음 |
| 같은 아이템 다시 클릭 / Esc | 사용 준비 해제 | Esc는 먼저 물건 선택을 해제하고, 그 다음 확대 장면을 닫음 |
| 아이템 설명 | 슬롯의 `i` 또는 명시적인 `살펴보기` | 길게 읽을 때만 작은 상세 패널. 우클릭을 필수로 하지 않음 |
| 확대 화면의 뒤로 화살표 | 직전 방·장치 단계로 복귀 | 실제 이동인지 확대 해제인지 라벨 `뒤로`로 구분 |
| 좌·우 이동 화살표 | 현재 존재하는 인접 시점/경로만 이동 | 기존 동선을 임의의 4방향 방 구조로 바꾸지 않음 |
| 스위치·다이얼 | 대상 위 클릭 또는 인접 증감 버튼 | 장치 자체가 바뀌며 텍스트와 소리/형태로 결과 전달 |
| 문서·단서 발견 | 원본을 먼저 보고 수첩에 기록, 짧은 알림 | 수첩을 강제로 매번 열지 않음 |

### 기존 인벤토리 계약과의 차이

기존 `meta_ui_flow.md`는 `아이템 선택 → 사용 버튼 또는 같은 아이템 재확정 → 대상 선택`이다. 이번에는 사용자에게 요청받은 Rusty Lake 참조를 반영하여 **아이템 선택 → 대상 클릭**을 기본 시안으로 제안한다. 이는 아직 구현·계약 변경이 아닌 시각 방향 검토안이다. 최종 방향 승인 후 메타 UI 계약과 action 상태를 함께 갱신한다. 화면 설명에 이전 `사용하기` 필수 단계를 섞지 않는다.

비가역 동작은 단순 클릭 흐름에서도 기존 확인 절차를 유지한다. 임의 클릭으로 세계 리셋·엔딩·슬롯 덮어쓰기를 확정하지 않는다.

## GGB에 필요한 보완

- 기본 탐색 화면에는 안내를 줄이고, 대상에 마우스를 올리거나 키보드 포커스가 가면 이름·동사를 표시한다. 한 화면의 모든 정답 대상을 항상 강조하지 않는다.
- 핫스폿 보기 보조 기능과 키보드 대상 순회를 제공한다. 작은 픽셀 찾기가 추론을 대신하지 않게 한다.
- 정밀 드래그가 필요한 조작에는 선택→목적지 또는 방향 버튼을 제공한다. 반사 신경과 드래그 속도를 정답 조건으로 쓰지 않는다.
- 좌하단 수첩과 오른쪽 인벤토리는 확대 조사 중에도 같은 위치에 남긴다. 수첩을 열면 장치 초안·선택 물건·장면 위치를 잠시 보관하고 닫으면 복귀한다.
- 증거의 중요성은 적절한 시각 구성과 반응으로 전달한다. 수첩에 자동 기록되더라도 결론을 자동으로 풀어 쓰지 않는다.
- 단순 행동은 물체 상태 변화로 먼저 보여 주고 긴 설명은 필요할 때만 표시한다. 필수 감각 정보는 자막으로도 제공한다.
- 확대·축소 애니메이션은 모션 감소 시 즉시 전환하며, 키보드 포커스는 해당 대상과 뒤로 버튼 사이에서 예측 가능하게 이동한다.

## 시안 예시의 경계

09 보드의 열쇠와 서랍은 상호작용을 설명하는 예시다. 실제 기록 내실 잠금이나 기존 퍼즐 조건을 열쇠 하나로 우회하도록 변경하는 제안이 아니다. 실제 아이템 레시피·획득 조건·소비 여부는 기존 상호작용 데이터에서 가져온다.
