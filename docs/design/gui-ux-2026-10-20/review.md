# 시안 검토 기록

검토일 2026-10-20. **방향 검토용 이미지**에 대한 정적 검토이며 실행 검증이 아니다.

## 확인한 것

- 생성된 각 보드를 도구가 반환한 이미지로 직접 보았다.
- 원본 자료가 중심에 놓이는지, 문장과 버튼이 분리되는지, 핵심 행동을 읽을 수 있는지 확인했다.
- 수첩 네 탭, 자료 두 개 비교, 3개 저장 슬롯, 확실/불확실 정보를 나누는 두 엔딩 선택을 현행 계약과 대조했다.
- 03 초안의 지도 닫기와 탐색 목적 표시 누락을 수정했다.
- 04 초안의 실패 결과와 실행 전 확인 혼합을 수정했다. 최종 보드의 실패 화면에는 실행 버튼이 없다.
- 06 초안의 게임패드 아이콘·인물별 색/문양·루카 표기를 수정 대상으로 지정했다.
- 07 초안에서 생성기가 추가한 서사 문구를 실제 `ending_decision_texts.gd`와 J4 기록에 맞는 원문/요약으로 교정했다.

최종 선택 파일은 README·gallery.html·validation.json이 참조한다. 01-v3, 02-v2, 04-v3, 05-v3, 06-v5, 07-v2, 08-v4, 09-v2, 10-v3, 11이 선택본이다. 03은 후속 요구 이전 초안으로 보존하며 최종 갤러리에서 제외했다. 생성 원본은 기본 저장 위치에 남겨 두고 프로젝트로 복사했다.

## 이미지별 해석 범위

| 보드 | 시안이 보여 주는 것 | 실제 적용 전에 필요한 것 |
| --- | --- | --- |
| 01 | 수첩의 정보 위계와 읽기→비교 흐름 | 실제 자료 종류·상태·정렬·필터 데이터 연결. 정적 썸네일을 정답 도식으로 쓰지 않음 |
| 02 | 병렬 비교와 A/B 재배치 | 실제 1280×720·UI/글자 200% 실행 검사, 긴 본문 스크롤과 포커스 확인 |
| 03 | 이전 탐색·대화·소지품·지도 초안 | 최종 기준에서 제외. 08·09·10·11로 대체 |
| 04 | 퍼즐 증거의 시각 비중과 조작줄, 힌트, 실패 정보 | 일지에 그려진 건축 도식은 배치 예시. 실제 J1~J5 문장·압흔·조각 수와 판정 근거를 정본에서 제작. 회전 버튼의 포커스와 핵심 검증 버튼의 위계를 실기에서 확인 |
| 05 | 시작·복귀·슬롯·복구의 공통 양식 | GGB 로고는 임시 표현. 저장 시각·시간·복구 영향 값을 채움. 빈 슬롯은 +, 손상 저장은 중립 오류 아이콘으로 수정함 |
| 06 | 미리보기 중심 설정, 입력 충돌과 화면 확인 | 인물 샘플은 발견 이후 예시. 첫 실행에는 이름 없는 중립 패턴 샘플로 바꿔 공개 범위 준수. 서명 도형은 코드/벡터로 정확히 제작 |
| 07 | 후반에도 유지되는 읽기 구조와 선택 중립성 | 확실/불확실 정보는 최종 원문 검수. 배경은 고딕 참조를 많이 유지한 방향 예시이며 파열·코어 아트 납품 아님 |
| 08 | 실제 주인공 기준 스탠딩, 마노사바식 하단 대화, 고정 모서리 HUD | 생성된 재현본은 원본 대체 에셋이 아님. 원본 연결 후 실루엣 안전 영역 검사 |
| 09 | 대상 클릭→가까이 보기→아이템 사용→상태 변화 | 서랍·열쇠는 조작 예시. 실제 방 잠금 우회나 새 레시피로 사용하지 않음 |
| 10 | 마라 2 발화·에드가와 관찰·이리스 선택·수첩 대화 | 대사는 UI 예문. 상단 마름모의 말하기/관찰/대화 선택은 보드 설명 표지이며 게임 HUD에 중복 추가하지 않음 |
| 11 | 손그림 평면도와 검은 현 위치 점 | 방 연결은 배치 예시. 실제 발견·문 상태 데이터로 제작. 우측·하단 목록 제외 |
| 12 / HTML | 실제 주인공 원본과 분리 배경의 커서 시차 이동 | 독립 미리보기. Godot 메뉴·저장·눈동자 애니메이션은 구현하지 않음 |

이미지 속 종이의 해·달·별 모양, 방의 연결, 조각의 건축 그림은 생성된 시각 샘플이다. **게임의 새로운 단서·정답·세계관 설정으로 채택하지 않는다.** UI 분위기 승인과 퍼즐 원화 승인을 분리한다.

## 텍스트와 접근성

- 한국어 주요 제목·행동 라벨을 눈으로 확인했다. 긴 생성 문장은 최종 카피로 간주하지 않는다.
- 04의 실패 화면과 비가역 실행 확인은 독립 상태다. `screen-spec.md`의 U27/U28을 따른다.
- 색상 외에 이름·문양·선이 남는 구성을 제안했다. 실제 색 제거 모드 통과를 주장하지 않는다.
- 본문과 UI를 이미지에 굽지 않고 Godot 텍스트·버튼으로 구현해야 한다. 영문은 별도 현지화 레이아웃 검사 대상이다.
- token 대비 수치는 후보색의 계산 결과다. 종이 질감·투명도·게임 배경까지 포함한 실제 대비 검증은 별개다.

## 정적 파일 검사

`validation.json`에 PNG 크기·SHA-256, 연결 파일 존재 여부, 프롬프트 JSON 파싱과 제안 색상 대비 계산을 기록한다. 검사는 이번 폴더만 읽는다. 게임 코드·실행 씬·사용자 저장은 수정하지 않았다.

## 생성 재현 정보

- 기본 프롬프트: `prompts.json`의 `shared + "\n\n" + boards[i].prompt`.
- 참고: 01은 기존 타이틀, 02~07은 01 수첩 시안.
- 수정 프롬프트와 수정 대상: `refinement-prompts.json`.
- 03 수정 목적: 명시적 탐색 목적과 지도 닫기.
- 04 수정 목적: 실패 결과에서 실행 확인 분리.
- 06 수정 목적: PC 입력과 인물 서명 의미 대응.
- 07 수정 목적: 실제 프로젝트의 기록·엔딩 정보 대응.
- 사용자 후속 1: 첨부 배경 제외, HUD·스탠딩 배치 반영. `user-layout-prompts.json`.
- 사용자 후속 2: Rusty Lake 직접 상호작용 참조. 03 최종 생성에는 `rusty-lake-prompts.json`의 `board03_override`를 뒤에 결합. 09는 같은 파일의 `board09.prompt`.
- 실행 도구: 기본 내장 `image_gen`. 별도 API 호출·CLI fallback 없음.

## 후속 요구 반영과 검토

- 책 오브젝트와 실제 스탠딩 네 장을 프로젝트 내 references에 복사하고 인물 대응을 기록했다. 원본은 변경하지 않았다.
- 핵심 수첩과 대화, 나머지 비교·퍼즐·메뉴·설정·후반·상호작용 보드를 공통 그림체로 다시 생성했다.
- 지도 11에서 오른쪽 탭·하단 목록 없이 건축 평면도, 현관 홀 안의 검은 점과 범례, 문 위치의 자물쇠를 확인했다.
- 06에서 키 충돌 예시를 소지품 H와 대화 기록 H로 일치시켰다. 상단 오른쪽 지구본 행의 오표기를 마지막 버전에서 `언어`로 교정했다.
- 05에서 빈 슬롯의 오류 아이콘을 +로, 손상 저장의 파괴된 방 이미지를 중립 문서 아이콘으로 교정했다.
- 작은 아이콘·출처 서명의 최종 형태와 수첩 아이콘 통일은 별도 컴포넌트 제작 사양을 따른다. 래스터 시안의 모든 픽셀이 최종 납품 규격을 통과했다는 의미가 아니다.

## 타이틀 미리보기 실행 확인

로컬 IAB 브라우저에서 실제 페이지를 열어 확인했다. [캡처](images/12-title-preview.jpg), [검증 기록](title-validation.json)을 보관했다.

- 주인공 원본 PNG의 알파가 유지되며 배경 위에 정상 표시된다.
- 커서를 오른쪽으로 옮긴 뒤 배경 변환은 `8.86px, -3.44px`, 주인공은 `-2.95px, 1.29px`였다. 메뉴의 경계 좌표는 전후 동일했다.
- 움직임 줄이기를 선택하고 커서를 다시 옮겨도 배경·인물 변환은 모두 `0, 0`이었다.
- 가로 스크롤 넘침을 수정하고 `scrollWidth > innerWidth`가 false임을 확인했다.
- 키보드 Enter로 새 이야기의 시안 모달을 열었고 이미지가 로드됐다. Esc로 닫힌 뒤 새 이야기 버튼으로 포커스가 돌아왔다.
- 시스템 모션 감소·창 숨김 대응은 코드에 포함했다. 브라우저에서 실행 확인한 범위는 위 항목이며 실제 게임 전체의 접근성 검사를 대신하지 않는다.
