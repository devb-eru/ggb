# 시안 제작 완료 확인

| 플레이어가 쉽게 읽고 행동을 이해 | 01의 목록→원본→관찰→행동, 02의 A/B, 09의 클릭→결과, 명시적 버튼 문구·복귀 규칙 | 시안에서 확인. 실제 플레이 검증은 구현 후 |

시안의 퍼즐 그림·방 연결·대화 예문은 배치 설명용이다. 최종 퍼즐 도식이나 새 서사로 채택하지 않는다. 게임 코드와 저장 파일을 수정하지 않았다. 래스터 시안은 통째로 런타임 UI에 넣기보다 원본 스탠딩·일러스트·텍스트·컨트롤을 분리해 구현한다.
