# 설정 UI 시안

새 게임·불러오기 시안의 청남색 서재, 밝은 종이, 보랏빛 음영, 리본과 식물 장식을 이어 쓰는 1920×1080 구성이다. 완성 화면 이미지 시안이며 게임 에셋이나 웹사이트를 제작하지 않는다.

왼쪽으로 돌출된 종이 책갈피에 접근성·화면·소리·조작·언어를 배치한다. 제목, 닫기, 뒤로, 적용은 모든 화면에서 같은 위치를 유지한다. 선택 상태는 글자와 배경 대비로 구분한다.

현재 프로젝트의 설정 항목을 기준으로 구성했다. 접근성은 글자 크기·단서 표시 방식·화면 움직임·감각 자막, 소리는 전체·배경 음악·공간음·효과음과 음소거, 화면은 표시 모드와 창 크기, 조작은 키 배정, 언어는 한국어·English이다.

표시 모드 변경은 15초 확인 후 저장하며 미응답 시 복구한다. 키 변경은 중복 키를 바로 표시하고 적용 전까지 저장하지 않는다. 적용하지 않은 변경이 있을 때 닫거나 뒤로 가면 유지/버리기를 선택하게 한다. 기본값은 현재 탭에만 적용하고 최종 저장은 적용 버튼으로 통일한다.

시안의 텍스트와 예시 값은 디자인 검토용이다. 생성 도구는 내장 image_gen이며 최종 프롬프트와 생성 경로는 settings-prompts.json에 기록한다.

완성 이미지: `images/15-settings-accessibility-v1.png`, `16-settings-display-v1.png`, `17-settings-audio-v1.png`, `18-settings-controls-v1.png`, `19-settings-language-v1.png`. 실제 생성 원본은 모두 1672×941이며, 1920×1080 화면에 대응하는 16:9 구성이다. 별도 확대나 에셋 분리는 하지 않았다.
