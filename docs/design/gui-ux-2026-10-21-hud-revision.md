# 대화 HUD 수정 · 2026-10-21

사용자 첨부 image-1.png와 image-2.png를 기준으로 기존 Godot 공통 프롤로그/챕터 UI를 수정했다. 아래 내용은 이전 GUI 적용 기록을 대체하는 후속 결정이다.

| 요청 | 구현 및 확인 근거 |
| --- | --- |
| 수첩·메뉴를 가로로 넓혀 아이콘과 글자 수용 | 1920×1080 기준 수첩 240×92, 메뉴 210×62. 수첩에는 `수첩`만 표시하며 N을 붙이지 않는다. 메뉴에도 Esc 표기를 붙이지 않는다. |
| 인벤토리 제목과 대화 중 안내 제거 | 제목 Label 및 InventoryReadOnlyHint를 생성하지 않는다. 대화 중 슬롯 입력 차단은 유지한다. |
| 흰 사각 포커스 테두리 숨김 | 공통 디자인 테마의 focus 스타일을 투명하게 변경했다. 키보드 포커스·확인 입력은 계속 작동한다. |
| 대화창 배경·그림자 뒤, 수첩·인벤토리 앞 | 배경 → 캐릭터 → 대화 그림자/장식 → 대사 → 고정 HUD → 모달 순으로 구성했다. HUD를 그림자로 어둡게 만들지 않는다. |
| 캐릭터 배율과 대화 디자인 | 왼쪽에 큰 상반신을 배치하고, 하단 원본 장식과 이름 마름모/금색 선을 사용한다. 이름과 본문에는 시스템 명조 계열 폰트를 적용했다. 200%에서 장식선 위치는 실제 이름 영역 아래로 정렬한다. |
| 대화기록(H), 다음(Enter) 표시 제외 | H 키와 대화기록 버튼이 기존 통합 수첩의 대화 탭을 연다. 다음 텍스트/아이콘은 없으며 대사 본문 클릭·기존 확인 키로 진행한다. 휠과 Page Down은 긴 본문을 스크롤한다. |
| 인벤토리 상하 빈 공간 제거 | 제목 행을 제거하고 6개 슬롯을 레일의 내부 높이에 맞춰 확장했다. 상하 장식 여백만 남긴다. |
| 배경이 화면 상단까지 채움 | 상단을 덮던 짙은 띠를 제거했다. 배경 TextureRect는 전체 화면을 채운다. |
| 메뉴·현재 공간 디자인 | 넓은 금색 프레임, 메뉴 아이콘 구분선, 메뉴와 장소 사이 세로 구분선, 명조 장소명. 개발자 버튼은 인벤토리와 겹치지 않도록 왼쪽으로 옮겼다. |
