# D6 큰 글자 화면 검증

검토일: 2026-09-13

D6의 조사·이동·휴식·안내 재시도 버튼이 고정 20px 대신 읽기 배율을 적용한다. 200%에서는 40px이다. 수첩 비교 버튼과 두 휴식 경로, 안내 재시도 버튼은 확대용 높이·간격을 사용한다. 다른 챕터의 모든 버튼까지 수정한 것은 아니다.

후반 회귀의 영어 캡슐 경로에서 글자 배율 200%, 창 크기 1280×720으로 조사 화면과 휴식 확인창을 캡처한다. 캡처 후 창 크기와 배율을 복원하며 취소 전후 상태 불변 검사를 유지한다. 재현 파일은 격리 테스트의 `user://d6_inspection_en_200.png`, `user://d6_rest_en_200.png`다.

2026-09-13 Windows OpenGL `BASEMENT_SESSION_SMOKE` PASS. 최종 두 캡처를 시각 확인했으며 조사 버튼·수첩 비교·두 휴식 경로와 확인창의 본문·두 선택 버튼에 잘림이나 겹침이 없었다. 확인창의 기본 초점은 계속 조사 선택에 있다. 버튼 폰트 40px 단언과 기존 데모·관계·엔딩 회귀도 통과했다. 인증서 저장소 경고 외 SCRIPT ERROR 없음.

상단 HUD 전체 배율, 독립 UI 배율, 4K·Windows DPI 조합과 실제 OS 입력 완주는 별도 검증 대상이다. 최종 통로 아트나 리소스 완성 판정이 아니다.
