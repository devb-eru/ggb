# F1·J5 초기 구현과 검증

## 연결

F0-E 이후 코어 기록실에 진입한다. 기록실 조사와 재생 보류, A1 자기 표시로 권한 확인, 순차 8세그먼트 재생, 재열람, J5 페이지와 직접 작성으로 연결했다. 일반 캠페인 저장에 세그먼트 위치를 저장한다. 완료 후 F2_PENDING으로 합류하며 최종 결정·임시 의향·관계 수치를 변경하지 않는다.

## 출처 구분 보완

기획 원문의 아버지 사망·사후 강제 기동 설명을 생전 음성으로 재생하면 시간상 모순이 생긴다. 해당 사실은 사후 시스템 기록·종료 이력으로 명시한다. 아버지 생전 원본과 사후 첨부 로그를 구분하고 필수 사실 자체는 유지한다. 이는 최종 녹음 대본에도 동일하게 반영할 필요가 있다.

## 검증 범위

basement-session-smoke: 미인증 재생과 세그먼트 건너뛰기 거부, 조사만으로 자동 완료되지 않음, 순서대로 전체 재생, 중간 저장 및 기록실 위치 재개, 해방 하드웨어 소실 필수 정보, J5 페이지 읽기와 외부 작성자 거부, 실제 J5 버튼, 최종 결정 불변. 캡처 user://f1_records.png.

## 남은 작업

현재 텍스트와 기존 배경을 사용하는 초기 연결이다. 최종 9~15분 음성 페이싱·기록 원문 패널·아버지 화자 표시 세분화·마라 2 보존 결과별 감정 주석·필기 연출은 남아 있다. J5는 직접 작성 버튼으로 의미를 확인하며 자유 입력이 아니다. F2/F3와 두 엔딩은 아직 구현 대상이다.
